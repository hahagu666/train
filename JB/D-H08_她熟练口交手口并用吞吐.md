# D-H08：她熟练口交手口并用吞吐
# 地点：你床上
# 情境：练习很多次之后，她口交技术越来越熟练，口手舌头配合得特别好

【哥】（你靠在床头，她洗完澡穿着睡衣爬到你腿上，主动伸手解开你裤子拉链，把你硬邦邦的肉棒掏出来。）
【妹】（跪在你两腿之间，小手轻轻地握住你的肉棒，抬头对你笑，脸红扑扑的但是已经不害羞了，声音黏黏的撒娇。）哥...今天我让你特别舒服好不好...
【哥】（捏了捏她的脸。）好啊，看你表现。
【妹】（笑了笑，低下头，先伸出舌头，从睾丸开始，慢慢往上舔，把两个蛋蛋都舔得湿湿的，含住一个轻轻吸吮了两下，舌头顺着阴茎体往上，一直舔到龟头，舌尖绕着冠状沟快速打圈，把马眼都舔遍。）嗯...
【哥】（嘶...她舌头软软的热热的，舔得特别到位，你舒服得摸她的头。）嘶...
【妹】（舔了一会龟头，她张开嘴，慢慢把整个龟头都含进去，嘴唇紧紧裹着，舌头在嘴里不停扫着冠状沟和系带，同时一只手握着阴茎体快速套弄，另一只手轻轻揉着你的睾丸，嘴和手保持一样的节奏，一起一落配合得特别好。）嗯...
【哥】（快感一波波涌上来，你闷哼出声。）嗯...对...就是这样...
【妹】（听见你夸她，她嘴角偷偷扬起来，加快速度，嘴快速上下吞吐，每次下去都含到一半的位置，喉咙夹着龟头，上来的时候特意用舌头扫过系带，手配合着她嘴的速度快速套弄，没含到的部分都被她手握着上下动，揉睾丸的手也没停，时不时轻轻捏一下，口水顺着她嘴角流下来，流到肉棒上和她手上，滑溜溜的，声音咕叽咕叽的。）嗯...
【哥】（她配合得太好了，比你自己弄舒服十倍，你舒服得轻轻喘气，手抓着她的头发，但是没用力按。）啊...太舒服了...
【妹】（吞吐了几十下，她突然抬起头，大口喘了两口气，吐出舌头，用舌头在龟头上快速左右舔了十几下，然后又张嘴含进去，这次她把嘴唇包紧，不让空气进去，做真空吸吮，一边吸一边舌头不停搅，手快速套弄。）嗯...哥...
【哥】（啊...真空吸吮加上舌头搅，快感一下子上来，你肉棒跳了一下。）啊...
【妹】（感觉到它跳，她知道你快了，抬起头看你一眼，眼睛水汪汪的，然后低下头，这次直接深含到喉咙口，龟头抵着她的喉咙，她停在那里，喉咙不停收缩夹着你的龟头，手快速套弄阴茎，另一只手用力揉你的睾丸，舌头在能碰到的地方不停舔。）嗯...
【哥】（快感快要冲到顶点，你抓着她的头发。）舒服...我要射了...
【妹】（不仅没退出来，反而喉咙夹得更紧了，快速小幅度上下动，龟头在她喉咙口摩擦，手快速套弄，等着你射。）嗯...射给我...
【哥】（快感冲到顶点，你腰一挺，一股股浓浓的精液直接射进她喉咙里。）啊...
【妹】（你射在她喉咙里，她乖乖咽下去，等你射完，还继续轻轻含着，舌头慢慢舔着龟头，把残留的精液都舔干净，才抬起头，嘴角亮晶晶的全是口水，但是一点精液都没洒出来，她抬头对你笑，特别得意，声音黏黏的。）哥...这次一点都没洒出来...全部咽下去了...舒服吗...
【哥】（把她拉上来抱在怀里，亲了亲她。）舒服，太舒服了，你怎么学得这么快。
【妹】（埋在你怀里笑，特别开心，手还轻轻摸着软下来的肉棒，声音黏黏的。）那是...我专门看了好多片子学的...就想让你舒服嘛...（她抬起头亲你，凑到你耳边小声说）下次我能整个吞进去了...
