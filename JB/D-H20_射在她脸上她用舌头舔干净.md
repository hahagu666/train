# D-H20：射在她脸上她用舌头舔干净
# 地点：你床上
# 情境：她给你口交，快射的时候你让她抬头，射在她脸上，她一点不生气，还舔干净

【哥】（她跪在你两腿之间给你口交，口手舌头配合得特别好，你快射了，但是这次你不想射在她嘴里。）
【妹】（含着龟头快速吞吐，舌头不停舔着系带，手快速套弄，另一只手揉着蛋蛋，能感觉到你肉棒跳得厉害，知道你快射了，她含得更紧了，等着你射进来。）嗯...
【哥】（快射的时候，你按住她的头，让她退出来抬头。）别含了，抬头。
【妹】（愣了一下，乖乖抬起头，仰着脸看着你，嘴角还挂着口水，脸红扑扑的，眼睛水汪汪的，不知道你要干嘛，还是乖乖仰着头，张着小嘴看着你。）哥...怎么了...你要射了吗...
【哥】（你自己快速套弄肉棒，对着她的脸，没几秒，腰一挺，第一股精液射出来，正好射在她的脸颊上。）啊...
【妹】（啊！她叫了一声，没想到你射在她脸上，她吓了一跳，但是没躲开，就那么仰着脸看着你，你一股股精液射出来，射在她脸颊上、鼻子上、嘴唇上，还有一点溅在她额头上，白白的精液沾在她红红的脸上。）啊...
【哥】（射完，你喘着气看着她，她脸上全是你白白的精液，顺着她的脸颊往下流，特别色情。）嗯...
【妹】（愣了几秒，才反应过来你射在她脸上了，她脸红透了，但是没生气，反而伸出舌头，先把嘴唇上的精液舔进嘴里，咽下去，然后用手指沾了脸上的精液，放进嘴里舔干净，一点一点把脸上的精液都舔干净。）嗯...
【哥】（看着她一点一点舔干净脸上的精液，你肉棒居然又有点硬了。）嘶...
【妹】（把脸上的精液都舔干净，还凑过来，用舌头把你龟头上残留的精液也舔干净，然后抬起头看着你，脸红扑扑的，嘴角还有点亮晶晶的，不仅没生气，还笑了，声音黏黏的）哥...你怎么射我脸上呀...吓我一跳...
【哥】（摸着她的脸，有点不好意思。）对不起...没忍住...你不生气吗？
【妹】（摇摇头，爬到你身边，依偎在你怀里，拿纸巾擦了擦脸上没擦干净的地方，声音黏黏的）不生气...射在脸上...看着你射出来的样子...我也觉得很刺激...
【哥】（亲了亲她的额头。）弄脏你了。
【妹】（往你怀里钻，摇摇头，手往下摸到你又有点硬的肉棒，轻轻套弄着，小声说）不脏...哥的什么我都不嫌弃...下次...下次你还想射脸上就射...或者射我胸上...我都愿意...
【哥】（惊讶地看着她。）真的？
【妹】（点点头，在你嘴唇上亲了一下，笑得甜甜的，然后又往下缩，跪在你两腿之间，握住你半硬的肉棒，抬头看着你，舌头轻轻舔了一下龟头，声音黏黏的）你看...它又硬了...我再帮你含出来...这次你想射哪里都可以...射我嘴里...脸上...胸上...都可以...
【哥】（摸着她的头，她低下头，张开嘴含住你的龟头，又开始认真给你口交，舌头软软的舔着。）嗯...
【妹】（含着你的龟头，这次一边吞吐一边抬头看着你，眼睛水汪汪的，好像在问你这次想射在哪里，口手配合得比刚才还好，反正她什么都愿意。）嗯...
