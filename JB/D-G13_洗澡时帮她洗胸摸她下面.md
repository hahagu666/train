# D-G13：洗澡时帮她洗胸摸她下面
# 地点：家里卫生间，爸妈不在家
# 情境：爸妈出去了，她洗澡忘记拿衣服，喊你送，你进去后一起洗，帮她搓澡的时候摸她

【哥】（你在客厅看电视，卫生间门开了一条缝，她在里面喊你。）
【妹】（在卫生间里，洗澡洗到一半才发现没拿睡衣，又不敢光着出来，只能喊你，脸红透了，幸好门是磨砂的看不见里面。）哥！帮我拿一下睡衣！！我忘记拿了！
【哥】（拿了她的小熊睡衣走到卫生间门口，敲了敲门。）给你放门口了。
【妹】（开了一条小缝，伸出一只湿漉漉的胳膊来拿，结果地上滑她差点摔倒。）啊！
【哥】（赶紧推开门扶住她，她光溜溜的站在你面前，浑身都是水珠，皮肤白白的，乳房小小的翘翘的，下面阴毛稀疏，你一下子看呆了。）啊...
【妹】（被你扶住才没摔倒，抬头看到你盯着她身体看，她啊的尖叫一声，赶紧捂住胸和下面，脸红得像煮熟的虾，但是门开着她又没法躲，声音都快哭了。）你...你出去！谁让你进来的！
【哥】（关上门，背过身。）对不起，我怕你摔倒。
【妹】（站在原地，捂着脸，浑身都红透了，热水还在淋着，过了半天，她声音小小的，黏黏的。）你...你转过来吧...反正...反正你都看过了...
【哥】（转过身，她还是捂着脸，但是手放下了一点，露出红红的身体，水珠顺着皮肤往下滑，特别好看。）嗯...
【妹】（脸红得要滴血，眼睛闭着不敢看你，过了半天，小声说。）你...你也脱了一起洗吧...顺便...帮我搓搓背...我够不到...
【哥】（脱了衣服，走进淋浴间，热水淋在两个人身上，你拿起沐浴露，搓出泡泡，帮她抹在背上，轻轻搓着。）好。
【妹】（背对着你，你手心的沐浴露滑滑的，在她背上搓着，她身体没力气的，任由你帮她洗，心跳快得不行。）嗯...
【哥】（搓完背，手顺着往前，抹在她的胸上，带着沐浴露的泡泡，轻轻揉着她软软的乳房。）真软...
【妹】（啊！她抖了一下，但是没躲开，身体没力气靠在你怀里，后背贴着你的胸口，热水淋在身上，加上你的手在她胸上揉着，特别舒服。）啊...嗯...
【哥】（一只手揉着她的胸，另一只手顺着往下滑，抹了沐浴露，滑溜溜地摸到她腿间，碰到她软软的小穴。）嗯...
【妹】（被你摸到下面，她腿一下子发颤了，站不住，你赶紧抱住她，她靠在你怀里，水顺着身体往下流，声音发颤带着哭腔。）哥...这里也洗吗...
【哥】（嗯了一声，手指顺着她湿滑的小穴摸进去，里面都是热水，还有她自己的水，滑溜溜的。）嗯，帮你洗干净。
【妹】（啊...在热水里被你手指插进去，感觉和平时不一样，暖暖的滑滑的，她站不住，只能靠在你怀里，腿分开让你摸，嗯嗯啊啊地呻吟着，淋浴的水声盖过了她的叫声，不怕被听见。）啊...
【哥】（手指在她小穴里抽插，另一只手揉着她的乳头，热水哗哗淋着，两个人的身体贴在一起，滑溜溜的。）嗯...
【妹】（被你插得很快就高潮了，身体抖了几下，一股热流混着热水流下来，她瘫在你怀里大口喘气，过了半天，转过身，抱着你的脖子，吻你，手往下摸到你的肉棒，也帮你用沐浴露洗着，套弄着，声音黏黏的。）哥...我也帮你洗...
