# D-I26：站着做她腿软你抱着她抵在墙上
# 地点：你房间门口
# 情境：她刚洗完澡出来，你把她抵在墙上站着做，她腿软站不住

【哥】（你刚洗完澡出来，她正好洗完澡从浴室出来，裹着浴巾，看见你，浴巾松了掉在地上，你直接把她按在墙上。）软软，浴巾掉了。
【妹】（刚从浴室出来，浴巾没系好掉在地上，光着身子站在你面前，啊了一声想捡浴巾，被你按在墙上，她脸红了，勾着你的脖子。）你干嘛...刚洗完澡...
【哥】（你吻住她的嘴唇，脱掉自己的浴袍，硬邦邦的肉棒抵在她小腹上，抱起她的一条腿，扶着肉棒对准她湿滑的穴口，直接插进去。）干你。
【妹】（啊！你突然插进来，她叫出声，后背贴在凉凉的墙上，一条腿被你抬着，站不住，只能勾着你的脖子，另一条腿环在你腰上，整个人挂在你身上。）哥...站着...我站不住...
【哥】（你抱着她的腿，把她抵在墙上，开始抽插，站着做的角度插得特别深，她小穴紧紧裹着你，因为她完全挂在你身上，你每一下都全部插到底。）站不住就抱着我。
【妹】（她紧紧勾着你的脖子，腿环着你的腰，整个人挂在你身上，你每一下都顶得她往上窜，舒服得她大声呻吟，奶子抵在你胸口蹭来蹭去，乳头硬得发疼。）啊...哥...好深...我要掉下去了...
【哥】（你一只手抱着她的腰，另一只手揉着她的屁股，把她牢牢抵在墙上，快速抽插，站着做比躺着费力但是特别爽，她的小穴紧紧吸着你。）掉不下去，我抱着你呢。
【妹】（啊...太舒服了...她哭着吻你，舌头和你缠在一起，小穴里不停流水，顺着你的蛋蛋流到地板上，她腿软得根本使不上劲，全靠你抱着她。）嗯...哥...我快到了...
【哥】（你加快速度，手伸到前面揉她的阴蒂。）快了...抱紧我。
【妹】（啊！你一揉阴蒂她立刻就高潮了，身体绷紧，小穴剧烈收缩，紧紧咬着你的肉棒，要不是你抱着她，她真的滑下去了，她抖个不停，叫声都哑了。）啊...哥...
【哥】（她高潮的收缩把你也夹射了，你抱着她腰一挺，全部插进去射在她里面，精液一股股喷出来，她又抖了一下。）嗯...射了...
【妹】（你射完两个人都喘着气，她腿软得根本站不住，挂在你身上，连动都动不了，你抱着她站了半天，才把她抱到床上去。）腿麻了...都怪你...非要站着...
【哥】（你笑着把她放在床上，帮她揉腿。）不是挺刺激的吗。
【妹】（她脸红了，往你怀里钻，但是腿还是抖的。）刺激是刺激...但是腿好酸...
【哥】（你吻了吻她的额头。）下次我多抱你一会。
【妹】（她点点头，吻你的嘴唇，笑得甜甜的。）嗯...
