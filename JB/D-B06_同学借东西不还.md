# D-B06：同学借东西不还
# 地点：客厅，放学回家
# 情境：她把笔袋往沙发上一扔，气鼓鼓坐下来，跟你吐槽同学借东西不还

【哥】（放学回家在书房看书，听见客厅"啪"一声响，好像什么东西被扔在沙发上，从书房出来看看）
【妹】（笔袋扔沙发上，整个人瘫进去，气鼓鼓）烦死了！
【哥】又怎么了？
【妹】（坐起来，鼓着脸）张磊！就是坐我前面那个男生！上个星期借了我两块橡皮，到现在都不还！
【哥】两块橡皮而已。
【妹】不是橡皮的事！（掰着手指头数）这学期他借了我三支笔，两个笔记本，还有一把尺子！没有一样还的！
【哥】你不会不借给他？
【妹】（鼓脸）他每次都可怜巴巴地说"就借一下"，我不好意思不借啊...结果借给他就没下文了...
【哥】那你就跟他要啊。
【妹】（声音变小）我要过一次...他说"哎呀不就是一根笔吗，你那么有钱再买一根不就行了"...
【哥】这什么人啊。
【妹】（越说越气）今天更过分！他直接从我笔袋里拿笔，都不问我！我跟他要他还说"借我用用怎么了，小气"！
【哥】（笑）那你下次把笔袋锁起来。
【妹】（瞪你）你还笑！（抱胳膊）我决定了，以后他借什么我都不借了！
【哥】早该这样。
【妹】（摸了摸笔袋，有点委屈）我那个笔还是你上次给我买的...按动的那个，我特别喜欢...
【哥】拿不回来就算了，哥再给你买一盒。
【妹】（眼睛亮了）真的？
【哥】嗯，周末带你去文具店，你自己挑。
【妹】（立刻开心起来，扑过来抱你胳膊）哥你最好了！（想了想又鼓脸）但是我还是很气！我明天一定要把笔要回来！
【哥】加油。
【妹】（握拳）嗯！他要是不还我就告诉老师！
【哥】（笑着揉了揉她的头发，看着她斗志昂扬的小模样，觉得特别可爱）好，要是他敢欺负你，哥去帮你要。
【妹】（开心得蹭你胳膊，眼睛亮晶晶的，像只得到承诺的小松鼠）
