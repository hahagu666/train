# D-I36：你舔完她再插进去她直接高潮
# 地点：你床上
# 情境：你先口交让她高潮一次，然后立刻插进去，她直接连续高潮

【哥】（晚上洗完澡，你把她压在床上，亲她的嘴唇、脖子、乳房，一路往下亲，亲到她大腿内侧，她抖个不停。）宝贝，把腿分开。
【妹】（你一路往下亲，她知道你要做什么，脸红透了，想并拢腿但是被你分开，手抓着床单，声音黏黏的带着害羞。）哥...别...那里脏...
【哥】（你没听，分开她的腿，舔上她湿漉漉的小穴，舌头绕着阴蒂转，她啊的一声叫出来，腰立刻弓起来。）不脏，甜的。
【妹】（啊...哥...她叫出声，手抓着你的头发，舌头舔得她又麻又痒，快感来得特别快，你舌头伸进她穴口里舔，手指揉着阴蒂，她没一会就开始抖。）啊...我要去了...哥...
【哥】（你加快舌头的动作，吸吮她的阴蒂，她身体猛地绷紧，啊的一声尖叫，第一次高潮了，淫水流了你一嘴，小穴不停收缩。）嗯...真甜。
【妹】（啊...她高潮了，身体抖个不停，还没缓过来，你就扶着硬邦邦的肉棒，直接对准她还在收缩的穴口，一下子全部插进去。）啊！你...你干嘛...刚...刚高潮...
【哥】（你没说话，直接开始快速抽插，刚高潮过的小穴特别敏感特别紧，裹着你肉棒特别舒服，你抓着她的腰快速顶弄。）唔...好紧...
【妹】（啊...太敏感了...啊...她话还没说完，第二次高潮就来了，比第一次还快还猛，她尖叫出声，小穴剧烈收缩，紧紧咬着你的肉棒，眼泪流出来，身体抖得停不下来。）啊...哥...太深了...我不行了...
【哥】（你继续快速抽插，她连续高潮，小穴一缩一缩的夹得你快射了，你揉着她的阴蒂，又顶了十几下。）再去一次，宝贝。
【妹】（啊...第三次...我又要...她已经语无伦次了，快感一波接一波，根本停不下来，她连叫都快叫不出声了，只能发出断断续续的呻吟，奶子晃来晃去，整个人软得像水一样。）啊...
【哥】（你腰一挺，全部插进去，射在她最里面，浓浓的精液喷在她宫颈上，她又抖了一下，直接瘫在床上，连眼睛都睁不开了。）嗯...射了...
【妹】（你射完趴在她身上喘了半天，退出来，抱她去清理，她连站都站不住，挂在你身上。）你太坏了...刚舔完就进来...我差点被你弄死...
【哥】（你笑着吻她的额头，帮她擦身体。）舒服吗？
【妹】（她脸红了，点点头，把脸埋在你脖子里，轻轻咬了一口你的脖子，腿还在微微发抖，连勾着你腰的力气都没有了，声音发黏带着哭腔后的鼻音。）...舒服...下次还这样...但是你下次要轻一点...连续三次...人家真的快被你弄坏了...
