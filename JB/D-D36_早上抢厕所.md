# D-D36：早上抢厕所
# 地点：家里卫生间，周一早上
# 情境：早上起晚了，两个人都急着上厕所，堵在卫生间门口

【哥】（周一早上闹钟响了三遍才起，一看时间快迟到了，抓了衣服往卫生间冲）
【妹】（穿着睡衣头发乱蓬蓬的，刚好也冲到卫生间门口，两个人撞在一起，她捂着肚子）哥！我先！我快憋不住了！
【哥】（也捂着肚子）我先！我昨天晚上喝冰啤酒闹肚子，快让开！
【妹】（堵在门口不让开，脸都憋红了）我先！我要迟到了！我还要刷牙洗脸扎头发！
【哥】我也要迟到了！你房间不是有个小卫生间吗，去你那上！
【妹】那个马桶坏了还没修！昨天就跟你说了！（她急得跺脚，脚踩在拖鞋上啪嗒响）你昨天用了我卫生间是不是没冲！我一按全堵了！
【哥】（愣了一下，确实是你昨天用堵的，但是现在顾不上了）我错了我错了，你先让我上，三秒钟就好！
【妹】（鼓着脸，但是看他确实急得额头都出汗了，犹豫了两秒，让开门口）那你快点！五分钟！超过五分钟我撞门了！
【哥】（冲进去关上门，她站在门口转圈，不停看手表，每隔三十秒就敲门）
【妹】哥你好了没有！都三分钟了！（又敲）你掉里面了啊！
【哥】（里面传来声音）快了快了！
【妹】（急得跳脚，头发乱糟糟的，睡衣扣子都扣错了一颗，在门口转来转去，又敲门）我要迟到了！班主任今天早自习查人！
【哥】（终于开门出来，她立刻冲进去，砰地关上门，反锁）
【妹】（在里面喊）你不许走！帮我拿一下发圈！在我梳妆台上！粉色的那个！
【哥】（无奈地去她房间拿发圈，靠在卫生间门口等她，过了五分钟她开门出来，牙没刷脸没洗，头发乱蓬蓬的）还说你快，比我还慢。
【妹】（鼓着脸，接过硬发圈一边扎头发一边往洗脸池跑）都怪你！昨晚把我马桶弄堵了！不然我才不跟你抢！（她刷牙刷得满嘴泡沫，含糊不清地说）下次你再把马桶弄堵，我就...我就把你牙刷扔马桶里！
【哥】（笑着靠在门口看她慌慌张张洗脸刷牙扎头发，头发扎歪了，脸上还沾了点泡沫）你头发扎歪了。
【妹】（抬头看镜子，果然歪了，急得要拆了重扎，但是看时间快迟到了，干脆随便抓了两下）歪就歪吧！来不及了！（她漱完口抓起书包往门口跑，跑了两步又跑回来，在你脸上亲了一下，嘴里还有薄荷牙膏的味道）晚上回来修马桶！
【哥】（还没反应过来，她已经冲到门口穿鞋了，袜子都穿错了，一只白的一只粉的，她抬头看你，脸跑得红扑扑的，头发虽然歪了但是眼睛亮晶晶的）
【妹】（穿好鞋站在门口喊）我走了！早餐你帮我带个包子！（说完砰地关上门，能听见她跑下楼的脚步声，咚咚咚的，像只小兔子）
