# D-E44：下雨天共撑一把伞往你身上靠
# 地点：放学路上，下大雨
# 情境：放学突然下大雨，你去接她，只有一把伞，她一直往你身边靠，半个身子都贴在你身上

【哥】（放学突然下大暴雨，你拿了一把伞去学校门口接她，她站在门卫室门口等你，鞋子都湿了一点，看见你过来立刻跑过来）
【妹】（跑到伞底下，立刻挽住你的胳膊，雨下得特别大，噼里啪啦打在伞上，风也大，伞被吹得晃来晃去，她半个身子都贴在你身上，紧紧挽着你的胳膊）这雨怎么突然下这么大！我早上看天气预报还说晴天呢！
【哥】（把伞往她那边歪，自己半个肩膀露在外面，很快就湿了，风一吹有点凉）搂着我点，别走散了。
【妹】（立刻乖乖把你胳膊抱得更紧了，整个人都贴在你身上，头靠在你胳膊上，雨太大了，伞又不大，她的肩膀还是湿了一点，但是她一点都不在意，反而往你身边靠得更近了，两个人紧紧贴在一起走，暖乎乎的）
【妹】（走了一会，抬头看见你半个肩膀全湿了，衬衫贴在身上，立刻把伞往你这边推，鼓着脸看着你）你伞往你那边挪挪！你肩膀都湿了！
【妹】（说着就伸手把伞往你那边推，结果她自己半个肩膀立刻露在雨里，头发都被打湿了一点，她也不在意，鼓着脸看着你）你看你都湿了！会感冒的！
【哥】（又把伞推回去，把她整个人都罩在伞底下，自己半个肩膀继续淋着雨）我没事，男的淋点雨怕什么，你别淋湿了，感冒了耽误上课。
【妹】（鼓着脸，但是没再推伞，反而往你身边靠得更近了，几乎整个人都挂在你胳膊上，把你往伞中间拉，两个人紧紧贴在一起，共用一把伞，虽然雨很大，但是两个人贴在一起暖乎乎的，她甚至能闻到你身上洗衣液的味道，被雨打湿了一点，但是特别好闻）
【哥】（雨越下越大，路上积水越来越深，她穿的小白鞋都湿透了，踩在水里凉丝丝的，你看见她皱了皱眉，但是没说，继续紧紧靠着你走）
【妹】（走了一会，她突然停下来，蹲下来，你以为她鞋子里进水了，结果她把自己的外套脱下来，举起来挡在你湿了的肩膀那边，自己半个身子露在伞外面，头发都湿了，鼓着脸看着你）这样你就不会淋到了！
【哥】（赶紧把她拉起来，把外套给她披上，把她整个人搂在怀里，伞完全罩在她头顶，自己半个身子全在雨里也不在乎）傻不傻，你本来就穿得少，再淋感冒了。
【妹】（被你搂在怀里，暖乎乎的，雨虽然大，但是被你抱着一点都不冷，她伸手紧紧抱着你的腰，把脸埋在你胸口，听着你的心跳，雨噼里啪啦打在伞上，但是她觉得特别安心，甚至有点希望这条路再长一点，能多被你抱一会）
【哥】（终于走到家了，两个人都湿了大半，你放下伞，她头发湿了贴在脸上，像只落汤鸡，但是笑得特别开心，眼睛亮晶晶的）
【妹】（站在门口擦头发，看你肩膀全湿了，伸手摸了摸你湿了的衬衫，有点心疼，但是又有点开心，凑过来在你没湿的那半边脸上亲了一下，然后红着脸跑回房间拿毛巾，跑到门口回头看你，脸红扑扑的，头发湿湿的，笑得特别甜）下次下雨带两把伞！不对...下次还是带一把吧...（说完她脸更红了，赶紧跑回房间，心跳得特别快，但是觉得下雨天好像也挺好的）
