# D-D07：感冒了
# 地点：她房间，早上
# 情境：她感冒了，没起床，裹在被子里，鼻子堵得说话瓮声瓮气

【哥】（敲门进房间，看到她还裹在被子里）怎么还不起？迟到了。
【妹】（从被子里探出头，脸红红的，鼻子不通气，说话瓮声瓮气）哥...我难受...
【哥】（走过去摸她额头）怎么这么烫？
【妹】（鼻子堵得难受，吸了吸鼻子，没吸出来，声音哑）昨天晚上踢被子了...醒的时候被子在地上...头好疼...
【哥】（拿体温计给她夹上）量个体温。
【妹】（乖乖夹着体温计，裹着被子缩成一团，鼻子红红的，眼睛水汪汪的）我嗓子也疼...还流鼻涕...
【哥】（看体温计）三十八度二，今天别去学校了，我给老师打电话请假。
【妹】（立刻点头，但是又有点担心）可是...今天讲新课...
【哥】讲新课也不差这一天，身体要紧。想吃什么？
【妹】（想了想，声音发哑，带着鼻音）...想吃橘子罐头。
【哥】（笑）病了还想着吃。
【妹】（小声嘟囔）生病的时候吃罐头就好了嘛...以前我生病你都给我买橘子罐头...
【哥】行，我去给你买。
【妹】（拉住你袖子，鼻子红红的）别走...先陪我一会...
【哥】不走，等你睡着了我再去。
【妹】（点点头，往被子里缩了缩，只露出一双眼睛看着你，鼻音很重）哥...
【哥】嗯？
【妹】（声音小小的）你会不会传染啊...
【哥】不怕。
【妹】（笑了，鼻子堵着笑起来声音怪怪的，往你身边挪了挪，靠在你胳膊上）那你给我讲故事好不好...
