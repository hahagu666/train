# D-A30：帮她做手抄报做到半夜
# 地点：妹妹房间/你房间，深夜→第二天早上
# 情境：国庆主题手抄报她画了三遍都不满意，急得快哭了，你陪她一起画，帮她排版写字，画到半夜她靠在你肩膀上睡着了

【哥】（晚上十一点，路过她房间，看见灯还亮着，走进去一看，桌子上扔了三张画废的手抄报，她趴在桌子上，手里拿着彩笔，眼睛红红的）
【妹】（看见你进来，委屈得不行，彩笔"啪"一声放在桌子上，眼眶红红的，眼泪在眼眶里打转，小嘴撅得老高，像只受了委屈的小兔子）哥...我...我画不好...
【哥】（走过去拿起废稿看了看，都是国庆主题的手抄报，不是排版歪了就是国旗画歪了，彩笔颜色涂得乱七八糟的，我揉了揉她的头发）怎么了这是？画了这么多张？
【妹】（把彩笔往桌子上一放，委屈得快哭了，声音带着哭腔）老师让交国庆手抄报...后天就要交了...我画了三遍都画不好...我怎么画都画不好...明天就要交了...我肯定要被老师说了...
【哥】（看了眼时间，都十一点了，她已经画了三个小时了，桌子上全是彩笔和橡皮屑，眼睛下面都有黑眼圈了。我拉过椅子坐在她旁边，把彩笔拿过来）行了，别哭了，我帮你一起画，保证你明天交上去拿一等奖，行不行？
【妹】（抬起头，泪眼婆娑地看着你，有点不敢相信）真的？你会画手抄报吗？你以前都没画过...
【哥】（笑着弹了她脑门一下）你哥我当年可是手抄报比赛一等奖得主，你忘了？来，我教你，你负责涂色，我负责排版和勾线，我们分工合作，保证两个小时搞定。
【妹】（眼睛一下子亮了，赶紧擦掉眼泪，使劲点头，把彩笔都递到你手里，坐得笔直地看着你，像个认真听课的小学生）好！我听你的！你让我涂什么颜色我就涂什么颜色！
【哥】（先用铅笔轻轻打草稿，排版排得整整齐齐，哪里写标题哪里画国旗哪里写字，安排得明明白白）
【妹】（趴在桌子旁边，托着下巴看你画，眼睛亮晶晶的，时不时"哇"一声，满眼崇拜地看着你）哥你怎么什么都会啊...
【哥】（勾完线，让她涂颜色）来，该你涂色了，小心点别涂出去。
【妹】（涂得特别认真，小舌头都微微伸出来了，涂到国旗的红色的时候，不小心涂出去一点，急得"啊"了一声）糟了！涂出去了！
【哥】（笑着拿修正液帮她改掉，说"没事，一点点而已，看不出来"）
【妹】（松了口气，但是涂着涂着就开始打哈欠，眼泪都打出来了，头一点一点的，但是还是强撑着涂颜色，你让她去睡觉她摇摇头，说"我不困，我要跟你一起画完"）
【哥】（两个人一起画到快一点，终于画完了，标题是"欢度国庆"四个大字，画着天安门和五星红旗，还有和平鸽，排版整齐颜色鲜艳，特别好看。刚要说话，转头一看，她靠在我肩膀上，呼吸均匀，已经睡着了，手里还攥着一支红色彩笔）
【妹】（睡梦中还微微蹙着眉，小脑袋一点一点的，靠在你肩膀上蹭了蹭，找了个舒服的位置继续睡，手里的红色彩笔都快掉了）
【哥】（看着她靠在我肩膀上睡得香的样子，睫毛长长的，脸上还沾了一点彩笔的蓝色印子，像只小花猫，忍不住笑了，轻手轻脚把她手里的彩笔拿下来放好，把她打横抱起来往床上走）
【妹】（迷迷糊糊中感觉到被你抱起来，往你怀里缩了缩，含糊不清地嘟囔）...哥...画完了吗...
【哥】（把她放在床上，帮她盖好被子，轻声说）画完了，特别好看，肯定拿一等奖，安心睡吧。
【妹】（迷迷糊糊点点头，嘴角带着笑，翻了个身就睡着了，睡得特别沉）
【哥】（帮她把桌子上的彩笔收拾好，把画完的手抄报小心翼翼夹在她课本里，才轻手轻脚关上门出去）
【妹】（第二天早上醒过来，看见桌子上收拾得干干净净，课本里夹着画好的手抄报，愣了一下，然后想起昨晚你帮她画到半夜，她还靠在你肩膀上睡着了，脸一下子红了）
【哥】（还在睡觉，迷迷糊糊感觉有人推开房门，轻手轻脚走到床边）
【妹】（抱着手抄报跑到你房间，趴在你床边，看了你好久，然后在你脸上轻轻亲了一口）
【哥】（迷迷糊糊感觉到脸上软软的触感，睁开眼）
【妹】（趴在床边晃着脚丫，眼睛亮晶晶的看着你，满脸都是崇拜和开心，举着手抄报给你看个不停）哥！你醒啦！手抄报太好看了！你看你看！这个天安门画得太像了！还有和平鸽！比我画的好看一百倍！
【哥】（坐起来揉了揉眼睛，看着她开心的样子，打了个哈欠，笑着说）那当然，也不看是谁画的。
【妹】（趴在床边，看着你，眼睛亮晶晶的，小声说）哥...谢谢你...昨晚陪我画到那么晚...你都没睡几个小时...
【哥】（揉了揉她的头发，捏了捏她的脸）傻瓜，跟我客气什么，你是我妹妹，我不帮你帮谁？快洗漱吃饭，一会儿该上学了。
【妹】（使劲点头，蹦蹦跳跳跑出去洗漱，把手抄报小心翼翼放进书包里，像放什么稀世珍宝）
【哥】（结果那幅手抄报真的拿了年级一等奖，我站在人群最前面，看着她站在领奖台上，第一个就往台下看，看见我冲她笑，她笑得特别开心，举着奖状冲我挥了又挥）
【妹】（放学扑进你怀里，把奖状塞给你，笑得眼睛都弯了）哥！一等奖！真的拿一等奖了！奖状给你！都是你的功劳！
【哥】（接过奖状，看着她开心得像只小鸟的样子，心里比自己拿了奖还开心，牵着她的手往家走）
【妹】（一路都在叽叽喳喳说领奖的时候有多开心，蹦蹦跳跳的，马尾甩来甩去，说要把奖状贴在你房间墙上，以后还要跟你一起画好多好多手抄报）
【哥】（笑着听她说，觉得熬夜帮她画手抄报真是全世界最值得的事）
【妹】（偷偷把脸贴在你胳膊上，心里甜滋滋的，觉得有个会画画的哥哥真好）
