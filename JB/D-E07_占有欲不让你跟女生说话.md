# D-E07：占有欲不让你跟女生说话
# 地点：小区楼下，你送她上学
# 情境：早上你送她去上学，碰到隔壁班女生跟你打招呼问路，她立刻拉着你胳膊瞪人家

【哥】（早上你送她到小区门口，碰到个穿校服的女生，是她隔壁班的，女生走过来，笑着问你）哥哥你好，请问去三号线地铁站是往这边走吗？
【妹】（原本拉着你胳膊晃悠，看到女生过来跟你说话，立刻把你胳膊抱得紧紧的，整个人往你身边靠，警惕地看着那个女生）
【哥】对，往前直走第二个路口左转就到了。
【妹】（女生说声谢谢就走了，等女生走远，她立刻鼓脸，拽着你胳膊往学校方向走，走得飞快）
【哥】（被她拽着走，笑）怎么走这么快？
【妹】（不说话，鼓着脸，走得飞快，到学校门口才停下来，回头看你，眼睛气鼓鼓的）
【哥】怎么了这是？
【妹】（掐你胳膊一下，有点凶）她为什么跟你说话！还叫你哥哥！哥哥只能我叫！
【哥】（笑）人家就是问个路。
【妹】（鼓脸，抱你胳膊更紧了）问路也不行！你是我哥！只能对我好！只能跟我说话！
【哥】那我上班总不能不跟女同事说话吧。
【妹】（愣了一下，更气了，鼓着脸想了半天，憋出来一句）...上班...上班可以说工作！但是不能笑！也不能帮她们指路！
【哥】（忍不住笑，捏她脸）小醋坛子。
【妹】（脸红，但是还是理直气壮）我就是小气！你是我的！谁都不能抢！
【哥】好好好，是你的是你的。快进去吧，要迟到了。
【妹】（松开手，走了两步又回头，跑回来抱你一下，在你耳边小声说）...晚上早点来接我。
【哥】知道了。
【妹】（这才满意地弯了弯眼睛，冲你挥挥手，转身蹦蹦跳跳跑进校门，跑了两步又回头看你一眼）
