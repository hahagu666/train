# D-E48：你背她上楼她趴在你背上唱歌
# 地点：单元楼楼梯，晚上爬楼梯回家
# 情境：电梯坏了，她穿新鞋磨破了脚，走不动路，你背着她爬楼梯，她趴在你背上唱歌

【哥】（晚上回家电梯坏了，要爬十楼，她穿了新买的小皮鞋，走了两层就磨破了脚后跟，疼得她站在原地不走了，皱着眉揉脚）
【妹】（站在楼梯拐角，可怜巴巴看着你，眼睛红红的，脚后跟磨出个红泡，一碰就疼，她咬着嘴唇，声音小小的带着哭腔）哥...我脚疼...磨破了...走不动了...
【哥】（蹲下来背对着她）上来，我背你。
【妹】（眼睛一下子亮了，但是又有点不好意思，犹豫了一下）十楼呢...你背不动我的...
【哥】让你上来你就上来，废话怎么这么多。
【妹】（立刻开心地趴到你背上，手臂紧紧勾住你的脖子，腿盘在你腰上，像只小树袋熊一样挂在你身上，你站起来往上走，她轻得很，乖乖巧巧趴在你背上，头发垂下来蹭着你脖子）
【哥】（背着她往上爬楼梯，爬了三层就有点喘，但是她趴在你背上特别轻，暖暖的，还带着她头发上的洗发水香味）
【妹】（趴在你背上，手勾着你的脖子，下巴垫在你肩膀上，看你爬楼梯喘气，有点心疼，但是又特别开心，凑在你耳边小声问）哥你累不累啊...要不我下来自己走吧...
【哥】不累，你才多重。
【妹】（咯咯笑，趴在你背上，开始小声唱歌，唱的是她最近最喜欢的那首甜甜的小情歌，声音黏黏甜甜的，就在你耳边唱，气息暖暖的吹在你耳朵上，唱跑调了自己先笑，笑完继续唱）
【哥】（背着她往上走，听着她在你耳边小声唱歌，跑调跑得离谱，但是特别好听，楼道里的声控灯一亮一灭，她的笑声在楼梯间回荡，爬楼梯好像也没那么累了）
【妹】（唱了半天歌，下巴垫在你肩膀上，脸贴在你脖子旁边，暖暖的，手轻轻摸你下巴上的胡茬，扎得她手痒，她咯咯笑，突然凑过来在你脸上亲了一下，温温热热的，亲完自己先脸红了，但是趴在你背上你看不见，她就偷偷笑）
【哥】（爬到七楼，确实有点累了，喘了口气，停下来歇两秒）
【妹】（她立刻轻轻拍你的肩膀，声音小小的带着心疼）累了吧...要不我下来走两层吧...就三层了...我能走...
【哥】不用，趴好，别摔下去。
【妹】（乖乖趴好，手臂勾得更紧了一点，把脸埋在你颈窝，呼吸暖暖的吹在你脖子上，不唱歌了，就安安静静趴在你背上，听着你的心跳声和喘气声，觉得特别安心，过了半天小声说）哥...你背我的感觉好舒服...
【哥】（终于爬到十楼，开门把她放下来，她脚一沾地就疼得嘶了一声，你扶着她坐到沙发上，给她找创可贴，她坐在沙发上，脸红红的，眼睛亮晶晶看着你，嘴角一直扬着，虽然脚后跟磨破了很疼，但是她特别开心，觉得电梯坏了真好）
【妹】（等你给她贴好创可贴，她突然凑过来抱了你一下，把脸埋在你胸口，声音小小的带着撒娇）下次电梯坏了我还要你背我...（她抬起头看你，眼睛亮晶晶的像装了星星，脸红红的，嘴角扬得高高的，刚才趴在你背上唱歌的感觉，还有你后背暖暖的温度，她觉得比任何时候都开心）
