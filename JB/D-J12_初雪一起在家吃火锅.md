# D-J12：初雪一起在家吃火锅
# 冬天第一场雪，你们窝在家里煮火锅，她抢毛肚抢不过你，耍赖把脸凑过来要你喂，窗外飘着雪屋里热气腾腾

【哥】（把火锅底料放进锅里，倒上水，插上电，底料慢慢化开，红油咕嘟咕嘟冒泡，香味一下子就出来了）去把洗好的菜拿过来，可以下了。
【妹】（趴在窗户边看外面下雪，听见你说话赶紧跑过来，手里还拿着个盘子装着毛肚和肥牛，脸冻得红红的，但是特别兴奋）哥！外面雪下得好大！地上都白了！等下吃完我们下去堆雪人好不好！
【哥】（笑着把肥牛卷下进锅里，肉片在红汤里滚了两下就熟了，你夹了一筷子放进她碗里）先吃饭，吃完饭再说，堆雪人可以，但是你得把围巾手套戴好，不许冻着手。
【妹】（乖乖点头，但是眼睛一直盯着锅里的毛肚，数着"七上八下"）
【哥】（你也盯着那片毛肚，她刚要夹，你眼疾手快先夹走了，放进自己碗里）
【妹】（鼓着脸看你，筷子停在半空中，瞪你一眼）哎！那片是我的！我数了半天的！
【哥】（故意逗她，把毛肚在她面前晃了晃，然后放进自己嘴里，嚼了两口，故意说）嗯，真脆，真好吃。
【妹】（气得鼓着脸，放下筷子，扑过来抢你碗里的，你笑着躲开，两个人在餐桌边闹了半天，她抢不到，干脆耍赖，坐在你腿上，把脸凑到你嘴边，张着嘴像只小燕子）啊——我要吃毛肚！你喂我！
【哥】（被她逗笑了，夹了一片刚烫好的毛肚，吹凉了喂到她嘴里，她心满意足地嚼了，腮帮子鼓鼓的像只小仓鼠，还不忘得意地看你一眼）
【妹】（坐在你腿上不肯下来，就赖在你怀里吃，你下什么她就张着嘴等你喂，吃了肥牛吃虾滑，吃了虾滑吃藕片，吃得满头是汗，脸红红的，嘴角还沾了点麻酱）
【哥】（拿纸巾帮她把嘴角的麻酱擦掉，窗外的雪越下越大，纷纷扬扬的，屋里火锅热气腾腾的，暖得不行，玻璃上都起了一层雾，她靠在你怀里，暖乎乎的）
【妹】（吃了个半饱，靠在你怀里，看着窗外的雪，手里拿着个丸子咬了一口，声音黏黏的）哥...初雪的时候吃火锅真好...
【哥】（搂着她的腰，下巴搁在她头顶，闻着她头发上洗发水的香味和火锅的香味混在一起，特别安心）嗯，真好。
【妹】（沉默了一会儿，突然转过头看你，眼睛亮晶晶的，因为火锅的热气，她眼睛湿乎乎的，特别好看）哥！你知道吗！初雪的时候许愿会实现的！和喜欢的人一起吃火锅，会一辈子在一起的！
【哥】（笑着捏了捏她红红的脸，故意逗她）又是从哪儿看来的这些乱七八糟的？
【妹】（鼓着脸，伸手掐你腰一下）什么乱七八糟的！是真的！我同学说的！特别灵！
【哥】（笑着点头，夹了一块鱼豆腐喂到她嘴里）好好好，灵，那我们妹妹许什么愿？
【妹】（张嘴吃鱼豆腐，想了想，脸红红的，往你怀里缩了缩，小声说）...我想...以后每一年初雪...都跟你一起在家吃火锅...就我们两个人...
【哥】（心里一暖，抱紧她，在她冒着热气的额头上亲了一下）好，每一年初雪都一起吃火锅，我给你烫毛肚，喂你吃虾滑，一辈子都这样。
【妹】（笑了，抬起头在你嘴角亲了一下，麻酱蹭在你脸上，她咯咯地笑，窗外雪还在下，屋里火锅咕嘟咕嘟冒着泡，热气腾腾的，两个人抱在一起，比火锅还暖）
【哥】（笑着擦了擦脸上的麻酱，又夹了一筷子她爱吃的宽粉喂她）
【妹】（张嘴吃了宽粉，眼睛弯成了月牙，窗外的雪静静地下着，屋里暖得像春天，她靠在你怀里，觉得这就是全世界最幸福的事情）
