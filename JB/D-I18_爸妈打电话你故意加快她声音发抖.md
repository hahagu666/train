# D-I18：爸妈打电话回来你故意加快她声音发抖
# 地点：你房间床上
# 情境：你们正做到一半，妈妈打电话回来，她接电话你故意加快，她声音发抖

【哥】软软，你手机响了，是妈打来的。（晚上爸妈出去参加朋友聚会，你们正做到一半，你后入式干她，她趴在床上屁股翘得高高的，你抓着她的腰快速抽插，她叫得正大声，突然她放在床头的手机响了，屏幕显示"妈妈"。）
【妹】（啊...哥...快...快一点...嗯...她正爽着，看见来电显示是妈妈，吓得魂都飞了，赶紧想爬起来。）完了完了！是妈妈！你快拔出来！
【哥】（你不仅没拔出来，反而抓着她的腰插得更深了，把手机递给她，凑在她耳边坏笑。）接啊，妈打来的，别让她担心。
【妹】（我不接！会被听见的！她想躲，但是你抓着她不让动，肉棒还深深插在她小穴里，龟头抵着宫颈，电话一直响，她急得快哭了。）你快拔出来...求你了哥...
【哥】（你按了接听，直接把手机放在她耳边，开始慢慢动，浅浅抽插。）快接，妈该担心了。
【妹】（电话接通了，妈妈的声音传来，她赶紧屏住呼吸，尽量让声音正常，但是你开始动了，每一下都蹭到她敏感点，她声音都在抖。）知...知道了妈...你们...你们玩吧...
【哥】（你听她强装镇定，故意加快速度，狠狠顶了一下，她啊了一声赶紧捂住嘴。）舒服吗？叫妈妈听听。
【妹】（妈妈在电话里问她声音怎么怪怪的，她赶紧摇头，声音发颤，回头狠狠瞪你，眼睛水汪汪的带着求饶，但是你越动越快，肉棒在她湿滑的小穴里快速抽插，发出咕叽咕叽的水声，她快忍不住了。）没...没事妈...我刚...刚在喝水...呛到了...
【哥】（你伸手到前面揉她的阴蒂，她身体立刻抖起来。）嗯...夹紧了...
【妹】（她急急忙忙想挂电话，但是你突然狠狠顶到她最敏感的地方，她啊的一声叫出来，赶紧把电话按掉扔到一边，再也忍不住了，哭着叫出来。）妈...我...我没事...就是...就是有点困了...先挂了啊...你们早点回来...啊...哥...你混蛋...我妈...我妈会听见的...
【哥】（电话挂了，你再也没有顾忌，抓着她的腰快速抽插，声音啪嗒啪嗒的。）听见就听见，让妈知道我们软软在干嘛。
【妹】（啊...不要...太舒服了...她被你操得站不住，趴在床上，屁股还翘着让你干，小穴剧烈收缩，没两下就高潮了，抖得像筛子。）啊...我去了...哥...
【哥】（她高潮的时候你也射了，腰一挺全部射在她里面，两个人趴在床上喘了半天。）啊...射了...
【妹】（喘了半天，她回头捶你，脸红得要滴血，眼泪还挂在脸上。）都怪你！我妈肯定听出来了！以后我怎么见她啊！
【哥】（你笑着把她抱起来吻她，帮她擦眼泪。）听不出来的，你最后不是挂得快吗。
【妹】（她鼓着脸瞪你，但是往你怀里钻，小声说。）下次妈打电话你再敢这样...我就...我就告诉妈你欺负我...
【哥】（你笑着捏她的屁股。）你舍得吗？
【妹】（她脸红了，咬了你的肩膀一口，小声嘟囔。）...舍不得...
