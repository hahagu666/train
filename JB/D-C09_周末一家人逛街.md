# D-C09：周末一家人逛街
# 地点：商场，周末下午
# 情境：爸妈带你们俩逛商场，她挽着你胳膊走，爸妈在后面说话，她偷偷捏你手

【哥】（商场里人来人往，爸妈走在后面聊着天，她挽着你胳膊走在前面，头靠你肩膀上，顺着她指的方向看过去）哪个运动鞋？带条纹的那个？
【妹】（拉着你往运动品店走，步子都轻快了）就是那个带粉色条纹的，上次跟朋友一起来她买了一双，特别好看！
【哥】（被她拉着走，笑着回头看了爸妈一眼，爸妈在后面笑着摇头）慢点走，别摔了。
【妹】（妈妈在后面说别总买粉色的买双黑色耐脏，她鼓脸，回头冲妈妈做了个鬼脸）
【哥】（笑，捏了捏她挽着你胳膊的手）粉色确实容易脏，不好洗。
【妹】（摇头，晃着你胳膊撒娇）不要，黑色不好看，我就要粉色的，我会小心穿的！
【哥】（被她晃得没办法，点点头）好好好，买粉色的，都听你的。
【妹】（爸爸笑着说女孩子穿粉色好看，她立刻开心了，挽着你胳膊晃，笑得眼睛弯起来）
【哥】（笑着拍了拍她的头）还是爸爸说话管用是吧，我说就不行。
【妹】（开心地蹦了一下）还是爸爸好！
【哥】（被她逗笑，推着她往店里走）快进去试，别让爸妈等久了。
【妹】（进了运动品店，坐在试鞋凳上试鞋子，你蹲下来帮她系鞋带，她低头看你，嘴角偷偷扬起来，手指轻轻碰了碰你的头发）
【哥】（系鞋带的手顿了一下，抬头看她，她立刻移开视线假装看别的地方）别乱动，系错了。
【妹】（妈妈在旁边看衣服，回头问合适吗，她立刻坐直，假装正经，脚在地上蹭了蹭）
【哥】（站起来，退后两步看她穿的效果）转一圈我看看。
【妹】合适！特别舒服！
【哥】（笑，捏捏她的脸）跑两步试试，别穿着不合脚磨起泡。
【妹】（穿着新鞋跑了两步，蹦了两下，又跑回来站在你面前，眼睛亮晶晶的看着你）嗯！特别轻！就买这双！
【哥】（笑着帮她理了理跑乱的刘海）好，就买这双，去结账。
【妹】（买完鞋继续逛，挽着你胳膊，趁爸妈不注意，偷偷在你手心捏了一下，脸有点红）
【哥】（低头看她，她假装在看旁边橱窗里的衣服，耳朵尖红了，你反手握了握她的手）
【妹】（脸红，假装看旁边的衣服，但是手没松开，嘴角扬着，手指偷偷勾住你的手指）
【哥】（指尖跟她勾在一起，任由她勾着，继续往前走，爸妈在后面笑）
【妹】（妈妈说前面有奶茶店问想喝什么，她立刻举手，蹦了一下，另一只手举得高高的）
【哥】（被她拽得晃了一下，笑着看她）慢点，别拽我。
【妹】我要珍珠奶茶！全糖加冰！
【哥】（挑挑眉）全糖？不怕胖了？上次是谁说要减肥的。
【妹】（妈妈笑着说你哥请客，她眼睛亮晶晶看你，晃着你胳膊撒娇）哥~
【哥】（被她晃得心软，捏了捏她的脸）行，我请，真是拿你没办法。
【妹】（开心得踮脚在你脸上亲了一口，拉着你往奶茶店跑）哥你最好了！
【哥】（被她亲得一愣，摸了摸被亲的地方，笑着跟上去，爸妈在后面笑得无奈）
【妹】（举着奶茶吸一口，笑得眼睛弯成月牙，另一只手还紧紧勾着你的手指）
