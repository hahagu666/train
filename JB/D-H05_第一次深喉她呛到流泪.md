# D-H05：第一次深喉她呛到流泪
# 地点：你床上
# 情境：她想试着把整个肉棒含进去，第一次尝试深喉，结果被呛到流泪

【哥】（她给你口交了好多次，越来越熟练，这次她吞吐着，突然抬头看你，脸红扑扑的。）
【妹】（含着龟头舔了半天，抬起头，嘴角全是口水，亮晶晶的，看着你，声音黏黏的。）哥...我看片子里...人家都能整个含进去...我也想试试...
【哥】（皱了下眉，摸摸她的头。）别勉强，那个不舒服，会呛到的。
【妹】（摇摇头，眼神很坚定，擦了擦嘴角的口水，重新低下头，手握住肉棒对准自己的嘴，慢慢往下吞，先含住龟头，然后慢慢往下，一点一点往喉咙里送。）嗯...
【哥】（能感觉到她温热的口腔一点点吞进来，比平时深了好多，特别紧特别暖。）嘶...
【妹】（含到一半，就感觉顶到喉咙了，有点难受，想吐，但是她忍住了，慢慢调整呼吸，再往下一点，龟头抵在她喉咙口。）嗯...
【哥】（感觉到龟头抵着她的喉咙，特别紧，你舒服得闷哼了一声。）嗯...
【妹】（被你闷哼鼓励了，她想再往下一点，结果龟头一下子滑进喉咙里，她瞬间喘不上气，喉咙一紧，呛到了，啊...她赶紧抬起头，退出来，剧烈咳嗽，眼泪都呛出来了，顺着脸颊往下流。）咳...咳咳...
【哥】（赶紧坐起来拍她的背，递水给她，心疼地说。）跟你说别勉强嘛，呛到了吧？
【妹】（咳嗽了半天，喝了口水，才缓过来，眼泪还挂在脸上，脸红得不行，有点委屈，又有点不服气，鼓着脸，声音哑哑的）我...我刚才没准备好...再来一次...
【哥】（擦了擦她的眼泪。）还来？不怕呛了？
【妹】（点点头，擦了擦眼泪，重新低下头，这次她更小心了，慢慢往下含，到喉咙口的时候停下来，调整呼吸，用喉咙口轻轻套弄龟头，手握着下面的部分快速套弄，舌头也没闲着，不停舔着肉棒下面的系带。）嗯...
【哥】（哦...龟头在她喉咙口被紧紧裹着，手还快速套弄下面，舌头舔着系带，三种刺激一起上来，比平时还舒服，你忍不住摸她的头。）哦...舒服...
【妹】（感觉到你舒服，她开心了，保持这个深度，嘴巴快速上下动，但是不到最深，就在喉咙口那里吞吐，喉咙紧紧夹着龟头，手配合着快速套弄，口水顺着肉棒流下来，流到蛋蛋上，她另一只手揉着你的睾丸，动作配合得特别好。）嗯...
【哥】（快感越来越强烈，你抓着床单。）对...就这样...特别舒服...别勉强深喉，这样就很好...
【妹】（听见你这么说，她就保持这个深度和速度，喉咙紧紧夹着龟头快速小幅度吞吐，手快速套弄，舌头一直顶着系带，揉蛋蛋的手也没停，偶尔还故意收缩喉咙，夹一下你的龟头。）嗯...
【哥】（快感涨得特别快，你呼吸越来越急促，肉棒在她嘴里跳得厉害。）快了...
【妹】（感觉到你要射了，她不仅没退出来，反而含得紧了一点，喉咙紧紧夹着龟头，等着你射进来。）嗯...射给我...
【哥】（你闷哼一声，腰一挺。）我要射了...
【妹】（这次她有准备，没呛到，乖乖咽了下去，等你射完，她还轻轻舔了舔龟头，才抬起头，脸上还挂着刚才呛出来的眼泪，嘴角亮晶晶的全是口水，但是笑得特别开心，像打赢了仗一样，声音黏黏的。）哥...我...我没让你失望吧...
【哥】（把她拉上来擦了擦她的脸和眼泪，亲了亲她。）特别棒，没让我失望。
【妹】（埋在你怀里笑，特别开心，但是喉咙还有点不舒服，咳了两声，声音哑哑的）下次...下次我肯定能整个吞进去...
【哥】（抱着她，轻轻拍她的背。）傻丫头，不用急，慢慢来。
【妹】（在你怀里点点头，但是偷偷握了握拳头，心里想着下次一定要成功。）嗯...
