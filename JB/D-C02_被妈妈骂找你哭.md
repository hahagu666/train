# D-C02：被妈妈骂找你哭
# 地点：你房间，晚上
# 情境：她被妈妈骂了，因为最近模拟考退步了，敲你房门眼睛红红的

【哥】（晚上在房间看书，听见轻轻的敲门声，声音小小的）进来，门没锁。
【妹】（推开门站在门口，眼睛红红的，抱着兔子玩偶）哥...你还没睡吗？
【哥】（看她站在门口眼睛红红的，赶紧放下书）怎么了？哭了？
【妹】（站在门口不说话，眼泪在眼眶里转）
【哥】（拉她进来，关上门，让她坐床边）被妈骂了？
【妹】（点头，嘴唇抖了一下，眼泪掉下来）妈说我再这样下去连一本都考不上...说我天天玩手机不学习...
【哥】（给她递纸巾，擦她眼泪）我看看，哭成小花猫了。
【妹】（接过纸巾擦眼泪，抽抽搭搭）我没有天天玩手机...我每天都学到十二点...这次题难嘛...
【哥】（摸她头）我知道，你最近有多努力我都看着呢。
【妹】（越说越委屈，眼泪掉得更凶）妈根本不听我解释...一进门就骂我...说我上次进步是运气...
【哥】（拍她背）妈也是着急，说话重了点，别往心里去。
【妹】（靠过来，脸埋你肩膀上哭）我知道...但是我还是好难过...
【哥】（轻轻拍她背，让她靠在你怀里哭）哭吧，哭完就好了，哥在呢。
【妹】（抱着你腰，哭了一会，声音慢慢小下来，肩膀还一抽一抽的）...哥。
【哥】（摸她头发）嗯？我在。
【妹】（声音闷闷的）我真的能考上吗...
【哥】（很肯定地点头）能，你最近进步多大，我都看着呢，哥相信你。
【妹】（抬头看你，眼睛肿肿的）真的？
【哥】（帮她擦眼泪）真的，哥什么时候骗过你。
【妹】（吸鼻子，擦干净眼泪，有点不好意思）...我把你衣服弄湿了...
【哥】（笑了笑）湿了就湿了，没事，衣服洗了就行。
【妹】（靠在你肩膀上，不哭了，手指揪着你衣服）...今晚我想在你这睡。
【哥】（捏捏她脸）行，你睡床我睡沙发。
【妹】（立刻摇头）不要，你也睡床上，我不挤你。
【哥】（笑）不怕妈看到说你？
【妹】（鼓脸）妈都睡了...而且...我不想一个人待着...
【哥】（把她往怀里带了带）好，一起睡，哥陪着你。
【妹】（立刻开心了点，往你被窝里钻，拉被子盖好，手紧紧抓着你衣服）哥你最好了。
【哥】（关灯，轻轻拍她背）睡吧，明天哥给你做你爱吃的早饭。
【妹】（往你怀里蹭了蹭，声音黏黏的，带着哭后的鼻音）嗯...
