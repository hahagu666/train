# D-G03：伸手进睡衣摸她胸
# 地点：你床上，深夜
# 情境：接了几次吻摸过几次胸之后，你大着胆子把手伸进她睡衣下摆，直接摸到她皮肤

【哥】（深夜爸妈都睡熟了，她穿着宽松的纯棉睡衣溜进你房间，钻到你被子里，像往常一样靠在你怀里接吻。）
【妹】（钻到你被子里，身体暖暖的，立刻凑过来吻你，嘴唇软软的贴上来，比第一次熟练了一点，小手抓着你睡衣。）嗯...
【哥】（回吻着她，手顺着她的腰慢慢往上摸，这次没停在睡衣外面，指尖轻轻掀起她睡衣下摆，摸到她腰上光滑的皮肤。）唔...
【妹】（正吻得认真，突然感觉到你冰凉的手碰到她腰上的皮肤，她身体猛地抖了一下，离开你的嘴唇，眼睛睁得圆圆的看着你，呼吸一下子急了，声音小小的发颤。）哥...你手凉...
【哥】（手在她腰上捂了一会，暖热了，才慢慢往上移，她腰上的皮肤细细滑滑的，特别软。）暖了。
【妹】（没推开你的手，只是身体有点僵硬，紧张得发抖，看着你，脸红扑扑的，咬着嘴唇，呼吸又快又浅，小手抓着你肩膀，没说话。）嗯...
【哥】（手慢慢往上移，终于碰到了她胸罩下面光滑的皮肤，然后整个手掌覆上去，直接握住了她的乳房，没有隔着衣服，温热柔软的触感直接传到手心。）软...
【妹】（被你直接握住胸的瞬间，她啊的一声叫出来，立刻捂住自己的嘴，怕声音太大被爸妈听见，身体没力气成了一滩水，靠在你怀里，浑身控制不住地发抖，眼睛水汪汪的立刻就蒙了一层雾，声音都带哭腔了，发着颤。）哥...你手伸进来了...
【哥】（手掌包裹着她软软的乳房，小小的一只，刚好握在手里，暖暖的，软软的，弹性很好，皮肤细腻得像丝绸一样，你轻轻捏了一下。）嗯...
【妹】（被你一捏，她浑身像过电一样麻到指尖，嗯...地闷哼出来，埋在你脖子里，牙齿轻轻咬了你肩膀一下，身体抖得更厉害了，呼吸热热的喷在你皮肤上，手紧紧抓着你的后背，声音闷闷的带着哭腔的撒娇。）轻...轻点...疼...
【哥】（放轻了动作，手心轻轻揉着她软软的胸，拇指不小心碰到了她硬硬的乳头。）这里？
【妹】（被碰到乳头的瞬间，她整个人都弓了一下，啊...叫得比刚才大声一点，她赶紧咬住枕头，眼泪都快出来了，不是疼的，是那种麻麻的痒痒的感觉窜遍全身，下面一下子就湿了，她声音抖得一塌糊涂，带着哭腔。）啊...那里...那里不能碰...好麻...
【哥】（能感觉到乳头在你拇指下硬硬的凸起来，你没再用力碰，只是用指腹轻轻蹭了蹭。）这样呢？
【妹】（被你蹭得浑身都酥了，腿都夹紧了，没力气地哼唧着，再也说不出完整的话，只能嗯嗯啊啊的小声呻吟，紧紧抱着你，主动吻住你的嘴唇，吻得又急又柔，把你的手按在她胸上，不让你拿开，声音断断续续的。）嗯...哥...我...我难受...
【哥】（抱着她发抖的身体，吻着她软软的嘴唇，手继续轻轻揉着她温热柔软的乳房，她的身体烫得吓人。）哪里难受？
【妹】（被你揉得浑身没力气，脑子一片空白，只觉得下面一股股地流着水，痒得难受，她无意识地蹭着你的腿，过了好半天，才缓过一点劲，埋在你怀里喘气，脸红得像要滴血，声音小小的发着颤，说完自己先羞得不行，把脸彻底埋在你怀里，不敢抬头，但是把后背往你手边凑了凑。）胸罩...胸罩后面有扣子...你...你解开...那样舒服...
