# D-D23：抢你可乐喝
# 地点：客厅沙发，夏天晚上
# 情境：你在看球赛，冰可乐放茶几上，她写作业写累了出来喝水

【哥】（夏天晚上窝在沙发里看球赛，冰可乐放在茶几上，刚打开喝了两口）
【妹】（写作业写得满头汗，从房间出来拿水喝，看见你茶几上的冰可乐，眼睛一下子亮了）哥！你喝可乐不叫我！
【哥】（眼睛盯着电视）你作业写完了？
【妹】（磨磨蹭蹭走过来，在你旁边坐下，眼睛一直瞟可乐）...快写完了...就差最后一道数学题。
【哥】那写完再喝。
【妹】（鼓脸，伸手去够可乐，你手一抬拿走了，她扑了个空）啊！
【哥】（喝了一口，故意气她）写完作业再说。
【妹】（扑过来抢，整个人趴在你身上，手伸过来够你举高的可乐）给我喝一口！就一口！
【哥】（另一只手按着她不让她够到，球赛正到关键时刻）别闹，看球呢。
【妹】（抢不到，干脆整个人坐你腿上，两只手抱住你举可乐的胳膊往下拽）我就喝一口！冰的！我都快热死了！
【哥】（被她晃得可乐都快洒了）行行行，给你喝，别晃了！
【妹】（立刻开心地接过来，仰着头咕咚咕咚喝了两大口，冰得她缩了下脖子，打了个小小的可乐嗝）
【哥】（笑着看她）说好一口的？
【妹】（脸红了，把可乐递还给你，但是嘴角沾了点可乐渍，眼睛亮晶晶的）太冰了嘛...没忍住...（又舔了舔嘴角）
【哥】（伸手用拇指擦掉她嘴角的可乐渍）喝你自己的去，冰箱里还有。
【妹】（坐在你腿上没动，看着你擦过她嘴角的手，脸更红了，小声说）那个...你的好喝一点...
【哥】（愣了一下，笑出声，把可乐递到她嘴边）那再喝一口。
【妹】（眼睛一下子弯起来，就着你的手又喝了一口，这次小口小口的，喝完抬头看你，嘴唇润润的，可乐的气泡在舌尖炸开，凉丝丝的，她凑过来在你脸上亲了一下，然后红着脸从你腿上跳下来跑回房间，跑到门口探出头）我去写作业了！剩下的给我留一点！（说完缩回去，门没关严，能听见她在里面偷偷笑）
