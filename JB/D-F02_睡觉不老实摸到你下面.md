# D-F02：睡觉不老实摸到你下面
# 地点：你房间床上，打雷的晚上她过来跟你睡
# 情境：打雷她害怕过来跟你一起睡，半夜她睡觉不老实，手伸到你睡裤里摸到了勃起的肉棒，吓醒了

【哥】（半夜她因为打雷跑过来跟你一起睡，你睡得迷迷糊糊，身边多了个软软暖暖的身体，她睡着睡着就往你怀里钻，手也不老实，到处乱摸。）
【妹】（睡得迷迷糊糊的，做了个梦，手到处乱抓，抓着抓着抓到一个硬硬的、热热的东西，还一跳一跳的，她迷迷糊糊捏了两下，感觉不对，一下子醒了。）
【哥】（睡得正香，突然感觉下面被一只软软的小手握住了，还捏了两下，一下子就勃起了，也醒了，一睁眼就看见她睁着大眼睛看着你，手还放在你睡裤里，脸在黑暗里都能看出来红透了。）你醒了？
【妹】（手僵在那里，握着那个硬硬热热的东西，能感觉到它在自己手里跳了一下，瞬间就明白是什么了，脑子嗡的一声，整个人都僵住了，手想收回来但是动不了，脸烫得吓人，在黑暗里眼睛睁得圆圆的，看着你说不出话，过了半天才发出小小的声音。）哥...我...我不是故意的...
【哥】（也有点尴尬，但是看见她吓成这样，想笑，黑暗里能闻到她头发上的香味，她的小手还软软地握在那里，虽然隔着内裤，但是热度传得清清楚楚。）没事，睡觉不老实是吧。
【妹】（听见你这么说，手像触电一样立刻收回来，赶紧往被窝里缩，转过身背对你，身体紧紧蜷成一小团，脸埋在枕头里，心跳快得咚咚咚的，手心里还留着那个硬硬热热的触感，烫得她手心都出汗了，身体在被子里轻轻发抖。）对...对不起...
【哥】（伸手拍了拍她的背，她身体抖了一下，但是没躲开，你能感觉到她背对着你，身体烫得吓人。）睡觉吧，没事。
【妹】（背对着你，过了半天，声音小小的、闷闷的，从枕头里传出来，带着点颤抖的鼻音。）它...它怎么硬了...
【哥】（愣了一下，忍不住笑了，伸手揉了揉她的头发。）男人早上都会这样，正常生理反应，睡吧。
【妹】（哦了一声，没再说话，但是身体还是烫得厉害，闭着眼睛全是刚才手里那种硬硬热热的触感，还有它跳了一下的感觉，过了好久都没睡着，身体一直绷得紧紧的，又过了半天，她慢慢转过身，面对着你，黑暗里看着你的脸，手犹豫了半天，轻轻拉住你的睡衣衣角，声音小小的带着点鼻音。）哥...我刚才是不是把你弄醒了...
【哥】（睁开眼睛，黑暗里她的眼睛亮晶晶的，离你特别近，呼吸暖暖的吹在你下巴上，能闻见她身上香香的味道。）没有，快睡吧，明天还要上课。
【妹】（点点头，但是没闭上眼睛，就那么看着你，过了一会，她悄悄往你身边挪了挪，身体贴在你身上，头靠在你肩膀上，手抓着你的衣角，但是这次手乖乖的没乱摸，脸烫得贴在你肩膀上，能听见你心跳也很快，过了半天，她小声嘟囔，说完把脸埋在你肩膀上，身体暖暖的贴着你，虽然害羞得要死，但是还是往你怀里钻了钻。）你...你不许笑我...我真的不是故意的...
