# D-I37：互相爱抚着然后慢慢插进去
# 地点：你床上
# 情境：两个人互相爱抚，你摸她她摸你，磨够了再慢慢插进去，特别缠绵

【哥】（晚上洗完澡，两个人躺在床上，都没穿衣服，你抱着她，吻她的脖子，手摸她的乳房，她的手也往下摸，握住你的肉棒轻轻套弄。）宝贝，你也硬了呢。
【妹】（手握着你的肉棒，软软的手上下套弄，吻你的嘴唇，腿分开让你的手摸她湿漉漉的小穴，她小声呻吟着，凑在你耳边说。）哥...硬了...
【哥】（你手指揉着她的阴蒂，指腹轻轻画圈，她套弄你肉棒的手越来越快，你吻着她的乳房，含住乳头吸吮。）嗯...你也湿了。
【妹】（啊...被你揉着阴蒂，她舒服得小声哼，手加快速度套弄你，龟头流出的前液被她涂满整个肉棒，滑溜溜的，她蹭着你的大腿，小穴贴在你腿上。）哥...我想要你插进来...
【哥】（你没急着插，继续揉她的阴蒂，手指插进去一根，抽插着，摸她的G点，她立刻抖了一下，叫出声。）再等等，让你更舒服一点。
【妹】（啊...手指...你的手指...她呻吟着，手紧紧抓着你的胳膊，小穴裹着你的手指不停收缩，快感越来越强，她套弄你的手也更快了。）不行了...哥...我要你的肉棒...不要手指...
【哥】（看她急成这样，你才抽出手指，扶着肉棒，龟头在她穴口蹭来蹭去，就是不进去，她急得腰往上抬，想自己吞进去。）这么想要？自己坐上来。
【妹】（啊...别蹭...进来...求你了哥...她急得快哭了，扶着你的肉棒往自己穴口里塞，你顺着她的力道慢慢顶进去，两个人同时闷哼一声，特别舒服。）嗯...进来了...
【哥】（全部插进去之后，你没急着动，就抱着她，吻她，两个人贴在一起，肉棒深深埋在她小穴里，能感觉到她小穴一缩一缩的，特别暖特别紧。）好紧...
【妹】（她抱着你的脖子，腿环着你的腰，让你全部插到底，小声呻吟着，吻你的下巴。）动一动...哥...
【哥】（你才开始慢慢抽动，特别慢特别深，每一下都顶到最深处，不像平时那么快，但是每一下都特别重，磨着她的G点，她舒服得直哼哼。）这样舒服吗？
【妹】（啊...就是这样...慢一点...深一点...她小声说着，配合你的动作抬腰，两个人像连体人一样贴在一起，吻着，摸着，慢慢做，做了快半小时，她才开始抖。）哥...我要到了...
【哥】（你加快了一点速度，揉着她的阴蒂，吻着她的嘴唇，她身体绷紧，高潮了，紧紧抱着你，小穴剧烈收缩，你也跟着射了，全部射在她里面。）嗯...射了...
【妹】（两个人同时高潮，抱在一起抖了半天，才慢慢软下来，你还插在她里面，抱着她，吻她的脸，她满足地叹了口气，窝在你怀里，声音黏黏的。）这样慢慢做...好舒服...比快的时候还舒服...
【哥】（你吻了吻她的额头，抱着她。）嗯，以后经常这样慢慢做。
【妹】（她往你怀里钻了钻，找了个舒服的姿势，手指轻轻划过你的背，两个人就这样紧紧贴在一起，肉棒还留在里面，声音温柔得像水一样。）嗯...就喜欢你这样抱着我...慢慢的...只有我们两个人...
