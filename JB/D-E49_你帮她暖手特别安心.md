# D-E49：你帮她暖手特别安心
# 地点：冬天放学路上
# 情境：冬天她手冻得冰凉，你把她的手揣进你口袋里帮她暖着，她特别开心

【哥】（冬天放学去接她，风特别大，刮在脸上像刀子一样，她站在学校门口等你，手揣在袖子里，冻得鼻子通红，看见你过来立刻跑过来）
【妹】（跑到你身边，手冻得冰凉冰凉的，指尖都冻红了，一碰到你就立刻往你身边靠，缩着脖子打了个哆嗦，声音都冻得发颤）哥...好冷啊...今天风太大了...
【哥】（握住她的手，她的手冰凉冰凉的，像冰块一样，冻得你都一哆嗦）怎么不带手套？
【妹】（鼓着脸，手被你握着，冰凉的手碰到你暖暖的手，舒服得她叹了口气，往你身边靠得更紧了，声音小小的）手套早上忘带了...中午就开始冷了...我揣袖子里揣了一下午还是冻得慌...
【哥】（把她的两只手都攥在自己手里，用手心捂着，给她搓手，她的手太凉了，搓了半天还是凉的，你干脆把她的手揣进你羽绒服口袋里，握着她的手一起放进去）这样暖得快。
【妹】（手被你揣进你暖暖的口袋里，你大大的手包裹着她冰凉的小手，暖乎乎的温度从手心传过来，一直暖到心里，她眼睛一下子亮了，乖乖把另一只手也递给你，让你一起揣进口袋里，整个人都贴在你胳膊上，靠得紧紧的）好暖...你口袋里怎么这么暖啊...
【哥】（握着她的手在口袋里慢慢给她搓，指尖给她揉冻得发红的指关节，她的手软软的，小小的，在你大手里慢慢暖过来，一点点变暖，她舒服得叹了口气，像只被暖过来的小猫一样靠在你身上）
【妹】（被你暖着手，整个人都贴在你胳膊上，风还是很大，但是她一点都不冷了，手暖乎乎的，连带着心里都暖融融的，她偷偷用手指勾住你的手指，在口袋里轻轻勾着玩，嘴角一直扬着，冻得通红的鼻子也慢慢恢复粉色了）
【哥】（走了一会，她的手彻底暖过来了，软软的暖暖的，在你手心里动来动去，时不时偷偷勾一下你的手指，像小钩子一样勾着你玩，你忍不住握紧了一点她的手）
【妹】（被你握紧手，她脸一下子红了，但是没抽回去，反而也握紧你的手，和你十指相扣在口袋里，脸靠在你胳膊上，风刮过脸也不觉得冷了，甚至觉得冬天好像也没那么讨厌了，因为你手特别暖）
【哥】（走到家楼下，你想把手从口袋里拿出来掏钥匙，她立刻握紧你的手不让你拿出来，鼓着脸看着你，像不想放开玩具的小孩）
【妹】（手紧紧握着你的手，揣在你暖暖的口袋里不肯拿出来，仰头看着你，脸冻得红扑扑的，但是眼睛亮晶晶的，嘴角扬着，撒娇一样晃了晃你们牵着的手）再放一会...就一会...外面太冷了...你口袋里特别暖...
【哥】（看着她撒娇的样子，眼睛亮晶晶的像只贪暖的小猫，忍不住笑了，就这么一只手牵着她揣在口袋里，另一只手掏钥匙开门，进门之后暖气扑面而来，她还是不肯把手拿出来，就那么牵着你的手，暖乎乎的，靠在你身上，觉得你手心的温度，是这个冬天最暖的东西）
【妹】（换了鞋，还是牵着你的手不放，手暖乎乎的，和你的手握在一起，抬头看你，脸红扑扑的，眼睛亮晶晶的，小声说）哥...以后冬天我的手都给你暖好不好...你的手比暖水袋还暖...（她凑过来在你脸上亲了一下，冰凉的小脸贴在你脸上蹭了蹭，手还是紧紧和你握在一起，藏在你口袋里不肯拿出来，觉得整个冬天都暖乎乎的）
