# D-E33：偷偷喷妈妈香水给你闻
# 地点：你房间，周末下午
# 情境：她偷偷喷了妈妈的香水，跑到你房间转来转去，想让你闻但是又不好意思说

【哥】（周末下午你在房间打游戏，门没关，她磨磨蹭蹭走进来，身上香香的，跟平时不太一样，在你房间转来转去，一会假装拿书，一会假装看窗外，就是不说话）
【妹】（转了两圈，见你没反应，故意在你身边走来走去，走到你椅子旁边站着，手揪着裙子边，脸有点红，时不时偷偷看你）
【哥】（打游戏打得认真，过了半天抬头看见她还站在旁边，一直不走）你站这干嘛？不写作业去？
【妹】（听见你跟她说话，眼睛一下子亮了，但是又装作不在意的样子，揪着裙子，故意凑得离你近一点，声音小小的）我...我就是过来拿本书。（她站在你旁边，身上香香的味道飘过来，甜甜的，不是她平时的沐浴露味道）
【哥】（又打了两分钟游戏，闻到她身上的香味，抬头看她，她今天好像还特意涂了点口红，淡淡的粉色，耳朵红红的，明显是特意打扮过）你身上怎么这么香？
【妹】（听见你这么问，脸一下子红了，但是嘴角偷偷往上扬，故意装作不在意的样子，摸了摸自己的头发，转了个圈）有吗？我怎么没闻到？
【哥】喷香水了？
【妹】（脸更红了，手揪着裙子边，有点不好意思，但是还是点了点头，小声说）嗯...我喷了点妈妈的香水...（她凑过来一点，离你更近了，脖子伸到你面前，声音小小的，带着点期待）你闻闻...好不好闻...
【哥】（凑过去闻了闻，是甜甜的栀子花香，很适合她，她脸红红的，耳朵都烫了，脖子伸得长长的，像等夸奖的小猫）嗯，挺好闻的。
【妹】（眼睛一下子亮了，开心得嘴角都扬起来了，但是又有点不好意思，低下头摸了摸自己的脖子，小声说）真的吗...我刚才喷了半天...怕喷多了太浓...
【哥】不浓，刚好。
【妹】（更开心了，干脆在你椅子旁边蹲下来，仰着头看你打游戏，身上的香味一直往你鼻子里飘，她时不时偷偷看你表情，看你有没有觉得好闻，蹲了半天，突然小声说）那...那我以后天天喷这个好不好...
【哥】你一个高中生喷什么香水，妈妈不说你啊。
【妹】（鼓着脸，但是没反驳，手托着下巴看你打游戏，身上的香味甜甜的，过了一会她又凑过来一点，声音小小的，黏黏的，像说悄悄话一样）我只在家喷...只喷给你闻...（她说完脸就红透了，赶紧转过头假装看你电脑屏幕，但是耳朵红得要滴血，手揪着你的裤脚轻轻晃，嘴角偷偷扬着，特别开心你说香水好闻）
【哥】（打完一把游戏低头看她，她蹲在你椅子旁边，仰着头看你，脸红扑扑的，身上香香的，眼睛亮晶晶的像装了星星，见你看她，她立刻有点不好意思，但是还是仰着头让你闻她头发上的香味，像只讨夸奖的小猫咪）
【妹】（看你打完游戏，干脆站起来凑到你怀里，坐在你腿上，让你能清楚闻到她身上的栀子花香，脸红红的但是没躲开，声音黏黏的，带着点撒娇）你再闻闻...头发上也有...（她把头发凑到你鼻子旁边，软软的头发蹭着你脸，香香的，她心跳有点快，但是特别开心，觉得今天偷偷喷香水真是太对了）
