# D-E50：她说我喜欢你以为是兄妹那种
# 地点：你房间，晚上她写完作业
# 情境：晚上在你房间写完作业，她突然很认真看着你说"哥我喜欢你"，以为是兄妹那种喜欢你，但是说完自己脸红了

【哥】（晚上她在你房间写作业，你在旁边看书，安安静静的，写完作业她收拾书包，收拾了一半突然停下来，坐在椅子上看着你，特别认真的样子）
【妹】（坐在椅子上，手里还攥着笔，看着你看了半天，脸有点红，但是特别认真，犹豫了好久才开口，声音小小的但是很清楚）哥...我跟你说个事。
【哥】（放下书抬头看她，她脸红红的，表情特别认真，不像平时闹着玩的样子，以为她又闯什么祸了）怎么了，又把什么东西打碎了？
【妹】（摇摇头，脸更红了，手指绞着衣角，深呼吸了一下，抬起头看着你，眼睛亮晶晶的，特别认真，一字一句地说）哥，我喜欢你。
【哥】（愣了一下，看着她认真的样子，心跳一下子快了，还没等你说话，她又开口了，自己先脸红透了）
【妹】（说完这句话，脸瞬间红到脖子根，耳朵都烫了，但是还是看着你，特别认真，然后又赶紧补充，像是怕你误会一样）就是...就是那种妹妹对哥哥的喜欢！你别想歪了！（她越说声音越小，头埋得低低的，手紧张地绞着衣角）我就是...就是觉得你对我特别好...比爸爸妈妈对我还好...我特别喜欢你...
【哥】（看着她紧张得手都在抖，脸通红通红的，像熟透的苹果，明明是说兄妹的喜欢，却紧张成这样，忍不住笑了，伸手揉了揉她的头）傻丫头，我也喜欢你。
【妹】（猛地抬起头看你，眼睛一下子亮了，像星星一样，但是脸还是红的，有点不敢相信，声音小小的）真的吗？
【哥】真的，你是我妹妹，我当然喜欢你。
【妹】（听见你这么说，脸更红了，但是嘴角控制不住往上扬，笑得特别开心，眼睛弯成月牙，一下子扑过来，扑进你怀里，抱着你的腰，把脸埋在你胸口，蹭啊蹭，像只开心的小猫）
【哥】（抱着她，她身体软软的暖暖的，脸埋在你胸口，能感觉到她脸烫得吓人，心跳得很快，咚咚咚的，不知道是因为害羞还是开心）
【妹】（抱了你半天，抬起头看你，脸还是红红的，眼睛亮晶晶的，但是特别认真，小声说）那...那你以后要一直喜欢我...不许喜欢别的女生比喜欢我多...
【哥】好，一直喜欢你。
【妹】（笑得更开心了，但是脸还是红的，凑过来在你下巴上亲了一下，软乎乎的嘴唇碰了一下，然后又立刻埋回你胸口，声音闷闷的，带着点撒娇）我以后也会一直喜欢你...比你喜欢我还多...（她抱着你，听着你的心跳，觉得特别安心特别幸福，她没说出口的是，她说的喜欢，早就不止是妹妹对哥哥的喜欢了，但是没关系，现在这样就很好，能一直待在你身边，被你喜欢着，就够了）
