# D-I20：她故意发语音给男生挑衅被你做到哭着认错
# 地点：你床上
# 情境：上次她打电话气你之后没过两天，又故意在你面前给男生发语音撒娇，你直接把她手机扔了，狠狠干她，她哭着求你说再也不敢了

【哥】软软，你又在发什么。（上次她打电话气你之后，你说了她一顿，以为她不敢了，结果今天晚上她躺在你身边玩手机，故意当着你的面给那个男生发语音，声音甜甜的。）
【妹】（躺在你身边，拿着手机，故意当着你的面发语音，声音嗲嗲的，还故意瞟你，看你生气的样子，发完还对着你得意地哼了一声。）子轩~明天放学你能送我回家吗？上次你送我的奶茶好好喝呀~明天我要喝珍珠奶茶~
【哥】（你本来在看书，听见她发语音，一下子火就上来了，上次刚说过她，她居然还敢！你直接把书扔了，一把抢过她的手机，她还想抢回去，你直接把手机扔到床对面的沙发上，把她按在床上。）还敢发？上次怎么跟你说的？
【妹】（啊！你干嘛！还我手机！她挣扎着想起来去拿手机，但是你直接把她睡裤和内裤一起扯下来，扶着硬邦邦的肉棒，没做前戏直接插进她湿漉漉的小穴里，她啊的一声叫出来，疼得皱眉但是立刻就被快感淹没了。）啊...你疯了...好粗...
【哥】（你抓着她的腰，直接开始快速抽插，比上次更狠更快，一点都不温柔，床晃得嘎吱响，你拍了一下她的屁股，声音冷冷的。）还敢不敢发了？上次怎么跟你说的？
【妹】（啊...疼...哥...你慢点...她被你操得说不出话，眼泪一下子就出来了，但是不是真的疼，是又疼又爽，小穴里淫水哗哗流，她想顶嘴但是一张嘴就是呻吟。）我...我就发...啊...
【哥】（你听见她还顶嘴，更生气了，把她翻过来，让她跪着屁股翘高，从后面更深更狠地干她，每一下都顶到她宫颈，她啊的一声叫出来，头埋在枕头里。）还顶嘴？还敢不敢？
【妹】（啊...太深了...哥...我错了...她哭着摇头，屁股却不自觉往后迎，小穴紧紧裹着你的肉棒，快感太强烈了，她快受不了了，手抓着床单，指节都发白了。）我再也不敢了...啊...别顶那里...
【哥】（你伸手到前面揉她的阴蒂，速度更快，她抖得更厉害了。）错哪了？说，你是谁的？
【妹】（我是你的...我是哥一个人的...啊...我错了...我不该跟别的男生说话...不该气你...她哭着求饶，话说得断断续续，被你操得连完整句子都说不出来，小穴开始剧烈收缩，快高潮了。）哥...我要去了...让我去...
【哥】（你故意停下来，不动了，肉棒还深深插在她小穴里，她急得腰往后扭，想自己动，你按住她不让动。）错了没有？还敢不敢气我？说清楚了才让你高潮。
【妹】（啊...你别动停啊...哥...我错了...真错了...她急得哭出来，眼泪流了一脸，小穴一缩一缩的夹着你，想高潮又达不到，难受得扭来扭去。）我再也不跟他说话了...明天我就跟他说清楚...我有哥哥了...让他别找我了...求求你哥...动一动...
【哥】（你听她这么说，才满意了，又开始快速抽插，比刚才更狠，揉着她阴蒂的手加快速度。）这才乖。
【妹】（啊...！你一动她立刻就高潮了，尖叫出声，小穴剧烈收缩，紧紧咬着你的肉棒，身体抖得像筛子一样，口水都流出来一点，整个人软得像一滩泥。）啊...哥...
【哥】（她高潮的收缩把你也夹射了，你腰一挺，全部插到底，浓浓的精液射在她子宫里，射得特别多特别深。）啊...射了...
【妹】（你射的时候她又抖了一下，趴在床上，连哭的力气都没有了，喘着气，你退出来，精液顺着她的大腿流下来，她连动都动不了。）啊...好烫...
【哥】（你躺下来，把她抱进怀里，她像小猫一样窝在你怀里，还在抽噎，你拿纸巾帮她擦眼泪和流出来的精液。）下次还敢不敢了？
【妹】（她摇摇头，往你怀里钻，手抱着你的腰，声音发颤带着哭腔，特别委屈。）不敢了...真的不敢了...你刚才好凶...弄疼我了...
【哥】（你吻了吻她哭红的眼睛，有点心疼，但是还是板着脸。）谁让你故意气我，下次再敢这样，我就干你一晚上不让你睡觉。
【妹】（她脸红了，把脸埋在你胸口，小声嘟囔。）...知道了...以后再也不气你了...
