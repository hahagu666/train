# D-B02：收到情书
# 地点：妹妹房间，放学回家
# 情境：她书包里装着一封粉色信封的情书，关着门在房间里坐着，你敲门进来送水果

【哥】（敲门，推门进来，端着一盘草莓）吃点草莓。
【妹】（坐在书桌前，手里拿着个粉色信封，看到你进来吓了一跳，赶紧往抽屉里塞）
【哥】（看到了）藏什么呢？
【妹】（脸瞬间红了，手按在抽屉上）没...没什么...
【哥】（把草莓放桌上）情书？
【妹】（脸更红了，低下头）...嗯。
【哥】谁给你的？
【妹】（抠手指，声音小小的）我们班...一个男生...放学塞我书包里的...
【哥】你认识？
【妹】（点头）知道...坐我斜后面...平时没怎么说过话...
【哥】你打算怎么办？
【妹】（抬头看你，有点慌）我...我不知道...我还没拆开看...
【哥】不喜欢就拒绝。
【妹】（小声）怎么拒绝啊...我不会...
【哥】就说你现在要高考，不想谈恋爱。
【妹】（想了想，点头）哦...那...他会不会难过啊？
【哥】（笑）你不拒绝他，他会一直缠着你。
【妹】（鼓脸）我才不要谈恋爱...高考完也不要...
【哥】（捏她脸）知道就好。
【妹】（把信封拿出来，犹豫了一下，递给你）你帮我看看写的什么...我不好意思看...
【哥】我看合适吗？
【妹】（点头，塞你手里）你看嘛...
【哥】（拆开扫了一眼，笑）写得还挺长，说喜欢你很久了。
【妹】（脸红到耳根）...你别念！
【哥】（把信放回去还给她）明天还给人家，好好说。
【妹】（把信塞到最下面的抽屉里，点点头）嗯...（拿草莓吃，小声）哥，你...你不生气啊？
【哥】生气干什么，说明我们妹妹招人喜欢。
【妹】（愣了一下，然后笑了，蹭你胳膊）哥你真好...
