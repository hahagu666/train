# D-H11：骑在你脸上她主动坐上来
# 地点：你床上
# 情境：你躺着，她害羞但是主动骑到你脸上，让你舔她，同时她低头给你口交

【哥】（你躺在床上，她站在床边脸红扑扑的看着你，扭扭捏捏半天不说话。）
【妹】（咬着嘴唇，犹豫了半天，才小声说）哥...我...我想骑在你脸上...让你舔我...
【哥】（愣了一下，看着她害羞得不行但是眼神很认真，点了点头。）好啊，上来吧。
【妹】（听见你答应，她脸红透了，但是还是爬上床，慢慢跨到你头上方，膝盖跪在你头两边，小穴正好对着你的嘴，她害羞得想把腿并拢，但是又分开了，声音小小的黏黏的。）那...那我坐下来了...你要是喘不上气就拍我腿...
【哥】（伸手扶着她的腰，把她往下拉了一点，让她的小穴贴在你嘴上。）嗯...
【妹】（啊...小穴碰到你嘴唇的瞬间，她叫出声，身体抖了一下，差点坐下去，赶紧扶住床头稳住身体，同时她低下头，张开嘴含住你硬邦邦的肉棒，舌头立刻开始舔。）啊...
【哥】（她的小穴就在你嘴边，湿漉漉的，水都流到你嘴唇上了，你伸出舌头，直接舔上她硬硬的阴蒂。）嘶...
【妹】（呜！被你一舔阴蒂，她浑身抖了一下，嘴里含着你的肉棒闷哼一声，震动传在龟头上特别舒服，她稳了稳神，开始含着你快速吞吐，舌头不停舔着冠状沟，一只手握着阴茎体套弄，另一只手抓着床头稳住身体。）呜...
【哥】（嘴唇含住她的阴蒂轻轻吸吮，舌头快速打着圈舔，同时把一根手指插进她湿滑的小穴里抽插。）嗯...
【妹】（手指插进来，舌头还舔着阴蒂，她爽得身体不停抖，但是嘴没停，努力给你口交，含着龟头快速吞吐，喉咙夹着龟头，手配合快速套弄，另一只手伸下去轻轻揉着你的睾丸，口手配合得特别好。）嗯...哥...
【哥】（她嘴里暖乎乎的，舌头不停舔，你舒服得闷哼，舌头加快速度舔她阴蒂，手指快速抠G点。）啊...舒服...
【妹】（被你舔得抠得快感很快上来，她嘴里开始发出呜呜的呻吟，震动得你更舒服了，她也加快速度，嘴快速上下吞吐，舌头不停扫着系带，手快速套弄，揉睾丸的手也没停，口水顺着肉棒流下来。）嗯...
【哥】（你们两个一个在上一个在下，互相舔着含着，快感同时累积，你能感觉到她小穴开始剧烈收缩，水流到你脸上。）快了...
【妹】（她快高潮了，动作更快，也更卖力，含着你的肉棒快速吞吐，喉咙紧紧夹着龟头，舌头死死顶着系带，她要在自己高潮的同时让你也射出来。）啊...
【哥】（快感冲到顶点，你闷哼。）我要射了...
【妹】（听见你说要射了，她立刻把龟头含得紧紧的，喉咙夹着，你也感觉到她要高潮了，你用最快速度舔她阴蒂，手指快速抠G点。）嗯...
【哥】（啊！！你感觉她身体猛地绷紧，剧烈颤抖，小穴里一股水喷出来，高潮了，同时她喉咙一紧，你忍不住腰一挺，精液射进她嘴里。）啊...
【妹】（你射在她嘴里，她乖乖咽下去，高潮完她腿一发颤，差点坐在你脸上，赶紧撑住，从你身上翻下来，躺在你身边大口喘气，脸红得像苹果，脸上全是汗和口水，看到你脸上全是她的水，她羞得捂住脸，但是又忍不住笑，声音黏黏的哑哑的。）哥...你脸上都是...丢死人了...
【哥】（把她搂进怀里，擦了擦脸，亲了亲她。）不丢人，特别舒服。
【妹】（埋在你怀里，点点头，小声说）那...下次还要这样...你舔得我好舒服...
