# D-G17：隔着内裤做爱磨她小穴
# 地点：你床上
# 情境：两个人都忍不住了，但是不敢真进去，就隔着内裤蹭，你肉棒磨她小穴

【哥】（你们都光着下半身，她躺在你身下，腿分开着，你肉棒硬邦邦抵在她小穴口，但是都没准备好真的进去。）
【妹】（躺在你身下，脸红扑扑的，眼睛水汪汪看着你，手抱着你的脖子，小穴就在你肉棒下面，水水的亮亮的，她声音发颤带着点颤抖。）哥...我...我还没准备好...真的进去会不会疼...
【哥】（摸着她的脸。）没事，我们不进去，就蹭蹭好不好？
【妹】（连忙点头，脸红得像苹果，声音小小的。）嗯...就蹭蹭...不进去...
【哥】（肉棒抵在她湿透的小穴上，隔着她薄薄的棉质内裤，慢慢摩擦起来，龟头蹭着她的阴蒂和穴口。）嗯...
【妹】（啊...你一动，她立刻叫出来，身体抖了一下，虽然隔着内裤，但是龟头顶着她阴蒂磨的感觉特别清楚，比用手摸还舒服，她立刻抱紧你，呻吟出来。）啊...哥...这样...这样好舒服...
【哥】（腰慢慢动着，肉棒隔着薄薄的内裤在她小穴上磨来磨去，龟头正好蹭着她硬硬的阴蒂，她的水都渗出来，把内裤和你肉棒都弄湿了，滑溜溜的。）好滑...
【妹】（被你磨得快感一阵阵上来，她嗯嗯啊啊地呻吟，腿缠上你的腰，主动抬着腰配合你的动作，让你磨得更准一点，小穴一股股流水，内裤早就湿透了，贴在她阴唇上。）嗯...哥...就是那里...再用力一点...啊...
【哥】（一只手揉着她的胸，捏着她硬硬的乳头，腰加快速度磨着，肉棒在她湿滑的小穴上摩擦，虽然没进去，但是被她内裤和软软的阴唇夹着，特别舒服。）嗯...
【妹】（被你磨得快要高潮了，她哭着抱紧你，指甲掐进你后背，身体不停抖，声音断断续续的。）哥...我要去了...要去了...
【哥】（腰用力顶了一下，龟头正好死死压在她阴蒂上磨了一下。）去了吗？
【妹】（啊！！她尖叫一声，身体猛地弓起来，剧烈颤抖，隔着内裤都能感觉到她小穴疯狂收缩，一股股水喷出来，高潮了，她瘫在床上大口喘气，眼泪都流出来了。）啊...
【哥】（她高潮的时候小穴一缩一缩的，夹着你的肉棒隔着内裤跳，你也忍不住了，腰一抖，精液射出来，射在她湿透的内裤上和小肚子上。）啊...
【妹】（感觉到你射了，滚烫的精液透过薄薄的内裤烫在她小穴上，她又是一阵轻颤，抱着你，等你射完，她低头看看两个人中间，你精液和她的水混在一起，把内裤弄得一塌糊涂，她脸红透了。）嗯...
【哥】（趴在她身上喘着气，亲了亲她的额头。）舒服吗？
【妹】（抱着你，过了半天，才小声说，声音黏黏的带着点期待。）哥...刚才...差一点就进去了...下次...下次我们试试真的进去好不好...我...我想给你...
【哥】（摸着她的头发。）你不怕疼吗？
【妹】（摇摇头，在你嘴唇上亲了一下，脸红得像熟透的苹果，但是眼神很认真。）不怕...只要是和你...我就不怕...
【哥】（把她搂进怀里，给她盖好被子。）不急，等你准备好了再说。
【妹】（乖乖窝在你怀里，点了点头，但是小手悄悄握住你还半硬的肉棒，轻轻套弄着，声音黏黏的。）那...那你再硬了...我们再试试...好不好...
