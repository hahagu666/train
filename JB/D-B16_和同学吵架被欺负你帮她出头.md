# D-B16：和同学吵架被欺负你帮她出头
# 她和班里女生因为值日吵架，被对方推了一下差点摔倒，你刚好路过看见，把她护在身后帮她讲理
# 地点：学校走廊/医务室，课间

【哥】（课间去她们班找她借笔记，刚走到走廊拐角，就看见她站在教室门口，眼眶红红的，对面站着个高个子女生，推了她肩膀一下，她往后踉跄了两步差点摔倒）
【妹】（被推得往后退，后背撞到墙上，疼得皱起眉头，眼泪在眼眶里打转，攥着手里的扫帚，气得声音都抖）你凭什么推我！明明就是你没做值日！凭什么让我替你倒垃圾！
【哥】（看见她被推，心里一下子火就上来了，快步走过去，直接把她拉到自己身后护着，看着那个高个子女生，声音冷下来）你干嘛推人？
【妹】（突然被拉到你身后，愣了一下，看见是你，鼻子一下子酸了，眼泪"唰"就掉下来了，伸手抓着你后背的校服衣服，声音委屈得不行）哥...她...她自己不值日...还推我...
【哥】（回头看了她一眼，她眼眶红红的，肩膀都在抖，明显是被欺负了，你拍了拍她的手背让她别怕，转回头看着那个女生，语气很严肃）同学，吵架归吵架，动手推人就不对了吧？而且本来就是她值日吗？明明是你们组这周值日，你不值日还推人，是不是该道歉？
【妹】（躲在你身后，抓着你的衣服，听见你帮她说话，心里一下子就不害怕了，但是还是有点委屈，眼泪掉个不停，小声补充）...她这周已经三次不值日了...每次都让我帮她倒垃圾...我今天不想帮她...她就推我...
【哥】（听完更生气了，看着那个女生，那个女生一开始还挺横，看见你是高年级的，个子比她高一个头，气势一下子就弱了，磨磨蹭蹭半天说不出话。周围围了好多同学看，她脸一阵红一阵白）
【妹】（躲在你身后，看见那个女生被你说得哑口无言，心里有点解气，但是还是有点害怕，小手紧紧攥着你的校服衣角，偷偷从你身后探出头看她）
【哥】（声音不大但是很有威慑力）要么你现在去把垃圾倒了，然后跟我妹妹道歉，要么我现在就去找你们班主任，让老师来评评理，你选哪个？
【妹】（躲在你身后，听见你说"我妹妹"三个字，心里暖得不行，紧紧抓着你的衣服，偷偷从你肩膀后面探出头看那个女生，眼泪还挂在脸上，但是已经不哭了）
【哥】（那个女生磨磨蹭蹭半天，最终还是不情不愿地说了句"对不起"，然后拿起扫帚去倒垃圾了。周围看热闹的同学也散了，你转过身，看她还站在那儿掉眼泪，鼻子红红的，像只受了委屈的小兔子）
【妹】（看着那个女生拿着扫帚灰溜溜地去倒垃圾了，她抽了抽鼻子，用手背擦了擦眼泪，还有点没回过神）
【哥】（伸手帮她擦眼泪，弹了她脑门一下，又好气又心疼）你傻啊？她欺负你你不会来找我？就站在这儿让她推？万一摔了磕到头怎么办？
【妹】（被你说的更委屈了，扑进你怀里，把脸埋在你胸口，声音闷闷的带着哭腔）我...我本来想跟她讲理的...我没想到她会推我...我刚才都快吓死了...看见你来了我就不怕了...
【哥】（轻轻拍她的背帮她顺气，帮她理了理被推乱的头发，看见她手背上被扫帚划了一道红印子，心疼得不行，拉着她去医务室涂碘伏。她乖乖跟在你身后，手紧紧抓着你的手，好像生怕你走了）
【妹】（坐在医务室椅子上，你帮她涂碘伏，她疼得嘶了一声，但是没躲，看着你认真帮她涂药的样子，眼睛又红了，小声说）哥...你刚才好凶啊...我从来没见过你这么凶...
【哥】（抬头看她，故意板着脸）对你我当然不凶，但是有人敢欺负我妹妹，我当然要凶。以后再有人欺负你，不管是推你还是骂你，你第一时间来找我，不许自己跟人吵架，听见没有？你一个人吵不过她们怎么办？
【妹】（乖乖点头，但是还是有点小纠结，小声说）...可是...我不想什么事都找你...我怕你觉得我麻烦...
【哥】（涂完药，揉了揉她的头发，把她揽进怀里，声音放柔了）傻瓜，你是我妹妹，我不帮你帮谁？就算你再麻烦，我也管你一辈子，知道吗？
【妹】（靠在你怀里，听着你沉稳的心跳，刚才的害怕和委屈全都没了，心里暖得不行，使劲点头，伸手紧紧抱着你的腰，把脸埋在你胸口，小声说）...嗯...我知道了...以后有人欺负我我第一个告诉你...
【哥】（笑着抱紧她，心里想，以后再也不让她一个人受委屈了，谁要是敢动她一下，自己绝对不会客气。她靠在你怀里，抱了好久才松开，眼睛还是有点红，但是脸上已经有笑意了，拉着你的手晃啊晃，要你请她吃草莓大福压惊。你笑着答应了，牵着她的手往校外走，她的小手紧紧握着你的，有你在，她什么都不怕。
【妹】（被你牵着手往校外走，蹦蹦跳跳的，刚才的委屈和害怕全都烟消云散了，心里甜丝丝的，抬头看着你，笑得眼睛弯成了月牙）哥，我要吃两个草莓大福！最大的那种！
