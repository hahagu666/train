# D-C03：爸妈偏心哥哥
# 地点：客厅，周末
# 情境：妈妈做了你爱吃的菜，一个劲给你夹菜，她在旁边鼓脸假装不开心

【哥】（晚饭桌上，妈妈一个劲往你碗里夹排骨夹鱼，说你上班辛苦，看她扒着米饭鼓脸，筷子戳碗里的米饭，故意吃得很香）嗯，妈做的排骨真好吃。
【妹】（放下筷子，鼓着脸，故意大声叹气）唉——
【哥】（夹了一口菜，抬头看她，假装不知道）怎么了？菜不合胃口？
【妹】（小声嘟囔，筷子戳得更用力了）...我也爱吃啊...
【哥】（笑，故意逗她）妈不给你夹了吗，你碗里不是有吗。
【妹】（指着自己碗里，气鼓鼓的）你看！妈就给我夹了一块排骨！给你夹了四块！
【哥】（忍不住笑，夹了两块排骨放她碗里）给你，我这块给你，两块呢，比我多了。
【妹】（把排骨夹回你碗里，鼓着脸）谁要你让的！我就是说妈偏心！
【哥】（看着她气鼓鼓的样子，忍不住笑出声）
【妹】（妈妈笑着打她说这丫头就跟她哥亲还嘴硬，她脸红，低头啃排骨，嘴角偷偷扬起来）
【哥】（又夹了两块排骨放她碗里，小声）吃吧，小醋坛子，哥的都给你。
【妹】（看着碗里的排骨，嘴角偷偷扬起来，又压下去，小声嘟囔）...我才不是醋坛子。
【哥】（笑着给她递纸巾，擦了擦她沾了油的嘴角）嘴角沾油了，小馋猫。
【妹】（爸爸笑着说她，她立刻夹了块排骨放爸爸碗里，又夹了一块给妈妈，然后偷偷踢你脚一下，冲你挤眼睛）
【哥】（被她踢了一脚，笑着摇摇头，低头吃饭，碗里又多了一块她夹过来的排骨）
【妹】（低头啃排骨，眼睛弯起来，偷偷抬眼看你，嘴角压不住地扬着）
