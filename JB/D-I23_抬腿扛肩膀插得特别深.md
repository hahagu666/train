# D-I23：把她腿扛在肩上插得特别深
# 地点：你床上
# 情境：你把她的腿抬起来扛在肩膀上，这个姿势插得特别深，她喊太深了

【哥】（你压在她身上做了一会，她腿环着你的腰，你把她的一条腿抬起来，扛在肩膀上，她愣了一下看着你。）宝贝，换个姿势。
【妹】（你突然把她的腿抬起来扛在肩上，她的身体被折起来，小穴穴口一下子被拉紧，她看着你，脸红了，有点紧张。）哥...你干嘛...这个姿势好奇怪...
【哥】（你扶着肉棒对准她穴口，慢慢顶进去，因为她腿被抬起来折着，穴口比平时高，你一进去就直接顶到最深处，比平时深好多，你自己都闷哼一声。）唔...好深...
【妹】（啊！！太深了！！她尖叫出声，一下子绷紧身体，手抓着床单，眼睛都瞪大了，眼泪一下子出来了，不是疼，是涨得太满了，肉棒直接抵在她宫颈上，动一下都麻。）哥...拔出来一点...太深了...顶到我肚子里了...
【哥】（你没拔出来，反而停在那里，吻她的眼泪，在她耳边说。）不深，刚刚好，都进去了。
【妹】（太...太满了...她哭着摇头，但是小穴紧紧裹着你，一点都没有往外推的意思，反而在收缩吸你，她咬着嘴唇，声音发颤。）动...你慢慢动...别那么深...
【哥】（你开始慢慢抽动，每次都全部插到底，顶到她最里面，她每次都啊的叫一声，这个姿势实在太深了，每一下都能顶到她G点和宫颈。）嗯...这样才舒服。
【妹】（啊...啊...哥...对...就是那里...她很快就受不了了，奶子被你压着，腿在你肩膀上，整个人被你折成两半，小穴被你撑得满满的，快感比任何时候都强烈，她哭着抱你。）好舒服...太深了...我要到了...
【哥】（你加快速度，每一下都重重顶在她最深处，手揉着她的阴蒂。）快到了...叫出来。
【妹】（啊...我不行了...来了...哥...她身体猛地弓起来，小穴剧烈收缩，高潮来得特别猛烈，她直接哭出来，叫得声音都哑了，身体抖了好半天都停不下来。）啊...！
【哥】（她高潮的时候小穴死死咬着你，你也忍不住了，腰一挺，插得更深，全部精液射在她宫颈口，她又抖了一下，啊的一声叫出来。）射了...宝贝好紧。
【妹】（你射完趴在她身上，两个人喘了半天，你把她的腿放下来，她腿都麻了，瘫在床上，动都动不了，连哭的力气都没有，眼睛水汪汪的看着你。）你差点把我弄死...太深了...
【哥】（你笑着吻她，帮她揉腿。）舒服吗？
【妹】（她脸红了，捶了一下你的胸口，但是往你怀里钻，小声说。）...舒服...下次还这样...但是你轻一点...
【哥】（你抱紧她，笑着说。）好。
【妹】（她腿还麻着，动都动不了，只能窝在你怀里，手指戳着你的胸口，眼睛水汪汪的瞪了你一眼但是一点威慑力都没有，声音黏黏的。）那你现在抱我去洗澡...我腿麻了走不动...都怪你...
