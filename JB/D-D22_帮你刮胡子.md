# D-D22：帮你刮胡子
# 地点：卫生间，周日早上
# 情境：你在洗脸，她凑进来看着你涂剃须泡沫，好奇要帮忙

【哥】（周日早上站在卫生间镜子前，热水洗完脸，挤了剃须泡沫在手心抹开）
【妹】（穿着睡衣睡眼惺忪地推门进来，靠在门框上看你，头发乱蓬蓬的）哥...你在干嘛？
【哥】刮胡子，没看见？
【妹】（凑过来，站你旁边盯着镜子里你脸上白花花的泡沫，手指戳了戳你下巴的泡沫）软乎乎的...
【哥】别戳，弄你手上了。
【妹】（手缩回去，但是眼睛一直盯着你手里的剃须刀，看你刮了两下）哥...我帮你刮好不好？
【哥】你？（看了她一眼）你会吗，别给我刮破了。
【妹】（立刻鼓起脸，伸手抢你手里的剃须刀）我会！看着很简单嘛！就是这样...（伸手比了个刮的动作）从上往下对不对？
【哥】（被她把剃须刀抢过去，无奈地低头）那你小心点，刮破了相你负责。
【妹】（眼睛一下子亮了，站到你面前，仰着头仔细看你的脸，手指轻轻摸着你胡茬的位置）这里...还有这里...
【哥】（低头看她认真的样子，睫毛长长的，呼吸都放轻了，手举着剃须刀有点抖）
【妹】（小心翼翼地把剃须刀贴到你脸上，慢慢刮，刮一下就凑到镜子跟前看一眼）
【哥】（忍着笑，她太专注了，眉头都皱起来，舌头微微抵着嘴角）你慢点儿，下巴这儿。
【妹】（按照你说的刮下巴，手稳了一点，刮完左边又刮右边，刮完了凑到跟前来回检查）
【哥】（洗了把脸，照镜子看了看，还真没刮破）
【妹】（紧张地站在旁边，手里还攥着剃须刀，看你照镜子，小声问）怎么样...有没有刮破？
【哥】（摸了摸下巴，滑溜溜的，转头看她紧张得手指都绞在一起）不错啊，比我自己刮得干净。
【妹】（眼睛一下子亮了，开心得蹦了一下，剃须刀差点掉地上）真的吗！我就说我会！（把剃须刀洗干净放好，凑过来摸你下巴）滑溜溜的...
【哥】（笑着弹她脑门）那以后每周日都交给你了。
【妹】（摸着被弹的额头，但是笑得特别开心，凑过来又摸了摸你光滑的下巴，指尖蹭过你下颌线，耳朵红红的，小声说）好啊...以后我都帮你刮...（踮起脚，在你刚刮干净的下巴上轻轻亲了一下，然后立刻红着脸转身跑出去了，跑到门口还回头看了你一眼，嘴角翘得老高）
