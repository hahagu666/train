# D-H10：舔完小穴接吻精液淫水混合
# 地点：你床上
# 情境：你帮她舔完她帮你口完，两个人接吻，嘴里有精液和淫水的味道混在一起

【哥】（你帮她舔到高潮，她瘫在床上大口喘气，你抬起头，下巴上全是她的水。）
【妹】（高潮完，浑身还在轻轻发抖，看到你下巴上亮晶晶全是她的水，她脸红透了，但是心里甜甜的，伸手拉你，让你躺到她身边。）哥...你过来...
【哥】（躺到她身边，刚要说话，她主动捧住你的脸吻上来，舌头直接伸进你嘴里。）嗯...
【妹】（主动吻你，舌头和你的舌头缠在一起，她能尝到自己小穴水甜甜的味道，还有一点你嘴里的味道，她不仅不嫌弃，反而吻得更认真更投入，手抱着你的脖子。）嗯...
【哥】（和她深吻，能尝到她甜甜的味道，两个人的舌头缠在一起，交换着彼此的味道。）嗯...
【妹】（吻了半天，才松开你，喘着气，脸红扑扑的看着你，眼睛亮晶晶的，然后她往下缩，跪在你两腿之间，握住你硬邦邦的肉棒低下头含进去。）嗯...
【哥】（她这次含得特别深，舌头不停舔着，手配合快速套弄，另一只手揉着你的睾丸，比刚才更卖力了。）啊...舒服...
【妹】（含着你快速吞吐，舌头不停扫着冠状沟和系带，手快速套弄，揉蛋蛋的手也没停，刚才高潮过，她现在特别想让你也射出来，想让你舒服，吞吐的速度越来越快。）嗯...
【哥】（快感很快就上来了，肉棒在她嘴里跳个不停。）快了...
【妹】（感觉到你要射了，她抬起头看你一眼，眼睛水汪汪的，然后低下头，这次直接深含到喉咙口，紧紧夹着，等着你射。）嗯...射给我...
【哥】（你闷哼一声，腰一挺。）我要射了...
【妹】（你射在她喉咙里，她乖乖全部咽下去，等你射完，她没立刻抬头，还轻轻舔了半天龟头，把残留的精液都舔干净，才抬起头，嘴角亮晶晶的，这次她没擦嘴，直接爬上来捧住你的脸，再次吻住你的嘴唇。）嗯...
【哥】（她主动吻你，舌头伸进你嘴里，你能尝到她嘴里浓浓的精液味道，还有她刚才自己的甜味，两种味道混在一起，特别色情。）嗯...
【妹】（和你深吻，把你嘴里她的味道和她嘴里你的味道混在一起交换，吻了好久，才松开你，喘着气，趴在你胸口，脸红得像苹果，声音黏黏的。）哥...什么味道...
【哥】（搂着她，亲了亲她的额头。）你的味道甜甜的。
【妹】（听见你说甜，她笑了，在你胸口蹭了蹭，小声说。）你的也不讨厌...咸咸的...是哥的味道...我都喜欢...
【哥】（摸了摸她的头发。）嗯...
【妹】（抬起头，眼睛亮晶晶看着你，手指在你胸口画圈圈，过了半天，小声说。）哥...下次...你射在我嘴里之后直接吻我好不好...我喜欢...
【哥】（你笑着问她。）不脏吗？
【妹】（摇摇头，在你嘴唇上亲了一下，认真地说，说完又吻住你，软软的舌头和你缠在一起，两个人身上全是汗水和体液的味道，但是抱得特别紧，心里特别满足。）不脏...哥的什么都不脏...和你有关的我都喜欢...
