# D-C13：一个人在家害怕
# 地点：家里/电话，傍晚雷雨天
# 情境：你还在公司加班，外面下大暴雨打雷，她一个人在家给你打电话声音发抖

【哥】（公司加班，接到她电话，背景是哗哗的雨声和雷声）喂？怎么了这时候打电话？
【妹】（声音发抖）哥...
【哥】（听出她声音不对，立刻放下手里的工作）怎么了？哭了？
【妹】（声音带着哭腔）外面打雷...好吓人...爸妈去奶奶家了还没回来...
【哥】（看了一眼窗外，确实在打雷，闪电照亮天空）别怕，把电视打开，声音开大一点就听不到雷声了。
【妹】（声音抖）我开了...还是能听到雷声...刚才打了个特别大的雷，我房间灯都闪了一下...
【哥】（站起来开始收拾东西）你现在在哪？别躲被子里。
【妹】（小声）我躲在我房间被子里...不敢出去...
【哥】（拿上钥匙和伞）我马上回去，大概二十分钟，你别挂电话。
【妹】（声音立刻带点哭腔但是安心了一点）真的？你别骗我...
【哥】（往电梯走）不骗你，我现在就走，戴着耳机跟你说话。
【妹】（嗯了一声，能听到她裹被子的声音）...你到哪了？
【哥】（刚下楼，在打伞，雨很大）刚下楼，在打伞，雨有点大。
【妹】雨大不大？你小心点...别淋湿了...
【哥】（往小区门口走）知道了，你把房间灯都打开，别躲被子里，听话。
【妹】我不敢出去...
【哥】（笑，声音温柔）胆子这么小，以前打雷不都是我陪着你的吗。
【妹】（声音小小的）本来就怕打雷嘛...以前打雷都是你陪着我的...
【哥】（加快脚步）嗯，马上就到家陪你，再等一会。
【妹】（电话里安静了一会，她小声）...哥。
【哥】（已经到小区里了）嗯？我在。
【妹】你快点回来...
【哥】（跑上楼，掏钥匙开门）快了，到门口了。
【妹】（听到开门声，电话都没挂，从房间跑出来，扑到你怀里）哥！
【哥】（接住她，她衣服都湿了一点，头发也湿了，赶紧关上门把伞放好）回来了，不怕了啊。
【妹】（抱着你腰不撒手，脸埋你胸口，声音还在抖）你终于回来了...
【哥】（手轻轻拍她背，摸她头发，把她往怀里带）回来了，不怕了，哥在呢。
【妹】（抱得更紧，脸埋在你胸口，听着你的心跳，声音黏黏的还带着点后怕）...你身上都湿了...
