# D-G07：手伸进内裤摸她小穴
# 地点：你床上
# 情境：她让你伸进去摸，你的手第一次伸进她内裤，直接摸到她湿漉漉的小穴

【哥】（她让你伸进去，你看着她脸红得要滴血，眼睛水汪汪看着你，腿分开着。）
【妹】（咬着嘴唇，看着你，轻轻点了点头，声音小得像蚊子叫。）嗯...你...你轻一点...我害怕...
【哥】（手顺着她内裤的腰边，慢慢伸进去，指尖刚碰到她卷曲的毛发，她就抖了一下。）嗯...
【妹】（感觉到你的手伸进内裤，碰到那里的毛，她身体猛地一僵，紧紧闭上眼睛，手抓着床单，呼吸都停了。）啊...
【哥】（手指继续往下探，终于碰到了她湿透的小穴，滑溜溜的，全是水，嫩得像水做的一样。）湿...
【妹】（啊！你的手指刚碰到她小穴的花瓣，她就叫出来，眼泪一下子流出来，身体抖得像筛糠，声音哽咽着。）啊！哥...烫...你的手好烫...
【哥】（整个手掌覆上去，能感觉到她饱满的阴唇，软软的，滑溜溜的，被水完全打湿了，你手指轻轻顺着阴唇缝摸了一下。）软...
【妹】（被你一摸，她腰猛地往上挺，紧紧咬住枕头，怕声音太大被隔壁爸妈听见，身体软得一塌糊涂，腿不自觉张得更开。）嗯...啊...
【哥】（摸到她小小的阴蒂，硬硬的凸起来，藏在阴唇包皮里面，你手指轻轻碰了一下。）这里？
【妹】（那里！她尖叫一声，又赶紧捂住嘴，眼泪顺着脸颊往下流，身体弓得像只虾，那股快感太强烈了，她连气都喘不上来，声音发黏发颤。）啊...那...那里...别碰...太舒服了...我...我要死了...
【哥】（手指停在阴蒂上，没敢动，能感觉到她小穴在一阵阵收缩，一股股水流出来。）嗯...
【妹】（喘了半天，快感稍微退下去一点，她睁开水汪汪的眼睛，看着你，脸红得像熟透的苹果，主动把你的手指往下按，声音带着哭腔的撒娇。）下面...哥...手指...伸进去一点点...好不好...里面空得难受...
【哥】（顺着她的意思，手指尖对准她湿滑的穴口，轻轻往里顶了一下，很紧，非常紧，嫩肉紧紧吸着你的指尖。）紧...
【妹】（啊...疼...她皱起眉头，小声叫出来，但是没让你停，反而腰轻轻往下沉，让你的手指进去得更多一点，眼泪流下来，但是眼神里是渴望，声音黏黏的。）啊...胀...好胀...但是...不疼了...你...你再进来一点...
【哥】（慢慢把一根手指插进去，她里面又热又紧，嫩肉层层叠叠裹着你的手指，还在不停吸吮收缩。）嗯...
【妹】（你的手指整个插进去，她长长地舒了一口气，紧紧抱着你，身体不停发抖，里面紧紧夹着你的手指，感觉涨涨的，满满的，但是特别舒服。）嗯...哥...动...你动一动...
【哥】（手指在她里面轻轻动了一下，抽动了半寸。）这样？
【妹】（啊...她立刻呻吟出来，快感从里面传上来，比碰阴蒂还舒服，她主动扭着腰配合你的动作，水哗哗流出来，把床单都打湿了一片，声音断断续续的。）啊...哥...好舒服...就是这样...再快一点...
【哥】（看着她满足又舒服的样子，手指在她紧致湿热的小穴里慢慢抽插起来，时不时蹭一下她敏感的阴蒂。）嗯...
【妹】（被你插得爽到不行，嘴里不停发出黏黏糊糊的呻吟，紧紧抱着你，指甲掐进你后背，水流得越来越多，里面紧紧吸着你的手指，她从来没有这么舒服过，过了一会，她身体猛地绷紧，尖叫一声，一股热流喷出来，高潮了，软在床上大口喘气，连眼睛都睁不开了。）啊...哥...我...
