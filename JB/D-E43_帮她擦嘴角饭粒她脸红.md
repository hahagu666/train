# D-E43：帮她擦嘴角饭粒她脸红
# 地点：家里餐厅，吃早饭
# 情境：她吃果酱面包，嘴角沾了一大块果酱自己不知道，你伸手帮她擦掉，她瞬间脸红

【哥】（早上一起吃早饭，她吃果酱面包吃得特别开心，狼吞虎咽的，嘴角沾了一大块草莓果酱，红红的，在脸上特别明显，她自己还不知道，正伸手去拿牛奶）
【妹】（拿起牛奶喝了一大口，嘴角的果酱沾到了牛奶杯口，她还是没发现，嚼着面包，眼睛亮晶晶的看着你，跟你说昨天学校里的趣事，说得特别开心，手舞足蹈的）我们班昨天有个男生上课睡觉，流了一桌子口水，被老师叫起来回答问题，他站起来还吧唧嘴，全班都笑疯了！
【哥】（听她说着，但是眼睛一直看着她嘴角那块红红的果酱，忍不住笑了，伸手过去，拇指轻轻擦过她的嘴角，把果酱擦掉）
【妹】（正说到兴头上，突然被你碰到嘴角，整个人一下子僵住了，话也说不出来了，眼睛睁得圆圆的看着你，脸瞬间从耳朵尖红到脖子根，手里的牛奶杯差点掉在桌子上）
【哥】（把擦了果酱的拇指在纸巾上擦干净，看着她僵在那里脸红得像熟透的苹果，忍不住笑了）嘴角沾果酱了，小馋猫。
【妹】（这才反应过来，赶紧伸手摸自己的嘴角，摸了个空，脸更红了，头埋得低低的，对着面包片，半天不敢抬头，耳朵红得都要滴血了，声音小小的，像蚊子叫）我...我自己没感觉到...
【哥】（看着她脸红成这样，连脖子都红了，觉得特别可爱，故意逗她，伸手又轻轻碰了碰她的嘴角）这里还有一点。
【妹】（被你一碰，整个人抖了一下，差点从椅子上跳起来，脸更烫了，头埋得更低，都快埋到盘子里了，声音小小的，带着点慌乱又有点撒娇）你...你别碰...我自己来...（她伸手拿纸巾胡乱擦嘴角，擦了半天其实已经擦干净了，但是她还是擦个不停，手都有点抖）
【哥】（笑着把她手里的纸巾拿下来，看着她红透的脸，眼睛水汪汪的，像受惊的小兔子）好了，擦干净了，脸怎么红成这样。
【妹】（抬起头看你，眼睛水汪汪的，脸红扑扑的，嘴唇因为刚才擦嘴巴有点红，润润的，过了半天才憋出一句）你...你突然伸手过来...吓我一跳...（她嘴上这么说，但是嘴角偷偷往上扬，刚才被你碰过的嘴角烫烫的，心跳快得不行，咚咚咚的，自己都能听见，面包也忘了吃，就那么看着你，脸红红的）
【哥】（看着她这副害羞的样子，觉得特别可爱，把牛奶递到她手里）快喝，牛奶都凉了。
【妹】（接过牛奶，小口喝着，但是眼睛一直偷偷看你，嘴角的温度一直没退下去，心跳还是快得不行，喝了两口牛奶，突然小声说）其实...其实你帮我擦也没关系...（她说完立刻低下头，脸埋在牛奶杯后面，耳朵红得要滴血，但是嘴角一直扬着，心里甜丝丝的，比刚才吃的果酱面包还甜）
