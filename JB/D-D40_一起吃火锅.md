# D-D40：一起吃火锅
# 地点：家里餐厅，冬天晚上
# 情境：爸妈不在家，你俩煮火锅吃，她辣得直吸气还要吃

【哥】（冬天晚上爸妈不在家，你在厨房煮火锅底料，香气飘满整个屋子，她闻着味就跑过来了）
【妹】（趴在厨房门口看，馋得直咽口水，鼻子动来动去像小狗一样）好香啊！可以吃了吗！我都快饿死了！
【哥】（把煮好的锅底端到餐厅电磁炉上，菜和肉都摆好了，肥牛卷、羊肉卷、虾滑、土豆片、娃娃菜摆了一桌子）急什么，水还没开。
【妹】（已经坐好了，筷子拿在手里，眼睛盯着锅，水一开她立刻下了半盘肥牛卷）熟了熟了！可以吃了！
【哥】（笑着给她捞了一筷子肉，她蘸了麻酱大口吃，烫得直吸气，还是咽下去了）慢点吃，没人跟你抢。
【妹】（嘴里塞满肉，鼓着脸像小松鼠，含糊不清地说）太好吃了...（又下了几个虾滑）哥你吃这个！虾滑我最爱吃了！
【哥】（她忙着下菜，自己没吃几口，一直在给你捞，捞到肉就放你碗里，自己吃土豆片）你自己多吃点，别光给我夹。
【妹】（摇摇头，又给你夹了一筷子羊肉，眼睛亮晶晶的，脸上被热气熏得红红的，鼻尖上都是汗）你上班辛苦！多吃点肉！（她夹了个丸子咬了一口，结果太烫，吸着气张着嘴哈气）好烫好烫！
【哥】（给她倒了杯冰可乐递过去，她接过去咕咚咕咚喝了两大口，打了个可乐嗝，脸一下子红了）
【妹】（不好意思地摸了摸头，但是还是继续吃，吃到一半她跑去厨房拿了瓶剁椒酱，挖了一大勺放自己碗里）
【哥】你不是不能吃辣吗？
【妹】（逞强地撇撇嘴）谁说我不能吃！我现在能吃辣了！（她夹了片肉蘸了剁椒，放进嘴里嚼了两下，脸瞬间红了，辣得直吸气，眼泪都快出来了，张着嘴哈气）好辣好辣好辣！
【哥】（笑着给她递可乐，又给她夹了块娃娃菜让她解辣）不能吃还逞强。
【妹】（喝了半杯可乐，舌头伸得长长的，眼泪汪汪的，嘴唇辣得红红的，但是还是不死心，又夹了一筷子）就...就是有点辣！我能行！（结果刚吃一口又辣得直跺脚）
【哥】（把她面前的剁椒酱拿走，换了碗麻酱给她）老老实实吃麻酱的，等你学会吃辣了再说。
【妹】（鼓着脸，但是没反抗，用麻酱蘸肉吃，嘴唇还是红红的，鼻尖上全是汗，头发被热气熏得乱蓬蓬的，但是吃得特别开心，吃到最后两个人都撑得靠在椅子上，锅里还有点菜，谁都吃不下了）
【哥】（看着她撑得摸肚子，嘴角还沾着麻酱，像只小花猫）吃饱了？
【妹】（点点头，打了个小小的饱嗝，脸一下子红了，赶紧捂住嘴，眼睛偷偷看你，看你没笑她才松了口气）好撑...下次我还要吃火锅...
【哥】下次周末再煮。
【妹】（眼睛一下子亮了，凑过来拉你的手，她的手因为吃火锅热乎乎的，嘴角还沾着麻酱，脸红扑扑的，被热气熏得眼睛水汪汪的）下次我要买好多好多肥牛卷！还有毛肚！还有鸭肠！（她顿了顿，小声说）下次...下次你别放那么多辣...（说完她自己先笑了，凑过来在你脸上亲了一下，沾了你一脸麻酱香味，然后红着脸跑去拿纸巾，回来的时候给你擦脸，手指细细的，擦得特别认真，热气在窗户上凝出一层水雾，外面是冬天的冷风，屋子里暖乎乎的，火锅咕嘟咕嘟冒着泡，全是香气）
