# D-B24：上课说话被老师罚站你在窗外陪她
# 她上课跟同桌说话被老师抓到，罚站在教室后面，她委屈得快哭了，你下课路过趴在窗外冲她做鬼脸陪她站着
# 地点：学校教室/走廊，上课/下课

【哥】（下课你们班拖堂，晚放了十分钟，你路过她们班教室）
【妹】（历史课跟同桌说昨天看的漫画，说得太投入没发现老师走到身边，老师敲了敲她的桌子，她吓了一跳，站起来脸都白了。老师让她站到教室后面去，罚站一节课，她磨磨蹭蹭走到教室后面站着，头埋得低低的，眼泪在眼眶里打转，觉得特别丢人）
【哥】（往里面扫了一眼，一眼就看见她站在教室最后面，靠着墙，头埋得低低的，肩膀缩着，眼眶红红的，明显是被罚站了。你觉得好笑，就没走，靠在窗外走廊上看着她）
【妹】（站在教室后面，特别丢人，全班同学都坐着就她一个人站着，脸烧得慌，眼睛盯着鞋尖，恨不得找个地缝钻进去。突然感觉窗户外面有人影，抬头一看，你趴在窗台上冲她笑，还做了个鬼脸，她一下子就愣了，脸"唰"地更红了，赶紧瞪你一眼，用口型说"你快走！"）
【哥】（不仅没走，反而靠在窗台上，冲她挤眉弄眼，还学她被罚站的样子，把背贴在墙上，故意做出一副委屈的表情）
【妹】（她看见你学她，忍不住"噗嗤"一声笑出来，又赶紧捂住嘴，怕老师看见，瞪你一眼让你别闹，但是眼睛里的眼泪已经没了）
【哥】（站了十分钟就看见她偷偷换脚，你在窗外冲她比了个"加油"的手势，还从口袋里掏出一颗草莓糖，举起来给她看，意思是下课给她吃）
【妹】（她看见糖，眼睛一下子亮了，偷偷冲你点了点头，站得也直了，也不觉得丢人了，反正有你在外面陪着她，罚站好像也没那么难受了）
【哥】（就这么在窗外陪她站了整整一节课，老师在上面讲课，你在外面冲她做鬼脸，给她比手势，她站在里面，偷偷跟你互动，一会儿笑一会儿瞪你，一开始的委屈和丢人全没了，甚至觉得罚站还挺有意思的。下课铃响了，老师一说下课，她第一个就往教室外面跑）
【妹】（跑出教室，扑到你面前，脸还是红的，但是已经不委屈了，捶了你胸口一下，又羞又笑）你讨厌！你怎么不早走啊！被我们老师看见怎么办！你还做鬼脸！我都快笑出声了！
【哥】（笑着躲开，把那颗草莓糖递给她，她接过去剥开吃了，甜甜的草莓味在嘴里散开。你揉了揉她的头发，弹了她脑门一下）我要是走了，我们小丫头一个人站在后面哭鼻子怎么办？我不得在外面陪着你啊？
【妹】（脸更红了，低下头踢小石子，嘴里含着糖，含糊不清地说）谁...谁哭鼻子了...我才没哭呢...就是有点丢人而已...你还学我...你学得一点都不像...
【哥】（忍不住笑出声，牵着她的手往小卖部走，她乖乖跟在你身边，含着糖，刚才罚站的窘迫全没了，蹦蹦跳跳的，好像刚才罚站的人不是她一样。你给她买了冰棒，她咬了一口冰棒，凉丝丝的）
【妹】（咬着冰棒，突然抬头看你，眼睛亮晶晶的，小声问）哥...你刚才真的在外面站了一节课啊？你们班不下课吗？
【哥】（笑着咬了一口自己的冰棒，点点头，说）我们班拖堂，我下课就看见你站在那儿了，当然要陪着你，总不能让你一个人站着啊，多孤单。
【妹】（听你这么说，心里暖乎乎的，咬着冰棒，脸红红的，往你身边靠了靠，小声说）...其实...你在外面陪着我...我就不觉得丢人了...一开始我都快哭了...看见你做鬼脸我就忍不住想笑...就不难过了...
【哥】（揉了揉她的头发，笑着说）那以后你要是再被罚站，我就还在窗外陪着你，给你带糖，陪你站着，好不好？
【妹】（赶紧摇摇头，鼓着脸说）谁要再被罚站啊！我以后上课再也不说话了！太丢人了！但是...但是要是我真的再被罚站...你一定要来陪我啊...
【哥】（笑着点头，牵着她的手往回走，夏天的风一吹，特别舒服）
【妹】（走到教室门口，上课铃响了，她赶紧跑进去，跑了两步又回头，冲你挥挥手，笑得眼睛弯成了月牙，嘴里还含着糖，腮帮子鼓鼓的像只小仓鼠）
