# D-B27：忘带饭卡她在食堂门口急得转圈圈
# 中午去食堂吃饭她发现饭卡落在教室了，回教室拿发现门锁了，急得在食堂门口转圈圈，你刚好打饭出来看见她
# 地点：学校食堂，中午放学

【哥】（刚打好饭找了个位置坐下，抬头往食堂门口看）
【妹】（中午放学冲到食堂，掏口袋掏了半天，饭卡不见了，想起来早上换校服落在教室桌子上了，赶紧跑回教学楼，结果教室门锁了，同学们都去吃饭了，她又跑回食堂，站在食堂门口转圈圈，肚子饿得咕咕叫，急得快哭了）
【哥】（一眼就看见她站在门口，背着书包转圈圈，脸皱成一团，像只找不到食物的小兔子，一看就是没带饭卡。你笑着摇了摇头，端着餐盘走过去）
【妹】（摸了摸口袋，一分钱现金都没带，手机也放在教室充电了，认识的同学都已经打好饭在吃了，她不好意思借饭卡，站在门口进不去，肚子饿得"咕咕"叫，委屈得鼻子都酸了，心想今天中午要饿肚子了）
【哥】（走到她身后，弹了她脑门一下）
【妹】（她吓了一跳，回头看见是你，眼睛一下子就红了，委屈巴巴地看着你）
【哥】怎么站在门口不进去吃饭？又忘带饭卡了？
【妹】（看见你，鼻子一酸，差点哭出来，点点头，声音小小的带着委屈）嗯...我饭卡落在教室了...教室门锁了...我一分钱都没带...手机也在教室...我进不去...
【哥】（忍不住笑了，揉了揉她的头发，把自己手里的餐盘塞到她手里，餐盘里有她最爱吃的糖醋排骨和番茄炒蛋，都是她喜欢的菜）傻丫头，不会过来找我啊？站在门口转圈圈就能转出饭来？走，我饭卡借你，再去打两个菜。
【妹】（接过餐盘，闻着糖醋排骨的香味，肚子叫得更响了，但是还是有点不好意思，小声说）那...那你吃什么啊...
【哥】（牵着她的手走到窗口，刷自己的饭卡又给她打了一份可乐鸡翅和一杯热牛奶，把她领到位置上坐下，自己坐在她对面，笑着说）我吃过了，这些都是给你打的，快吃吧，看你饿的，肚子都叫得我都听见了。
【妹】（看着一桌子都是她爱吃的菜，眼睛一下子就亮了，但是还是有点不好意思，拿起筷子小口小口吃排骨，吃了两口，抬头看你，小声说）你真的吃过了吗？你别骗我...我们一起吃好不好？这么多我吃不完...
【哥】（笑着夹了一块排骨放到自己嘴里，说"你看我这不是吃了吗，你多吃点，早上就没吃多少，中午肯定饿坏了"）
【妹】（她这才放心，大口大口吃起来，吃得腮帮子鼓鼓的像只小仓鼠，吃得特别香）
【哥】（她吃着吃着，突然想起什么，抬起头看你，嘴里还塞着饭，含糊不清地问）哥...你怎么知道我没带饭卡啊？你怎么打了这么多我爱吃的菜？
【妹】（看着你，等你回答）
【哥】（笑着递了张纸巾给她擦嘴，说"我刚坐下就看见你站在门口转圈圈，看你那可怜样就知道肯定是忘带饭卡了，我还不知道你？丢三落四的，哪天不带点东西落家里或者教室"）
【妹】（鼓着脸，有点不好意思，但是心里暖乎乎的，低下头继续吃饭，把一块最大的可乐鸡翅夹到你碗里，小声说"给你吃最大的，谢谢你给我打饭，不然我今天中午就要饿肚子了"）
【哥】（笑着吃掉鸡翅，看着她吃得香的样子，特别有成就感。她吃饭的时候嘴角沾了点饭粒，你伸手帮她擦掉，她脸一下子红了，但是没躲开，冲你笑了笑，继续低头吃饭）
【妹】（吃饱喝足，摸着圆滚滚的肚子，打了个小小的饱嗝，脸一下子红了，赶紧捂住嘴，不好意思地看着你）
【哥】（你被她逗笑了，递给她热牛奶让她喝）
【妹】（她喝着牛奶，小声说"哥，你对我真好"）
【哥】（揉了揉她的头发，笑着说"不对你好对谁好？下次再忘带饭卡就直接来我班找我，不许自己站在门口饿肚子，知道吗？多大的人了，还能把自己饿到"）
【妹】（乖乖点头，喝着牛奶，眼睛亮晶晶的看着你，突然想起什么，从口袋里掏出一颗草莓糖递给你，是你上次给她的，她一直没舍得吃，"给你吃糖，下次我一定记得带饭卡，再也不丢三落四了"）
【哥】（接过糖，剥开糖纸塞进嘴里，草莓味甜甜的，跟她一样甜）
【妹】（下午放学她蹦蹦跳跳跑过来找你，手里举着两个草莓大福，递一个给你，说"用剩下的利息买的，给你吃"，你接过大福咬了一口，甜甜的豆沙和草莓在嘴里散开，她笑得甜甜的像只开心的小松鼠）
