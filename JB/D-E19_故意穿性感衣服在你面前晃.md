# D-E19：故意穿性感衣服在你面前晃
# 地点：你房间，周末下午
# 情境：她偷偷买了件有点露的吊带裙，穿上来你房间晃来晃去，想看看你反应又不好意思

【哥】（周末下午你在房间看书，门没关，听见脚步声，抬头看见她站在门口，穿了件你从没见过的黑色吊带裙，裙摆很短，露出肩膀和锁骨，头发还特意披散着）进来啊，站门口干嘛。
【妹】（磨磨蹭蹭走进来，手不知道放哪里，揪着裙边，脸有点红，但是故意装作不在意的样子，在你房间里走了两圈，假装看你书架上的书）我...我就是来拿本书。
【哥】（看着她穿成这样，耳朵上还戴了个小小的耳钉，平时都不戴的，明显是特意打扮过）拿书穿成这样？
【妹】（脸一下子红了，转过身背对你，假装找书，声音小小的）什么穿成这样...新买的裙子...我穿上试试合不合身...
【哥】哦，挺好看的。
【妹】（听见你说好看，立刻转过身，眼睛亮晶晶的，但是又装作不在意的样子，揪了揪裙摆，故意在你面前转了个圈）真的吗？（转完圈站在你面前，有点紧张地看你表情，手指绞着裙边）会不会...太短了？
【哥】（合上书看她，裙子确实短，大腿都露出来了，锁骨白白的，她脸红红的，明显是故意穿给你看的）是有点短，谁让你买这么短的裙子的。
【妹】（鼓着脸，走到你面前站着，离你很近，香水味淡淡的飘过来，她故意挺了挺胸，吊带很低，露出一点胸口）哪里短了！我们班好多女生都穿这么短的！
【哥】（伸手把她拉过来，她没站稳，坐到你腿上，脸一下子红透了，手撑在你胸口想起来又没真的起来）她们穿是她们的事，你不许穿这么短出去。
【妹】（坐在你腿上，眼睛水汪汪的看着你，呼吸有点快，裙子往上滑了一点，露出更多大腿，她故意凑得更近一点，声音发嗲）为什么不许...不好看吗...
【哥】好看，但是只能在家穿给我看。
【妹】（听见这句话，脸一下子红到脖子根，耳朵都烫了，但是嘴角偷偷往上扬，手勾住你的脖子，故意在你腿上蹭了一下，声音小小的像蚊子叫）那...那我只穿给你看...（她低头看你，睫毛忽闪忽闪的，嘴唇粉润润的，离你很近，呼吸都喷在你脸上）那...你要不要摸摸看...料子很滑的...
【哥】（看着她红透的脸，明明是她故意穿来勾引你，自己反倒先害羞得不行，手抓着你的衣领，眼睛湿漉漉的像小兔子）
【妹】（等了半天见你没动，她有点急了，又有点不好意思，鼓着脸把你手放到她腰上，吊带裙的料子确实滑溜溜的，她腰细细的，皮肤烫得吓人）你摸啊...（她声音发颤，耳朵红得要滴血，但是还是硬撑着看着你，吊带从肩膀滑下来一点，她也没拉上去，就那么看着你，脸红得像熟透的苹果，心跳得咚咚快，你都能感觉到）
