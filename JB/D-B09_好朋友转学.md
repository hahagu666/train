# D-B09：好朋友转学
# 地点：她房间，晚上
# 情境：她最好的朋友要转学去外地，她回来眼睛肿的，坐在床上抱着玩偶不说话

【哥】（推开门，看到她坐在床上，抱着兔子玩偶，眼睛红红的，桌上放着一张同学录）怎么了？眼睛怎么肿了？
【妹】（抬头看你，声音哑哑的）...小雅要走了。
【哥】你那个闺蜜？
【妹】（点头，眼泪又掉下来）她爸妈工作调去外地了，她也要转过去...下学期就不来了...
【哥】（走过去坐她旁边）什么时候的事？
【妹】（擦眼泪）今天她告诉我的...我们俩从初中就是好朋友...（声音哽咽）她走了就没人陪我去食堂吃饭了...
【哥】（摸她头）又不是见不到了，现在微信视频那么方便。
【妹】（摇头）不一样...她不在学校了...（抱玩偶抱得更紧）我们还约好一起考同一个城市的大学来着...
【哥】（拍拍她背）以后考到一个城市不就行了。
【妹】（吸鼻子）她说她不知道会分到哪个省...可能很远...
【哥】（没说话，陪她坐着）
【妹】（靠在你肩膀上，眼泪蹭你衣服上）哥...你以后会不会也走啊...
【哥】（愣了一下）我去哪？
【妹】（声音很小）...你以后毕业了会不会去别的城市工作...不回来了...
【哥】（揉她头发）想什么呢，你去哪我去哪。
【妹】（抬头看你，眼泪还挂在脸上）真的？
【哥】真的。等你考上大学，我就在那边找工作，周末带你去吃好吃的。
【妹】（听完，眼泪掉得更凶了，但嘴角扬起来了）...嗯。
【哥】（给她递纸巾）别哭了，明天她最后一天上学吧？给她带点她爱吃的。
【妹】（接过纸巾擦眼泪，点头）嗯...我明天把那个小熊笔袋送给她...就是她上次说喜欢的那个。
【哥】好。
【妹】（靠你肩膀上，慢慢不哭了）...哥，你别走。
【哥】不走，一直陪着你。
【妹】（听到你这么说，紧紧抱着你的胳膊，把脸埋在你肩膀上，小声地"嗯"了一声，眼泪蹭在你衣服上，但是心里踏实多了）
