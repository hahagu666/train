# D-K05：她熬夜看漫画你没收她手机
# 明天要上学，她躲在被窝里熬夜看漫画到两点，被你抓包，你没收她手机，她委屈巴巴跟你撒娇要手机

【哥】（半夜两点起来喝水，看见她房间门缝还透着光，皱起眉头走过去，轻轻推开门。她躲在被窝里，被窝一鼓一鼓的，还亮着手机光，时不时还传出憋笑的声音）
【妹】（正看到精彩的地方，躲在被窝里憋笑，笑得肩膀都抖，完全没发现你进来了，直到你把被子一下子掀开，她吓了一跳，手机"啪"一声砸在脸上）啊！！
【哥】（站在床边，双手抱胸看着她，她捂着脸，手机掉在枕头上，屏幕还亮着，正是漫画页面，你挑了挑眉）几点了？还不睡觉？
【妹】（看见是你，吓得脸都白了，赶紧把手机往背后藏，坐起来靠在床头，头发乱蓬蓬的，眼神躲躲闪闪，声音小小的）...我...我马上就睡...我就看了一会儿...
【哥】（伸手）手机拿过来。
【妹】（把手机往背后藏得更深了，鼓着脸，可怜巴巴地看着你，摇了摇头）不要...我明天还要定闹钟起床呢...没有手机我起不来...
【哥】（不理她，伸手到她背后把手机拿过来，按了一下，她手机还没锁屏，漫画看到最新一话，电量都快用完了，你看了眼时间，两点零五分。你皱着眉头把手机揣进兜里）我叫你起床，手机我没收了，周末再给你。
【妹】（看见你把手机拿走了，一下子急了，掀开被子跪坐在床上，伸手要抢，但是你举得高高的她够不着，急得眼眶都红了）哎！别！哥！我错了！我真的马上就睡！你把手机还给我好不好！我保证这一章看完就睡！
【哥】（把她按回被窝里，帮她盖好被子，态度很坚决）不行，这都两点了，明天还要上课，你上次熬夜看漫画，第二天上课睡着了被老师点名批评，忘了？
【妹】（被你按在被窝里，知道抢不回来，委屈得瘪了嘴，眼泪在眼眶里打转，拉着你的衣角晃啊晃，声音黏黏的撒娇）哥...我错了...我真的知道错了...你把手机还给我好不好...我就把这一章看完...就一章...看完立刻就睡...以后再也不熬夜了...
【哥】（坐在床边，帮她把额前乱掉的头发理好，语气稍微软了一点，但是还是很坚决）一章也不行，现在立刻闭眼睡觉。听话，不然周末我也不给你。
【妹】（看你态度坚决，知道没戏了，"呜"了一声，把被子蒙住头，在被子里小声嘀咕，声音闷闷的）...你坏...你欺负人...连漫画都不让我看...
【哥】（又好气又好笑，隔着被子轻轻拍了拍她）我欺负你？上次是谁熬夜看漫画看到三点，第二天早上起不来，迟到了半节课，哭着给我打电话让我帮她跟老师请假的？
【妹】（从被子里探出头，眼睛红红的，像只受了委屈的小兔子，但是还是嘴硬）...那是上次...这次我定了闹钟...不会迟到的...
【哥】（弹了她脑门一下，帮她把床头灯关掉）少来，闭眼睡觉，我看着你睡着再走。
【妹】（鼓着脸，不情不愿地闭上眼睛，但是翻来覆去睡不着，过了一会儿睁开一只眼睛偷偷看你，你还坐在床边看着她，她赶紧闭上眼睛，又过了一会儿，又睁开眼睛看你，小声说）...哥...你坐在这儿我睡不着...
【哥】（故意逗她）那我坐这儿陪你，直到你睡着为止，省得你等我走了又偷偷找手机看。
【妹】（鼓着脸，又翻了个身，背对着你，但是过了一会儿，声音小小的，发黏的传过来）...哥...我错了...我以后真的再也不熬夜看漫画了...你别生气好不好...
【哥】（叹了口气，其实根本没真生气，就是怕她熬夜对身体不好，你伸手轻轻帮她顺了顺头发，声音放柔了）我不生气，但是你熬夜对身体不好，第二天上课也没精神，万一再胃疼怎么办？嗯？
【妹】（转过身，眼睛亮晶晶的看着你，在黑暗里特别亮，她小声问）...那...那我以后每天晚上看半小时...看到十点半就睡觉...你不要没收我手机好不好...
【哥】（想了想，点点头，但是伸出一根手指）可以，但是说话算话，到点必须睡觉，要是被我发现偷偷熬夜，就再也不给你看了，听见没有？
【妹】（一下子眼睛就亮了，赶紧点头，开心得差点蹦起来）说话算话！我保证！每天十点半准时睡觉！
【哥】（笑着揉了揉她的头发）好，那快睡，手机我先帮你保管，明天早上给你。
【妹】（乖乖点头，闭上眼睛，这次很快就呼吸均匀了，看来是真困了。你帮她把被子掖好，轻轻带上门出去，心想这小丫头，下次还得盯着点）
