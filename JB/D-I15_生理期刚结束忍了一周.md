# D-I15：生理期刚结束忍了一周急着做
# 地点：你床上
# 情境：她生理期刚结束，忍了一周，两个人都特别想要，急急忙忙的

【哥】软软，你慢点...急什么。（她生理期终于结束了，晚上一到你房间，就直接扑上来吻你，手急急忙忙解你的裤子。）
【妹】（生理期终于结束了，忍了一周，一进你房间就扑到你怀里，吻你的嘴唇，手急着解你的皮带和裤子，呼吸急促，脸红扑扑的。）哥...我好了...姨妈走了...
【哥】（你抱着她，回吻她，手也急着脱她的衣服，两个人都忍了一周，硬得不行，她下面肯定湿透了。）这么急？小淫娃，忍了一周忍不住了？
【妹】（她脸红了，但是没反驳，急急忙忙脱掉自己的睡裙和内裤，连胸罩都没穿，直接扑到你身上，分开腿坐在你腰上，扶着你的肉棒就往自己穴口塞，声音黏黏的带着急色。）忍不住了...哥...快给我...我想要了一周了...
【哥】（她扶着你的肉棒，龟头刚碰到穴口她就往下坐，一下子全部吞进去，两个人同时闷哼一声，忍了一周，她小穴比平时紧多了，夹得你差点直接射出来。）嗯...好紧...
【妹】（啊...全部进来的时候她舒服得叫出声，一个星期没做，突然被撑得满满的，胀得她有点疼，但是更多的是舒服，她立刻开始自己动，上下起伏，急得不行，奶子在你眼前晃。）啊...哥...好满...太舒服了...
【哥】（你抱着她的腰帮她动，忍了一周，她里面又热又紧，淫水特别多，抽插起来咕叽咕叽响得厉害，你也急得不行，快速抽插。）慢点...别急...
【妹】（我不慢...她摇摇头，反而动得更快了，小穴紧紧裹着你的肉棒，一个星期没做，稍微动一下就特别敏感，她没动几下就开始喘气呻吟。）嗯...哥...我太敏感了...一动就麻...
【哥】（你翻个身把她压在下面，快速抽插，一周没做两个人都特别敏感，你吻着她的乳房，含住乳头用力吸吮，手揉着她的阴蒂。）唔...你的奶子还是这么软...
【妹】（啊...你动得太快太猛，她舒服得叫出声，手抓着你的背，指甲都掐进去了，腰抬得高高的配合你，小穴不停流水，把床单都弄湿了一大片。）啊...哥...对...就是那里...太快了...我要去了...
【哥】（你没停，继续快速抽插，揉着她阴蒂的手加快速度，她身体立刻绷紧了。）嗯...到我这里来...
【妹】（啊...！她高潮来得特别快，比平时快多了，小穴剧烈收缩，紧紧咬着你的肉棒，身体抖得像筛子一样，叫得特别大声，眼泪都出来了。）啊...哥...
【哥】（她高潮的收缩把你也夹得射了，你腰一挺，全部插到底，浓浓的精液射在她最里面，射得特别多，两个人同时颤抖。）啊...射了...
【妹】（你射在里面她又抖了一下，抱着你喘了半天，才软下来，两个人都出了一身汗，她靠在你怀里，小穴还在一缩一缩的，声音发颤。）好快...但是好舒服...
【哥】（你笑着吻她的额头，没拔出来，就这么插在她里面抱着她。）忍了一周，当然快，一会再来一次。
【妹】（她脸红了，往你怀里钻，腿环着你的腰，小声说。）嗯...今天晚上要三次...补回来...
【哥】（你笑了，捏了捏她的屁股。）好，三次就三次，喂饱你。
【妹】（她满足地笑了，吻你的嘴唇，小穴还在不自觉地收缩夹你的肉棒，她坏心眼地动了动腰。）那现在就第二次...
