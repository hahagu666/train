# D-H30：生日前一天她主动给你深喉
# 地点：你床上，她十八岁生日前一天晚上
# 情境：明天她就十八岁了，晚上她溜进你房间，说要提前给你个礼物，主动给你深喉

【哥】（明天就是她十八岁生日，晚上她溜进你房间，关上门，爬到你床上，脸红扑扑的看着你。）
【妹】（她坐在你旁边，小手放在你腿上，抬头看着你，眼睛亮晶晶的，脸红红的。）哥，明天我就十八岁了，是成年人了。
【哥】（你摸了摸她的头，笑着。）是啊，你长大了。
【妹】（她往你身边靠了靠，小手往下摸，摸到你裤子里硬起来的地方，抬头看着你，声音发颤。）所以...今天晚上，我想把全部都给你...但是先给你个礼物好不好？
【哥】（你看着她，她眼神很认真，你还没说话，她就已经跪下去，跪在你两腿之间。）你...
【妹】（她解开你裤子，把你硬邦邦的肉棒掏出来，握在手里，抬头对你笑了笑，这次她没犹豫，低下头，慢慢把嘴张得很大，一点点往下吞，比平时都深，一直到全部龟头都进喉咙。）嗯...
【哥】（龟头直接进到她喉咙深处，紧紧的暖暖的包裹着，比平时任何一次都深都紧，你舒服得闷哼出声，手轻轻摸着她的头发。）不用勉强...
【妹】（她摇摇头，嘴里含着肉棒没法说话，只是抬头看了你一眼，眼神很坚定，然后开始慢慢动，喉咙收缩夹着你的龟头，一只手握着阴茎没进去的部分快速套弄，另一只手轻轻揉着你的蛋蛋，动作比任何一次都熟练都认真。）呜...
【哥】（她这次真的全部吞下去了，喉咙紧紧夹着龟头，舌头在能碰到的地方不停舔着系带，手快速套弄，深喉的感觉太强烈了，你快感涨得飞快。）啊...舒服...
【妹】（她慢慢上下动着，这次真的做到了全吞，鼻子都碰到你阴毛了，每一下都到底，喉咙紧紧夹着龟头，口水顺着流下来，流到蛋蛋上，她也不在意，一直认真地动着，手一直配合着套弄揉蛋蛋。）嗯...哥...
【哥】（你看着她跪在你腿间，认真地给你深喉，眼睛都有点红了，但是一直坚持着，你心里又感动又舒服，摸了摸她的脸。）嗯...
【妹】（她能感觉到你肉棒跳得厉害，知道你快射了，不仅没退出来，反而含得更深更紧，喉咙不停收缩夹着你，手快速套弄，等着你射进来。）嗯...射给我...
【哥】（你再也忍不住，腰一挺，一股股精液直接射进她喉咙最深处。）我要射了...
【妹】（你射的时候她乖乖咽着，一口接一口，把所有精液都咽下去，一点都没漏，等你射完，她还轻轻舔了半天龟头，才慢慢抬起头，嘴角全是口水，但是笑得特别开心特别满足。）嗯...
【哥】（你拉她上来，把她紧紧抱在怀里，擦了擦她的嘴，亲了亲她红红的眼眶。）傻丫头，呛到没有？
【妹】（她趴在你怀里，摇摇头，紧紧抱着你的腰，声音发颤带着点哭腔，但是笑得很幸福。）没有...哥，我成功了...我全部吞下去了...
【哥】（你亲了亲她的额头，把她搂得紧紧的。）你怎么这么傻。
【妹】（她抬起头，看着你，眼睛亮晶晶的，凑过来亲你的嘴唇，吻得特别认真特别软。）因为我爱你呀，哥。明天...明天我就把第一次真正给你，好不好？
【哥】（你看着她认真的眼神，点了点头，亲了亲她的嘴唇。）好。
【妹】（她笑得特别甜，往你怀里钻得更深，紧紧抱着你，听着你的心跳。）哥，我爱你，一辈子都爱你。
【哥】（你抱着她软软的身体，心里满满的。）我也爱你。
【妹】（她乖乖窝在你怀里，抱着你的腰，腿搭在你的腿上，两个人就这么抱着，谁都没说话，但是心里都特别暖，特别甜。）嗯...
