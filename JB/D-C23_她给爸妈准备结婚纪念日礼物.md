# D-C23：她给爸妈准备结婚纪念日礼物
# 地点：家里，周末
# 情境：爸妈结婚纪念日，她偷偷准备了礼物，但是不好意思拿出来，找你商量

【哥】（周末看见她在客厅鬼鬼祟祟藏东西，看见你过来赶紧往背后藏，笑）藏什么呢？看见我就藏，什么好东西？
【妹】（脸一下子红了，手往背后藏，摇摇头）没...没什么...没藏东西...
【哥】（走过去故意逗她）没藏东西？那你手背后是什么？拿出来我看看。
【妹】（鼓脸，往后退了一步）不给看！这是秘密！
【哥】（笑了，坐在沙发上）什么秘密啊？跟哥还保密？
【妹】（犹豫了半天，磨磨蹭蹭走过来，从背后拿出一个包装好的小盒子，脸红红的）...今天是爸妈结婚纪念日...我给他们准备了礼物...
【哥】（愣了一下，然后笑了）哟，我们丫头长大了，还知道给爸妈准备纪念日礼物了，什么礼物啊？
【妹】（把盒子递过来给你看，耳朵尖红红的）我...我攒了好久零花钱，给妈妈买了条丝巾，给爸爸买了个钱包...但是我不好意思给他们...
【哥】（打开看了看，丝巾是妈妈喜欢的颜色，钱包也是爸爸常用的款式，笑）挑得挺好啊，为什么不好意思给？
【妹】（低下头，手指绞着衣角）我...我从来没给他们送过礼物...我怕他们不喜欢...
【哥】（揉她头发）傻丫头，你送的他们怎么会不喜欢，高兴还来不及呢。
【妹】（抬头看你，眼睛亮晶晶的）真的吗？他们不会觉得我乱花钱吧？
【哥】（帮她把礼物重新包好）不会，这是你心意，走，哥陪你一起给爸妈送过去。
【妹】（有点紧张，拉着你的手）哥...你陪我一起...我害怕...
【哥】（笑，拉着她往爸妈房间走）怕什么，有哥在呢，走。
【妹】（走到爸妈门口，又犹豫了，站在门口不敢敲门）哥...要不...还是明天再给吧...
【哥】（敲了敲门，冲她鼓励地点点头）就今天，别怕。
【妹】（爸妈开门，她脸红红的，把礼物递过去，声音小小的）爸妈...结婚纪念日快乐...这是我给你们买的礼物...
【哥】（站在她旁边，笑着看爸妈惊讶又开心的样子，摸了摸她的头）
【妹】（妈妈抱住她夸她懂事，爸爸也笑着摸她头，她靠在妈妈怀里，偷偷回头看你，眼睛亮晶晶的，笑得特别开心）
