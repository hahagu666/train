# D-H22：边看片子边给你口交模仿动作
# 地点：你房间，电脑放着片
# 情境：电脑放着色情片，她一边看一边学着女优的动作给你口交，口手配合

【哥】（你们坐在床上，电脑里放着色情片，女优正跪着给男的口交，各种动作，你看得硬了。）
【妹】（她坐在你旁边，脸红得像苹果，偷偷看了一眼你鼓起来的裤子，又看了看电脑里女优的动作，咬了咬嘴唇。）哥...我学着她那样给你弄好不好？
【哥】（你转头看她，她脸红扑扑的，眼睛水汪汪的，你点点头。）好啊。
【妹】（她开心地笑了笑，跪下来，爬到你两腿之间，抬头看了一眼电脑里女优的动作，然后学着她的样子，先低下头伸出舌头，从你的蛋蛋开始往上舔，和片子里一模一样。）嗯...
【哥】（她软软的舌头顺着阴茎根往上舔，热热的湿湿的，你舒服得摸了摸她的头。）嘶...
【妹】（她抬头看了一眼电脑，女优正在舔冠状沟，她也学着样子，舌尖绕着你的冠状沟快速打转，舔了几十圈，然后抬头看你反应。）哥，是这样吗？
【哥】（她学得有模有样，舌尖扫着冠状沟特别舒服，你点头。）对，就是这样，特别舒服。
【妹】（听见你说舒服，她更开心了，又看了一眼电脑，女优把整根肉棒吞进去，她也张开嘴，学着女优的样子慢慢往下吞，一直到喉咙口。）嗯...
【哥】（她把龟头吞进喉咙里，暖暖的紧紧的，你舒服得闷哼了一声。）哦...
【妹】（她学着女优的样子，喉咙收缩夹着你的龟头，然后开始慢慢上下吞吐，手学着片子里女优的样子，一只手握着阴茎没含进去的部分快速套弄，另一只手揉着你的蛋蛋，和片子里动作一模一样。）嗯...
【哥】（她学得太像了，喉咙夹着龟头，手快速套弄还揉蛋蛋，你舒服得呼吸都急促了。）啊...太舒服了...
【妹】（她吞吐了几十下，又抬头看电脑，女优正在舔马眼，她立刻退出来，学着女优的样子，舌尖快速点着你的马眼舔，手继续套弄阴茎，另一只手还揉着蛋蛋。）嗯...哥...
【哥】（马眼被她舌尖快速点着，太刺激了，你肉棒忍不住跳了一下。）啊...那里...
【妹】（看见你反应这么大，她知道这里特别敏感，学得更起劲了，舌尖快速扫着马眼，时不时把整个龟头含进去吸两下，手和嘴的配合和片子里女优几乎一样。）嗯...
【哥】（快感涨得特别快，你抓着床单，呼吸越来越重。）我快射了。
【妹】（她抬头看了一眼电脑最后女优射在嘴里的镜头，立刻低下头，把整个龟头紧紧含在嘴里，舌头死死顶着系带，手快速套弄，等着你射进来。）嗯...射给我...
【哥】（你再也忍不住，腰一挺，一股股精液射进她嘴里。）啊...
【妹】（她乖乖咽下去，学着片子里女优的样子，等你射完还轻轻舔干净龟头，才抬起头，嘴角亮晶晶的全是口水，对你笑。）哥，我学的像不像？
【哥】（你拉她上来抱在怀里，亲了亲她红红的脸。）像，太像了，比片子里还舒服。
【妹】（往你怀里钻，笑得特别开心，手还轻轻摸着你的肉棒。）那以后我天天看片学，学更多新动作给你弄。
【哥】（你捏了捏她软软的屁股，笑着。）小坏蛋，学坏了。
【妹】（她在你怀里笑，凑到你耳边小声说。）只对你坏嘛...
