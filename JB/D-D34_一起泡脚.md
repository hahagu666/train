# D-D34：一起泡脚
# 地点：客厅沙发，冬天晚上
# 情境：你烧了热水泡脚，她看见了非要把脚也伸进来跟你一起泡

【哥】（冬天晚上烧了壶热水，倒在泡脚桶里，坐在沙发上泡脚，水温刚好，舒服得叹了口气）
【妹】（端着水杯从房间出来，看见你在泡脚，凑过来看了看，脚盆挺大的，她眼睛转了转）哥，水够热吗？
【哥】挺热的，怎么了。
【妹】（站在旁边磨磨蹭蹭不走，看着你泡，拖鞋踢掉了，光着脚踩在地板上，凉得缩了下脚趾）地板好凉...
【哥】那穿拖鞋去。
【妹】（没穿拖鞋，反而在你旁边坐下，把脚伸到泡脚桶旁边试了试水温）好烫...（她偷偷看你，试探着把一只脚伸进去）
【哥】哎，你干嘛呢。
【妹】（脚已经伸进去了，舒服得眯起眼睛，然后把另一只脚也伸进来，桶一下子挤了，她的脚踩在你脚背上，她有点不好意思）桶这么大...一个人泡浪费...一起泡嘛...
【哥】（脚被她的小脚踩在脚底下，她的脚凉凉的，碰到热水就往你脚上躲）水都溢出来了。
【妹】（低头看，水确实溢出来一点，流到地板上，她吐了吐舌头，但是脚没拿出来，反而往你这边挪了挪，整个人靠在你肩膀上）那...我待会擦地板。（她的脚在水里轻轻蹭你的脚，脚趾头动来动去，像小鱼一样）哥你脚好大。
【哥】（笑了，靠在沙发上，她靠在你肩膀上，暖暖的水，两个人的脚挤在一个桶里，她的脚小小的，暖乎乎的）你脚才小，跟小孩似的。
【妹】（鼓脸，脚趾头故意踩你脚背）我脚不小！我都穿37码的鞋了！
【哥】嗯，不小不小。
【妹】（被你敷衍了，哼了一声，但是没走开，继续靠在你肩膀上，脚在水里轻轻晃，水哗啦响，泡了一会她额头出了点汗，脸红红的，舒服得快睡着了）哥...
【哥】嗯？
【妹】（声音发懒，迷迷糊糊的）以后我们每天都一起泡脚好不好...泡完脚睡觉特别暖和...
【哥】行。
【妹】（开心地蹭了蹭你肩膀，脚趾头勾了勾你的脚趾，两个人的脚在热水里贴在一起，暖暖的水一直暖到心里，电视开着没人看，窗外是冬天的冷风，屋子里暖乎乎的）
【哥】（泡了二十分钟水有点凉了，想把脚拿出来，她按住你的脚不让起）再泡一会...还暖着呢。
【妹】（声音黏糊糊的，脸泡得红红的，靠在你肩膀上不想动，头发蹭着你脖子，手偷偷抓住你的手，手指和你扣在一起，小声说）泡完脚你抱我回房间...我脚麻走不动了...（她仰起头看你，眼睛湿漉漉的，脸上红扑扑的，嘴唇粉润润的，额头上有细细的汗，脚还在水里和你的脚贴在一起，暖暖的）
