# D-E18：你加班她等你到深夜
# 地点：家里客厅，深夜
# 情境：你加班到很晚才回家，发现她窝在沙发上睡着了，电视还开着，桌上温着牛奶

【哥】（加班到十二点多才到家，轻轻开门，客厅灯还亮着，电视小声放着动画片，她窝在沙发上，身上盖着小毯子，头歪在靠垫上睡着了）
【妹】（睡得很沉，眉头微微皱着，手里还抱着抱枕，茶几上放着一杯温牛奶，旁边还有她没写完的作业，应该是写着写着就睡着了）
【哥】（轻轻走过去，蹲下来看她，她脸上还有压出来的靠垫印子，头发散在脸上，小嘴微微张着，呼吸轻轻的，墙上的钟已经指向十二点四十了）
【妹】（感觉到有人，迷迷糊糊睁开眼睛，看见是你，眼睛一下子亮了，但是还没完全醒，揉了揉眼睛，声音哑哑的）哥...你回来了...
【哥】不是让你先睡吗，怎么在这睡着了。
【妹】（坐起来，打了个小小的哈欠，头发乱蓬蓬的，伸手摸了摸茶几上的牛奶，已经凉了，她有点懊恼）我本来想等你回来的...给你热了牛奶...等你等到我就睡着了...
【哥】（摸了摸她的头，她头发睡得乱蓬蓬的，脸睡得红扑扑的）我又不是小孩，等我干嘛。
【妹】（鼓着脸，伸手抱你的胳膊，脸靠在你袖子上蹭了蹭，声音带着刚睡醒的鼻音）你加班到这么晚...我不放心嘛...而且我一个人睡不着...（她抬头看你，眼睛还没完全睁开，迷迷糊糊的）你吃饭了吗？我给你留了饭在冰箱里，我去给你热。
【哥】不用了，我在公司吃过了，你快去睡吧，都一点了。
【妹】（摇摇头，抱着你的胳膊不撒手，困得眼睛都快闭上了，还是强撑着）那我陪你...你洗澡我给你拿睡衣...
【哥】（忍不住笑了，看她困得头一点一点的，像小鸡啄米一样，还硬撑着要陪你）你都快睡着了，怎么陪我。
【妹】（使劲摇摇头让自己清醒一点，但是没用，头还是靠在你胳膊上，声音越来越小）我没睡...我就是闭眼睛休息一下...
【哥】（把她打横抱起来，她轻得很，像小猫一样，立刻本能地伸手抱住你的脖子，脸埋在你颈窝，迷迷糊糊的）
【妹】（被你抱起来，也不挣扎，乖乖抱着你脖子，脸蹭了蹭你脖子，呼吸暖暖的，含含糊糊说）我牛奶还给你留了...你记得喝...
【哥】（抱着她往她房间走，她房间灯开着小夜灯，暖暖的光，把她放到床上盖好被子）
【妹】（躺到床上还是抓着你的衣领不放，眼睛半睁半闭看着你，声音发黏）哥...以后别加班到这么晚了好不好...我等你等得都睡着了...
【哥】好，下次尽量早点回来。
【妹】（这才满意了，松开手，但是伸手抓着你的手指不放，慢慢闭上眼睛，嘴角微微扬着，声音越来越小，快睡着了）牛奶在桌上...记得喝...热一下...（她握着你的手指，呼吸慢慢平稳下来，彻底睡着了，眉头也舒展开了，小夜灯暖黄的光照在她脸上，红红的印子还没消，像只安心睡在窝里的小猫）
