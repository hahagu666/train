# D-A34：分班选科她纠结拿不定主意
# 高二分班选科，她一会儿想选文科一会儿想选理科，纠结得饭都吃不下，坐在你房间地板上把选科指南翻烂了还是拿不定主意
# 地点：家里哥哥房间，高二选科期间晚上

【哥】（写完作业抬头看她，她坐在地板上，头发都抓乱了，选科指南都被她翻得起皱了，面前还放着上次考试的成绩单）想好了吗？到底选文选理？
【妹】（晚饭都没吃几口，就抱着选科指南坐在你房间地板上，翻来翻去看，眉头皱得紧紧的，一会儿叹气一会儿咬笔帽，坐了快一个小时了，还没决定）
【哥】（走过去坐在她旁边的地板上，拿过她的成绩单看了看，她的语文英语历史都是年级前五十，物理化学却在一百名开外，明显文科更有优势。你弹了她脑门一下）傻丫头，选科是看你自己擅长什么，不是看我选什么，你物理每次都考六十多分，学理科学得那么累，何必呢？
【妹】（抬起头看你，眼睛亮晶晶的，但是满是纠结，把笔一扔，往地上一坐，鼓着脸说）不知道！我想选文科吧，历史政治我背得快，但是文科专业少；选理科吧，物理我总是考不好，但是你选的理科，我想跟你一个班...
【哥】（心里一暖，揉了揉她的头发，笑着说）不在一个班怎么了？就算不在一个班，我也是你哥啊，你理科题不会做，放学我照样给你讲，晚自习下课我照样去你班门口等你，又不是见不到了，对不对？
【妹】（鼓着脸，揪着地毯上的毛，小声说）可是...可是如果我选文科，我们就不在一个班了...以后上晚自习也不能坐一起了...你帮我讲题也不方便...我想跟你在一个班...
【哥】（把选科指南拿过来翻到文科那一页，指着她擅长的历史和语文成绩，认真看着她）选文选理不重要，重要的是你喜欢什么，擅长什么。你背历史看一遍就能记住年代表，做物理题抠半小时都做不出来，为什么要勉强自己学不擅长的东西呢？而且你不是喜欢文学吗？以后想当编辑，学文科才对口啊。
【妹】（还是有点纠结，手指戳着成绩单，小声说）可是...可是我妈想让我学理科...说理科好找工作...我同学也说理科录取分数线低...我...我不知道怎么办了...
【哥】（笑着捏了捏她的脸，认真地说）怎么会考不上，你文科成绩那么好，稍微努力一下肯定能上重点。你忘了你上次历史考了年级第八？老师都夸你史论写得好，有自己的想法。学你喜欢的东西，才会有动力学，对不对？
【妹】（抬起头看你，眼睛亮晶晶的，有点犹豫，小声问）...可是...如果我选文科，以后考不上好大学怎么办...我万一学文科也学不好怎么办...
【哥】（笑着伸出小拇指跟她拉钩，大拇指按在一起盖章）我答应你，就算不在一个班，每天放学我都在你班门口等你，题不会做我随时给你讲，周末我还陪你去图书馆背历史，好不好？
【妹】（坐在地板上想了半天，眉头一会儿皱一会儿松，过了好久，终于像是下定了决心，点点头，但是还是有点舍不得，小声说）...那...那我选文科...但是...但是你要答应我...就算不在一个班...你也不能不理我...每天放学都要等我一起回家...不会的题你还要给我讲...
【哥】（愣了一下，然后笑了，伸手把她揽进怀里，捏了捏她红红的脸蛋，故意逗她）哦？原来我们妹妹是怕我跟别的女生玩啊？放心吧，我才不跟她们玩，我就陪我们妹妹一个人，她背历史我陪着，她写作文我帮她改，她想吃什么我带她去，好不好？
【妹】（脸一下子红了，但是往你怀里缩了缩，点了点头，心里的大石头终于落地了，纠结了好几天的选科问题终于定下来了。她抬头看你，眼睛亮晶晶的，小声问）...哥...那你会不会觉得我很没主见啊...选个科都纠结这么久...
【哥】（笑着揉了揉她的头发，亲了亲她的发顶，轻声说）怎么会，人生大事本来就要好好想清楚，纠结说明你认真对待。不管你选什么，我都支持你，知道吗？
【妹】（开心地笑了，搂住你的腰，把脸埋在你怀里，刚才的纠结和不安全都没了。选文选理又怎么样呢，只要有你在，不管选什么都不怕）
【哥】（晚上你帮她把文科的选科表填好，她趴在你旁边看你写，看着看着就笑了，眼睛弯成了月牙）
【妹】（虽然不在一个班，但是想想以后放学你还是会等她，不会的题你还是会给她讲，好像也没那么可怕了，反而有点期待新班级的生活呢，偷偷在你脸上亲了一口）
