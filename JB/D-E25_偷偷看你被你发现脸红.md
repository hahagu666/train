# D-E25：偷偷看你被你发现脸红
# 地点：你房间，你在看书她在写作业
# 情境：她在你房间写作业，写着写着就盯着你看发呆，被你发现了脸瞬间红透

【哥】（周末下午你在房间书桌前看书，她搬了个小桌子在你旁边写作业，安安静静的，过了一会你感觉有人在看你，抬头）
【妹】（正撑着下巴盯着你看，眼睛眨都不眨，不知道看了多久了，手里的笔还停在作业本上，嘴角微微扬着，明显在发呆，被你突然抬头吓了一跳，立刻低下头假装写作业，但是笔尖都戳到纸外面去了，耳朵一下子红了）
【哥】（忍住笑，假装没看见继续看书，过了两分钟，用余光看见她又抬起头偷偷看你，这次看得更认真，眼睛亮晶晶的，从你的眉毛看到鼻子，再看到嘴唇，看得特别专注，连你看她她都没发现）看什么呢？
【妹】（又被抓包，吓得手一抖，笔都掉在桌子上了，脸瞬间红透，一直红到脖子根，赶紧低下头捡笔，头埋得低低的，声音小小的）没...没看什么...我写作业呢...
【哥】写作业盯着我脸看？我脸上有答案啊？
【妹】（脸更红了，头埋得更低，耳朵红得都要滴血了，手指绞着作业本角，半天憋出一句）我...我就是看你睫毛好长...比女生还长...
【哥】（笑了，凑过去一点，她吓得往后缩了一下，但是眼睛偷偷抬起来看你，又立刻低下头，脸红得像熟透的苹果）
【妹】你凑这么近干嘛...
【哥】让你看个够啊，省得你偷偷摸摸的。
【妹】（脸埋在作业本上，不好意思抬头，但是又忍不住从胳膊缝里偷偷看你，被你发现了立刻又把脸埋回去，声音闷闷的，带着点撒娇）你别笑我了...
【哥】我没笑你。看就看呗，又不收你钱。
【妹】（这才慢慢抬起头，脸还是红红的，但是不躲了，撑着下巴光明正大看你，眼睛亮晶晶的，从额头看到下巴，看得特别认真，看了半天，小声说）哥你长得真好看...
【哥】（被她说得一愣，她看见你愣了，自己先笑了，嘴角扬着，眼睛弯成月牙，但是脸还是红的）
【妹】（伸手戳了戳你胳膊，声音发嗲，带着点不好意思，但是还是看着你）我们班女生都说你长得帅...上次你来接我放学，她们都问我那是谁...
【哥】那你怎么说？
【妹】（得意地扬了扬下巴，但是脸还是红的）我说那是我哥！亲哥！（说完又有点不好意思，低下头假装写作业，写了两个字又抬头偷偷看你，这次和你对视上，她没躲开，就那么看着你，眼睛水汪汪的，脸红扑扑的，嘴角偷偷扬着，看了好半天，才小声说）看自己哥哥怎么了...我就看...（她嘴上这么说，手还是紧张地绞着作业本角，耳朵红得发烫，但是眼睛一直没移开，就那么亮晶晶地看着你，像看什么宝贝一样）
