# D-E11：闹小脾气故意不理你
# 地点：客厅，周末
# 情境：你周末一直在忙工作没时间陪她，她坐在沙发上故意弄出声响，你叫她她也不理，鼓着脸看电视

【哥】（周末你在家加班，坐在书桌前对着电脑忙了一上午，她坐在客厅沙发上看电视，每隔五分钟就故意咳嗽一声，或者把薯片袋子弄得哗啦响，你都故意没理她）
【妹】（听到你出来喝水的声音，故意把头扭向电视，鼓着脸不看你，电视开着但是眼神根本没在看屏幕）
【哥】怎么了？脸拉那么长。
【妹】（不说话，别过头去看电视，故意不理你）
【哥】（笑，走过去坐她旁边）生气了？
【妹】（还是不说话，往旁边挪了挪，离你远一点，鼓着脸）
【哥】上午忙工作没陪你，生气了？
【妹】（沉默了半天，终于开口了，声音气鼓鼓的）你还知道啊！你从早上八点坐到现在！都四个小时了！水都没出来喝一口！我叫你三次你都没听见！
【哥】抱歉抱歉，今天报表要得急，忙完了，下午陪你好不好？
【妹】（偷偷看你一眼，但是还是鼓着脸）谁要你陪...我自己看电视挺好的...
【哥】哦？那我下午接着工作去了。（假装站起来要走）
【妹】（立刻伸手拽你袖子，但是又立刻松开，嘴硬）...你敢！
【哥】（笑，坐回来，把她揽过来）好了，是我不对，下午带你去吃你想吃的那家火锅，然后去逛书店，好不好？
【妹】（眼睛亮了一下，但是还是装出不情愿的样子）...那...那好吧...这次就原谅你了...（顿了顿，小声）下次再不理我，我就...我就把你电脑电源线藏起来！
【哥】（笑）知道了小祖宗。
【妹】（往你怀里蹭了蹭，鼓着脸，但是手紧紧抱着你胳膊，嘴角偷偷扬起来）
