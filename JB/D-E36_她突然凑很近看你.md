# D-E36：她突然凑很近看你
# 地点：沙发上，一起看电视
# 情境：你脸上沾了点奶油，她突然凑过来很近帮你擦掉，距离特别近，你能闻到她身上的香味

【哥】（晚上一起吃蛋糕，你脸上沾了点奶油自己没注意，正看电视，她突然往你这边凑过来，越凑越近，脸离你只有几厘米）
【妹】（凑到你面前，眼睛亮晶晶的盯着你嘴角，离得特别近，呼吸都喷在你脸上，她的睫毛长长的，能数清楚有几根，身上香香的蛋糕味飘过来，她伸出手指轻轻擦过你嘴角）你脸上沾奶油了。
【哥】（被她突然凑这么近，心跳一下子漏了一拍，僵在那里不敢动，能闻到她头发上的洗发水香味，还有嘴里的蛋糕甜味，她的手指软软的擦过你嘴角，暖暖的）
【妹】（擦掉奶油，还故意把手指放在自己嘴里舔了一下，眼睛亮晶晶的看着你，嘴角带着坏笑，发现你耳朵红了，她眼睛更亮了，故意凑得更近一点，鼻尖都快碰到你鼻尖了）哥...你耳朵红了。
【哥】（赶紧别过头，假装继续看电视，但是心跳得特别快，耳朵烫得吓人，故作镇定）谁红了，太热了。
【妹】（咯咯笑，故意往你身边挪了挪，凑得更近了，整个身体都靠在你胳膊上，脸凑到你耳朵旁边，呼吸暖暖的吹在你耳朵上，声音黏黏的带着笑意）哦~太热了啊...那我离你近点是不是更热了？
【哥】（被她吹得耳朵更痒了，往旁边躲了躲，她立刻跟着凑过来，像故意逗你一样，你躲到哪她凑到哪，嘴角一直扬着坏笑）别闹，看电视呢。
【妹】（根本不看电视，就撑着下巴看着你，离得特别近，眼睛亮晶晶的，从你的眉毛看到眼睛，再看到鼻子，最后落在你嘴唇上，看了半天，小声说）哥...你睫毛好长啊...比我的还长...
【哥】（被她看得有点不自在，伸手想把她推开，手碰到她的脸，她的脸软软的，烫烫的，原来她也脸红了，只是故意逗你，自己其实也害羞）
【妹】（被你碰到脸，她自己的脸也一下子红透了，但是还是不躲开，就那么近距离看着你，眼睛水汪汪的，呼吸有点快，喷在你脸上暖暖的，过了半天，她小声说）你刚才是不是心跳快了...我都听见了...咚咚咚的...
【哥】（被她说中，更尴尬了，想往后退，但是沙发就那么大，退无可退，她凑在你面前，脸红扑扑的，嘴唇粉润润的，离得特别近，好像一抬头就能碰到）
【妹】（看着你窘迫的样子，她终于忍不住笑了，但是没退开，反而伸手勾住你的脖子，凑得更近了一点，声音黏黏的，带着点撒娇又有点坏）那...你要不要也看看我...我脸上有没有沾奶油...（她仰着头，把脸凑到你面前，闭着眼睛，睫毛轻轻颤抖，脸红扑扑的，嘴唇微微嘟着，等着你亲她，呼吸甜甜的，全是蛋糕的香味）
