# D-E35：吃醋你跟女同事说话故意不理你
# 地点：你公司楼下，她等你下班
# 情境：她去公司楼下等你下班，看见你跟女同事笑着说话出来，立刻吃醋了，一路不理你

【哥】（下班从公司出来，看见她站在楼下等你，手里还拿着两瓶水，刚要喊她，旁边女同事跟你说工作上的事，你停下来笑着跟她说了两句话，说完转头找她，她已经转身往前走了，背挺得直直的）
【妹】（走在前面，你喊她她也假装没听见，步子迈得特别快，鼓着脸，眼睛看着前面，就是不回头，手里的水捏得紧紧的，瓶身都被捏变形了）
【哥】（赶紧追上去，走到她旁边，她立刻往旁边挪了一步，离你远远的，还是不看你）走这么快干嘛，等我一会啊。
【妹】（不理你，继续往前走，脸鼓得像包子，嘴角往下撇，就是不看你，你走左边她就往右边躲，就是不跟你并排走）
【哥】（这才发现她不对劲，故意凑过去，她又往旁边挪，差点撞到路边的树，你忍不住笑了）这是怎么了？谁惹我们妹妹生气了？
【妹】（终于停住脚步，回头瞪了你一眼，眼睛气鼓鼓的，但是红红的，好像有点委屈，鼓着脸哼了一声，继续往前走，还是不理你）
【哥】（追上去拉住她的手，她立刻使劲把手抽回去，抱在胸前，别过头不看你，鼓着脸）还说没生气，手都不让碰了。
【妹】（哼了一声，还是不说话，但是眼眶有点红了，手指揪着书包带子，走得更快了，但是你能看见她嘴角撇着，委屈得快哭了）
【哥】（想了想才反应过来，刚才跟女同事说话被她看见了，忍不住笑了，又追上去）刚才那是我们部门同事，说下周项目的事呢。
【妹】（听见你这么说，脚步顿了一下，但是还是没回头，继续走，声音闷闷的，带着点醋味）跟我说干嘛，你愿意跟谁说话跟谁说话，跟我没关系。
【哥】哦，没关系啊，那我明天还跟她一起吃午饭呢。
【妹】（立刻停住，猛地回头看你，眼睛里全是气，眼泪都快出来了，鼓着脸瞪着你，声音都有点抖了）你敢！
【哥】（忍住笑，看着她气鼓鼓的样子，脸都鼓成包子了，眼泪在眼眶里打转，明明吃醋吃得不行还硬撑）不是说跟你没关系吗？
【妹】（被你问住了，脸一下子红了，又气又委屈，眼泪啪嗒一下就掉下来了，鼓着脸打你胳膊一下，但是没用力，声音带着哭腔）有关系！就有关系！你是我哥！你不许对着别的女生笑！（她越说越委屈，眼泪掉得更凶了）你刚才笑那么开心！你都没那么对我笑过！
【哥】（赶紧给她擦眼泪，她哭得一抽一抽的，但是还是鼓着脸瞪你，像只炸毛的小猫）傻不傻，工作上的事笑一下怎么了，我天天在家不也对你笑吗。
【妹】（鼓着脸，但是没躲开你擦眼泪的手，用手背擦眼泪，抽噎着，声音还是酸溜溜的）那不一样...那个女的长得好看...
【哥】哪有我们妹妹好看。
【妹】（听见这句话，哭声一下子停了，但是还是鼓着脸，耳朵红了，别过头不看你，但是嘴角偷偷往上扬了一下，又立刻压下去，声音还是闷闷的，但是没刚才那么气了）就会说好听的...
【哥】（伸手牵她的手，她这次没抽回去，但是还是故意轻轻挣了一下，没挣开就任由你牵着，手软软的）
【妹】（故意用力捏了你一下，小声嘟囔）下次再跟别的女生笑那么开心，我就...我就再也不等你下班了...（她嘴上这么说，但是手指却偷偷勾住你的手指，紧紧握着，头靠在你胳膊上，虽然脸还是鼓着，但是嘴角已经扬起来了，醋味还没完全散，但是已经不生气了）
