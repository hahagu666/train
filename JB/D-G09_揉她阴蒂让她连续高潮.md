# D-G09：揉她阴蒂让她连续高潮
# 地点：你床上
# 情境：她已经有过高潮经历了，这次你专注揉她阴蒂，让她连续爽了两次

【哥】（你手指插在她小穴里，她已经高潮过一次了，软在床上大口喘气，你手指还留在她里面。）
【妹】（喘着气，浑身还在轻轻发抖，里面还在一缩一缩夹着你的手指，她抱着你，声音黏黏的带着满足。）哥...太舒服了...我刚才好像飘起来了...
【哥】（没把手指拔出来，拇指往上移，轻轻按在她硬硬的阴蒂上。）
【妹】（啊！刚高潮过，那里特别敏感，被你一按，她立刻叫出来，身体抖了一下，想往后躲，但是你另一只手按着她的腰不让她躲，她声音带着哭腔。）啊！哥...那里不行...太敏感了...碰了...碰了难受...
【哥】（没听她的，拇指指腹轻轻在她阴蒂上打着圈揉，动作很轻很慢。）不难受的。
【妹】（被你揉得一阵阵麻意窜上来，她又开始小声呻吟，身体不受控制地往你手心里凑，刚才说不行，现在却主动往上挺，眼泪汪汪的。）嗯...啊...哥...别揉了...我...我又要来了...
【哥】（手指在她里面也动起来，抠着她敏感的G点，外面拇指继续揉阴蒂，里外配合。）嗯...
【妹】（啊！！她尖叫一声，这一次比上次来得还快还猛，她身体猛地弓起来，浑身剧烈颤抖，小穴里一股股水流出来，紧紧夹着你的手指，第二次高潮了，她连叫都叫不出声，只有气音从喉咙里漏出来。）啊...
【哥】（能感觉到她里面剧烈收缩，水哗哗流出来，打湿了床单，你没停手，继续轻轻揉着她的阴蒂。）爽吗？
【妹】（第二波高潮还没退下去，你还在揉，她爽得直哭，眼泪不停流，身体抖得像筛糠，想推开你的手但是浑身一点力气都没有，只能断断续续呻吟。）哥...不...不行了...要死了...真的要死了...
【哥】（这才放慢动作，轻轻揉着，等她缓过来。）好了好了。
【妹】（喘了足足有半分钟，才慢慢平静下来，浑身像散了架一样软在床上，连动手指的力气都没有了，眼睛半睁着，水汽朦胧，看着你，声音哑哑的黏黏的。）哥...你坏死了...让我...让我那样...
【哥】（抽出手，手指上全是她的水，亮晶晶的。）不舒服吗？
【妹】（脸红透了，往你怀里钻，抱着你的腰，把脸埋在你胸口，声音小小的黏黏的，带着撒娇。）舒服...太舒服了...我从来没这么舒服过...就是...就是有点丢人...我尿出来了...
【哥】（擦了擦手，抱着她。）那不是尿，是潮吹，说明你舒服了。
【妹】（哦了一声，似懂非懂，但是听你说不是尿，就放心了，往你怀里蹭了蹭，下面还在一抽一抽的，余韵还没过去，她过了半天，小声说。）哥...以后...以后你经常这样弄我好不好...
【哥】（亲了亲她的额头。）好，只要你喜欢。
【妹】（听见你答应，她笑得特别甜，抬起头亲了亲你的下巴，但是一动，下面又流出一点水来，她羞得赶紧把腿夹紧，埋回你怀里，声音闷闷的。）但是...今天不能再弄了...我...我真的没力气了...
【哥】（把她搂进怀里，给她盖好被子，擦了擦她额头的汗。）好，不弄了，睡觉吧。
【妹】（乖乖窝在你怀里，手紧紧抱着你的腰，身体还在偶尔轻轻抖一下，脸上带着满足的笑，过了没两分钟，就呼吸均匀地睡着了，嘴角还扬着，做着甜甜的梦。）嗯...
