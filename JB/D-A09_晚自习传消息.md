# D-A09：晚自习偷偷给你发消息
# 地点：妹妹教室晚自习，你在公司加班
# 情境：晚自习静悄悄大家都在刷题，她把书立在前面挡着，偷偷在桌子底下给你发消息

【哥】（在公司加班，放在桌上的手机震了一下，屏幕亮起来，是妹妹发来的消息）
【妹】（手机藏在课本后面，亮度调到最低，打字飞快）哥，晚自习好无聊啊
【哥】（没过两分钟手机震了，放下手里的工作回消息）不是让你好好刷题吗，怎么又玩手机，小心被老师抓
【妹】（消息提示音吓得她一哆嗦，赶紧按黑屏抬头看讲台，老师在低头改作业，松了口气，打字回你）同桌在看小说，我学累了歇会嘛，我把书堆得很高老师看不见的
【哥】（笑着摇摇头，打字）就你理由多，我在加班，大概九点多回去，想吃什么给你带
【妹】（眼睛一下子亮了，打字飞快）想吃校门口那家烤肠！要辣的！两根！🥺
【哥】（打字）大晚上吃辣的也不怕胃疼，上次来姨妈疼哭是谁啊
【妹】（鼓着脸打字）今天肚子不疼！真的！求求了哥，就这一次！🥺
【哥】（被她发的可爱表情逗笑，打字）行，给你带两根，多放辣，这下满意了吧
【妹】（开心得差点笑出声，赶紧捂住嘴，肩膀都在抖，这时候同桌胳膊肘碰了碰她，小声说"笑什么呢，老师看你呢"）
【哥】（她半天没回消息，猜她是被老师盯上了，发了个消息过去）别笑了，好好学习，坐直点
【妹】（看见消息脸一下子红了，打字回）你怎么知道我在笑！你在我身上装监控了啊！
【哥】（回）我还不知道你？拿到吃的就美得不行，尾巴都要翘上天了
【妹】（哼了一声打字）哼，不理你了，等你回来记得给我开门带烤肠，我好好学习了！收手机刷题了
【哥】（打字）乖，认真写题，回去给你带热乎的
【妹】（刚把手机收进笔袋拿出卷子，老师就走下来巡逻，走到她旁边停住了，她心跳快得不行，握笔的手都紧了，假装认真做题一动不动）
【哥】（老师站了两秒，看了一眼她写满字的卷子，没说什么就走过去了，她松了一大口气）
【妹】（等老师走远了，又偷偷把手机拿出来，飞快给你发了一条）刚才老师差点抓到我！吓死我了！心脏都快跳出来了！
【哥】（手机震的时候刚好在开会，开完会看见消息笑着回）让你上课玩手机，活该吓吓你，快写题，等我回去
【妹】（吐了吐舌头，把手机收起来，这次真的乖乖低头刷题了，嘴角却一直扬着，等着九点多你回来带烤肠）
【哥】（把手机揣回兜里，笑着摇摇头，加快手里的工作，想早点下班回去给小丫头带热乎的烤肠）
【妹】（握着笔认真写题，笔尖在草稿纸上飞快演算，嘴角忍不住偷偷往上翘，烤肠的香味好像已经飘到鼻子里了）
