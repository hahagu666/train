# D-D31：给你织围巾
# 地点：沙发，冬天晚上
# 情境：她偷偷织了一个月围巾，藏在背后拿给你，织错了好几针不好意思

【哥】（冬天晚上坐在沙发上看书，空调开着，她坐在你对面的地毯上织东西，织了快一个月了，每次你问她都藏起来）织什么呢，神神秘秘的。
【妹】（听见你问，手立刻背到身后，脸有点红）没...没什么！就是...随便织织！
【哥】随便织织织了一个月？（放下书伸手）给我看看。
【妹】（赶紧把织了一半的东西抱怀里，往后缩）不行！还没织好呢！织好了再给你看！
【哥】（笑了，也不抢她，继续看书）行，那我等着。
【妹】（看你不抢了，才松了口气，又继续织，织错了一针，拆了重织，急得小声嘟囔）怎么又错了...
【哥】（偷偷看她，她皱着小眉头很认真的样子，手指被毛线针戳了一下，她嘶了一声，把手指放嘴里含了一下，又继续织）
【妹】（又织了一个星期，圣诞节那天晚上，她背着手走到你面前，脸红红的，眼睛不敢看你）哥...那个...织好了。
【哥】（放下手机看她，她从背后拿出一条深灰色的围巾，围巾有点歪，还有几针织错了鼓起来一块，但是针脚很密，看得出来织得很用心）给我的？
【妹】（把围巾递过来，紧张地绞手指）嗯...织了好久...第一次织，织得不好...有几针错了...你别嫌弃...
【哥】（接过围巾围在脖子上，很暖和，毛线软软的，虽然有点歪但是特别舒服）挺好的，不嫌弃。
【妹】（抬头看你围上了，眼睛一下子亮了，但是又有点不好意思，伸手摸了摸围巾）真的吗？我拆了好多次的...织错了就拆，织错了就拆...（声音小小的）本来想赶你生日给你的，结果织慢了...
【哥】（摸了摸围巾上鼓起来的那一块，应该就是她一直织错的地方，笑着揉她的头）现在送刚好，天冷了刚好能围。
【妹】（开心起来，凑过来帮你把围巾理好，围了两圈，把你脖子都裹住，只露出眼睛）这样就不冷了！（她仰着头看你，手还扶着围巾，鼻尖红红的，因为织了一个月手指上还有被毛线针扎的小印子）我以后每年都给你织一条好不好？织不同颜色的...
【哥】好啊。
【妹】（眼睛弯成月牙，踮起脚在你围着围巾的下巴上亲了一下，围巾上全是她的味道，软软的毛线蹭得你下巴发痒）这个不许摘！出门就要围着！（她退后两步看着你围着歪歪扭扭的围巾，笑得特别开心，嘴角都快咧到耳朵根了，自己也围了条同色系的女款，转了个圈）你看！我们是一样的！
