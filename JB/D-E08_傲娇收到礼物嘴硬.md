# D-E08：傲娇收到礼物嘴硬
# 地点：她房间，你生日给她买了新耳机
# 情境：你发工资给她买了她念叨好久的无线耳机，她拿到手嘴硬说谁让你买的，但是转身就拆包装用上了

【哥】（下班回家，从包里拿出个包装好的盒子递给她，笑着晃了晃）喏，给你的。
【妹】（正在写作业，抬头看，接过来）什么啊？
【哥】拆开看看。
【妹】（拆开，看到是她念叨了好久的那款粉色无线耳机，眼睛一下子亮了，但是立刻压下去，鼓脸）...谁让你买这个的啊，多贵啊。
【哥】你不是上次跟同学出去玩说她那个耳机好用吗，发工资了就给你买了。
【妹】（摸着盒子，嘴角忍不住往上扬，但是还是嘴硬）我就是随口说说...我又没说要...
【哥】不想要啊？那我退了。（伸手要拿回来）
【妹】（立刻把盒子抱在怀里，瞪你）干嘛！给我了就是我的！哪有往回要的！
【哥】（笑）不是说不想要吗。
【妹】（脸红，抱着盒子拆包装，拆得有点急）...我...我这是怕你浪费钱！既然买了就别退了！
【哥】嗯，用吧，试试音质好不好。
【妹】（拆开，拿出耳机戴上，连蓝牙，放了首歌，眼睛弯起来，但是故意装出平平淡淡的样子）...也就一般般吧...跟我同学那个差不多...
【哥】是吗，那我下次不买了。
【妹】（立刻摘下来一个耳机，急了）哎别！...我不是那个意思...（声音变小）挺...挺好用的...
【哥】（笑，揉她头发）喜欢就直说，嘴硬什么。
【妹】（脸更红了，把耳机戴上，转过身去不看你，但是嘴角压不住地扬着，连写作业都在晃脚）...谢谢哥。
