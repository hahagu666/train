# D-B04：闺蜜说你帅
# 地点：放学回家路上/客厅，傍晚
# 情境：和闺蜜一起放学回来，在楼下跟闺蜜分开，回家就有点鼓脸

【哥】（傍晚在客厅看报纸，听见开门声，知道她放学回来了）
【妹】（开门进来，换鞋，把书包往沙发上一扔，鼓着脸坐下来）
【哥】怎么了？谁惹你了？
【妹】（拿起抱枕抱怀里，不说话，哼了一声）
【哥】（笑）这是怎么了，气鼓鼓的。
【妹】（鼓脸看你）还不都是因为你！
【哥】我怎么了？
【妹】（噘嘴）今天跟小雅一起走，她看到你在楼下等我...
【哥】嗯，然后呢？
【妹】（声音变大一点）然后她一直说"你哥好帅啊""你哥长得好好看"！一路都在说！说了三遍！
【哥】（笑）说就说呗，我又不掉块肉。
【妹】（更气了，抱枕砸你）你还笑！她还问我你有没有女朋友！
【哥】你怎么说？
【妹】（瞪你）我怎么说！我说没有！然后她居然说"那我能不能追你哥啊"！
【哥】（挑眉）你同意了？
【妹】（立刻炸毛）我当然不同意！我跟她说"我哥不找高中生！你死心吧！"
【哥】（笑出声）
【妹】（鼓脸，坐过来拧你胳膊）你还笑！她还说周末要来我们家问题！她根本就不是来问题的！她就是来看你的！
【哥】（揉被拧的地方）那不让她来？
【妹】（想了想，又有点犹豫）...那也不行，都是同学，不让来显得我小气...（抬头看你，恶狠狠）但是你不许跟她说话！不许对她笑！
【哥】（忍住笑）行，不笑。
【妹】（还是有点气，抱你胳膊）哥，你以后不准在我同学面前穿那件白衬衫！
【哥】为什么？
【妹】（脸红）...那件显得你特别好看...
【哥】（弹她额头）小醋坛子。
【妹】（捂额头，鼓脸，但没真生气）我才没有吃醋！
【哥】（笑着把她揽进怀里，捏了捏她鼓起来的腮帮子）好好好，没吃醋，是哥错了，以后不穿白衬衫给别人看，只穿给我们妹妹一个人看，行不行？
【妹】（靠在你怀里，脸红红的，嘴角却忍不住扬起来，伸手抱住你的腰，小声嘟囔）这还差不多...
