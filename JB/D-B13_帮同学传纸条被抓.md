# D-B13：帮同学传纸条被抓
# 地点：老师办公室/你接她回家
# 情境：上课帮同学传纸条被老师抓到，不是她写的但她背锅，委屈得眼睛红红的在学校门口等你

【哥】（开车到学校门口，看到她站在保安室旁边，背着书包，眼睛红红的，脚踢着地面）怎么了这是？
【妹】（抬头看到你，嘴一撇，跑过来，差点哭出来）哥...
【哥】（下车）怎么了？老师留你了？
【妹】（点头，声音哽咽）上课的时候...后座同学让我帮她传个纸条给前面...我刚递过去就被老师看到了...
【哥】纸条上写的什么？
【妹】（擦眼睛）我没看...好像是说放学去哪玩...然后老师把我叫到办公室，说我上课传纸条不认真听课...还说要叫家长...
【哥】你没跟老师说不是你写的？
【妹】（摇摇头，委屈）我说了...老师说"传纸条就是不对，不管是谁写的"...还让我写检讨，明天交...
【哥】（叹气，拉她上车）行了，先回家。
【妹】（坐上车，系安全带，还是闷闷不乐）老师还说要给爸妈打电话...
【哥】我一会给老师打，说明情况。确实不是你写的，但传纸条确实不对。
【妹】（低头抠手指）我知道不对...但是她一直戳我后背让我帮忙传...我不好意思拒绝...
【哥】（摸她头）下次这种事你就说"上课呢别传"，别什么忙都帮。
【妹】（点头，眼睛还是红的）...嗯。
【哥】你那个同学呢？她没站出来承认？
【妹】（摇摇头，更委屈了）她全程一句话都没说...就看着我被老师说...
【哥】（皱眉）以后少跟这种人来往，没担当。
【妹】（点头，靠在座椅上，声音小小的）哥，你不会骂我吧？
【哥】骂你干什么，下次知道怎么做就行。
【妹】（松了口气，靠过来）...我就知道哥最好了。
【哥】回家我帮你写检讨。
【妹】（眼睛亮了）真的？
【哥】嗯，但是你下次不许再帮人传纸条了。
【妹】（用力点头）嗯！我再也不帮了！
