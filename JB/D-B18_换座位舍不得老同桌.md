# D-B18：换座位舍不得老同桌
# 月考后调座位，她和坐了一年的同桌分开了，放学见到你就红了眼，拉着你去买了两支棒棒糖说要纪念
# 地点：校门口/小区长椅，傍晚放学

【哥】（放学在校门口等她，看见她磨磨蹭蹭走出来，肩膀耷拉着，头低着，手里攥着什么东西，眼眶红红的，看见你也没像平时一样蹦过来，就慢慢走到你身边）怎么了这是？谁欺负你了？眼睛怎么红了？
【妹】（走到你身边，头埋得低低的，半天没说话，过了好一会儿才小声开口，声音带着浓浓的鼻音，快哭了）哥...我们...我们今天调座位了...
【哥】（松了口气，还以为出什么大事了，原来是调座位，揉了揉她的头发，笑着说）调座位就调座位呗，多大点事，怎么还哭了？新同桌不好吗？
【妹】（抬起头，眼泪"唰"就掉下来了，赶紧用手背擦，但是越擦越多，抽抽搭搭的）我...我跟林晓分开了...我们坐了一年同桌了...老师把我调到第三排去了...她一个人坐最后一排...我舍不得她...
【哥】（这才明白过来，她跟她同桌林晓坐了整整一年，两个人关系特别好，上课一起偷偷传纸条，下课一起去买零食，连去厕所都要一起去，难怪她这么难过。你掏出纸巾帮她擦眼泪，牵着她往路边走）好了好了，不就是换个座位吗，又不是见不到了，还在一个班呢，下课照样可以一起玩啊。
【妹】（抽抽搭搭地跟在你身边走，眼泪还是掉个不停，攥着你的手，委屈得不行）不一样...以前上课的时候...我们一起偷偷看漫画...她帮我挡着老师...我不会的题她给我讲...现在换了新同桌...我都不认识...我上课连个说话的人都没有了...
【哥】（听她这么说也有点心疼，停下脚步，帮她把脸上的眼泪擦干净，捏了捏她红红的鼻子）傻丫头，就算换了座位，你们还是最好的朋友啊，下课可以一起去买零食，放学可以一起走，周末还可以一起写作业，怎么就没人说话了？而且新同桌过两天熟悉了不就好了？
【妹】（还是难过，吸了吸鼻子，从口袋里掏出两颗草莓味的棒棒糖，一颗递给你，一颗自己攥在手里，声音闷闷的）...刚才放学...我跟林晓一起去小卖部买的...她说一人一颗...纪念我们做了一年同桌...
【哥】（接过棒棒糖，草莓味的，你不太爱吃糖，但是还是揣进了口袋里。她剥开自己那颗含在嘴里，糖甜甜的，但是她还是皱着眉头，眼泪吧嗒吧嗒掉）
【妹】（含着糖，眼泪还是止不住地掉，糖是甜的，但是心里酸酸的，小手紧紧攥着你的衣角，一步一步跟着你走）
【哥】（牵着她走到长椅边坐下，让她靠在你肩膀上，她乖乖靠过来，含着糖，抽抽搭搭的，像只被抛弃的小兔子。你轻轻拍她的背，轻声说）我知道你舍不得，坐了一年同桌，突然分开肯定难受，但是你想想，换了新座位，你可以认识新的朋友，而且坐第三排看黑板更清楚，对你学习也好，对不对？
【妹】（靠在你肩膀上，含着棒棒糖，过了好半天才点点头，但是还是有点难过，小声说）...道理我都懂...但是我就是舍不得...林晓还说...以后没人帮我挡着老师看漫画了...我上课看漫画肯定会被抓...
【哥】（被她逗笑了，弹了她脑门一下）你还说，上课看漫画本来就不对，以后少上课看漫画，好好学习。还有，新同桌要是不好相处，你就来找我，我去跟你们老师说，帮你换回来，行不行？
【妹】（抬起头看你，眼睛肿得像桃子，但是听到你这么说，眼睛亮了一下，小声问）真的？你真的会帮我跟老师说？
【哥】（点点头，帮她把脸上沾的糖渣擦掉，笑着说）真的，但是我觉得新同桌肯定也挺好的，你先跟人家相处两天试试，要是实在合不来，我再去找老师，好不好？
【妹】（含着棒棒糖，想了半天，终于点了点头，但是还是有点舍不得，从口袋里掏出她和林晓上课传的小纸条给你看，纸条上画着两个小人手拉手，写着"永远的同桌"。她看着看着，又掉了两滴眼泪，但是很快就擦掉了）
【哥】（陪她在长椅上坐了好久，她情绪慢慢稳定下来了，棒棒糖也吃完了，但是还是把糖纸折得整整齐齐夹在课本里，说要留作纪念。你牵着她往家走，她不像平时一样蹦蹦跳跳了，但是已经不哭了，跟你说新同桌是个安安静静的女生，学习特别好，说不定以后可以问她数学题）
【妹】（走到家门口，她突然停下来，抬头看你，眼睛还是有点红，但是已经有笑意了，小声说）哥...谢谢你...刚才我哭的时候你没笑我...还陪我坐了那么久...
【哥】（揉了揉她的头发，笑着说）傻瓜，我是你哥，你难过我当然要陪你。今天想吃什么？我给你做，就当给我们换了新座位的小丫头接风，好不好？
【妹】（终于笑了，眼睛弯成了月牙，晃着你的手说想吃番茄炒蛋，你笑着答应了。她牵着你的手进门的时候，还在说周末要约林晓一起来家里写作业，你笑着说好，心里想，小丫头的友情真是简单又真诚，换个座位都能哭成这样，但是也正是这样才可爱啊。晚上你口袋里那颗草莓棒棒糖，你一直没舍得吃，放在书桌抽屉里，放了好久）
