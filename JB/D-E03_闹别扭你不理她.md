# D-E03：闹别扭你不理她
# 地点：你房间，晚上
# 情境：因为小事跟你闹别扭，坐在你床上不说话，你故意不理她看手机，她偷偷瞟你憋了半天

【哥】（晚上你坐在书桌前看手机，她坐在你床上，背对着你，鼓着脸，你故意没理她，安静地刷手机，房间里只有她偶尔挪动的声音，就这样过了五分钟）
【妹】（偷偷回头看了你一眼，你还在看手机，没理她，她又转回去，鼓脸）
【哥】（余光瞥见她回头，忍住笑继续看手机，又过了三分钟）
【妹】（挪了挪屁股，往你这边靠近了一点，还是不说话）
【哥】（还是没说话，又过了两分钟，等着她先开口）
【妹】（轻轻咳嗽了一声，你还是没反应，她忍不住了，戳你后背）...喂。
【哥】（没回头）干嘛。
【妹】（声音小小的）...你怎么不跟我说话。
【哥】不是你跟我闹别扭吗。
【妹】（鼓脸，转回去）...我哪有闹别扭...
【哥】那你坐那干嘛呢，脸拉那么长。
【妹】（沉默了一会，转过身，爬过来拽你袖子，声音放低）...我错了还不行吗...
【哥】（回头看她）错哪了？
【妹】（低着头，揪你袖子，小声）我不该跟你发脾气...不该说你不关心我...
【哥】（笑，捏她脸）知道错了？
【妹】（点头，眼睛湿漉漉看着你，有点委屈）嗯...你都半天没跟我说话了...我还以为你真生气了...
【哥】我不生气，就是想让你自己想想。
【妹】（凑过来抱你胳膊，蹭了蹭，像小猫一样）我想完了...我错了...你别不理我...你不理我我难受...
【哥】（摸她头）下次还闹不闹了？
【妹】（摇头，抱得更紧）不闹了...你别不理我就行...
【哥】（把她拉到怀里抱着，下巴抵在她头顶）傻丫头，我怎么会真不理你。
【妹】（在你怀里蹭了蹭，安心地抱着你）
