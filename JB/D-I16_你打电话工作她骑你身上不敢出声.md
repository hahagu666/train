# D-I16：你接工作电话她骑你身上故意动
# 地点：你房间书桌前
# 情境：你正在接工作/同学的重要电话，她故意骑到你身上，你捂着电话不敢出声

【哥】软软，别闹，我在接电话。（晚上你坐在书桌前接组长的电话，正在说工作的事，语气严肃，她洗完澡进来，看见你在打电话，眼睛转了转，坏笑了一下。）
【妹】（洗完澡穿着浴袍，看见你在打电话，故意轻手轻脚走过去，你看了她一眼，用口型说"别闹，工作电话"，她装作没看见，直接跨坐在你腿上，浴袍敞开，里面什么都没穿。）唔...哥在打电话呀...
【哥】（她突然坐在你腿上，浴袍敞开露出白白的身体，你一下子就硬了，赶紧对着电话说"嗯组长您继续说"，手捂着话筒，瞪了她一眼，用口型说"下去，别闹"。）别...别闹...
【妹】（她不仅没下去，反而对着你坏笑，手往下摸，握住你硬邦邦的肉棒，轻轻套弄了两下，然后扶着对准自己湿漉漉的小穴，慢慢坐下去，全部吞进去，你闷哼一声，她赶紧捂住你的嘴。）唔...进去了...
【哥】（你被她突然坐进来，差点叫出声，赶紧咬着嘴唇，对着电话强装镇定。）没...没事组长，刚刚喝水呛了一下，您继续。
【妹】（她全部坐到底，肉棒深深插在小穴里，她开始慢慢动，腰轻轻上下起伏，但是不敢动太大，手捂着你的嘴，脸凑在你耳边，小声坏笑。）哥...你继续打电话呀...别管我...
【哥】（你狠狠瞪了她一眼，但是小穴紧紧裹着你太舒服了，你一边对着电话应付，声音都有点发颤，一边手抱着她的腰，不让她动太快，但是她故意慢慢磨，龟头蹭着她最敏感的地方。）嗯...对...这个方案我明天改好给您...
【妹】（她故意动得越来越快，小穴里不停流水，你穿着西裤，她的淫水把你的裤子都弄湿了一片，她咬着你的耳朵，小声坏笑。）哥...你硬了...是不是特别舒服...你说话呀...别停呀...
【哥】（你被她磨得快受不了了，但是电话还在打，组长还在絮絮叨叨说工作，你只能强装镇定，声音抖得更厉害了。）好的组长...我知道了...嗯...一定按您说的改...
【妹】（看你声音发颤，她更坏了，突然坐到底重重一顶，你差点叫出来，赶紧捂着话筒闷哼一声，她小穴开始收缩，快高潮了，咬着你的肩膀不让自己出声。）唔...
【哥】（你快射了，但是电话还没挂，你急得不行，对着电话说"组长我这边有点急事，我先挂了，明天跟您详谈！"不等对方回答就直接挂了电话，把手机往桌上一扔，抱着她的腰就开始快速抽插。）小坏蛋，你敢故意玩我！
【妹】（啊！你突然动这么快，她叫出声，抱着你的脖子，笑得特别得意。）谁让你打电话不理我...现在该理我了吧...啊...哥...好深...
【哥】（你抱着她狠狠干了几十下，她小穴紧紧夹着你，你腰一挺射在她里面，她也跟着高潮了，两个人抱着喘了半天。）啊...射了...
【妹】（趴在你怀里，喘着气，笑得特别开心。）下次你打电话我还这样...看你还敢不敢不理我...
【哥】（你捏了捏她的屁股，咬了咬她的耳朵。）下次我就把电话按免提，让你叫给所有人听。
