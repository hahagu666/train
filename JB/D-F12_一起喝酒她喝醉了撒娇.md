# D-F12：一起喝酒她喝醉了撒娇
# 地点：家里，爸妈出去了，周末晚上
# 情境：爸妈不在家，她偷喝你的啤酒，喝醉了，脸颊红红的黏着你撒娇

【哥】（周末晚上爸妈出去参加聚会，你在客厅喝啤酒看球赛，她坐在你旁边，看你喝得香，趁你不注意偷喝了一大口，结果被呛到了，咳得脸通红。）你偷喝什么呢，小孩子不能喝酒。
【妹】（咳得眼泪都出来了，脸通红，但是不服气，鼓着脸抢过杯子又喝了一大口，擦了擦嘴，理直气壮，结果啤酒苦苦的，她皱了皱鼻子，但是硬撑着又喝了两口，一杯啤酒下去，脸瞬间就红了，眼睛水汪汪的，开始犯晕。）我才不是小孩子！我都十七了！能喝！
【哥】（笑着没管她，继续看球赛，过了半场转头看她，她脸通红通红的，眼睛水汪汪蒙着一层水汽，歪着头靠在你肩膀上，眼神都直了，明显喝醉了。）说你不能喝还喝，醉了吧。
【妹】（靠在你肩膀上，脸红红的，烫得吓人，听见你说话，抬起头看你，眼睛水汪汪的像蒙了一层雾，傻乎乎笑，伸手摸你的脸，摸了半天摸不准位置，软软的手摸在你脸上，声音黏糊糊的，拖长了音调撒娇。）我没醉~哥~我好热啊...
【哥】（她整个人都靠在你身上，身体软软的暖暖的，脸颊红红的，嘴唇因为喝酒润润的粉粉的，呼出的气都带着啤酒的麦芽香气，手不老实，到处乱摸，摸完你脸摸你胸口，最后勾住你的脖子不撒手，整个人挂在你身上。）热就把外套脱了。
【妹】（不仅没脱外套，反而往你怀里钻，整个人坐在你腿上，跨坐在你大腿上，脸对着脸，离你特别近，呼吸暖暖的带着酒气喷在你脸上，眼睛水汪汪看着你，傻乎乎笑，手勾着你的脖子，身体软软的贴在你身上，胸软软的压在你胸口，声音黏糊糊的撒娇。）哥~你身上好凉快~让我抱抱~
【哥】（她坐在你腿上，整个身体都贴在你身上，软软的暖暖的，酒气混着她身上的香味特别好闻，她的脸离你只有几厘米，嘴唇粉粉的就在眼前，眼神迷离看着你，手还在你脸上乱摸，摸你眉毛摸你鼻子最后摸你嘴唇，软软的手指按在你嘴唇上，蹭来蹭去。）别闹，坐好。
【妹】（不仅没坐好，反而凑得更近，鼻尖都碰到你的鼻尖了，呼吸暖暖喷在你嘴唇上，她盯着你的嘴唇看了半天，眼睛水汪汪的，傻乎乎笑，声音黏黏糊糊的，说完不等你回答，就凑上来要亲你，你赶紧偏头，她亲在你脸颊上，温温热热的嘴唇碰在你脸上，亲了一口还不够，又在你脸上蹭来蹭去，像只撒娇的小猫。）哥~你的嘴唇看起来好软啊~我能不能亲一下...
【哥】（被她亲在脸上，温温热热的嘴唇带着啤酒的甜味，她整个人挂在你身上，黏黏糊糊撒娇，脸红扑扑的，眼睛水汪汪，身体没力气得像没有骨头一样靠在你怀里。）你喝醉了，别闹。
【妹】（听见你说她喝醉了，鼓着脸，气呼呼地看着你，但是脸红红的一点威慑力都没有，反而更可爱了，她伸手捧着你的脸，让你看着她，眼睛水汪汪认认真真看着你，看了半天，突然笑了，凑在你耳边，声音黏黏的，带着酒气，热气吹在你耳朵里，说完就咯咯笑，把脸埋在你肩膀上，抱着你的脖子不肯撒手，身体没力气地挂在你身上，像只喝醉了的小猫，嘴里还嘟囔着喜欢你，没两分钟就靠在你怀里睡着了，呼吸平稳，脸红扑扑的，嘴角还扬着笑，手紧紧抓着你的衣服。）哥~我喜欢你~特别特别喜欢~不是妹妹那种喜欢哦~
