# D-G11：两根手指插她小穴
# 地点：你床上
# 情境：一根手指已经满足不了她了，她红着脸让你插两根进去

【哥】（一根手指在她小穴里抽插，她水很多，滑溜溜的，快感上来她不停呻吟。）
【妹】（被一根手指插着，虽然舒服，但是总觉得不够满，里面还是空空的，她扭着腰，夹着你的手指，声音发颤带着哭腔。）哥...不够...
【哥】（手指动了动。）不够什么？
【妹】（脸红得像苹果，咬着嘴唇，不好意思说，但是里面实在太空了，她小声说。）手指...再加一根...一根太细了...不满...
【哥】（看着她渴望的眼神，你把中指也沾了她的水，对准穴口，和食指并拢，慢慢往里顶。）好。
【妹】（啊...两根手指一起进来，撑得满满的，胀痛感混着快感，她叫出来，眉头轻轻皱了一下，但是没让你停，反而腰往下沉，让你插得更深。）啊...胀...好胀...但是...好满...
【哥】（两根手指慢慢全部插进去，她里面又热又紧，层层嫩肉紧紧裹着你的两根手指，吸吮得特别紧。）紧...
【妹】（被插得满满的，那种充实感让她满足地叹了口气，紧紧抱着你，身体轻轻发抖，声音黏黏的。）嗯...就是这样...满了...舒服...
【哥】（等她适应了一会，才开始慢慢抽动两根手指，比一根的时候撑得更满，刮蹭到更多敏感的嫩肉。）嗯...
【妹】（她呻吟着，腿张得更开，主动扭着腰配合你的动作，水哗哗流出来，把床单浸湿了一大片。）啊...啊...哥...你动一动...太舒服了...
【哥】（手指在她紧致的小穴里快速抽插，发出咕叽咕叽的水声，时不时蹭一下她的G点。）嗯...
【妹】（被插得爽到不行，嘴里语无伦次地叫着哥哥，手抓着床单，头来回摇，眼泪顺着脸颊流，那是太舒服的眼泪，她突然身体绷紧。）哥...那里...就是那里...好麻...
【哥】（知道碰到G点了，手指故意对着那个点快速抠动。）这里？
【妹】（啊！！我不行了...她尖叫一声，浑身剧烈颤抖，小穴疯狂收缩，紧紧吸着你的手指，一股股水喷出来，高潮得比哪次都厉害，直接晕过去几秒，瘫在床上大口喘气。）啊...
【哥】（等她高潮完，慢慢抽出手指，两根手指上全是她的水，亮晶晶的。）舒服了？
【妹】（喘了半天，才回过神，浑身一点力气都没有，看到你手上全是她的水，羞得把脸埋进枕头里，但是又忍不住往你身边蹭，声音小小的黏黏的，带着哭腔。）哥...你好坏...弄的我...我又尿出来了...
【哥】（擦了擦手，抱着她。）那不是尿，是你太舒服了。
【妹】（抬起头，脸红扑扑的，眼睛水汪汪的，主动凑过来吻你，吻得黏黏的，小手往下摸，握住你的肉棒套弄，声音黏黏的撒娇。）哥...我也想让你舒服...下次...下次你把那个插进来好不好...我想试试...
