# D-D25：一起晒被子
# 地点：阳台，周末上午
# 情境：大晴天，你在阳台晒被子，她抱着枕头过来凑热闹，阳光晒得人暖洋洋的

【哥】（周末上午拉开窗帘，太阳晒进来，难得的好天气，抱了被子去阳台晒）
【妹】（听见动静从房间探出头，看见你在晒被子，立刻抱着自己的枕头跑过来）哥！我也要晒！
【哥】你那被子上周不是刚晒过？
【妹】（把枕头递到你面前，枕头上有她洗发水的香味）晒过了也要晒！晒完了有太阳的味道，睡觉特别香！
【哥】（笑着接过枕头搭在晾衣绳上，她又跑回去抱自己的被子，抱不动，被子拖在地上）
【妹】（被子太大了拖在地上，她整个人被被子裹住一半，踉踉跄跄走过来）哥...帮我...
【哥】（走过去接过来，帮她把被子搭在晾衣绳上，拍拍被子，灰尘在阳光里飞起来）
【妹】（站在旁边仰头看被子晒在太阳下，伸手摸了摸被面，阳光晒得她手背暖乎乎的，她舒服得眯起眼睛）好暖和啊...
【哥】（拿了晒被棍拍被子，她站在旁边躲，灰尘飘到她鼻子上，她打了个喷嚏）
【妹】（揉鼻子，鼓着脸看你）你拍轻点！灰都弄到我脸上了！
【哥】（笑着放下棍子，帮她把脸上的灰擦掉）站远点。
【妹】（没躲，仰着脸让你擦，阳光晒得她脸红红的，睫毛在阳光下投下一小片影子）哥...
【哥】嗯？
【妹】（突然伸手抱你的腰，把脸贴在你背上，声音闷闷的）等晚上被子收进来，我们一起在我床上叠被子好不好？
【哥】叠个被子还要一起？
【妹】（抱着你腰晃了晃，声音发黏）晒完太阳的被子蓬蓬的，裹在里面特别舒服...而且...（声音更小了）我想跟你一起裹着被子看动画片嘛...
【哥】（笑着回头揉她的头，她头发晒得暖乎乎的，发梢带着阳光的味道）行，晚上收了被子一起叠。
【妹】（立刻开心了，松开手蹦到阳台边，仰头看着晒在绳子上的两床被子，风一吹被子鼓起来像云朵一样，她伸手拍了拍被子，阳光洒在她身上，整个人都暖洋洋的）
【哥】（站在旁边看着她，她转过头来冲你笑，眼睛弯成月牙，鼻尖上还有一点被晒出来的汗，脸颊粉扑扑的）
【妹】（跑过来拉住你的手，把你的手贴在她晒得暖暖的脸上，眼睛亮晶晶的）哥你摸！太阳晒过的脸都是暖的！（她的手也暖暖的，阳光把两个人的影子拉得很长，叠在一起落在阳台的地板上，被子在风里轻轻晃着，全是阳光的味道）晚上我要吃橘子！叠被子的时候吃！
