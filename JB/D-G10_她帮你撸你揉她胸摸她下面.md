# D-G10：她帮你撸你揉她胸摸她下面
# 地点：你床上
# 情境：两个人互相爱抚，她帮你打飞机，你的手揉她胸摸她下面，同时达到高潮

【哥】（你们躺在床上，被子盖着，侧对着对方，她的手伸在你睡裤里握着你的肉棒慢慢套弄。）
【妹】（小手软软的握着你，慢慢上下动着，脸埋在你肩膀上，呼吸暖暖的喷在你脖子上，时不时轻轻吻一下你的脖子，声音黏黏的。）哥...舒服吗...
【哥】（嗯...舒服。你的手也没闲着，一只手伸到她睡衣里揉着她软软的胸，拇指蹭着她硬硬的乳头。）嗯...舒服。
【妹】（嗯...被你揉着乳头，她舒服地哼了一声，手不自觉加快了一点速度，下面不由自主往你身上蹭。）嗯...
【哥】（另一只手往下滑，伸进她内裤里，直接摸到她湿漉漉的小穴，手指轻轻揉着她的阴蒂。）湿了。
【妹】（啊！两边同时被你摸着，她一下子叫出声，手都停了一下，身体抖得厉害，声音黏黏的带着哭腔。）啊！哥...你太坏了...两边一起摸...我...我受不了...
【哥】（手指没停，一边揉着她胸捏乳头，一边手指在她阴蒂上快速打着圈，她很快就呼吸急促起来。）嗯...
【妹】（被你揉得快感一波接一波，她赶紧继续手上的动作，快速给你套弄着肉棒，两个人都在给对方快感，她吻住你的嘴唇，呻吟都咽进你嘴里，小穴里的水流得满手都是。）嗯...
【哥】（她的手又快又稳，软软的握着特别舒服，加上吻着她甜甜的嘴唇，快感越来越近。）快了...
【妹】（吻着你，手上不停，下面被你揉得快要高潮了，她手也越来越快，小穴不停收缩，身体抖得厉害，呻吟断断续续。）哥...我...我又要来了...
【哥】（喘着气。）我也要射了...
【妹】（听见你说要射了，她立刻握紧了一点，套弄速度更快，拇指紧紧按着你龟头下面的系带，那是你最敏感的地方，同时她自己也被你揉到了顶点，身体猛地绷紧。）嗯...
【哥】（啊...我射了...你腰一挺，一股股精液射在她手里和被子上，肉棒剧烈跳动着。）啊...
【妹】（啊...哥！她也同时高潮了，小穴里一股股水喷出来，浇在你手指上，身体剧烈颤抖，软在你怀里，手还下意识握着你跳动的肉棒，直到你射完。）啊...哥...
【哥】（喘着气，把她紧紧搂在怀里，两个人都浑身是汗，她的手还放在你软下来的肉棒上，你的手还留在她湿透的内裤里。）嗯...
【妹】（喘了半天，才缓过来，抽出她黏糊糊的手，上面全是你的精液，她也没嫌脏，拿纸巾随便擦了擦，又抽出手帮你擦了擦，然后钻回你怀里，紧紧抱着你，声音黏黏的带着满足。）哥...我们一起...一起到的...好舒服...
【哥】（摸了摸她汗湿的头发，亲了亲她的额头。）嗯。
【妹】（往你怀里蹭了蹭，腿搭在你的腿上，下面湿乎乎的蹭在你大腿上她也不在意，只要能抱着你就好，她过了一会，声音小小的，带着点羞涩。）哥...我喜欢这样...和你一起...
【哥】（抱着她。）我也喜欢。
【妹】（听见你说也喜欢，她笑得甜甜的，在你嘴唇上亲了一下，然后乖乖窝在你怀里，抱着你的腰，听着你的心跳，慢慢呼吸平稳下来，满足地睡着了，脸上还带着红晕。）嗯...
