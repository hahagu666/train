# D-E02：撒娇不想让你去上班
# 地点：玄关，周一早上
# 情境：周一早上你要出门上班，她从房间跑出来，抱着你腰不让你走，困得眼睛都睁不开

【哥】（周一早上闹钟响了，你换好衣服准备出门，在玄关处换鞋）
【妹】（她房间门突然开了，穿着睡衣，头发乱蓬蓬的，光着脚跑出来，从后面抱着你腰，脸埋在你后背，声音黏糊糊的，困得鼻音很重，眼睛都没睁开）唔...哥...
【哥】（回头看她）怎么起来了？再睡会。
【妹】（摇头，抱得更紧，脸蹭你后背）不要...你别走...
【哥】我得上班啊，乖。
【妹】（鼓脸，不撒手，脚勾着你腿）不上班行不行...
【哥】不上班你养我啊？
【妹】（想了想，小声）我...我攒了压岁钱...我养你...你别去上班了...在家陪我...
【哥】（笑，转过身揉她头发）傻丫头，我下班就回来，晚上给你带草莓蛋糕。
【妹】（眼睛睁开一条缝，看着你，还是不撒手）...真的？
【哥】真的。
【妹】（犹豫了一下，慢慢松开手，但是还是拽着你衣角）那...那你早点回来...
【哥】嗯，一定早点。
【妹】（踮起脚，在你下巴上亲了一口，然后脸红红的，转身往房间跑）我等你回来！
【哥】（笑）回去穿鞋，别光脚。
【妹】（在房间门口回头，头发乱蓬蓬的，冲你挥挥手）知道啦！路上小心！
