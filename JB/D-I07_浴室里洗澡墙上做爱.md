# D-I07：浴室里洗澡墙上做爱
# 地点：你家浴室
# 情境：一起洗澡，你硬了，扶着她在浴室墙上做，热水冲在身上

【哥】（晚上你在洗澡，她推开门进来，说要一起洗，你还没反应过来她就脱光了站在淋浴下面，热水冲在她白白的身体上，皮肤粉粉的。）你怎么进来了？
【妹】（光着身子走进来，站在热水下面，头发湿湿的贴在脸上和脖子上，对着你笑，水顺着她的乳房往下流，流过小腹，流到腿间，她走到你身边抱住你。）一起洗嘛，我帮你搓背。
【哥】（她软软的身体贴过来，皮肤滑滑的，热水冲在两个人身上，你一下子就硬了，肉棒抵在她小腹上。）你这是勾我犯罪。
【妹】（她感觉到你硬了抵着她，脸红了，但是故意装作不知道，小手往下摸，握住你的肉棒，轻轻套弄了两下，对着你笑。）什么犯罪呀...我帮你洗这里...
【哥】（被她湿滑的小手一握，你舒服得闷哼一声，伸手抱住她，把她按在浴室瓷砖墙上，热水喷在旁边，瓷砖凉凉的，她背靠着墙，你吻住她的脖子。）小坏蛋，洗完澡再收拾你。
【妹】（被你按在墙上，后背碰到凉凉的瓷砖，她抖了一下，但是张开腿缠上你的腰，小穴刚好抵着你的肉棒，已经湿了，不知道是水还是她自己的水，她吻着你的耳朵小声说。）不要等洗完...现在就要...
【哥】（你扶着肉棒，龟头对准她湿滑的穴口，因为有水特别滑，你一挺腰就全部插进去了。）嗯...进去了...
【妹】（啊！全部进来的太突然，她叫出声，后背在凉凉的瓷砖上，前面是你热热的身体，肉棒深深插在她小穴里，热水从上面冲下来，打在两个人身上，她抱着你的脖子，腿夹得紧紧的。）啊...哥...好深...
【哥】（你抱着她的腿，把她抬起来一点，靠在墙上开始抽插，水冲在身上滑溜溜的，每一下都插得特别深，水声、抽插的水声、还有她的呻吟声混在一起。）舒服吗？
【妹】（啊...啊...你动得太快，她舒服得头往后仰，撞在瓷砖上也不疼，热水冲在她奶子上，你含住一个乳头吸吮，她手抓着你的头发，呻吟声在浴室里有回音，特别大。）哥...嗯...好舒服...水...水进小穴里了...
【哥】（听她这么说你更兴奋了，加快速度抽插，热水确实顺着你们交合的地方流进去，和她的淫水混在一起，滑得不行，每一下都整根没入。）舒服吗？
【妹】（舒服...太舒服了...她哭着点头，眼睛水汪汪的，脸上全是水，不知道是洗澡水还是眼泪，她小穴紧紧裹着你，腰主动扭着配合你，奶子在你眼前晃来晃去。）哥...我要去了...
【哥】（你一只手揉着她的阴蒂，快速抽插，她抖得厉害。）嗯...到我这里来...
【妹】（啊...！她身体猛地绷紧，小穴剧烈收缩，高潮了，嘴里发出断断续续的呻吟，身体软得挂在你身上，要不是你抱着她就滑下去了。）啊...哥...
【哥】（她高潮的时候夹得你特别紧，你也忍不住了，腰猛地往前顶，全部插到底，射在她里面，精液混着热水流出来，顺着她的大腿往下流。）啊...射了...
【妹】（你射在里面她又抖了一下，抱着你喘了半天，热水还在冲，把两个人身上的汗水和精液都冲干净，她趴在你肩膀上，小声说。）腿软了...站不住...
【哥】（你抱着她，让她靠在墙上，吻了她半天，等她缓过来，才帮她洗干净身体，用浴巾裹住她抱出去。）乖，我抱你出去。
【妹】（被你抱到床上，她裹着浴巾往你怀里钻，脸红扑扑的，头发还是湿的，小声说。）在浴室做好刺激...水声好大，我还以为会被听见...
【哥】（你笑着揉了揉她的头发，拿吹风机帮她吹头发。）下次还敢不敢勾引我了。
【妹】（她转过身，跨坐在你腿上，浴巾滑下来，露出白白的身体，吻你的嘴唇，眼睛亮晶晶的。）敢...下次还要在浴室做...
