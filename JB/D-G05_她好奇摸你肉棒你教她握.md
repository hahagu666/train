# D-G05：她好奇摸你肉棒你教她握
# 地点：你床上
# 情境：你摸她胸摸得她很舒服，她好奇伸手摸你下面，第一次摸到硬邦邦的肉棒

【哥】（你躺在她身边，吻着她，手揉着她软软的胸，她在你怀里轻轻哼着。）
【妹】（被你揉得浑身发软，靠在你怀里，手不知不觉往下摸，碰到你睡裤里硬硬的一大团，她愣了一下，手停在那里，抬头看你，眼睛水汪汪的。）哥...你这里...怎么这么硬...
【哥】（身体僵了一下，抓住她的手，想拿开。）别...别乱摸...
【妹】（不仅没拿开，反而把手按得更紧一点，隔着睡裤摸了摸那个硬硬的东西，它在她手底下跳了一下，她脸红得更厉害了，但是好奇心压过了害羞，声音黏黏的。）我...我想摸摸...好不好...
【哥】（看着她好奇又害羞的眼神，点了点头，松开了她的手。）好。
【妹】（得到允许，她手有点抖，慢慢掀开你睡裤的松紧带，往里探进去，第一次碰到你的肉棒，滚烫，坚硬，她吓了一跳，手缩了一下，又大着胆子伸手进去，握住了它。）啊...这么烫...还在跳呀...
【哥】（被她软软凉凉的小手一握，你忍不住闷哼了一声。）嗯...
【妹】（听见你闷哼，她抬头看你，脸红扑扑的，手轻轻握了握，有点不知所措。）我...我怎么握...这样对不对...
【哥】（伸手覆在她的小手上，带着她的手轻轻上下套弄，她的手小小的，软软的，握得有点紧。）这样...慢慢动...
【妹】（跟着你的力道，小手慢慢上下动起来，肉棒在她手里硬硬的一跳一跳的，她能感觉到上面血管的跳动，好奇怪的感觉，但是看着你舒服的表情，她心里甜甜的，脸红红的。）它...它好硬啊...比我想的大...
【哥】（她的小手软软的，虽然动作很生涩，但是特别舒服，你忍不住轻轻喘气。）嗯...
【妹】（看着你喘气的样子，她胆子大了一点，手加快了一点速度，但是她没经验，动作有点乱，指甲不小心刮到了龟头。）啊...
【哥】（嘶了一声。）嘶...你轻一点...这里很敏感...
【妹】（赶紧停下来，看着你，有点慌，声音带着哭腔的撒娇。）对...对不起...我弄疼你了吗...
【哥】（摇摇头，指着龟头。）这里最敏感，你慢点，轻一点。
【妹】（点点头，按照你说的，动作放轻放慢，小手轻轻握着，拇指轻轻蹭了蹭龟头湿漉漉的顶端，那里已经流出一点透明的液体了，她好奇的摸了摸，滑滑的。）哥...这里湿了...是什么...
【哥】（喘着气。）那是前列腺液...正常的...
【妹】（哦了一声，似懂非懂，但是手没停，继续慢慢给你套弄，虽然动作生涩，但是软软的小手握着特别舒服，她看着你舒服的表情，自己也觉得开心，凑过来吻你的下巴，声音黏黏的撒娇。）这样...这样舒服吗...
【哥】（舒服地叹了口气。）舒服...软软你真乖...
【妹】（听见你夸她，她笑得眼睛都弯了，虽然手酸了，但是还是继续慢慢动着，认真地给你撸，脸红红的，时不时抬头看你表情，凑过来亲你嘴唇，心里偷偷想，原来哥哥的这个东西是这样的，硬硬的，烫烫的，握着好有感觉。）嗯...
