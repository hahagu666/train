# D-G02：摸她大腿内侧她夹紧腿
# 地点：客厅沙发上看电影
# 情境：周末爸妈不在家，你们一起在沙发上盖着毯子看电影，你手慢慢伸到毯子下面摸她大腿，摸到内侧她夹紧腿

【哥】（周末爸妈出去买菜，你们在沙发上用毯子盖着腿看电影，她靠在你肩膀上，穿着短裙。）
【妹】（靠在你肩膀上，抱着爆米花吃，看到恐怖的地方就往你怀里钻，短裙盖住大腿，露出白白的膝盖，皮肤滑滑的。）哥...这个电影好吓人啊...
【哥】（伸手揽着她的肩膀，另一只手自然地放在她膝盖上，她的膝盖暖暖的滑滑的。）别怕，有我在。
【妹】（没在意，继续靠在你怀里看电影，还把爆米花递到你嘴边喂你吃。）啊~张嘴。
【哥】（张嘴吃了爆米花，手慢慢从膝盖往上移，一点一点挪到她大腿上，她的大腿皮肤特别滑，软软的。）好吃。
【妹】（一开始没反应过来，还在看电影，过了两秒才感觉到你的手往上移了，身体轻轻抖了一下，但是没躲开，只是身体稍微僵硬了一点。）哥...你手往哪放呢...
【哥】（没说话，手继续慢慢往上挪，摸到她大腿内侧，那里的皮肤更软更嫩，比别的地方都要热一点。）嗯...
【妹】（被你摸到大腿内侧最敏感的地方，她啊的小声叫出来，身体猛地一抖，立刻并拢腿，紧紧夹住你的手，不让你再往上动，脸瞬间红透了，电影也不看了，转头看你，眼睛水汪汪的，呼吸都急了。）啊！
【哥】（手被她夹在大腿中间，软软的腿夹住你的手，温度很高，能感觉到薄薄的内裤布料就在不远处，你没抽手，就那么放在那里。）夹这么紧。
【妹】（夹着你的手，脸红得像苹果，心跳快得咚咚咚，过了半天，不仅没把你的手推开，反而悄悄把腿分开了一点点，但是只分开了一点点，还是夹着你的手，声音小小的发着颤，带着撒娇和羞涩。）这里...这里不能摸...痒...
【哥】（手轻轻在她大腿内侧揉了一下，细腻光滑的皮肤触感特别好。）痒？
【妹】（被你一揉，她浑身麻了一下，嗯...地小声哼出来，赶紧捂住嘴，身体没力气地靠在你怀里，腿不自觉又分开了一点点，但是还是有点紧张，夹着你的手轻轻发抖，声音发着颤带着哭腔。）嗯...你别揉了...我...我腿发颤了...
【哥】（能感觉到她腿确实在轻轻发抖，手没再往上，就轻轻在她大腿内侧摸着，偶尔捏一下她软软的大腿肉。）好。
【妹】（被你摸得浑身都没力气了，下面慢慢开始发热，有点湿湿的感觉，她咬着嘴唇，靠在你怀里，呼吸暖暖的喷在你脖子上，过了半天，悄悄拿起你的手，往上带了一点点，又立刻停下，脸红得快滴血，声音小得像蚊子叫。）只...只能再往上一点点...不许碰那里...
【哥】（看着她脸红害羞的样子，特别可爱，手顺着她的力道又往上挪了一点，离她内裤只有一点点距离了，能感觉到那里热热的温度传过来。）好。
【妹】（感觉到你的手离那里那么近，她浑身都僵了，但是没躲开，反而往你怀里缩了缩，把脸埋在你胸口，手紧紧抓着你的胳膊，身体轻轻发抖，连电影情节都完全看不见了，满脑子都是你放在她大腿上的手，热热的，痒痒的，特别舒服。）嗯...
