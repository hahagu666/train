# D-B20：当语文课代表收作业被刁难
# 她刚当上课代表，收作业的时候有男生故意不交还刁难她，把她气哭了，你帮她去讲道理，教她怎么当课代表
# 地点：学校走廊/教室，早自习下课

【哥】（早自习刚下课，她红着眼睛跑到你教室门口，也不进来，站在门口冲你招手，眼泪在眼眶里打转，你赶紧走出去）怎么了这是？又被谁欺负了？
【妹】（站在走廊里，手里抱着一摞语文作业本，眼泪"啪嗒"掉在作业本上，委屈得不行，声音哽咽）哥...我...我不想当语文课代表了...
【哥】（赶紧把她拉到没人的地方，接过她怀里沉甸甸的作业本，帮她擦眼泪，这才问怎么回事。她上周刚被选为语文课代表，开心了好几天，今天怎么就不想当了）慢慢说，怎么回事？谁惹你了？
【妹】（抽抽搭搭的，一边哭一边说）我...我收作业...张浩他不交作业...还说"你一个新选的课代表算什么，我就不交你能把我怎么样"...还把我手里的作业本碰掉了一地...我让他交他还说我多管闲事...
【哥】（心里一下子火就上来了，但是看着她哭得稀里哗啦的样子，先压着火气，蹲下来帮她把眼泪擦干净，揉了揉她的头发）就因为这个就不想当了？他不交作业是他不对，你按照规矩记名字交给老师就行了，哭什么？
【妹】（哭得更委屈了，捶了你胸口一下，但是力气轻得像挠痒痒）我...我不敢记他名字...他是班里的体育生...个子那么高...我怕他记仇...以后欺负我...我当课代表本来就不容易...每天早早就来收作业...大家都不配合...我不想当了...
【哥】（听她这么说，心疼得不行，把她揽进怀里轻轻拍背，她趴在你怀里哭了半天，把一早上的委屈都哭出来了。等她哭够了，你帮她把作业本整理好，牵着她的手往她们班走）走，哥陪你去收作业，我看看谁敢不交。
【妹】（赶紧拉住你，有点害怕，摇摇头）别...别去...你去了他更要笑话我了...说我找哥哥帮忙...更要欺负我了...
【哥】（停下脚步，蹲在她面前，看着她红红的眼睛，认真地说）我不去跟他吵架，我就在旁边看着，你自己去收，他要是敢刁难你，我再说话，好不好？你不能遇到一点困难就不当课代表了，这是老师同学信任你才选你当的，你要是就这么放弃了，以后遇到别的事怎么办？
【妹】（看着你认真的样子，犹豫了半天，终于点了点头，抱着作业本，磨磨蹭蹭跟在你身后走进教室。你靠在教室后门门框上看着，她走到张浩桌子旁边，虽然还是有点紧张，但是声音比刚才大了点）张浩，请你交语文作业。
【哥】（你靠在后门门框上，双手抱胸，就那么看着那个男生，没有说话，但是眼神很严肃，意思很明显——你今天最好乖乖交作业）
【妹】（那个男生抬头看见你站在后门，愣了一下，他认识你，知道你是高年级的，上次运动会你拿了三千米冠军他还看过你比赛，刚才的嚣张劲一下子就没了，磨磨蹭蹭从书包里掏出作业本递过去，小声说"我...我忘写了，下午交行不行"）
【妹】（没想到他突然就软下来了，愣了一下，回头看你，你冲她点点头，她转过头，学着你的语气，鼓起勇气说）那...那你下午第一节课之前一定要交给我，不然我就告诉老师你没交作业，知道吗？
【哥】（那个男生赶紧点头，说"知道了知道了，下午肯定交"，她抱着作业本收完最后几本，整理好给老师送过去，回来的时候脸红红的，眼睛还肿着，但是特别开心，跑到你面前，眼睛亮晶晶的）哥！他交了！不对...他说下午交！他刚才居然没凶我！
【哥】（笑着揉了揉她的头发，牵着她走出教室，靠在走廊栏杆上跟她说）你看，你自己也能收好作业对不对？当课代表不是让你去凶别人，但是也不能怕别人，你按规矩来，不交作业就记名字告诉老师，谁也不能把你怎么样，知道吗？
【妹】（乖乖点头，但是还是有点小纠结，趴在栏杆上，小声问）...可是...如果他以后还是故意不交作业刁难我怎么办...我还是有点怕...
【哥】（弹了她脑门一下，笑着说）怕什么？有我在呢，他要是敢欺负你，你就来找我，我帮你讲道理。但是你也要学会自己处理，不能什么事都找我，对不对？你现在是课代表了，要负责任，不能说不当就不当了，知道吗？
【妹】（想了想，使劲点头，眼睛亮晶晶的，刚才的委屈全没了，又充满干劲了，攥着小拳头说）嗯！我知道了！我肯定当好这个课代表！每天把作业收齐！不让老师失望！也不让你失望！
【哥】（笑着捏了捏她红红的脸蛋，从口袋里掏出一颗草莓糖递给她，她接过糖剥开吃了，甜甜的，脸上还挂着泪痕，但是笑得特别甜。你看着她开心的样子，心想，小丫头总是要长大的，你不能一辈子帮她解决所有问题，但是你可以一辈子站在她身后，在她需要的时候做她最坚实的后盾。
【妹】（吃着糖，突然想起什么，抬头看你，有点不好意思，小声说）哥...刚才谢谢你...要不是你站在后面...我肯定不敢跟他说话...你教我的我都记住了...以后我自己能收好作业...但是...但是如果我真的处理不了...我还能来找你吗...
【哥】（笑着揉了揉她的头发，认真地点头）当然可以，不管什么时候，不管遇到什么事，你都可以来找我，我永远在你身后，知道吗？
【妹】（笑得眼睛弯成了月牙，使劲点头，抱着作业本蹦蹦跳跳回教室了，跑了两步又回头冲你挥挥手，说"放学等我一起回家"，你笑着点点头，靠在栏杆上看着她跑进教室，阳光照在她身上，像个充满干劲的小勇士。下午那个男生果然准时把作业交了，她收齐作业的时候，特别骄傲地冲你比了个耶，你笑着冲她竖了个大拇指）
