# D-E15：生病脆弱依赖你
# 地点：她房间，她发烧了
# 情境：她发烧了，脸通红躺在床上，你照顾她喂她吃药，她抓着你手不让你走，特别依赖

【哥】（端着水和退烧药进来，坐在床边，她发烧了38度9，脸通红躺在床上，盖着厚被子，眼睛湿漉漉的）来，把药吃了。
【妹】（迷迷糊糊睁开眼睛，看到是你，伸出手从被子里伸出来，抓着你衣角，声音哑哑的，带着鼻音）哥...
【哥】（扶她起来）烧退了就好了，先吃药。
【妹】（乖乖靠在你怀里，你喂她吃药，她皱着眉咽下去，苦得眯眼睛，然后埋在你胸口蹭，像只小猫）苦...
【哥】吃了药睡一觉就好了。（想把她放回枕头上）
【妹】（立刻紧紧抱着你腰，不撒手，声音发哑，带着哭腔）...你别走...
【哥】我不走，我在这陪着你。
【妹】（摇头，抱得更紧了，脸贴在你胸口，声音发颤）我难受...浑身都疼...你抱着我睡好不好...
【哥】（躺下来，把她搂在怀里，盖好被子）好，抱着你睡。
【妹】（蜷缩在你怀里，脸贴在你胸口，手紧紧抓着你衣服，呼吸热热的喷在你脖子上，声音小小的）...哥，我会不会死啊...
【哥】（笑，摸她额头，还是烫的）瞎说什么，就是个感冒，睡一觉就好了。
【妹】（蹭了蹭，找了个舒服的位置，闭上眼睛，声音越来越小）...你不许走...
【哥】不走，一直在这。
【妹】（嗯了一声，抓着你衣服的手慢慢放松了，呼吸变得平稳，在你怀里睡着了，眉头还是皱着，但是嘴角放松下来）
【哥】（你摸了摸她的头，还是烫的，但是她睡得很安稳，手一直抓着你衣服没松开）
【妹】（在你怀里蹭了蹭，睡得更沉了）
