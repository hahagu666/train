# D-C21：她偷偷用你电脑被抓
# 地点：你房间，周末下午
# 情境：你出去买东西，她偷偷溜进你房间想用你电脑看动漫，结果你提前回来了

【哥】（买完东西提前回家，推开自己房门，看见她坐在你电脑前，手还放在鼠标上，慌慌张张想关页面）哟，干嘛呢？偷偷进我房间？
【妹】（整个人僵住，脸瞬间红了，手忙脚乱想关浏览器，结果越急越点错）我...我没有...我就是...我进来找本书...
【哥】（走过去靠在桌边，似笑非笑看着她）找书找到我电脑跟前来了？书在电脑里啊？
【妹】（脸更红了，低下头手指绞着衣角，声音小小的）...我就是想借你电脑用一下...我房间电脑坏了...
【哥】（伸手点开浏览器历史，看见一堆动漫播放记录，还有她没关的番剧页面，挑眉）哦？看番呢？什么番啊让我看看。
【妹】（赶紧伸手挡屏幕，急得快哭了）不许看！哥你不许看！
【哥】（笑，把她的手轻轻拿开）还不好意思了？看个番而已，哥又不说你。
【妹】（鼓脸，眼睛红红的，手指揪你衣服）我...我就是想看新出的那一集...我房间电脑刚好坏了...我不是故意偷偷进来的...
【哥】（揉她头发，拉了把椅子让她坐）想看就跟我说啊，偷偷摸摸进来干嘛，我又不让你看。
【妹】（坐下来，还是低着头，耳朵尖红红的）我...我怕你说我不学习偷看动漫...
【哥】（弹她脑门）你作业写完了吗？就看动漫。
【妹】（声音更小了）...写完了...真的...我写了一上午了...就想看一集...
【哥】（笑，把鼠标给她）行了，看吧，就看一集啊，看完了去背单词。
【妹】（眼睛一下子亮了，抬头看你，又立刻低下头，声音黏黏的有点不好意思）...谢谢哥...
【哥】（靠在旁边看她打开动漫，故意逗她）这男主长得还挺帅啊，你是不是喜欢这款？
【妹】（脸一下子红到脖子根，伸手捂你嘴）哥你不许说！
【哥】（笑着拿开她的手）好好好，不说不说，快看吧，一会妈该过来叫我们吃饭了。
【妹】（点点头，点开播放，但是坐得离你很近，肩膀时不时碰到你，看一会就偷偷看你一眼，嘴角扬着）
