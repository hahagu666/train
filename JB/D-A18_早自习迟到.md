# D-A18：早自习迟到
# 地点：家里玄关/学校路上，早上七点半
# 情境：起晚了，书包都没整理好，嘴里塞着面包往门口冲

【哥】（在厨房做早饭，突然听见房间里传来慌乱的叫声）
【妹】（房间里传来慌乱的声音）啊——！
【哥】（在厨房探出头）怎么了？
【妹】（头发乱蓬蓬冲出来，校服拉链都没拉，看墙上的钟）七点半了！我闹钟没响！
【哥】我叫你了你没起来。
【妹】（急得快跳脚，到处找袜子）我袜子呢...我另一只袜子哪去了...
【哥】（从沙发上捡起来扔给她）在这。
【妹】（单脚站着穿袜子，差点摔倒）完了完了早自习要迟到了，老王今天值班...
【哥】（把一袋面包和牛奶塞她手里）路上吃。
【妹】（接过塞嘴里，叼着面包背书包，一只手穿鞋）我走了啊！
【哥】慢点跑，别摔着。
【妹】（开门冲出去，门砰一声关上）
【哥】（摇摇头，刚要收拾，门又开了）
【妹】（探头进来，脸红）那个...我校牌呢？
【哥】（从玄关挂钩上摘下来递给她）你啊。
【妹】（接过校牌挂脖子上，又冲出去）
【哥】（笑，回去收拾，手机震了一下）
【妹】（发消息）哥！我跑到校门口了！打铃了！我冲进去了！
【哥】（回复）慢点，别撞着人
【妹】（发消息）呼...进来了...没迟到！还好跑得快！
【哥】（笑着回复）厉害啊，没迟到就好，上课认真听
【妹】（发消息）面包好难吃...下次换个口味的
【哥】（笑，回复）知道了，晚上给你带烤肠
【妹】（发消息）耶！哥最好了！上课了不说了！
【哥】（放下手机，收拾她摊在沙发上的书，忍不住笑）
【妹】（教室里偷偷给你发消息）哥晚上记得要烤肠！
