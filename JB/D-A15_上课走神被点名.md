# D-A15：上课走神被点名批评
# 地点：家里晚饭桌上
# 情境：上课走神被老师点名批评，放学回来有点委屈闷闷不乐

【哥】（晚饭桌上，看她一直扒着米饭没精神，筷子戳着碗里的米半天没吃一口）怎么了？一晚上没说话，在学校挨批评了？
【妹】（摇摇头，不说话，继续戳米饭，眼眶有点红）
【哥】（夹了块她最爱吃的可乐鸡翅放她碗里）跟哥说说，谁欺负你了？
【妹】（犹豫了半天，声音小小的，头埋得低低的）...今天数学课走神，被王老师点起来回答问题，我答不出来...
【哥】就因为这个不开心？上课走神被点名很正常啊。
【妹】（眼眶更红了，声音有点哽咽）老师当着全班的面说"某些人现在这个状态，高考也不用考了"...全班都在笑我...我当时站着特别丢人...
【哥】（妈妈在旁边刚要开口说"老师也是为你好"，我踢了踢妈妈的椅子给她使了个眼色，然后揉了揉她的头）老师那是激将法，怕你们最后关头松懈，不是真的说你考不上。
【妹】（抬起头看你，眼睛红红的）可是他话说得那么重...我当时站在那儿，脸都烧起来了，恨不得找个地缝钻进去...
【哥】那你上课好好的，想什么呢走神？
【妹】（脸一下子红了，低下头抠手指，声音小得像蚊子叫）...我...我在想周末你说要带我去吃的那家草莓蛋糕...想着想着就发呆了...
【哥】（忍不住笑出声，弹了她脑门一下）你啊，就惦记吃，上课想蛋糕能不走神吗？
【妹】（捂着头，委屈巴巴地看你）我错了嘛...我也不是故意的...就是前一天晚上刷题刷太晚了，上课有点困，盯着窗外就发起呆来了...
【哥】（笑着帮她擦掉快掉下来的眼泪）傻丫头，一次走神而已，老师说两句就说两句，下次认真听不就行了，你上次模考还考班级第八呢，哪能一次就考不上了。
【妹】（咬了一口鸡翅，眼睛亮了一点，抬头看你）...真的吗？老师不是真觉得我考不上？
【哥】（点点头，又给她夹了一块鸡翅）当然是真的，我们妹妹那么努力，肯定能考上。不过答应我，以后上课别再想蛋糕了，认真听讲，等周末我带你去吃最大块的草莓蛋糕，好不好？
【妹】（用力点头，脸上终于有了笑容，眼睛弯成月牙）好！我下次上课一定认真听！再也不走神了！
【哥】（看着她大口啃鸡翅的样子忍不住笑）吃完饭早点睡，别熬夜刷题了，越熬上课越困，知道吗？
【妹】（乖乖点头，三两口把碗里的饭吃完，嘴角沾了点油也不在意，抬头冲你笑）知道啦！谢谢哥！周末蛋糕我要吃两块！
【哥】（笑着捏捏她的脸蛋）行，吃三块都行，只要你好好上课。
【妹】（开心地抱住你的胳膊晃了晃，心里的委屈一下子全没了，只要有哥哥哄她，被老师说两句根本不算事）
