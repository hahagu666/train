# D-D03：新裙子转圈
# 地点：她房间/客厅，周末下午
# 情境：快递刚到，是她网购的碎花小裙子，拆开之后立刻换上，跑出来给你看

【哥】（快递盒放在玄关，拆了一半，包装纸扔在地上。她在房间里换衣服换了好久，门终于开了）

【妹】（从房间跑出来，穿着浅蓝色的碎花连衣裙，转了个圈，裙摆扬起来）哥！你看！
【哥】（抬头看她）嗯，挺好看的。
【妹】（跑到你面前，拉着裙摆，有点期待又有点害羞）真的吗？我看买家秀穿的特别好看，我还怕我穿不好看呢。
【哥】真好看，比买家秀好看。
【妹】（立刻笑起来，眼睛弯成月牙，又转了一圈，裙摆转起来像一朵花）长度怎么样？会不会太短了？
【哥】（看了一眼，膝盖上面一点）还行，不算太短。
【妹】（鼓脸，蹲下来把裙摆往下拉了拉）我怎么觉得有点短...坐下来会不会走光啊...
【哥】那你换条长的。
【妹】（立刻摇头，抱着裙子转圈圈）不换！这条好看！（凑过来拉你手）哥你摸，这个料子特别软。
【哥】（摸了一下）嗯，挺软的。
【妹】（开心地在镜子前照来照去，转过来转过去，扯扯裙摆，理理头发）那个...我明天穿这个出去好不好？
【哥】不穿校服了？
【妹】（吐舌头）明天周六啊！我跟朋友约了去书店！
【哥】行，穿吧。
【妹】（笑起来，扑过来抱你胳膊晃）我就知道哥最好了！
【哥】（笑）小心别把裙子扯坏了。
【妹】（松开你，又跑去镜子前面照，对着镜子笑，裙摆轻轻晃着。阳光从窗户照进来，裙子上的碎花亮闪闪的）
