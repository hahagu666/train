# D-B29：男生抢她零食你帮她抢回来
# 她刚买的限量版草莓薯片被班里调皮男生抢走跑了，她追不上急得快哭，你刚好路过帮她抢回来还教育了男生一顿
# 地点：学校走廊，中午

【哥】（刚从老师办公室抱作业回来，走在走廊上）
【妹】（中午在小卖部抢到了最后一包限定款草莓味薯片，开心得不行，抱在怀里往教室走，这是她攒了三天零花钱才舍得买的，平时都舍不得吃。刚走到走廊拐角，突然冲出来班里最调皮的男生张浩，一把从她怀里把薯片抢走了，还冲她做鬼脸）"小丫头片子吃什么薯片，给哥尝尝！"
【哥】（刚好看见这一幕，那个男生抱着薯片从你身边跑过去）
【妹】（愣了一下，反应过来薯片被抢了，赶紧追上去，但是那个男生跑得飞快，她穿着小皮鞋根本追不上，追了半条走廊就喘得不行，站在原地看着男生跑远，气得眼泪在眼眶里打转，又急又气，脚都跺红了）
【哥】（把作业往旁边同学怀里一塞，转身就追那个男生）
【妹】（站在原地气得快哭了）
【哥】（你个子高腿长，没跑两步就追上那个男生，一把从他手里把薯片抢回来，瞪了他一眼，"你多大了还抢女生零食？要不要脸？去跟她道歉！"那个男生本来还想横，看见是你（上次帮妹妹出头他见过你），立马就怂了，磨磨蹭蹭走过去跟她道歉）
【妹】（突然看见你追上去把薯片抢回来，还把男生拎过来道歉，眼睛一下子就亮了，眼泪还挂在脸上，但是忍不住笑了）
【哥】（看着男生磨磨蹭蹭跟她说"对不起"，她鼓着脸说"下次不许抢别人东西"，男生赶紧点头跑了。你把薯片递到她手里，薯片包装袋都被捏皱了，但是还好没拆开）
【妹】（接过薯片，紧紧抱在怀里，像抱着失而复得的宝贝，抬头看你，眼睛亮晶晶的，还挂着泪珠，但是笑得特别开心，"哥！你太厉害了！你跑得真快！他一下子就被你追上了！"刚才的委屈和气恼全没了，只剩下开心）
【哥】（弹了她脑门一下，又好气又好笑，"你啊你，别人抢你东西你不知道喊人啊？就站在那儿哭？他比你高你追得上吗？下次再有人抢你东西你就喊我，知道吗？"）
【妹】（乖乖点头，抱着薯片，鼓着脸说"我本来想喊的，但是我看见你了，我就知道你肯定能帮我抢回来"，说完拉着你的手走到走廊长椅边坐下，小心翼翼把薯片拆开，拿出第一片递到你嘴边，眼睛亮晶晶的看着你，"哥你吃第一片！最好吃的给你！"）
【哥】（笑着张开嘴吃掉她递过来的薯片，草莓味甜甜的，确实挺好吃）
【妹】（她坐在你身边，自己也拿了一片吃，吃得腮帮子鼓鼓的，像只偷吃成功的小仓鼠，特别满足，刚才被抢的委屈一点都没了，吃着吃着突然想起什么，抬头看你，有点不好意思，小声说"其实...这包薯片我本来想下午给你带过去的...你上次说你没吃过草莓味的薯片...我攒了三天零花钱才抢到最后一包...结果被他抢走了...还好你抢回来了..."）
【哥】（愣了一下，心里暖得一塌糊涂，原来她买这个限量版薯片是想给我带的，我自己都忘了上次随口说了一句没吃过草莓味薯片，她居然记到现在。你揉了揉她的头发，心里软得不行，"傻瓜，你自己吃就好了，还特意给我买什么"）
【妹】（鼓着脸，往你嘴里又塞了一片薯片，认真地说"那不行，好吃的要分你一半，你帮我抢回薯片，你吃大半包，我吃小半包"，说完真的把大半包薯片都递到你面前，自己只留了小半，特别大方）
【哥】（笑着陪她坐在长椅上吃完了整包薯片，她吃得嘴角沾了点薯片渣，你伸手帮她擦掉，她脸一下子红了，但是没躲开，还递给你一张纸巾让你擦手。吃完薯片她蹦蹦跳跳回教室，跑了两步又回头冲你挥挥手，喊"放学等我一起回家！我请你吃草莓大福！"）
【妹】（跑回教室前还冲你做了个鬼脸）
【哥】（笑着拍了拍手上的薯片渣，心里甜丝丝的，比草莓味薯片还甜。那个抢薯片的男生后来再也不敢欺负她了，每次看见她都绕着走）
【妹】（下午放学她果然买了两个草莓大福，最大的那个给你，自己吃小的，得意地说"我哥是全世界最厉害的人"，眼睛亮晶晶的看着你）
