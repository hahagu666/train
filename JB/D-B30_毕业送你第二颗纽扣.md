# D-B30：毕业照她把校服第二颗纽扣送给你
# 拍毕业照那天流行送校服第二颗纽扣给喜欢的人，她偷偷把自己校服第二颗扣子扯下来，红着脸塞到你手里
# 地点：学校操场/校园，拍毕业照当天

【哥】（拍毕业照那天，校园里特别热闹，大家都在互相合影，女生们都在扯喜欢的男生校服上的第二颗纽扣，说第二颗纽扣离心脏最近，送给最爱的人，能永远在一起。你刚和班里同学合完影，就看见她站在不远处，磨磨蹭蹭往你这边看，看见你看她，又赶紧低下头，脸红红的）
【妹】（穿着干净的校服裙子，扎着马尾辫，手里攥着什么东西，站在树底下纠结了半天，看见好多女生都去扯男生的扣子，她鼓了好几次勇气都没好意思走过去，脸憋得通红，手指紧张地抠着校服衣角）
【哥】（笑着走过去，站在她面前，弹了她脑门一下，"站在这儿干嘛呢？不跟同学合影去？"）
【妹】（她吓了一跳，抬起头看见是你，脸"唰"地一下红透了，手攥得更紧了，头埋得低低的，半天没说话）
【哥】（看着她紧张的样子）
【妹】（站在你面前，紧张得心怦怦跳，感觉都快跳到嗓子眼了，手心里全是汗，攥着那颗纽扣，犹豫了好半天，才猛地闭着眼睛把右手伸出来，摊开手心，手心里是一颗白色的校服纽扣，是她校服上的第二颗，声音小得像蚊子）给...给你的...
【哥】（愣了一下，看着她手心里那颗纽扣，第二颗，正好是校服靠近心脏位置的那颗，你知道这个传统，心里一下子就软了，像被什么东西撞了一下，暖得一塌糊涂。你看着她闭着眼睛，睫毛都在抖，脸通红通红的，像熟透的苹果，特别可爱）
【妹】（闭着眼睛等了半天没听见你说话，还以为你不要，赶紧睁开眼睛，眼睛亮晶晶的快哭了，有点慌，"我...我听她们说...第二颗纽扣离心脏最近...要送给最喜欢的人...我...我只有这一颗...你...你要是不要就算了..."说完就想把手收回去）
【哥】（赶紧伸手握住她的手，把那颗纽扣接过来，紧紧攥在手里，纽扣被她攥了半天，还带着她手心的温度，暖暖的。你揉了揉她的头发，声音温柔得能滴出水来，"谁说我不要？我们妹妹送的，我当然要"）
【妹】（睁开眼睛看见你把纽扣收下了，脸更红了，但是眼睛一下子就亮了，嘴角忍不住往上翘，又不好意思表现得太开心，低下头踢小石子，手指抠着校服剩下的扣子，小声说"那...那你要好好收着...不许丢...我扯了半天呢...扣子线都被我扯断了..."）
【哥】（笑着把那颗纽扣放进衬衫口袋里，贴在胸口的位置，正好对着心脏，"放心吧，我天天放在胸口口袋里，走到哪里带到哪里，绝对不丢，好不好？"）
【妹】（她抬头看你把纽扣放在胸口口袋里，脸红红的，但是笑得特别甜，眼睛弯成了月牙，站在你身边，看着好多同学互相合影，偷偷往你身边靠了靠，小声说"哥...我们也一起拍张照吧...就我们两个人...我还没跟你单独拍毕业照呢..."）
【哥】（点点头，拉着她走到操场边的梧桐树下，叫路过的同学帮你们拍一张）
【妹】（拍照的时候她站在你身边，紧张得手都不知道放哪里，你伸手轻轻揽住她的肩膀，她僵了一下，然后慢慢靠在你身上，笑得特别甜。"咔嚓"一声，照片拍好了，照片上的她靠在你肩膀上，阳光透过梧桐树叶洒在你们身上，她脖子上戴着你送她的小草莓项链，笑得眼睛都弯了）
【哥】（拿到照片，她看了半天，笑得合不拢嘴，小心翼翼把照片夹在自己的同学录里，说要放在钱包里天天看。拍完全班毕业照，大家都散了，她还站在你身边，拉着你的衣角，有点舍不得）
【妹】（牵着你的手在校园里走，走了一圈又一圈，走过你们一起跑过的操场，走过你陪她补作业的长椅，走过你帮她讲题的走廊，走过你在窗外陪她罚站的教室，每一处都有你们的回忆，她乖乖跟在你身边，手紧紧握着你的，一句话不说，但是特别安心）
【哥】（走到校门口，她停下来，转过身看着你，摸了摸你胸口放纽扣的口袋，眼睛亮晶晶的）
【妹】（抬头看着你，小声问"哥...纽扣真的会带来好运吗？我们以后真的会一直在一起吗？"）
【哥】（低头看着她红红的脸蛋，伸手把她揽进怀里，在她额头上轻轻亲了一下，认真地说"会的，我们会一直在一起，以后我们要上同一所城市的大学，要一起租房子，要一起吃好多好多顿饭，要一起过好多年好多节日，这颗纽扣会帮我们见证的，好不好？"）
【妹】（靠在你怀里，使劲点头，把脸埋在你胸口，听着你的心跳，跟那颗纽扣贴在一起，特别安心，笑得眼泪都快出来了。风一吹，梧桐树叶子沙沙响，夏天的风暖暖的，吹起她的马尾辫，这是你们毕业的夏天，也是你们在一起的开始）
【哥】（紧紧抱着她）
【妹】（把脸埋在你胸口，手紧紧抱着你的腰，舍不得松开，心里偷偷想，这颗纽扣会帮他们见证一辈子的）
