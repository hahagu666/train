# D-K10：写情书恶作剧反被撩
# 愚人节她模仿女生字体写了封情书夹在你课本里恶作剧，想看你出糗，结果你看完直接把她按在墙上问是不是她写的

【哥】（早上到教室翻课本，从里面掉出来一个粉色的信封，信封上还画着小爱心，你捡起来，周围同学都在起哄"哟，有人给你写情书啊"）
【妹】（坐在你斜前方，趴在桌子上偷偷回头看，捂着嘴憋笑憋得肩膀都抖，就等着看你出糗的样子，眼睛亮晶晶的全是恶作剧得逞的得意）
【哥】（拿起信封拆开，拿出里面的信纸，粉色的信纸，字故意写得歪歪扭扭的，一看就是刻意模仿女生字体，但是"喜欢""放学操场见"几个字写得太用力，笔锋都透出来了，你一眼就认出来是她的字。你挑了挑眉，抬头看向她的方向，她赶紧缩回去趴在桌子上假装看书。下课了，她正想溜，被你一把抓住手腕拉到走廊转角没人的地方，把情书在她面前晃了晃）我写的？
【妹】（脸不红心不跳，故意装糊涂，眨着眼睛看你，一脸无辜）什么情书？我不知道啊？谁给你写的？哪个女生啊？长得好不好看？
【哥】（看她装得还挺像，忍不住笑了，把她按在墙上，两只手撑在她两边，把她圈在怀里，凑过去近距离看着她，近得能闻到她头发上的洗发水香味）哦？不知道？那我读给你听听？"我注意你好久了，你打篮球的时候特别帅，我喜欢你，放学操场北边见，不见不散。"嗯？写得挺肉麻啊。
【妹】（被你按在墙上，距离这么近，她一下子就慌了，脸"唰"地红了，心跳得飞快，眼睛躲躲闪闪不敢看你，但是还是硬撑着）我...我怎么知道谁写的...你...你放开我...等下有人来了...
【哥】（不仅没放开，反而凑得更近了，鼻尖都快碰到她的鼻尖了，故意逗她，声音低低的）真不是你写的？那我放学可真去操场见人家了啊？万一人家女生等急了怎么办？
【妹】（一听你要去，一下子急了，也顾不上装了，伸手捶你胸口一下，脸通红通红的，鼓着脸瞪你）你敢！不许去！
【哥】（挑了挑眉，看着她急得红扑扑的脸，故意逗她）哦？不是你写的吗？我为什么不能去？人家都跟我表白了，我总得去见见吧？
【妹】（被你问得说不出话来，脸更红了，眼眶都有点红了，又急又气，伸手抢你手里的情书）我让你不许去就不许去！那是我写的！恶作剧！愚人节快乐！行了吧！
【哥】（笑着把情书举高不让她抢到，看着她脸红得像熟透的苹果，眼睛水汪汪的，特别可爱，忍不住逗她）哦？原来是我们妹妹写的啊？我还以为真有女生给我写情书呢，白高兴一场。
【妹】（抢了半天抢不到，气鼓鼓地瞪你，但是被你圈在怀里动不了，脸红得快滴血了，小声说）...谁让你昨天打游戏不理我...我就想恶作剧吓吓你...谁让你真要去见人家...
【哥】（看着她又气又羞的样子，心都化了，低头在她红红的嘴唇上快速亲了一下，然后退开一点，笑着看她愣住的样子）情书我收到了，操场就不去了，但是表白我接受了。
【妹】（整个人都僵在原地，眼睛睁得大大的，摸了摸自己的嘴唇，脸通红通红的，半天反应不过来，过了好半天才结结巴巴地说）你...你你你...我那是恶作剧！不是真的表白！
【哥】（笑着把情书折好放进钱包里，认真地看着她，揉了揉她的头发）我当真了就行，恶作剧也当真，谁让是你写的呢。
【妹】（脸更红了，连耳朵尖脖子都红透了，低下头不敢看你，手指使劲揪着自己的衣角，声音小得像蚊子）...你耍赖...
【哥】（笑着捏了捏她红红的脸，拉着她往教室走）走了，快上课了，下次再写情书恶作剧，我就当你是真的跟我表白，直接亲你，听到没有？
【妹】（被你拉着手，脸还是红得不行，但是嘴角忍不住偷偷往上翘，小声嘟囔）...谁...谁要跟你表白...下次我还写...
【哥】（听见她的话，回头看她，她赶紧低下头，但是耳朵尖红得快要滴血，你握紧她的手，心里甜得不行，钱包里还放着她写的那封歪歪扭扭的恶作剧情书，比收到真的情书还开心）
【妹】（被你牵着手往教室走，脸还是烫得不行，但是心里甜甜的，偷偷抬眼看你，嘴角的笑意压都压不住，觉得这恶作剧好像玩得有点值了）
