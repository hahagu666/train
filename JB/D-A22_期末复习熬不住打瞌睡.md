# D-A22：期末复习熬不住打瞌睡
# 地点：书房/妹妹房间，期末复习周
# 情境：期末复习周她每天熬到半夜，坐在你对面看书看着看着就打瞌睡，头一点一点的像小鸡啄米，笔都掉了

【哥】（坐在书桌前帮她整理复习资料，抬头看见她坐在对面，手里拿着历史书，眼睛半睁半闭，头一点一点像小鸡啄米，"啪"一声笔掉在桌子上，她猛地惊醒揉眼睛）
【妹】（迷迷糊糊捡起笔，坐直身子，使劲摇摇头想清醒，但是眼睛还是睁不开，又开始一点一点的，打了个大大的哈欠，眼泪都打出来了）
【哥】（看了眼时间，已经十一点半了，她从放学到家就一直在看书，吃完饭又坐在这里学了四个小时，连水都没喝几口。我敲了敲她的书）别学了，去睡觉。
【妹】（猛地抬起头，眼睛还迷迷糊糊的，使劲摇头，声音带着刚睡醒的鼻音）不行...我还有半本历史没背完...明天要考的...我再背一会儿...
【哥】（皱起眉头，伸手摸了摸她的头，她头发都因为熬夜有点乱了，脸因为困红红的，眼睛下面都有黑眼圈了）你看看你，都困成什么样了，现在背也记不住，白浪费时间，去睡觉，明天早上起来再背，早上记忆力好。
【妹】（鼓着脸，摇摇头，强撑着翻开书，但是字都看成重影了，看了两行，头又开始往下点，差点磕在桌子上）
【哥】（伸手垫在她额头下面，她撞在我手心里，迷迷糊糊"嗯"了一声）
【妹】（迷迷糊糊的，还伸出小手想去够书，声音黏黏的带着鼻音，像只小猫一样蹭了蹭你的胳膊）我还没看完...再看十分钟...就十分钟...我马上就看完了...
【哥】（叹了口气，把她手里的书抽走合上）
【妹】（"哎"了一声想抢，但是你举得高我够不着，我困得连站起来抢的力气都没有了，坐在椅子上可怜巴巴地看着你，眼睛红红的像只小兔子）...我还没看完...
【哥】（不由分说把她从椅子上拉起来）
【妹】（被拉起来的时候腿都软了，站不稳往你身上倒，你扶住我，我整个人都靠在你身上，困得眼睛都快闭上了，脑袋靠在你肩膀上，嘟囔着"我还能学..."）嗯...我还能学...真的...
【哥】（把她打横抱起来，她轻呼一声搂住我脖子）
【妹】（脸埋在你肩膀上，瞬间就放松了，打了个哈欠，困得连眼睛都睁不开了）
【哥】（把她抱到她房间床上，帮她脱了外套盖好被子）
【妹】（躺在床上，抓着你的手不放，眼睛半睁半闭的，声音黏黏的）...可是我历史还没背完...我要是考砸了怎么办...
【哥】（坐在床边，帮她把额前的碎发理好，揉了揉她的头发，轻声哄她）不会考砸的，你都背了一晚上了，肯定记住了，现在好好睡觉，睡够了明天才能发挥好，要是熬通宵明天考试睡着了，才真的考砸了，知道吗？
【妹】（迷迷糊糊点点头，但是还是抓着你的手不放，眼睛慢慢闭上了，快睡着的时候又突然睁开一条缝，小声问）...那...那你明天早上六点叫我起床...我再背一个小时...
【哥】（笑着帮她把被子掖好，捏了捏她的脸）好，六点叫你，快睡吧。
【妹】（这才安心地闭上眼睛，抓着你的手慢慢松开，呼吸很快就均匀了，睡得特别沉，嘴角还微微翘着，看来是真累坏了，睡梦中还轻轻嘟囔了一句"哥最好了"）
【哥】（帮她把台灯关掉，轻手轻脚走出去，把她没看完的历史书拿过来，帮她把重点考点都整理出来，写在小本子上，整理到快一点才睡）
【妹】（第二天早上六点被叫醒的时候，还迷迷糊糊地揉眼睛，头发睡得乱蓬蓬的像个鸟窝，打了个大大的哈欠，眼睛都睁不开）
【哥】（把整理好的重点小本子递给她）
【妹】（愣了一下，接过小本子，翻开一看，上面是你帮我整理的所有考点重点，用不同颜色的笔标出来了，一目了然，字写得工工整整的，我眼睛一下子就红了，抬头看你）哥...你昨晚帮我整理的？
【哥】（笑着揉了揉她的头发，把热好的牛奶和面包放在她桌子上）嗯，快背吧，这些都是高频考点，背完吃早饭，我送你去考试。
【妹】（捧着那个小本子，眼泪"啪嗒"掉在本子上，我赶紧擦掉，怕弄湿了本子，使劲点头，翻开小本子开始背，背得特别认真）
【哥】（站在门口看着她认真的样子，笑了笑，去给她煮鸡蛋）
【妹】（出门考试前，我把小本子小心翼翼放进笔袋里，像捧着什么宝贝，然后扑过来抱了你一下，在你下巴上亲了一口，眼睛亮晶晶的）哥！我一定会考好的！不辜负你熬夜帮我整理笔记！
【哥】（笑着帮她把书包背好，捏了捏她的脸）尽力就好，别紧张，我在考场外面等你，考完带你去吃你最爱的火锅。
【妹】（用力点头，攥紧笔袋，蹦蹦跳跳跑进考场，还不忘回头冲你挥挥手）
【哥】（站在外面，看着她的背影）
【妹】（心里想着，不管考成什么样，有哥哥在就什么都不怕）
