# D-A17：体育会考
# 地点：学校操场，你去看她体育会考
# 情境：800米跑终点，她跑完全程喘得不行，扶着腰站不住

【哥】（站在800米终点线等着，看见她冲过来）
【妹】（冲过终点线，腿一软，差点摔下去）
【哥】（赶紧走过去扶她）慢点。
【妹】（扶着你胳膊，弯着腰大口喘气，话都说不出来）呼...呼...
【哥】（给她递水和毛巾）先别坐，慢慢走两步。
【妹】（摇摇头，喘了半天才说出话）...我跑不动了...最后一百米...我差点放弃...
【哥】能跑下来就不错了。
【妹】（接过水喝了一口，呛到了，咳嗽）咳...
【哥】（拍她背）慢点喝。
【妹】（擦了擦嘴，脸通红，满头是汗）我跑了多少名？
【哥】你们组你是第五个到的，及格肯定没问题。
【妹】（松了口气，扶着腰，腿在抖）那就好...我刚才跑到第二圈的时候，肚子旁边疼得要死...
【哥】岔气了？
【妹】（点头，声音还喘）嗯...疼得我想停下来走...但是我看到你在终点站着，就咬牙跑下来了...
【哥】（笑，帮她把外套披上）出汗了别着凉。
【妹】（披上外套，还是扶着你胳膊，腿软）我腿软...站不住了...
【哥】（扶她到旁边台阶坐下）坐会歇会。
【妹】（坐下，头靠在你肩膀上，喘气）...我好久没跑这么远了...累死我了...
【哥】平时让你多运动你不听。
【妹】（鼓脸）我每天都在坐着学习啊...哪有时间运动...（拉你袖子）哥，我跑及格了，有没有奖励？
【哥】你想要什么？
【妹】（想了想）我想喝冰奶茶，全糖的。
【哥】刚跑完步喝冰的不怕肚子疼？
【妹】（撒娇）就喝一杯嘛...我都及格了...
【哥】（叹气）行，给你买。
【妹】（开心，靠在你肩膀上笑）耶！
【哥】（笑着搂住她的肩膀，从口袋里掏出纸巾帮她擦额头上的汗）
【妹】（靠在你肩上，满足地眯着眼睛，觉得有你在真好）
