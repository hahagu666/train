# D-I38：清晨边接吻边慢慢做
# 地点：你床上，清晨
# 情境：清晨阳光照进来，你们醒了，边接吻边慢慢做，特别温柔

【哥】（清晨，阳光透过窗帘照进来，你醒了，她窝在你怀里睡着，睫毛长长的，嘴唇粉粉的，你低头吻她的嘴唇，她迷迷糊糊醒了。）早，宝贝。
【妹】（迷迷糊糊感觉到有人吻她，睁开眼睛看见是你，笑了，主动回吻你，手臂环住你的脖子，光溜溜的身体贴过来，腿搭在你的腰上。）早...哥...
【哥】（早，你吻着她，手顺着她的背往下摸，摸到她软软的屁股，捏了一把，你晨勃硬得厉害，抵在她小穴上。）硬了。
【妹】（她脸红了，但是主动分开腿，小穴蹭着你的肉棒，已经有点湿了，她吻着你的嘴唇，声音黏黏的带着睡意。）那...要吗...
【哥】（你扶着肉棒对准她湿滑的穴口，慢慢顶进去，清晨特别敏感，慢慢全部插进去，两个人同时舒服得叹了口气，你抱着她，开始慢慢抽动，边吻她边做。）嗯...进来了。
【妹】（啊...嗯...你慢慢动着，边吻她，舌头缠在一起，每一下都插得很深很慢，她舒服得小声哼着，手抱着你的脖子，腿环着你的腰，阳光照在两个人赤裸的身体上，暖暖的。）哥...好舒服...早上里面好敏感...
【哥】（你慢慢动着，不着急，吻她的嘴唇、脸、脖子、乳房，含住她的乳头轻轻吸吮，手揉着她的屁股，肉棒在她湿滑的小穴里慢慢抽插，水声轻轻的，特别温柔。）喜欢吗？早上做。
【妹】（嗯...她被你操得软成一滩水，主动抬腰配合你的动作，和你吻在一起，呼吸交融在一起，快感慢慢积累，不像晚上那么猛，但是暖暖的，遍布全身。）哥...我爱你...
【哥】（你在她耳边说，加快了一点速度，手揉着她的阴蒂，她抖了一下。）我也爱你。
【妹】（啊...我快到了...哥...她小声说，抱紧你，小穴开始收缩，你继续慢慢磨着她的G点，没过多久她就高潮了，小声叫出来，身体轻轻抖着，紧紧抱着你，吻你的嘴唇。）啊...哥...
【哥】（她高潮的收缩把你也带射了，你腰一挺全部插进去，射在她最里面，精液暖暖的喷在她子宫里，两个人抱着不动，吻了好久。）嗯...射了...
【妹】（你射完趴在她身上，两个人喘着气，阳光越来越亮，她满足地摸着你的头发，小声说。）早上做好舒服...懒洋洋的...
【哥】（你吻了吻她的额头，没拔出来，就这么插在她里面抱着她。）那就天天早上做一次。
【妹】（她笑着点点头，在你嘴唇上亲了一下，脸红扑扑的。）好...天天早上给你...
