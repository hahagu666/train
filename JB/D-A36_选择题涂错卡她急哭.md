# D-A36：选择题涂错卡她急哭
# 模考结束对答案，她发现自己数学选择题答题卡涂串了，十二道选择题全错，当场就哭了，你哄了好久才哄好
# 地点：学校走廊/楼梯间，三模数学考完出考场

【哥】（刚考完数学出考场，就看见她站在走廊里，手里拿着答案和答题卡对比，脸色越来越白，嘴唇都在抖，眼泪在眼眶里打转，你赶紧走过去）怎么了？考得怎么样？
【妹】（抬起头看见是你，眼泪"唰"一下就掉下来了，手里的答题卡都掉在地上，声音抖得不成样子）哥...我...我答题卡涂串了...
【哥】（心里咯噔一下，赶紧捡起答题卡看，果然，从第三题开始她就涂串行了，后面九道选择题全涂错位置了，十二道选择题六十分，她至少要丢四十五分。你心里也一沉，但是看她哭得快喘不过气了，赶紧把她拉到没人的楼梯间）
【妹】（靠在墙上，眼泪不停地掉，哭得肩膀一抽一抽的，话都说不完整，手使劲抓着你的校服袖子）我...我写完选择题就去做大题了...最后剩五分钟才涂卡...我太着急了...涂串了我都没发现...四十五分啊...我肯定考砸了...我怎么这么笨啊...
【哥】（把她拉进怀里轻轻拍背，她趴在你怀里哭得稀里哗啦的，眼泪把你校服都打湿了一大片，你心里又心疼又着急，但是还是得哄她）没事没事，不就是一次模考吗，涂错卡是意外，又不是你不会，下次注意就好了，不哭了啊。
【妹】（哭得更凶了，捶了你胸口一下，又委屈又自责）怎么没事啊...这是三模啊...跟高考难度一样...我要是高考也涂串了怎么办...我复习了这么久...就因为涂错卡...全都白费了...
【哥】（轻轻帮她擦眼泪，但是越擦她掉得越凶，你干脆就让她在你怀里哭，等她哭够了再说。哭了快十分钟，她才慢慢停下来，抽抽搭搭的，眼睛肿得像桃子，鼻子红红的，可怜巴巴的）
【妹】（哭够了，抬起头，眼睛肿得像桃子，可怜巴巴地看着你）
【哥】（等她哭够了，才拿出纸巾帮她擦脸，弹了她脑门一下，故意板着脸说）你看你，哭什么，不就是一次模考吗？发现问题是好事，总比高考的时候涂串了强，对不对？这次涂串了，下次你肯定就记住了，做完选择立刻涂卡，留十分钟检查，不就不会错了？
【妹】（抽抽搭搭的，还是很自责，低着头踢楼梯台阶，小声说）可是...可是这次排名肯定会掉好多...我还想考进前五十给你看的...这下肯定考不上了...
【哥】（笑着揉了揉她的头发，把她掉在地上的笔捡起来递给她）傻丫头，一次模考而已，说明不了什么，你只要记住这个教训，高考的时候不犯这种错误，比什么都强。走，我带你去吃草莓冰，吃完回去我帮你分析卷子，那些题你是不是都会？
【妹】（点点头，她那些题其实都会做，就是最后涂卡太着急涂串了，想起来还是委屈，又掉了两滴眼泪，小声说）...都会...就是涂错了...
【哥】（牵着她的手往校外走，她的小手冰凉冰凉的，紧紧攥着你的手，你带她去吃了她最爱的草莓冰，她吃了两口冰，情绪慢慢稳定下来了，但是还是有点闷闷不乐）
【妹】（吃了两口冰，还是有点闷闷不乐）
【哥】（吃着冰，你跟她约法三章，以后考试，做完选择题立刻涂卡，不许留到最后，涂完再检查一遍题号对不对，剩下的时间再做大题）
【妹】（乖乖点头，把这几条记在小本子上，说以后绝对不会再犯了）
【哥】（看着她认真记笔记的样子，忍不住笑了）
【妹】（吃了大半碗冰，心情终于好多了，抬起头看你，眼睛还是红红的，小声说）哥...你会不会觉得我特别没用啊...这么低级的错误都能犯...
【哥】（伸手捏了捏她红红的脸蛋，笑着说）怎么会，谁考试没犯过低级错误？我高考前最后一次模考还忘写名字呢，被老师骂了一顿，高考不照样好好的？这种错犯一次记一辈子，以后绝对不会再犯了，对你来说是好事，知道吗？
【妹】（听你说你也忘写过名字，一下子就笑了，虽然眼睛还是肿的，但是脸上终于有笑意了，捶了你一下，小声说）你骗人...你怎么会忘写名字...
【哥】（笑着举起手发誓）真的，骗你是小狗，比你涂串卡还蠢，准考证号都填错了，还是监考老师帮我改的。所以啊，这种错误谁都会犯，改了就好，没什么大不了的。
【妹】（终于破涕为笑，把最后一口冰喂到你嘴里，晃着你的手，小声说）那...那你以后要提醒我...每次考试前都跟我说一遍"记得涂卡，别涂串了"...
【哥】（笑着点头，握紧她的手）好，每次考试前我都跟你说一百遍"记得涂卡别涂串"，说到你耳朵起茧子，保证你高考的时候想忘都忘不掉。
【妹】（笑得眼睛都弯了，虽然眼睛还是肿的，但是已经不难过了，牵着你的手往家走，心里想，幸好有你在，就算天塌下来也有你帮她顶着，涂错卡好像也不是什么天大的事了）
