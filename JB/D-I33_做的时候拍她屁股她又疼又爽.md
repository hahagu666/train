# D-I33：做的时候拍她屁股她又疼又爽
# 地点：你床上
# 情境：做的时候你拍她白白的屁股，她又疼又爽，哭着求你再打

【哥】（晚上你后入式干她，她跪趴在床上屁股翘得高高的，白嫩嫩的屁股在你眼前晃，你忍不住拍了一下，啪的一声特别响。）啪...
【妹】（啊！你突然拍她屁股，她疼得叫出声，但是小穴一下子夹紧了你的肉棒，身体抖了一下，她回头看你，脸红扑扑的，眼睛水汪汪的，居然没有生气，反而有点期待。）你...你打我...
【哥】（看她小穴反而夹紧了，你笑了，又连着拍了两下另一边屁股，两边都红了，你一边抽插一边拍。）怎么，被打屁股反而更紧了？喜欢哥哥打你屁股是不是？
【妹】（啊...唔...她被你打得又疼又爽，那种疼麻麻的，顺着屁股传到小穴里，快感更强烈了，她咬着枕头，但是屁股反而翘得更高，小声哼着。）别...别打了...羞死人了...
【哥】（你没停，继续拍，每拍一下就重重插一下，她小穴就缩一下，你拍得越来越响，她的屁股红了一片，你抓着她的腰快速抽插。）不喜欢？不喜欢屁股怎么翘这么高，小穴还夹这么紧？
【妹】（啊...喜欢...哥...打我...再打...她被你操得胡言乱语，哭着回头看你，屁股主动往后迎你的巴掌和肉棒，奶子晃来晃去，淫水顺着大腿往下流。）打我屁股...哥...用力...好舒服...
【哥】（你连着狠狠拍了十几下，两边屁股都红透了，她小穴紧得你快射了，你伸手揉着她的阴蒂，快速抽插。）小淫娃，被打屁股还这么舒服，是不是天生就该被哥哥操。
【妹】（是...我是哥的小淫娃...啊...我要到了...哥...她抖得厉害，小穴剧烈收缩，没一会就高潮了，叫得特别大声，身体软得快趴下去，你抓着她的腰不让她倒。）啊...！
【哥】（她高潮夹得你也忍不住了，腰一挺全部插进去，射在她最深处，你趴在她背上喘气，拍了拍她还红着的屁股。）嗯...射了...宝贝真乖。
【妹】（喘了半天，她趴在床上，屁股还火辣辣的疼，但是小穴里还在一缩一缩的，满足得不行，回头瞪你一眼，脸红红的。）你打得好疼...但是...但是好舒服...
【哥】（你笑着揉她红了的屁股，帮她按摩。）下次还打不打？
【妹】（她脸红了，把脸埋在枕头里，小声说。）...打...但是轻一点...
