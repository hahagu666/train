# D-E47：故意跟男生说话气你
# 地点：家里客厅，你带女同事回家拿文件
# 情境：你带女同事回家拿文件，她吃醋了，等女同事走了之后故意说班里男生给她写情书，想气你

【哥】（工作上有个文件落家里了，带同部门女同事回家拿，开门的时候她正坐在客厅吃水果，看见你带女生回来，脸一下子拉下来了）
【妹】（坐在沙发上，看见你带女生回来，手里的苹果也不吃了，鼓着脸盯着你们看，也不打招呼，就那么看着，女同事跟她打招呼她也只是嗯了一声，别过头不说话，但是眼睛一直偷偷看你们）
【哥】（拿了文件送女同事出门，回来关上门，就看见她还坐在沙发上，鼓着脸，苹果扔在盘子里不吃了，抱臂看着你，明显不高兴了）怎么了？脸拉这么长。
【妹】（哼了一声，别过头不看你，声音酸溜溜的）没怎么，那是谁啊，长得挺好看的啊。
【哥】同事，回来拿个文件。
【妹】（鼓着脸，手指揪着抱枕角，故意装作不在意的样子，撇撇嘴）同事啊，怪不得带回家呢。（她顿了顿，故意装作随口一说的样子）对了，今天我们班有个男生给我写情书了。
【哥】（本来在喝水，听见这句话抬头看她，她正偷偷看你表情，眼睛亮晶晶的，明显是故意说给你听气你的）哦？然后呢。
【妹】（看你反应不大，有点急了，鼓着脸继续说）那个男生长得可高了，篮球打得特别好，我们班好多女生都喜欢他呢，他还说周末想约我去看电影。
【哥】（忍住笑，故意装作不在意的样子）那你想去啊？
【妹】（愣了一下，没想到你是这个反应，一下子急了，站起来走到你面前，鼓着脸瞪着你，眼睛都有点红了）你怎么一点反应都没有啊！
【哥】我要有什么反应？
【妹】（被你问住了，脸一下子红了，又气又委屈，眼泪都快出来了，鼓着脸打你胳膊一下）你！你是不是我哥啊！有男生约我你都不担心啊！
【哥】（终于忍不住笑了，伸手捏了捏她鼓起来的脸）我们妹妹这么乖，肯定不会去的，对不对？
【妹】（被你说中心事，脸一下子红透了，但是还是嘴硬，鼓着脸别过头）我...我还没说不去呢！我觉得他挺好的啊...
【哥】哦，那你去啊，记得早点回来。
【妹】（这下真急了，眼泪啪嗒一下就掉下来了，扑过来打你，但是没用力，打得特别轻，带着哭腔）你坏！你一点都不在乎我！你都不吃醋！你还让我跟别的男生去看电影！
【哥】（赶紧抱住她给她擦眼泪，她趴在你怀里哭，哭得一抽一抽的，手轻轻捶你胸口，像只炸毛又委屈的小猫）
【妹】（哭了半天，抬起头看你，眼睛红红的像兔子，鼓着脸，声音带着哭腔撒娇）你不许让我跟别的男生去看电影...你都没带我去看过电影...
【哥】好，周末带你去，想去看什么都行。
【妹】（这才破涕为笑，但是还是鼓着脸，伸手掐你腰一下，但是嘴角已经扬起来了，紧紧抱着你的腰，把脸埋在你胸口，声音闷闷的）那你以后也不许带别的女生回家...尤其是长得好看的...（她顿了顿，小声说）我比她们好看...
