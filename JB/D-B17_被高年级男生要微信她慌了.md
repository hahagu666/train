# D-B17：被高年级男生要微信她慌了
# 放学在奶茶店买奶茶，有个高年级男生过来要她微信，她慌得手足无措，抬头就看见你站在门口，直接跑过去躲你身后
# 地点：学校门口奶茶店/回家路上，傍晚放学

【哥】（放学在学校门口等了半天没看见她，猜她肯定又来买奶茶了，往奶茶店走过去）
【妹】（放学背着书包去奶茶店买珍珠奶茶，正踮着脚等奶茶呢，一个穿高三校服的男生走过来，站在她面前，她愣了一下，以为是要排队，往旁边让了让）
【哥】（走到奶茶店门口，刚好看见一个男生站在她面前，你靠在门框上没进去，想看看她怎么应对）
【妹】（那个男生没去点单，反而看着她，笑着说"同学，能加个微信吗？我注意你好久了"，她一下子就慌了，脸"唰"地红了，手里攥着书包带子，不知道该说什么，长这么大第一次被人当面要微信，紧张得手都在抖）
【哥】（你靠在门框上，看着她像只受惊的小兔子一样四处张望，眼睛红红的，手都在抖，你心里软了一下，差点就走过去了，但还是忍住了，想看看她会不会自己跑过来）
【妹】（紧张得话都说不完整，结结巴巴地说"我...我没有微信..."，说完自己都觉得假，现在哪个高中生没有微信，那个男生还在笑，说"没关系，QQ也行"，她更慌了，往后退了两步，不知道怎么办才好，抬头四处看，一眼就看见你站在门口，眼睛一下子就亮了）
【哥】（看着她什么都顾不上了，奶茶也不要了，转身就往门口跑）
【妹】（什么都顾不上了，奶茶也不要了，转身就往门口跑，直接躲到你身后，紧紧抓着你的校服衣角，从你身后探出半个脑袋，对着那个男生小声说"我...我有男朋友了..."）
【哥】（被她扑过来躲在身后，心里有点想笑，但是还是板着脸，伸手把她护在身后，对着那个男生挑了挑眉，没说话。那个男生看见你，愣了一下，知道是没戏了，说了句"不好意思啊"就走了）
【妹】（躲在你身后，看着那个男生走了，才松了口气，但是脸还是通红通红的，心脏怦怦跳，手还紧紧抓着你的衣角，头埋在你后背，不好意思出来）
【哥】（转过身看着她，她脸红得像熟透的苹果，头埋得低低的，耳朵尖都红透了，你故意逗她，弹了她脑门一下）哟，我们妹妹长大了啊，都有人要微信了？刚才怎么不说你没有微信啊，跑那么快干嘛？
【妹】（抬起头瞪你一眼，但是脸还是红的，捶了你胸口一下，又羞又窘）你还笑！我都快吓死了！我第一次遇到这种事！我都不知道说什么！你早就来了是不是！你故意站在门口看我笑话！
【哥】（终于忍不住笑出声，揉了揉她的头发，走到吧台把她点的珍珠奶茶拿过来，插好吸管递给她）我要是不看你笑话，怎么能看见我们妹妹说"我有男朋友了"的时候那么理直气壮啊？嗯？什么时候有男朋友了，我怎么不知道？
【妹】（接过奶茶吸了一大口，听见你这么说，脸更红了，低下头戳奶茶里的珍珠，声音小小的，像蚊子哼哼）...我...我那不是急了吗...我不说有男朋友他一直缠着我怎么办...
【哥】（牵着她的手往家走，她乖乖跟在你身边，小手紧紧握着你的手，脸还是红红的，一路都没怎么说话）
【妹】（走到半路，她突然停下来，抬头看你，眼睛亮晶晶的，有点紧张地问）哥...刚才...刚才我说我有男朋友...你会不会生气啊...
【哥】（低头看着她紧张的样子，心里软得一塌糊涂，故意装作认真地想了想，说）生气啊，怎么不生气，我妹妹随便说别人是她男朋友，我当然生气。
【妹】（脸一下子白了，赶紧松开你的手，有点慌，声音都快哭了）我...我不是故意的...我就是太急了...我下次不说了...你别生气...
【哥】（看她真急了，赶紧把她拉回来，握紧她的手，笑着说）傻瓜，我骗你的，我高兴还来不及呢。你说的男朋友，是我对不对？
【妹】（愣了一下，脸"唰"地又红透了，低下头，半天没说话，过了好久才小声"嗯"了一声，声音小得几乎听不见，但是你听见了，心里甜得像喝了蜜一样）
【哥】（笑着把她揽进怀里，揉了揉她的头发，在她耳边轻声说）记住了，以后再有人要你微信，你就说你有男朋友了，叫某某（你的名字），是高三的，让他们有事来找我，知道吗？
【妹】（靠在你怀里，脸通红通红的，但是使劲点头，把脸埋在你胸口，心里怦怦跳，但是特别开心。她抬起头，吸了一口珍珠奶茶，珍珠QQ的，奶茶甜甜的，就像现在的心情一样。她小声说）...其实...我刚才看见你站在门口...我一下子就不慌了...我就知道你会保护我...
【哥】（抱紧她）
【妹】（牵着你的手，蹦蹦跳跳往前走，奶茶喝得"吸溜吸溜"响，刚才的惊慌失措全没了，只剩下满满的安心和甜蜜，夕阳把两个人的影子拉得很长）
