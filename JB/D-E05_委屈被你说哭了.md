# D-E05：委屈被你说哭了
# 地点：你房间，讲题
# 情境：讲了好几遍的数学题她还是不会，你语气稍微重了点，她眼眶红了咬着嘴唇不哭出来

【哥】（晚上你给她讲数学题，讲了三遍她还是没听懂，皱着眉咬着笔，语气有点急）这题我都讲三遍了，你怎么还不会？上课听什么了？
【妹】（愣了一下，咬着嘴唇，低下头，没说话，笔在草稿纸上划来划去）
【哥】（看她不说话）你自己再想想，想明白了叫我。（站起来要走）
【妹】（突然声音发颤，带着哭腔）...哥。
【哥】（回头，看到她眼眶红了，眼泪在里面打转，咬着嘴唇忍着不哭，肩膀有点抖，立刻慌了，坐回来）怎么了？我不说你了，别哭啊。
【妹】（摇头，用手背擦眼睛，但是眼泪还是掉下来了，声音抽抽搭搭）我...我不是故意不会的...我就是...脑子转不过来...我已经很努力在听了...
【哥】（心一下软了，拿纸巾给她擦眼泪）是我不好，我不该急，是我没讲明白。
【妹】（眼泪掉得更凶了，抽噎着）你是不是觉得我特别笨...讲三遍都不会...
【哥】（摸她头，把她揽过来）瞎说，我们丫头最聪明了，是哥太急了，对不起啊。
【妹】（靠在你肩膀上，眼泪蹭你衣服上，声音小小的）...你刚才那么凶...我以为你讨厌我了...
【哥】怎么会呢，哥永远不会讨厌你。（拍她背）不哭了啊，我慢慢给你讲，讲到你会为止。
【妹】（点头，蹭了你一肩膀眼泪，抽鼻子）嗯...
