# D-C05：偷偷进你房间
# 地点：你房间，深夜一点多
# 情境：你已经睡着了，门轻轻被推开，她抱着枕头站在门口，小声叫你

【哥】（睡得迷迷糊糊，感觉门被推开了，睁开一条缝）
【妹】（抱着枕头站在门口，穿着小熊睡衣，光着脚，小声）哥...你睡了吗...
【哥】（声音沙哑）...怎么了？
【妹】（声音小小的，有点怕）我...我做噩梦了...
【哥】（掀开被子一角）过来。
【妹】（立刻光着脚跑过来，钻进你被窝，抱着你腰，身体还有点抖）
【哥】（摸她头，她头发凉凉的）梦到什么了？
【妹】（脸埋你胸口，声音闷闷的）梦到你不要我了...我怎么找都找不到你...
【哥】（笑，拍她背）傻丫头，梦都是反的。
【妹】（抱你抱得更紧了，声音有点哑）我醒了之后一个人在房间里，特别害怕...爸妈出差又不在家...
【哥】（把被子给她盖好）不怕了，哥在这。
【妹】（嗯了一声，往你怀里钻了钻，冰凉的脚贴在你腿上）
【哥】（嘶了一声）脚怎么这么冰。
【妹】（赶紧把脚缩回去）对不起...我冰到你了...
【哥】（把她脚夹在你腿中间暖着）没事，暖一会就热了。
【妹】（安静了一会，在你怀里，声音黏黏的）哥。
【哥】嗯？
【妹】（小声）我能一直跟你睡吗...
【哥】等你长大了就不能了。
【妹】（鼓脸，蹭你胸口）我不长大...
【哥】（笑，摸她头发）快睡吧，明天还要上学。
【妹】（点点头，闭眼睛，手还抱着你腰不放）嗯...你别趁我睡着了走...
【哥】不走，睡吧。
【妹】（呼吸慢慢平稳了，在你怀里睡着了，嘴角还扬着）
