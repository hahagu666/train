# D-A35：高考前一天紧张失眠
# 高考前一天晚上她紧张到失眠，翻来覆去到两点还没睡着，爬起来敲你房门，你抱着她哄她睡觉
# 地点：家里，高考前一天半夜两点

【哥】（半夜两点多，睡得正香，听见轻轻的敲门声，迷迷糊糊爬起来开门，就看见她穿着小熊睡衣，抱着枕头站在你门口，眼睛红红的，头发乱蓬蓬的，像只受了惊的小兔子）
【妹】（站在门口，手指揪着睡衣衣角，声音小小的，带着点哭腔）哥...我...我睡不着...
【哥】（赶紧让她进来，打开床头灯，她站在你床边，眼眶红红的，明显是躺了好几个小时没睡着，你拉她坐在床边，摸了摸她的手，冰凉冰凉的）怎么了？紧张了？
【妹】（点点头，坐到你床边，抱着枕头，眼泪在眼眶里打转，声音哽咽）我躺了三个小时了...怎么都睡不着...一闭上眼睛就想起我还有好多知识点没背...万一考砸了怎么办...万一我忘带准考证怎么办...万一...
【哥】（赶紧把她拉进怀里抱住，轻轻拍她的背，像哄小孩子一样，她靠在你怀里，身体都有点微微发抖，明显是紧张坏了）不怕不怕，不想那些，都准备好了，你复习了一年了，什么知识点都背熟了，不会考砸的，嗯？
【妹】（靠在你怀里，摇了摇头，声音带着哭腔）可是我还是怕...我刚才想起来有个古诗词我还没背熟...还有数学那个公式我总是记错...我越想越睡不着...越睡不着越着急...
【哥】（把她抱到床上，让她躺在你身边，帮她盖好被子，把她搂在怀里，轻轻拍她的背，声音放得很柔很轻）不想那些了，现在就睡觉，什么都不用想，考成什么样都没关系，尽力就好，就算考砸了也没关系，天塌下来有哥哥顶着呢，知道吗？
【妹】（躺在你身边，往你怀里缩了缩，像只小猫一样，你身上熟悉的味道让她安心了不少，但是还是有点紧张，小手紧紧抓着你的睡衣，小声问）...哥...你说...我要是真的考不上跟你同个城市的大学怎么办...我不想跟你分开...
【哥】（低头亲了亲她的发顶，揉了揉她的头发，轻声说）傻丫头，就算考不到一个城市，我也会经常去看你，我们又不是永远分开。而且你复习得那么好，肯定能考上的，相信自己，好不好？
【妹】（靠在你怀里，听着你沉稳的心跳声，"咚咚咚"的，特别有规律，慢慢就不那么慌了，但是还是睁着眼睛看着天花板，过了一会儿，小声说）...哥...你给我唱首歌好不好...我小时候睡不着你都给我唱小星星...
【哥】（忍不住笑了，这么大了还要听儿歌，但是还是轻轻哼起了《小星星》，声音低低的，跑调跑得厉害）
【妹】（靠在你怀里"噗嗤"一声笑出来，捶了你胸口一下，小声嘟囔）你唱得还是那么难听...（但是身体却慢慢放松了下来，往你怀里缩了缩，找了个舒服的位置）
【哥】（哼了两遍小星星，感觉怀里的人呼吸慢慢平稳下来，抓着你睡衣的手也慢慢松开了，低头一看，她已经睡着了，睫毛长长的，脸上还带着点没消下去的红，嘴角微微翘着，像做了什么好梦。你帮她把额前的碎发理好，轻轻搂着她，不敢动怕吵醒她）
【妹】（一觉睡到天亮，醒的时候阳光已经透过窗帘照进来了，她躺在你怀里，你还在睡，手轻轻搭在她腰上，她看着你熟睡的脸，心里一点都不紧张了，暖乎乎的，忍不住偷偷伸手戳了戳你的脸颊）
【哥】（被她戳得醒了，揉了揉眼睛看她，看着她脸红扑扑的样子，忍不住笑了）醒了？不紧张了吧？
【妹】（脸红了，点点头，往你怀里缩了缩，小声说）...不紧张了...有你在...我什么都不怕...
【哥】（笑着揉了揉她的头发，起来给她做早饭，做了她最爱吃的煎蛋和热牛奶，还特意煮了一根火腿肠两个鸡蛋，摆成100分的样子）
【妹】（她坐在餐桌边吃早饭，吃得特别香，昨天晚上的紧张全没了，看着盘子里100分形状的早饭，忍不住笑了，心里甜滋滋的）
【哥】（送她去考场，走在路上她紧紧牵着你的手，手心还是有点出汗，但是不再发抖了。到了考场门口，她松开你的手，转身抱了你一下）
【妹】（在你嘴唇上快速亲了一口，然后红着脸，眼睛亮晶晶地看着你）哥，等我好消息！（说完就转身跑进考场了，跑了两步还回头冲你挥了挥手）
【哥】（站在考场外面，看着她跑进去的背影，笑着摸了摸被她亲过的嘴唇，心里一点都不担心，你知道她肯定可以的，她那么努力，又有你在她身后，什么都不用怕）
【妹】（考试的时候一点都不紧张，写得特别顺，遇到不会的题也不慌，想起你昨天晚上抱着她哄她睡觉的样子，心里就特别安定，所有知识点都清清楚楚浮现在脑子里。她写完卷子检查的时候，嘴角一直带着笑，她知道，她肯定能考上你的城市，因为你在等她）
