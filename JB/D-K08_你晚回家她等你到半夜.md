# D-K08：你晚回家她等你到半夜
# 你和同学聚会喝酒，说好十点回家结果两点多才回来，她坐在客厅沙发上等你等到睡着，醒了之后生气不理你

【哥】（聚会喝了点酒，两点多才到家，轻手轻脚开门，一抬头就看见客厅灯还亮着，她窝在沙发里，抱着抱枕，头一点一点的，已经睡着了，茶几上还放着给你留的蜂蜜水）
【妹】（听见开门声，一下子醒过来，揉了揉眼睛，看见你站在门口，愣了两秒，然后脸一下子沉下来，站起来就往房间走，也不跟你说话）
【哥】（赶紧换鞋走过去拉住她，一身酒气）丫头？怎么睡在沙发上？等我呢？
【妹】（挣开你的手，背对着你站着，不说话，肩膀有点抖，声音闷闷的）谁等你了，我就是看电视看睡着了。
【哥】（看了眼电视，电视根本没开，再看看茶几上温着的蜂蜜水，还有她身上盖着的小毯子，知道她是特意等自己的，心里又暖又愧疚，走过去从后面轻轻抱住她）对不起，同学聚会太高兴了，多喝了两杯，忘了看时间，回来晚了，让你担心了。
【妹】（被你抱着，挣了两下没挣开，听你身上一股酒气，更生气了，声音带着点哭腔）你还知道回来！我给你打了八个电话你都不接！发消息也不回！我以为你出什么事了！我都差点要报警了！
【哥】（愣了一下，掏出手机一看，果然有八个未接来电，都是她打的，还有好多条消息，问你什么时候回来，让你少喝点酒，你当时喝多了没听见，心里一下子更愧疚了，抱紧她，声音放软）对不起对不起，我错了，手机放包里没听见，让你担心了，下次再也不会了，别生气了好不好？
【妹】（听你道歉，眼泪一下子掉下来，转过身捶你胸口，力气不大，但是带着哭腔）你坏！你说好十点回来的！我等到十二点你都没回来！我还给你煮了醒酒汤，都热了三回了！
【哥】（心里一暖，伸手帮她擦眼泪，看见她眼睛红红的，明显是等急了哭过，心疼得不行，赶紧把她搂进怀里）是我不好，说话不算话，让我们妹妹等这么久，还让你担心了，你打我骂我都行，别气坏了身体，嗯？
【妹】（靠在你怀里，捶了你两下就没力气了，抓着你的衣服，委屈得不行，眼泪把你衬衫都打湿了）...你下次再这么晚回来不接电话...我就...我就再也不理你了...我就锁门不让你进来...
【哥】（赶紧点头，帮她顺着背哄，像哄小孩子一样）好好好，下次再晚回来我一定提前给你打电话，手机一定放在手里，随时接你电话，再也不让你等这么久了，行不行？
【妹】（在你怀里抽抽搭搭的，闻到你身上的酒气，皱起眉头，从你怀里挣出来，拉着你往厨房走，声音还是闷闷的）...先去喝醒酒汤，都给你热了三回了，再不好好喝我就倒了。
【哥】（乖乖跟着她走到厨房，她把温在锅里的醒酒汤盛出来递给你，自己坐在对面看着你喝，脸还是沉着，但是眼神里满是担心。你喝了一口，醒酒汤温温的，酸酸甜甜的，是她的手艺，特别好喝）
【妹】（看着你喝完一碗汤，脸色才稍微好看了一点，但是还是鼓着脸不说话，起身要去给你放洗澡水，你拉住她的手）
【哥】（拉着她的手，她的手冰凉冰凉的，肯定是在沙发上等了你好久冻的，你心疼得不行，把她的手放在你手里暖着）手怎么这么冰？等了多久啊？
【妹】（别过脸不看你，但是手却没抽回去，任由你握着，小声说）...也没多久...就从十点等到两点...
【哥】（心里更愧疚了，把她拉进怀里抱着，亲了亲她的发顶，声音哑哑的）傻瓜，等不到我就先睡啊，在沙发上睡冻感冒了怎么办？
【妹】（靠在你怀里，听你这么说，又有点委屈，声音小小的）...我不放心...你不回来我睡不着...我怕你喝多了出事...
【哥】（抱紧她，在她额头上亲了一下，认真地说）我保证，下次再也不会了，以后不管多晚都给你报平安，再也不让你等我到这么晚了，好不好？
【妹】（在你怀里点点头，犹豫了一下，抬起头看你，眼睛红红的，小声问）...那...那你下次聚会能不能带我一起去啊...我不是要管你...我就是...我就是想在你身边...你喝多了我能照顾你...
【哥】（心里一下子软得一塌糊涂，捏了捏她红红的脸蛋，笑着答应）好，下次聚会都带你去，让你看着我，省得你在家担心得睡不着觉。
【妹】（终于笑了，但是还是有点不好意思，把脸埋在你怀里，小声嘟囔）...谁要看着你...我就是怕你喝多了没人给你煮醒酒汤...
【哥】（笑着抱起她往卧室走，她轻呼一声搂住你脖子，你把她放在她床上，帮她盖好被子）好了，快睡觉，都两点多了，明天还要上课呢，我洗完澡就睡。
【妹】（抓着你的手不放，眼睛半睁半闭的，困得不行了，但是还是小声说）...你洗完澡过来给我道晚安...不许又偷偷睡了...
【哥】（笑着点头，在她额头上亲了一下）好，一定过来跟你道晚安，快睡吧。
【妹】（这才松开手，闭上眼睛，很快就呼吸均匀睡着了，脸上还带着点没消下去的红，但是嘴角带着点安心的笑。你帮她把灯关掉，轻手轻脚走出去，心想以后再也不能让她这么等自己了）
