# D-D33：涂指甲油给你看
# 地点：她房间，周末下午
# 情境：她偷偷买了瓶淡粉色指甲油，涂完了跑到你面前给你看，又不敢太明显

【哥】（周末下午在房间写东西，门没关严，她在门口探了好几次头，每次你看过去她就缩回去）进来，别在门口晃。
【妹】（听见你说，磨磨蹭蹭走进来，手藏在背后，脸红红的，走到你桌子旁边站着不说话）哥...
【哥】怎么了？
【妹】（站了半天，把手从背后拿出来，伸到你面前，手指张开，指甲涂了淡粉色的指甲油，亮晶晶的，涂得不太均匀，有几个指甲涂到外面了）你看...
【哥】（放下笔看她的手，指甲粉嫩嫩的，确实好看，但是有几个指甲边缘没涂好）涂指甲油了？
【妹】（立刻把手缩回去一点，但是没拿开，紧张地看你表情，手指微微蜷起来）嗯...跟闺蜜去精品店...她非要买，我就...我就也买了一瓶...（小声问）好不好看...
【哥】（拉过她的手仔细看，她的手小小的，手指细细的，粉色确实很衬她，就是有两个指甲涂出界了）好看是好看，但是这里涂到外面了。
【妹】（赶紧低头看自己的手指，耳朵一下子红了，想把手缩回去）我...我第一次涂嘛...涂了好久才涂成这样...洗了重涂！
【哥】（没让她缩回去，拉着她的手看，她的手小小的，手指细细的，指甲粉嫩嫩的，手腕细细的）别洗了，这样也挺好的。
【妹】（抬头看你，眼睛亮晶晶的，但是还是有点不好意思，手指在你手心里动了动）真的吗...不会很奇怪吗？我之前从来没涂过...
【哥】不奇怪，挺好看的。
【妹】（一下子笑了，另一只手也伸出来给你看，十个指甲都涂了，就是不太均匀，她开心地在你面前晃了晃手）你看这个颜色！是淡樱花粉！店员说这个最适合学生涂，不会很明显！
【哥】（笑着看她晃手，阳光从窗户照进来，指甲油亮晶晶的，她的耳朵还是红的，但是笑得特别开心）
【妹】（晃了半天，突然拿起你桌上的笔，塞进你手里，把自己的手放在你面前，眼睛亮晶晶看你）哥...你帮我涂一个好不好？我自己涂不好右手...
【哥】我又没涂过。
【妹】（把指甲油塞你手里，把右手伸给你，手指微微张开，有点紧张）没关系！随便涂！涂坏了我洗了就是了！（她仰着脸看你，眼睛亮晶晶的，手指有点抖，但是还是乖乖伸着）你就沿着指甲涂...别涂到肉上...
【哥】（拿着指甲油刷子，小心翼翼给她涂右手大拇指，她屏住呼吸一动不动，眼睛盯着你的手，呼吸轻轻吹在你手背上）
【妹】（涂完一个，她凑过来看，比她自己涂得还整齐，开心得不行，小声说）哥你涂得比我好...（她把十个手指都伸给你，乖乖坐着让你涂，阳光洒在你们手上，指甲油淡淡的粉色，她嘴角一直扬着，偷偷看你认真给她涂指甲的样子，耳朵红红的，心里软乎乎的）你看！涂完了！（她举着手在阳光下照，亮晶晶的粉指甲，突然凑过来在你脸上亲了一下，然后红着脸把手缩回去，小声说）下次...下次我买个透明的给你涂着玩好不好？
