# D-B22：借笔记给同学被弄丢她难过
# 她把你熬夜帮她整理的历史笔记借给同学，结果同学弄丢了，她急得快哭了，你又帮她重新整理了一本
# 地点：家里，放学回家

【哥】（放学回家，看见她坐在书桌前翻书包，翻来翻去翻了好多遍，眉头皱得紧紧的，眼泪在眼眶里打转，把书包里的东西都倒在桌子上，还是没找到要找的东西）找什么呢？这么着急？
【妹】（抬起头看见你，眼泪"唰"一下就掉下来了，声音哽咽，带着哭腔）哥...我...我历史笔记不见了...
【哥】（心里咯噔一下，那本历史笔记是你期中考试前熬了三个晚上帮她整理的，重点考点都用不同颜色的笔标出来了，还有你画的时间轴和记忆口诀，她平时宝贝得不行，连翻都舍不得用力翻，怎么会不见了）怎么会不见？你放哪里了？
【妹】（眼泪掉得更凶了，抽抽搭搭的，手紧张地揪着衣角，特别愧疚）我...我上周借给林晓了...她历史不好要复印...结果她今天告诉我...她把笔记弄丢了...找了一整天都没找到...
【哥】（原来是这样，那本笔记确实挺可惜的，但是看着她哭得这么难过，你也舍不得说她，走过去帮她擦眼泪，揉了揉她的头发）丢了就丢了，哭什么，我再帮你整理一本就是了。
【妹】（听你这么说，哭得更凶了，扑进你怀里，捶了你胸口一下，又愧疚又难过）那是你熬了三个晚上帮我整理的...你那几天每天都写到一点多...我都没好好谢谢你...就被我弄丢了...我怎么这么笨啊...我为什么要借给别人啊...
【哥】（轻轻拍她的背，让她靠在你怀里哭，她哭得肩膀一抽一抽的，特别自责，把你衬衫都哭湿了一大片。你等她哭够了，才帮她擦干净脸，弹了她脑门一下）傻丫头，不就是一本笔记吗，丢了我们再写就是了，人没事就行，哭什么。
【妹】（抬起头，眼睛肿得像桃子，鼻子红红的，抽抽搭搭地说）可是...可是那本笔记你写了好久...上面还有你画的小兔子...还有你写的记忆口诀...都没了...我都快心疼死了...我以后再也不把东西借给别人了...
【哥】（笑着帮她理了理哭乱的头发，把她拉到椅子上坐下，拿出新的笔记本和彩笔放在桌子上）没事，小兔子我再给你画，口诀我再给你写，这次我写得更详细，比上次那本还好，好不好？你去把历史书拿过来，我们现在就开始写。
【妹】（愣了一下，看着你拿出新本子，眼泪还挂在脸上，有点不敢相信）...你...你现在就帮我整理？你不生气吗？我把你辛辛苦苦写的笔记弄丢了...
【哥】（笑着弹了她脑门一下）我生什么气，你又不是故意的。下次借东西给别人记得提醒人家别弄丢就行了，这次就当长个记性，好不好？来，帮我翻书，我们从头开始整理。
【妹】（看着你已经开始写了，眼泪又掉下来了，但是这次是感动的，她赶紧擦掉眼泪，搬了个小椅子坐在你旁边，帮你翻书，递彩笔，你写字的时候她就托着下巴看着你，眼睛亮晶晶的）
【哥】（你写重点，她在旁边帮你画时间轴，虽然画得歪歪扭扭的，但是特别认真，还在每一页角落都画了个小小的小兔子，比上次那本还可爱。写了两个多小时，才写了半本，你让她先去睡觉，她不肯，要陪着你写，趴在你旁边看着，看着看着就困了，头一点一点的像小鸡啄米）
【妹】（困得眼睛都快睁不开了，小脑袋一点一点的，但是还是强撑着不肯去睡，小手还紧紧握着彩笔，嘴里含糊不清地说"我不困...我陪哥..."，话还没说完，头就靠在你胳膊上睡着了）
【哥】（看她困得不行，把她抱到床上让她睡觉，她迷迷糊糊抓住你的手，含糊不清地说"哥你别写了，早点睡"，你笑着答应了，帮她盖好被子，又回到书桌前继续写，一直写到快十二点，终于把整本笔记整理完了，比上次那本还详细，还加了好多新的重点）
【妹】（第二天早上醒过来，走到书桌前，看见一本崭新的笔记放在桌子上，整整齐齐的，重点标得清清楚楚，每一页角落都有她画的小兔子，你还在最后一页画了个大大的笑脸，写着"我们妹妹历史肯定考满分"。她愣了半天，眼泪又掉下来了，跑到你房间，你还在睡觉，她趴在你床边，看了你好久，然后在你脸上轻轻亲了一口）
【哥】（迷迷糊糊醒过来，看见她趴在床边，眼睛红红的，但是笑得特别甜，手里紧紧抱着那本新笔记。你坐起来揉了揉眼睛，笑着说"醒了？看看新笔记喜不喜欢"）
【妹】（使劲点头，把笔记抱在怀里，像抱着什么稀世珍宝，趴在你床边，声音黏黏的带着鼻音）哥...你写到半夜对不对...你怎么那么好啊...
【哥】（笑着揉了揉她乱蓬蓬的头发，故意逗她）我不对你好对谁好啊？这次可不许再弄丢了啊，再弄丢我就不帮你写了。
【妹】（赶紧把笔记抱得更紧了，使劲摇头，像个护食的小仓鼠，认真地说）不会了！这次我绝对不借给别人了！我天天揣在书包里！走到哪里带到哪里！绝对不会再弄丢了！
【哥】（被她认真的样子逗笑了，起床给她做早饭，她跟在你身后，抱着笔记，叽叽喳喳说这次历史考试一定要考个好成绩，不辜负你熬了两个晚上帮她整理笔记。你笑着听她说，心里暖暖的，其实别说熬两个晚上，就算熬二十个晚上，只要她开心，什么都值得。后来她这次历史考试真的考了年级第三，拿到卷子第一个跑过来找你，把卷子举得高高的，笑得眼睛都弯了，你看着卷子上的高分，觉得再熬多少个晚上都值了）
【妹】（拿着考了高分的历史卷子扑进你怀里，笑得特别开心，把卷子举到你面前炫耀，声音甜甜的）哥你看！我考了年级第三！我就说我不会辜负你的！你太棒了！
