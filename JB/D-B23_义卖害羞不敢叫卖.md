# D-B23：义卖活动她害羞不敢叫卖
# 学校组织爱心义卖，她抱着自己做的手工发夹站在摊位后面，害羞不敢叫卖，半天没卖出去一个，你过去帮她一起卖
# 地点：学校操场，爱心义卖活动当天

【哥】（学校组织爱心义卖，操场全是摊位，你逛了一圈，在操场角落找到她们班的摊位）
【妹】（站在摊位后面，怀里抱着一堆自己做的手工蝴蝶结发夹，头埋得低低的，有人路过她就紧张得往后缩，半天一个都没卖出去，脸憋得通红）
【哥】（走过去，敲了敲她的摊位桌子，她吓了一跳，抬头看见是你，脸一下子红了，有点不好意思）
【妹】（小声说）哥...你怎么来了...
【哥】（笑着拿起一个粉色蝴蝶结发夹看了看，做得特别精致，针脚整整齐齐的，上面还粘了小珍珠，特别好看。你弹了她脑门一下）你怎么不叫卖啊？你站在这里不说话，谁知道你卖发夹啊？你看别的班喊得多大声。
【妹】（脸更红了，低下头揪衣角，小声说）我...我不敢...那么多人...我不好意思喊...我一喊就紧张...声音都发抖...
【哥】（看着她害羞得耳朵尖都红了的样子，忍不住笑了，拿起一个发夹别在她头发上，然后拿起一个扩音小喇叭（旁边摊位借的），对着操场就喊："走过路过不要错过！手工做的蝴蝶结发夹！五块钱一个！买两个送小皮筋！小姑娘戴上特别好看！"
【妹】（没想到你会直接喊出来，脸"唰"一下红透了，赶紧伸手拉你的衣服，又羞又急）哥！你别喊！太丢人了！
【哥】（笑着躲开她的手，继续喊，声音很大，周围路过的同学都看过来，很快就有几个女生走过来，拿起发夹看，说"做得好精致啊""这个粉色的好好看"）
【妹】（站在你身边，脸通红通红的，但是眼睛亮晶晶的，赶紧给同学介绍发夹，声音小小的但是很认真，说"这个是我自己做的，珍珠是粘上去的，不会掉"，很快就卖出去了第一个，她接过五块钱，手都在抖，特别激动，抬头看你，眼睛亮得像星星）
【哥】（低头看她）
【妹】（卖出第一个之后，她就没那么害羞了，虽然还是不敢大声喊，但是有人过来问她会认真介绍，你在旁边帮她喊，她负责拿发夹收钱，两个人配合得特别好，一堆发夹不到一个小时就卖光了，她手里攥着一把零钱，数了数有一百多块，特别开心，笑得眼睛都弯了）
【哥】（看着她数完钱，抬起头看你，脸还是红扑扑的，但是特别有成就感，激动得拉着你的手晃啊晃）
【妹】哥！卖光了！我们全卖光了！一百二十七块钱！比别的班卖得都多！
【哥】（笑着揉了揉她的头发，帮她把额前汗湿的碎发理好，把刚才别在她头发上那个粉色蝴蝶结发夹重新别好，笑着说）你看，这不是卖得挺好吗？一开始害羞不敢说话，现在不也卖光了？
【妹】（脸还是红红的，有点不好意思，低下头踢小石子，小声说）...还不是因为你帮我喊...我自己肯定卖不出去...我一看见人多就紧张...张不开嘴...
【哥】（把她手里的零钱整理好，放进义卖捐款箱里，她亲手把钱放进去的时候，特别骄傲，胸脯都挺起来了。你牵着她的手在操场逛，买了两根冰棒，递给她一根）
【妹】（咬了一口冰棒，凉丝丝的，特别甜）
【哥】（走在路上，你跟她说，害羞不敢说话很正常，但是有些事你不试一下怎么知道自己不行呢？你看你后来介绍发夹的时候说得特别好，比我喊得都管用）
【妹】（咬着冰棒，认真听你说话，点点头，说下次义卖她肯定敢自己喊了）
【哥】（吃完冰棒，她突然停下来，从口袋里掏出一个最好看的水钻蝴蝶结发夹，别在你衬衫领口上，你愣了一下，低头看）
【妹】（笑着说）这个是做得最好的一个，送给你，谢谢你帮我卖发夹。
【哥】（低头看着领口那个粉色的水钻蝴蝶结，忍不住笑了，一个大男生别个蝴蝶结确实有点奇怪，但是你没摘下来，就这么别着陪她逛完了整个义卖会，路过的同学都看你，你也不在乎，她走在你身边，笑得眼睛都弯了，特别开心）
【妹】（逛到义卖结束，你们班摊位也收了，她帮着收拾东西，收拾完跑过来找你，看见你领口还别着那个蝴蝶结，脸又红了，伸手想摘下来，说"还是摘下来吧，别人都看你呢"）
【哥】（摇摇头，把她的手挡住，笑着说）别摘，我们妹妹送的，我天天戴着。
【妹】（脸更红了，但是笑得特别甜，往你身边靠了靠，牵着你的手往校门口走，夕阳把两个人的影子拉得很长，她蹦蹦跳跳的，跟你说下次义卖要做更多更好看的发夹，还要自己喊，不用你帮忙了）
