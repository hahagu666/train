# D-E12：感动你记得随口说的话
# 地点：家里，晚上
# 情境：上周她随口说想吃巷口那家老字号的桂花糕，你今天下班绕远路去买了，她拿着桂花糕眼睛红了

【哥】（晚上下班回家，拎着个纸袋子递到她面前，笑着晃了晃）喏，给你买的，还热乎着呢。
【妹】（接过来，打开，看到是桂花糕，愣了一下）桂花糕？
【哥】你上周不是说巷口张记的桂花糕好久没吃了吗，今天下班绕路过去买的，还热着呢。
【妹】（拿着纸袋子，愣了半天，眼睛一点点红了，低下头看着桂花糕，声音有点发颤）...我就是上周随口说了一句...
【哥】你说的话我都记着。趁热吃吧，晚了就卖完了，我排了二十分钟队呢。
【妹】（拿起一块桂花糕，咬了一口，还是热的，甜丝丝的，她低着头，眼泪吧嗒一下掉在纸袋子上）
【哥】（慌了）怎么哭了？不好吃？
【妹】（摇头，用手背擦眼睛，但是眼泪越擦越多，声音抽抽搭搭）好吃...特别好吃...
【哥】（摸她头，把她揽过来）好吃就多吃点，哭什么。
【妹】（靠在你怀里，手里还拿着桂花糕，眼泪蹭你衣服上，声音小小的）...哥，你怎么对我这么好啊...
【哥】不对你好对谁好，傻丫头。
【妹】（抱着你腰，脸埋在你胸口，闷声说）...我以后一定对你更好...给你买大房子...给你做饭...
【哥】（笑）好，我等着。
【妹】（擦了擦眼泪，拿起一块桂花糕递到你嘴边）你也吃！特别甜！
