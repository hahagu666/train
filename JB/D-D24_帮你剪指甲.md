# D-D24：帮你剪指甲
# 地点：客厅沙发，晚上
# 情境：你在沙发上看手机，她写完作业出来，看见你指甲长了，非要帮你剪

【哥】（晚上靠在沙发上看手机，手指无意识敲着沙发扶手）
【妹】（写完作业伸着懒腰从房间出来，倒了杯水坐在你旁边，目光落在你手上）哥，你指甲好长了。
【哥】（看了一眼自己的手）是吗，明天剪。
【妹】（立刻放下水杯，从抽屉里翻出指甲剪，坐到你旁边拉过你的手）现在剪！明天你又忘了。
【哥】我自己来就行。
【妹】（把你的手放在她膝盖上，握着你的手指，指甲剪对准指甲）我帮你剪！你别乱动，剪到肉我不管。
【哥】（笑了，放下手机任由她弄）你行吗，别剪太秃了。
【妹】（皱着眉头很认真的样子，咔嚓咔嚓剪，剪一下就抬起你的手对着灯看看）我剪指甲可好了，我自己的都是我自己剪的。
【哥】（看着她低头认真的侧脸，头发垂下来挡住一点眼睛，她时不时吹掉指甲屑）
【妹】（剪完大拇指剪食指，一个一个剪得很仔细，剪到你中指的时候不小心剪到一点肉，你嘶了一声）
【哥】疼疼疼！
【妹】（立刻慌了，把你手指拿过去看，有点红，她赶紧凑过去对着吹了吹）对不起对不起！我不是故意的！（眼睛里都快急出眼泪了）疼不疼啊？
【哥】（看着她慌成那样，笑了）没事，就一点点，没破。
【妹】（不放心，还是捧着你的手指吹了好几下，然后更加小心地剪剩下的，这次动作慢了好多）
【哥】（看她那么认真，嘴角忍不住往上扬，指尖能感觉到她的呼吸轻轻吹在手上）
【妹】（终于剪完了，又拿指甲锉一个个磨平，磨完了把你的手翻来覆去看了好几遍，确认没剪破才松了口气）好了。
【哥】（活动了一下手指，剪得整整齐齐的，磨得也光滑）手艺不错啊。
【妹】（听见你夸她，立刻开心起来，但是还是有点愧疚，摸着刚才剪红的地方）刚才那个...真的对不起嘛。（她突然低头，在你剪红的指尖上轻轻亲了一下，然后脸一下子红了，赶紧把指甲剪收起来）我...我去把指甲屑倒了！（说完转身就往卫生间跑，跑到一半又回头看你，耳朵红红的，嘴角偷偷翘着）剪完了记得洗手！
