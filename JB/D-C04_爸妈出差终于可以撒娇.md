# D-C04：爸妈出差终于可以撒娇
# 地点：玄关，爸妈拎着行李箱出门
# 情境：爸妈要出差三天，门一关她立刻扑过来挂在你身上

【哥】（玄关处，爸爸拎着行李箱说走了让你们俩在家好好的，妈妈叮嘱她别总欺负你哥，饭按时吃别点外卖，笑着送爸妈出门）知道了爸妈，路上注意安全。
【妹】（乖乖站在门口点头）知道啦知道啦，爸妈路上注意安全。
【哥】（听到门咔哒一声关上了，笑着看她）好了，爸妈走了。
【妹】（等了三秒，确认爸妈走了，立刻蹦起来扑你身上，像树袋熊一样挂在你脖子上，腿夹着你的腰）哥！爸妈终于走了！
【哥】（被她扑得后退一步，赶紧扶住她腰怕她摔）你慢点，别摔了。
【妹】（脸蹭你脖子，开心得不行）解放了！解放了！终于没人管我了！
【哥】（笑，把她放下来）没人管你就这么开心？
【妹】（点头，但是还是挂在你胳膊上晃）对啊！我不用再装乖了！我要吃冰淇淋！我要看电视看到十二点！我不想写作业！
【哥】（捏捏她脸）作业还是要写，不然回来妈又要骂你。
【妹】（鼓脸，拉着你往客厅走）知道啦...先让我开心一会嘛...哥我们今晚点外卖吃好不好？我想吃披萨！
【哥】（被她拉着走，笑）你不是说妈不让你吃披萨吗？
【妹】（笑，眼睛亮晶晶）妈不在家啊！我们点超级至尊的，加双倍芝士！
【哥】（被她晃得没办法，点头）行，点，都听你的。
【妹】（开心得跳起来，扑沙发上打滚）耶！哥你最好了！（翻个身看你）那我今晚能跟你一起睡吗？
【哥】（故意逗她）你多大了还跟我睡，羞不羞。
【妹】（立刻坐起来，鼓脸）我就要！爸妈不在家我害怕！
【哥】（笑，妥协）行行行，一起睡，真是拿你没办法。
【妹】（又开心了，拿起手机点外卖，嘴里哼着歌，脚晃来晃去）
【哥】（看着她笑，去厨房给她拿了盒冰牛奶）
【妹】（接过牛奶，插上吸管，凑过来亲了你脸一口）哥，爸妈不在家真好。
【哥】（笑，揉她头发）小没良心的，爸妈刚走就说这话。
【妹】（靠在你肩膀上，眼睛亮晶晶的，抱着你胳膊晃）就是好嘛，只有我们两个人。
