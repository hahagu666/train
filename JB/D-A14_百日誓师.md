# D-A14：百日誓师
# 地点：学校操场/回家路上，傍晚
# 情境：百日誓师大会结束，她穿着校服，手里攥着写着目标大学的卡片，背着书包走回来

【哥】（提前下班在小区门口等她，远远看见她穿着校服背着书包走过来）
【妹】（抬头看见你，眼睛一下子亮了，攥着卡片朝你跑过来）
【哥】（迎上去接她沉甸甸的书包）回来了？背这么多书回来？
【妹】（抬头看你，脸被太阳晒得红红的，把手里的卡片递给你）哥！你看！
【哥】（接过来，卡片上写着"A大学"三个字，旁边还画了个小星星）这是你写的？
【妹】（有点不好意思，点头）誓师大会上写的...每个人都要写自己的目标大学，贴在教室后面。
【哥】（笑）写得挺好看。
【妹】（走在你旁边，踢着路上的小石子）我们校长讲了好久的话，太阳晒得我头都晕了...
【哥】让你戴帽子你不戴。
【妹】戴帽子丑...（抬头看你）哥，你说我真的能考上吗？
【哥】写都写了，还怕考不上？
【妹】（捏手指）可是我们班好多人都写A大...录取名额就那么几个...
【哥】你最近模考不是越来越好了吗。
【妹】（点头，又摇摇头）我还是有点怕...（晃了晃手里空了的矿泉水瓶）对了，我们今天还集体宣誓了，喊得我嗓子都哑了。
【哥】喊的什么？
【妹】（清了清嗓子，小声）"百日冲刺，决战高考！"（自己笑出来）特别傻是不是，全年级一起喊，声音大得我耳朵都疼。
【哥】不傻，挺有气势的。
【妹】（笑，把卡片小心夹进笔记本里）我要把这个留着，等考上了拿出来看。
【哥】等你考上了，哥请你吃大餐。
【妹】（眼睛亮了）说话算话？
【哥】算话。
【妹】（蹦蹦跳跳往前走，马尾晃）我要吃火锅！还要吃烤肉！还要吃上次没吃到的那个草莓蛋糕！
【哥】行，都给你买。
【妹】（回头笑）那我回去做题了！最后一百天，拼了！
【哥】（看着她蹦蹦跳跳往前跑的背影，笑着摇摇头跟上去，夕阳把两个人的影子拉得很长）
【妹】（跑了两步又回头，冲你挥了挥攥着卡片的小拳头，马尾在夕阳下晃啊晃，眼睛亮得像星星）哥你等着！我一定考上A大！
