# D-F11：玩游戏输了被弹脑瓜崩耍赖
# 地点：客厅，周末下午玩纸牌游戏
# 情境：玩纸牌游戏她输了，你要弹她脑瓜崩，她耍赖扑到你怀里躲，两个人抱在一起摔倒在沙发上

【哥】（周末下午没事干，两个人坐在地毯上玩纸牌游戏，说好输了的被弹脑瓜崩，她已经连输三把了，捂着额头鼓着脸看着你。）再来！这次我肯定赢！
【妹】（鼓着脸，拿着牌，气呼呼的，结果最后一把又输了，她把牌一扔，双手捂着额头往后躲，眼睛水汪汪看着你耍赖。）我不玩了！你肯定出老千！我怎么一直输！不弹！
【哥】（笑着伸手要弹她，她赶紧往后躲，你往前凑她就往后退，退着退着退到沙发边，没地方躲了，你伸手作势要弹，她吓得直接扑过来，直接扑进你怀里，整个人撞在你身上，你没坐稳，两个人一起倒在沙发上，她压在你身上。）啊！
【妹】（扑在你怀里，把你撞倒在沙发上，她整个人都压在你身上，软软的胸压在你胸口，脸离你特别近，头发散在你脸上，香香的，她愣了一下，脸一下子红了，但是没起来，就那么趴在你身上看着你，眼睛亮晶晶的，呼吸一下子乱了，暖暖的吹在你脸上。）呃...
【哥】（被她压在沙发上，她软软的身体整个贴在你身上，胸软软的压在你胸口，能闻到她头发上的香味，脸离你只有几厘米，嘴唇粉粉的就在眼前，心跳一下子快了，手不自觉地扶在她腰上，她的腰细细的软软的。）怎么，输了还想打人啊。
【妹】（趴在你身上，能感觉到你扶在她腰上的手暖暖的，能听见你心跳很快，和她的心跳一样快，她脸更红了，不仅没起来，反而故意往你身上压了压，软软的胸蹭了你一下，眼睛水汪汪看着你，故意耍赖，声音黏黏的带着撒娇。）就打你！谁让你一直赢我！弹脑瓜崩太疼了！你弹轻点行不行...
【哥】（看着她近在咫尺的脸，脸红扑扑的，嘴唇粉润润的，呼吸暖暖的喷在你嘴唇上，腰上她的皮肤软软的，你故意逗她，手在她腰上轻轻捏了一下。）不行，愿赌服输。
【妹】（被你捏了一下腰，她最怕痒了，身体一抖，整个人更没力气了，趴在你怀里，脸埋在你颈窝，笑得直抖，暖暖的呼吸喷在你脖子上，痒痒的，她趴在你身上不起来，笑得浑身没力气，手轻轻捶你胸口一下。）啊！你坏！你捏我痒！我不跟你玩了！
【哥】（她趴在你身上，软软暖暖的，头发蹭得你脖子痒痒的，胸软软的压在你胸口，手轻轻拍了拍她的屁股，拍了一下，软软的很有弹性。）快起来，重死了。
【妹】（被你拍了一下屁股，她身体一下子僵住了，脸瞬间红透了，连耳朵都红了，趴在你颈窝不敢动，呼吸都停了半秒，过了半天，不仅没起来，反而把脸埋得更深，抱着你的脖子，身体软软的贴在你身上，声音小小的闷闷的，带着点撒娇和羞涩，几乎听不见，她嘴上这么说，但是身体却悄悄往你身上贴得更紧，胸软软地压在你胸口，能感觉到两个人的心跳都快得不行，她趴在你颈窝，嘴角偷偷扬起来，觉得这样被你抱着压在你身上，比赢了游戏还开心，一直赖着不肯起来。）就不起来...你欺负我...我就压着你...
