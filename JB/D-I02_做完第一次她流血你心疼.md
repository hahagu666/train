# D-I02：做完第一次她流血你心疼
# 地点：你床上，第一次做完后
# 情境：第一次做完，你拔出来发现床单上有血，她疼得皱眉，你特别心疼

【哥】软软...你流血了...（你射在她里面，趴在她身上喘了半天，才慢慢退出来，起身一看，白色床单上沾了一小片鲜红的血，她躺在那里，眉头皱着，下面还有点血渗出来。）
【妹】（她躺在那里，腿还张着，下面有点疼，看见你看着床单发呆，她脸红了，想拉被子盖住，但是一动就疼得嘶了一声。）别看...
【哥】（你赶紧拿过纸巾，轻轻帮她擦下面，碰到她她疼得缩了一下，你心疼得不行，摸了摸她的脸。）疼不疼？都流血了，对不起...
【妹】（她摇摇头，但是眼睛里还有眼泪，伸手抱住你的腰，把脸埋在你肚子上，声音黏黏的。）刚开始疼...后来就不疼了...你别自责...
【哥】（你轻轻把她抱起来，让她靠在你怀里，拿过被子盖在她身上，吻她的额头。）我去给你倒点水，拿毛巾擦一擦。
【妹】（她紧紧抱着你不让你走，腿环住你的腰，埋在你怀里摇摇头，声音带着点哭腔。）不要...你别走...就抱我一会...
【哥】（你赶紧躺下来，把她紧紧搂在怀里，她身体软软的，暖暖的靠在你胸口，能感觉到她下面还有点血蹭在你腿上，你一点都不嫌弃，只是心疼。）好，我不走，抱着你。
【妹】（她乖乖窝在你怀里，手轻轻摸着你的胸口，过了半天，抬起头看你，脸红扑扑的，眼睛还有点红，小声说。）哥...我现在真的是你的人了...
【哥】（你吻了吻她的嘴唇，把她搂得更紧。）你早就都是我的了。
【妹】（她笑了，往你怀里钻了钻，但是一动下面就疼，嘶了一声，皱起小脸，但是还是笑着。）就是有点疼...走路会不会疼啊...
【哥】（你心疼地摸了摸她的头，手轻轻揉着她的腰。）明天就好了，明天你别乱跑，在家休息，我给你做好吃的。
【妹】（她点点头，亲了亲你的下巴，小声说，脸更红了。）那...那下次...还会疼吗...
【哥】（你笑着捏了捏她的脸。）下次就不疼了，会舒服的。
【妹】（她脸更红了，把脸埋在你胸口，不敢看你，过了半天，小声嘟囔。）那...那你下次还要我...
【哥】（你笑了，抱着她亲了亲。）要，当然要，要一辈子。
【妹】（她开心地笑了，紧紧抱着你，虽然下面还是有点疼，但是心里甜得像蜜一样，听着你的心跳，过了一会，她小声说。）床单脏了...明天妈妈看到怎么办...
【哥】（你看了一眼床单上的血迹，笑了笑。）没事，明天我起来洗，你别管。
【妹】（她抬起头，在你嘴唇上亲了一下，软软的，眼睛亮晶晶的看着你。）哥...我爱你。
【哥】（你回吻她，抱着她软软的身体，心里满满的。）我也爱你。
【妹】（她满足地窝在你怀里，抱着你的腰，虽然身体累，下面还有点疼，但是被你抱着就特别安心，没过一会就在你怀里睡着了，嘴角还带着笑。）嗯...晚安...哥...
