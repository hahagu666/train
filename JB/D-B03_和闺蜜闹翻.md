# D-B03：和闺蜜闹翻
# 地点：她房间，晚上
# 情境：放学回来就关着门不说话，晚饭也没吃多少，你敲门进去发现她眼睛红的

【哥】（敲门，推开门，看到她趴在床上，脸埋在枕头里）怎么了？晚饭没吃多少。
【妹】（没回头，声音闷闷的）...不饿。
【哥】（走过去坐床边）跟同学吵架了？
【妹】（肩膀抖了一下，没说话）
【哥】（伸手摸她头发）跟你那个闺蜜？
【妹】（终于坐起来，眼睛红红的，脸上还有枕头压的印子）...她把我跟她说的秘密告诉别人了。
【哥】什么秘密？
【妹】（擦眼睛，声音哽咽）我...我跟她说我想考你那个城市的大学，因为我想跟我哥在一起...结果她转头就跟别人说我恋兄...
【哥】（愣了一下，然后摸她头）别人说什么让他们说去。
【妹】（眼泪掉下来）现在全班都知道了...她们都在背后笑我...
【哥】（把她拉过来靠你肩膀上）哭什么，这有什么好哭的。
【妹】（靠你肩膀上，擦眼泪）我把她当最好的朋友...她怎么能这样...
【哥】那就不是真朋友。
【妹】（抽鼻子）我以后再也不跟她说悄悄话了...
【哥】嗯，以后有什么话跟哥说就行。
【妹】（点点头，抱着你腰，脸埋你衣服上）...哥，你不会也笑我吧？
【哥】笑你什么。
【妹】（声音很小）...想跟你在一个城市...
【哥】（揉她头发）我高兴还来不及。
【妹】（抬头看你，眼泪还挂在脸上就笑了）真的？
【哥】真的。饿不饿？我给你热杯牛奶，拿点饼干？
【妹】（点头，擦干净眼泪）嗯...要草莓味的饼干。
【哥】（起身）等着。
【妹】（看着你出去，拿起手机，把闺蜜对话框删掉了）
