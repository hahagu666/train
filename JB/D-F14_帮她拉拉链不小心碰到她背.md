# D-F14：帮她拉拉链不小心碰到她背
# 地点：她房间，她要穿裙子参加同学聚会
# 情境：她穿连衣裙后背拉链拉不上，喊你帮忙，你手指不小心碰到她光滑的后背，她身体发抖

【哥】（你正在客厅看电视，她在房间喊你，声音有点急，你走过去推开她房门，她站在镜子前面，穿了一条浅粉色的连衣裙，后背拉链拉到一半拉不上了，露出白白的后背，皮肤细腻光滑。）哥你快过来帮我拉一下拉链！我够不到！
【妹】（站在镜子前面，裙子拉链卡在后背中间，露着大半个光滑的后背，白白的皮肤在灯光下像牛奶一样，她一只手抓着前面的裙子，另一只手往后够拉链，够了半天够不到，急得脸都红了，看见你进来，赶紧转过身背对着你。）快帮我拉一下！一会就要迟到了！
【哥】（走过去，她的背白白的，皮肤细腻光滑，能看到脊椎浅浅的沟，肩胛骨很漂亮，脖子上有细细的绒毛，你捏着拉链头慢慢往上拉，手指不小心碰到她后背的皮肤，她的皮肤暖暖的滑滑的。）嗯。
【妹】（被你手指碰到后背，她身体像过电一样猛地抖了一下，整个人都僵住了，呼吸一下子停了半秒，后背的皮肤瞬间起了一层细细的鸡皮疙瘩，她赶紧咬住嘴唇，不让自己发出声音，脸一下子红透了，从耳朵尖一直红到脖子根。）啊！
【哥】（感觉到她身体猛地抖了一下，指尖能感觉到她皮肤细腻光滑的触感，暖暖的，还有点微微发抖，你继续慢慢拉拉链，手指偶尔碰到她的后背，每次碰到她都轻轻抖一下。）怎么了？
【妹】（背对着你，你每次手指碰到她皮肤，她都像触电一样浑身发麻，身体控制不住轻轻发抖，呼吸变得又快又浅，热热的喷在镜子上，蒙上一层雾气，她看着镜子里自己红透的脸和脖子，心跳快得咚咚咚的，手紧紧抓着裙摆，指节都发白了，但是没躲开，就那么站着让你拉拉链，声音小小的发颤，带着点撒娇。）你...你手别乱碰...痒...
【哥】（拉链拉到最上面，刚好在她脖子下面，你指尖不小心碰到她后颈的皮肤，那里特别敏感，她猛地缩了一下脖子，你赶紧收回手。）好了，拉上了。
【妹】（拉链拉好了，但是她没立刻转身，就那么背对着你站着，身体还在轻轻发抖，后背的皮肤还是红红的，能感觉到你站在她身后，呼吸就在她后颈那里，暖暖的，过了半天，她才慢慢转过身，脸红得像熟透的苹果，眼睛水汪汪的，不敢看你，头埋得低低的，声音小小的。）谢...谢谢你...
【哥】（看着她脸红成这样，眼睛水汪汪的，脖子都红透了，裙子穿在她身上特别好看，衬得她皮肤白白的。）穿这件裙子很好看。
【妹】（听见你夸她好看，脸更红了，但是忍不住偷偷抬眼看你，眼睛亮晶晶的，嘴角控制不住往上扬，但是又立刻低下头，手指绞着裙摆，过了半天，小声说，声音小小的带着羞涩，说完自己先反应过来这句话有多暧昧，脸瞬间红得能滴血，赶紧拿起包包，捂着脸就往门口跑，跑到门口回头看了你一眼，眼睛亮晶晶的像装了星星，脸红得像苹果，然后就跑出去了，留你一个人站在她房间，空气里还留着她身上的香水味，和她后背滑滑的触感。）那...那我聚会回来...你再帮我拉开...
