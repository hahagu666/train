# D-A04：考砸了
# 地点：家里客厅，傍晚
# 情境：开门进来，肩膀耷拉着，书包带子滑到胳膊上，成绩单藏在背后

【哥】（坐在沙发上看电视，听到开门声）回来了？
【妹】（换鞋，声音小小的）...嗯。
【哥】怎么了？不高兴？
【妹】（磨磨蹭蹭走过来，低着头，不看你）没...
【哥】（看她样子）成绩单出来了？
【妹】（肩膀一僵，手在背后攥紧成绩单，没说话）
【哥】给我看看。
【妹】（慢吞吞把成绩单从背后拿出来，递给你，眼睛盯着地板）...
【哥】（接过来，看了一眼）数学六十三？
【妹】（抠校服衣角，声音很小）这次题太难了...
【哥】你上次七十八。
【妹】（声音更小）最后两道大题我不会...全班及格的都没几个...
【哥】不会怎么不问我？
【妹】（眼眶有点红）你上次说这周末教我，结果你加班去了...（小声嘟囔）
【哥】（顿了一下）那是我不对。但你自己也没主动问。
【妹】（抬头，眼睛红红的）我问了啊，你说你在忙让我等一会，我等了好久你都没过来...
【哥】（沉默几秒，把成绩单放茶几上）先去吃饭吧。
【妹】（站着不动，眼泪在眼眶里转）你骂我吧...
【哥】我骂你干什么。（叹了口气）吃完饭我看看你卷子，哪不会给你讲。
【妹】（抬头看你，眼泪掉下来一颗，眼睛亮晶晶的）真的？
【哥】我什么时候骗过你。
【妹】（吸了吸鼻子，用袖子擦眼睛）我还以为你会生气...
【哥】生气有什么用。以后不会的题攒着，等我回来问，别拖着。
【妹】（走过来，把脸埋在你肩膀上蹭了蹭，声音还带着鼻音）哥你最好了...
【哥】一身校服汗味，快去洗手。
【妹】（松开你，往卫生间走，走了两步又回头）那个...你别告诉爸妈好不好？
【哥】这次先不告诉。下次再考成这样我就不管了。
【妹】（用力点头，眼泪还挂在脸上就笑了）嗯！
