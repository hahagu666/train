# D-A37：课间操帮她系鞋带被同学起哄
# 课间操她鞋带散了自己系不上，你蹲下来帮她系，被周围同学看见起哄，她脸红得像苹果躲在你身后
# 地点：学校操场/走廊，课间操时间

【哥】（课间操排队，你站在她斜后面，看见她白色运动鞋的鞋带散了，她自己蹲下来系了两次都系松了，走两步又散了，她鼓着脸踹了踹地，有点急）
【妹】（蹲在地上系鞋带，系了两次都系成死结，一拉就散，课间操马上就要开始了，她急得脸都红了，鼓着脸跟鞋带较劲）
【哥】（笑着走过去，没说话，直接蹲下来，把她散开的鞋带解开，重新帮她系成一个漂亮的蝴蝶结，动作很自然。她愣了一下，低头看着你蹲在她面前帮她系鞋带，脸"唰"地一下红了）
【妹】（周围排队的同学都看见了，开始起哄，"哇——""哥哥帮妹妹系鞋带哦——""好甜啊——"，她脸一下子红得像熟透的苹果，赶紧往后退了半步，小声说"我自己来就好..."但是你已经系好了，还轻轻拽了拽确认系紧了）
【哥】（站起来，拍了拍手上不存在的灰，完全没把周围的起哄当回事，弹了她脑门一下，笑着说）多大的人了，系个鞋带都系不好，等下跑操摔了又要哭。
【妹】（脸通红通红的，头埋得低低的，耳朵尖都红透了，周围同学还在笑，她恨不得找个地缝钻进去，但是看着你帮她系得整整齐齐的蝴蝶结鞋带，心里又甜丝丝的，偷偷用脚踩了踩鞋带，确实系得特别紧，不会散了）
【哥】（课间操跑操的时候，她跑在你前面，鞋带果然没散，跑起来稳稳的。她时不时偷偷回头看你，你冲她笑，她赶紧转回头，脸还是红的，嘴角却忍不住往上翘）
【妹】（课间操结束，她磨磨蹭蹭走在你旁边，周围还有同学冲你们挤眼睛，她赶紧拉着你快走，走到没人的走廊拐角，才停下来，鼓着脸瞪你，但是脸还是红的）都怪你！刚才那么多人看着！他们都起哄！丢死人了！
【哥】（被她逗笑了，靠在墙上看着她红红的脸，故意说）我帮你系鞋带怎么就丢人了？你自己系不上，摔了怎么办？上次你跑操鞋带散了摔在操场上，膝盖都摔破了，哭了半天才忘？
【妹】（想起上次确实摔了一跤，膝盖破了皮你背她去医务室涂碘伏，疼得她抓着你衣服哭，脸更红了，但是还是嘴硬，捶了你胸口一下）那...那我这次肯定能系好...你突然蹲下来帮我系...大家都看见了...他们肯定要说我们闲话...
【哥】（笑着揉了揉她的头发，伸手帮她把跑操跑乱的刘海理好，故意逗她）说什么闲话？说哥哥疼妹妹，天经地义，爱说就让他们说去，我帮我妹妹系鞋带，关他们什么事？
【妹】（听你这么说，心里甜滋滋的，但是脸还是红的，低下头看自己鞋上那个整齐的蝴蝶结，小声嘟囔）...那...那你以后不许在这么多人面前帮我系鞋带...要系...也要找没人的地方系...
【哥】（忍不住笑出声，捏了捏她红红的耳朵尖，点头答应）好，下次找没人的地方给你系，不让他们看见，好不好？
【妹】（脸更红了，但是点了点头，往你身边靠了靠，小声音说）...其实...你系的蝴蝶结...比我系的好看...
【哥】（被她可爱的样子逗得心里软乎乎的，牵着她的手往教室走，她的手小小的暖暖的，被你握在手里。她一开始还怕被人看见，想挣开，但是挣了两下没挣开，就乖乖让你牵着了，头埋得低低的，嘴角却一直翘着，心里甜得像吃了蜜一样）
【妹】（走到教室门口，她才松开你的手，跑进去之前回头冲你做了个鬼脸，小声说"下次鞋带散了我还叫你"，然后红着脸跑回座位了，留下你站在走廊上笑。下午你再看见她的时候，她的鞋带还是好好的，那个蝴蝶结整整齐齐的，她一直没舍得解开）
