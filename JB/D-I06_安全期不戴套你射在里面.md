# D-I06：安全期不戴套你射在里面
# 地点：你床上
# 情境：她算好是安全期，求你不戴套直接做，射在里面，两个人都特别舒服

【哥】（晚上洗完澡，她穿着睡衣爬到你床上，拿着手机给你看，是个安全期计算器，上面显示今天是安全期。）你拿的什么？
【妹】（爬到你腿上坐着，把手机举到你面前，脸红红的，眼睛亮晶晶的看着你，手指着屏幕。）哥你看！今天真的是安全期！不会怀孕的...
【哥】（你看了一眼手机，又看了看她期待的眼神，捏了捏她的脸。）你从哪找的这些东西？万一算错了怎么办。
【妹】（她摇摇头，伸手解开你睡衣扣子，手往下摸，握住你的肉棒，轻轻套弄着，凑过来吻你的脖子，声音黏黏的撒娇。）不会算错的...我算好多天了...求你了哥...今天不戴好不好...我想直接要你...
【哥】（被她套弄了几下就硬了，她的小手软软的握着特别舒服，你吻着她的嘴唇。）真的想要？
【妹】（她嗯了一声，主动脱掉自己的睡裙，连内裤一起脱了，分开腿坐在你腿上，小穴正对着你的肉棒，她扶着龟头对准自己穴口，看着你，眼睛水汪汪的。）想要...特别想...想要你直接进来...
【哥】（你扶着她的腰，她慢慢往下坐，龟头挤开湿滑的穴口，一点点吞进去，没有套隔着，直接感觉到她小穴里热热的嫩嫩的褶皱，太舒服了你忍不住闷哼一声。）嗯...
【妹】（啊...她直接坐到底，全部吞进去，没有套隔着，能清清楚楚感觉到你肉棒上每一根血管，热热的胀胀的，比戴套的时候粗多了，她舒服得叫出声，抱着你的脖子，腰开始自己动。）哥...好烫...好粗...比戴套舒服...
【哥】（太舒服了，直接贴在她嫩肉上的感觉比戴套爽一百倍，你抱着她的腰，帮她上下动，每一下都插到底，龟头直接蹭到她宫颈。）嗯...你里面好紧好热...
【妹】（她自己动着，小穴紧紧裹着你的肉棒，没有套隔着，每一下摩擦都特别清楚，她舒服得头往后仰，呻吟声都变大了，奶子在你眼前晃，你含住一个乳头吸吮。）啊...对...就是那里...哥...好舒服...
【哥】（你吸吮着她的乳头，手揉着另一个乳房，腰往上挺，配合她的动作，每一下都顶到她最深处，肉棒在她湿滑的小穴里快速抽插，发出咕叽咕叽的水声。）唔...你的奶子好软...
【妹】（啊...太舒服了...她叫得更大声了，也不管会不会被听见，腰动得越来越快，小穴里不停流水，顺着你的蛋蛋流到床单上，她抱着你的头，自己吻住你的嘴唇，舌头和你缠在一起。）哥...我爱你...好爱你...
【哥】（你抱着她，翻个身把她压在下面，快速抽插，从上面看着她脸红动情的样子，太漂亮了，你快射了。）我要射了...
【妹】（她听见你说要射了，不仅没躲，反而把腿张得更开，抬腰迎你，小穴死死夹着你的肉棒，眼睛水汪汪看着你，声音发颤。）射给我...射在里面...哥...把你的精液都给我...我要...
【哥】（你腰一挺，全部插到底，龟头抵着她宫颈，一股股浓浓的精液直接射在她子宫里，射得特别多特别深。）啊...射了...
【妹】（你射的时候她清楚地感觉到一股股热流喷在自己身体最里面，太刺激了，她也高潮了，小穴剧烈收缩，紧紧咬着你的肉棒，身体抖个不停，啊的一声叫出来，眼泪都出来了。）啊...哥...好烫...你的精液...好烫...
【哥】（你射完趴在她身上喘着气，没拔出来，就这么插在她里面抱着她，能感觉到她小穴还在一缩一缩的。）嗯...都给你了...
【妹】（她抱着你，脸红红的，腿还在抖，吻着你的下巴，声音黏黏的满足。）好舒服...射在里面的感觉...好幸福...
【哥】（你捏了捏她的屁股，笑着说。）你啊，万一怀孕了看你怎么办。
【妹】（她往你怀里钻，把脸埋在你脖子里，小声说。）怀孕了就生下来...我给你生孩子...
【哥】（你心里一暖，紧紧抱着她，吻她的头发。）好。
【妹】（她满足地蹭了蹭你的胸口，手臂环紧你的腰，腿还缠着你，肉棒依然插在里面，声音黏黏的带着鼻音。）那你要一直抱着我...不准拔出来...就这样睡到天亮...
