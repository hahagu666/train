# D-H18：你舔她阴蒂她含着你龟头
# 地点：你床上
# 情境：你给她舔阴，她一边被舔一边给你口交，同时自己揉乳头

【哥】（你趴在她两腿之间，她平躺着，腿张得开开的，你低头舔她的小穴。）
【妹】（躺在床上，腿张得开开的，你舌头舔着她的阴蒂，她舒服得弓起腰，但是没忘记你，她伸出手握住你硬邦邦的肉棒，凑到嘴边，张开嘴含住龟头。）啊...
【哥】（她一边被你舔得浑身发抖，一边还含着你的龟头，舌头轻轻舔着系带，你舒服得闷哼一声，嘴唇含住她的阴蒂吸吮。）嗯...
【妹】（呜！你吸吮她阴蒂，她爽得闷哼一声，震动传在你龟头上特别刺激，她稳了稳神，一边承受着你舌头的舔弄，一边含着你的龟头慢慢吞吐，舌头不停舔着冠状沟和系带，一只手握着阴茎体慢慢套弄。）呜...
【哥】（你一边舔她阴蒂，把一根手指插进她湿滑的小穴里抽插抠G点，她快感更强，嘴里发出的震动也更强烈。）啊...舒服...
【妹】（手指插进来抠G点，加上舌头舔阴蒂，她爽得浑身抖个不停，但是嘴没停，努力含着你吞吐，舌头不停舔着，虽然动作因为快感有点抖，但是一直没停下，另一只手伸到自己胸前，揉着自己的乳房，捏着自己的乳头，自己给自己加快感。）嗯...哥...
【哥】（你能感觉到她小穴在不停收缩，水流得你满下巴都是，她嘴里含着你，震动越来越强，她自己揉胸揉乳头，同时还在给你口交。）嗯...软软...
【妹】（快感越来越强，她嘴里开始发出呜呜的呻吟，全传在你龟头上，手也加快了套弄的速度，含着龟头快速吞吐，舌头不停扫着系带，自己揉乳头的手也越来越用力，腰不停往上挺，让你舌头舔得更深一点。）啊...
【哥】（你加快舌头舔阴蒂的速度，手指快速抠G点，她震动得你特别舒服，你也快射了。）快了...
【妹】（她快高潮了，动作更快，含着你快速吞吐，喉咙夹着龟头，手快速套弄，没办法揉蛋蛋了，但是速度特别快，嘴里震动特别强烈。）嗯...
【哥】（快感冲到顶点，你闷哼。）我要射了...
【妹】（听见你说要射了，她立刻把龟头含得紧紧的，舌头顶着系带，等着你射，同时她自己也被你舔到了临界点。）嗯...射给我...
【哥】（在你射出来的同一秒，她也到了高潮，她身体猛地绷紧，小穴剧烈收缩喷出水来，喉咙一紧，你腰一挺，精液射进她嘴里。）啊...
【妹】（高潮的痉挛让她喉咙不停收缩，把你的精液都挤出来咽下去，她身体剧烈颤抖了十几秒才软下来，嘴里还含着你的龟头，大口喘气，过了半天才慢慢把你软下来的肉棒吐出来。）啊...
【哥】（你也抬起头，下巴上全是她的水，爬到她身边躺下。）累坏了吧...
【妹】（她软在床上，大口喘气，脸红得像苹果，浑身都是汗，过了半天，才转过头看你，看到你下巴上全是她的水，她羞得捂住脸，但是又忍不住笑，声音黏黏的哑哑的）哥...刚才...我差点同时爽晕过去...
【哥】（把她搂进怀里，亲了亲她。）我也差点。
【妹】（往你怀里钻，抱着你的腰，过了一会，她手往下摸，握住你软下来的肉棒，小声说）休息一会...再玩一次好不好...这次我想一边被你舔...一边自己摸着胸给你含...那样太舒服了...
【哥】（捏了捏她软软的屁股。）好，都听你的。
【妹】（听见你答应，她笑得特别甜，在你嘴唇上亲了一下，腿悄悄缠上你的腿，下面湿乎乎的蹭在你腿上她也不在意。）嗯...
