# D-E26：你出差几天她想你
# 地点：家里，你出差三天刚回家
# 情境：你出差三天，她每天都给你发消息说想你，你一开门她就扑过来抱你

【哥】（出差三天，终于到家，开门刚把行李箱放地上，就听见咚咚咚的跑步声，从她房间冲出来）
【妹】（穿着睡衣，头发还乱蓬蓬的，拖鞋都没穿好，光着一只脚就冲过来，直接扑进你怀里，手臂紧紧抱着你的腰，脸埋在你胸口，声音闷闷的）哥！你回来了！
【哥】（抱住她，她抱得特别紧，像怕你再走了一样，拍了拍她的背）我回来了，怎么拖鞋都不穿。
【妹】（抬起头看你，眼睛亮晶晶的，好像有点红，但是笑着，伸手摸你的脸，摸了摸又摸，好像好久没见了一样）你怎么才回来...三天了...
【哥】不是每天都跟你视频吗。
【妹】（鼓着脸，但是手还是抱着你的腰不肯放，脸埋回你胸口蹭了蹭，闻你身上的味道）视频又摸不到...（她声音小小的，像小猫撒娇一样）我每天都看你照片...吃饭也看...睡觉也看...
【哥】（忍不住笑了，伸手揉她的头发，她头发软软的，蹭得你手心痒，三天不见，好像更黏人了）想我了？
【妹】（使劲点头，脸埋在你胸口不肯抬起来，手抱得更紧了，声音闷闷的）想...特别想...你不在家我吃饭都不香...妈妈做的糖醋排骨都不好吃了...
【哥】那我下次不出差了。
【妹】（这才抬起头，眼睛红红的，但是笑得特别开心，伸手勾住你的脖子，踮起脚在你脸上亲了一口，然后又不好意思地脸红了，但是还是抱着你不撒手）你说的！不许再去了！要去也带我去！
【哥】（把她抱起来，她轻得很，乖乖勾着你的脖子，腿盘在你腰上，像树袋熊一样挂在你身上，脸埋在你颈窝蹭啊蹭）不穿鞋也不怕凉。
【妹】（摇摇头，在你颈窝蹭来蹭去，呼吸暖暖的吹在你脖子上，声音发黏）凉了也不怕...你回来了就暖和了...（她伸手摸你的下巴，有胡茬，扎得她手痒，她咯咯笑，又亲了亲你脖子）哥你都有胡茬了...
【哥】三天没刮了。
【妹】（伸手轻轻摸你的胡茬，扎得她手指痒痒的，她笑了半天，然后突然紧紧抱着你，声音小小的，带着点委屈又有点撒娇）你不在家我晚上都睡不着...做了噩梦也没人哄我...
【哥】现在回来了，晚上陪你睡。
【妹】（眼睛一下子亮了，但是立刻又装作不在意的样子，鼓着脸，但是耳朵红了，嘴角偷偷往上扬，手勾着你的脖子不肯放，脸贴在你脸上蹭了蹭，像只终于等到主人回家的小猫，蹭得你满脸都是她的头发香味）那我今晚要抱着你睡...你不许跑...（她挂在你身上不肯下来，你拖着行李箱往客厅走，她就一直挂在你身上，像个小挂件，头靠在你肩膀上，一直笑，笑得特别开心，三天的想念全都在这个紧紧的拥抱里了）
