# D-I13：吵架和好你把她按在床上做
# 地点：她房间
# 情境：你们因为小事吵架冷战了一下午，晚上你去她房间，把她按在床上做，做着做着她就哭了

【哥】软软，还生气呢？（下午因为一点小事吵架了，她赌气不理你，晚饭也没跟你说话，晚上你推开她房间门，她背对着你躺在床上，好像在哭。）
【妹】（听见开门声，她赶紧擦眼泪，把脸埋在枕头里，不理你，声音闷闷的。）你来干什么...我不想跟你说话...
【哥】（你走过去，坐在床边，伸手摸她的背，她抖了一下躲开了。）还生气呢？
【妹】（她躲开你的手，还是背对着你，声音带着哭腔。）别碰我...你下午凶我...你坏...
【哥】还闹脾气呢？（你没说话，直接把她翻过来，她眼睛红红的，脸上还有眼泪，你直接吻住她的嘴唇，她一开始挣扎，拍你的胸口。）
【妹】（唔！你放开我！我还在生气呢！她挣扎着，但是你吻得很紧，手抱着她的腰，她挣扎了几下就没力气了，手慢慢抓住你的衣服，哭出声来。）你混蛋...下午凶我...你还凶我...
【哥】（你吻着她的眼泪，把她的睡衣脱掉，她没怎么反抗，还在哭，你脱掉自己的裤子，硬邦邦的肉棒抵在她穴口，她已经湿了。）是我错了，不该凶你，罚我给你赔罪好不好？
【妹】（她哭着捶你的胸口，但是分开了腿，让你的肉棒抵在穴口，抽噎着说。）谁要你赔罪...你滚开...我不理你...
【哥】那我可进来了。（你没滚，直接一挺腰全部插进去，她啊的一声叫出来，哭声更大了，但是腿环住了你的腰。）
【妹】（啊...你混蛋...你就会欺负我...你一进来她就哭得更厉害了，但是小穴紧紧裹着你，一点都没有推开你的意思，手抓着你的背，指甲都快掐进肉里了。）你下午凶我...你还凶我...你坏...
【哥】（你开始慢慢抽动，吻着她的眼泪，吻她的脸，她的嘴唇，在她耳边一遍遍说对不起，说我错了，我爱你。）对不起...我错了...
【妹】（你慢慢动着，她哭声慢慢变小，变成小声的呻吟，手从捶你变成抱着你的脖子，抽噎着，小穴里不停流水，配合你的动作抬腰。）唔...哥...以后不许凶我了...
【哥】（你加快速度，揉着她的阴蒂，吻着她的耳朵说，不凶了，以后再也不凶你了，谁让你生气我就打谁。）嗯...不凶了...
【妹】（你骗人...你刚刚还凶我...她话还没说完，就被你插得啊的一声，小穴开始收缩，快高潮了，她抱着你，哭着说。）哥...我要去了...
【哥】（你快速抽插，狠狠顶了她十几下，她身体绷紧，高潮了，小穴死死咬着你的肉棒，你也跟着射了，全部射在她里面。）啊...射了...
【妹】（你射的时候她还在哭，但是抱着你抱得紧紧的，身体抖个不停，等你射完，她趴在你怀里，还在抽噎，但是手轻轻摸着你的脸。）你下次再凶我...我就...我就再也不理你了...
【哥】（你抱着她，吻她哭红的眼睛，帮她擦眼泪。）再也不敢了，再凶我我自己打自己。
【妹】（她破涕为笑，捶了一下你的胸口，把脸埋在你脖子里，小声说。）谁让你打自己...傻子...
【哥】（你抱着她，两个人就这么躺了半天，肉棒还在她小穴里，她腿环着你的腰。）其实...我也有错...不该跟你闹脾气...不，都是我的错，以后不吵架了好不好。
【妹】（她点点头，在你嘴唇上亲了一下，眼睛红红的但是笑得特别甜，轻轻咬了一口你的锁骨，肉棒还插在里面，小穴一缩一缩的夹着你，声音黏黏的带着撒娇。）嗯...不吵架了...但是你以后要是再敢凶我...我就真的不理你了...听到没有...
