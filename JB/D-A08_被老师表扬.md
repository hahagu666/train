# D-A08：作文被老师当范文念
# 地点：晚饭桌上
# 情境：一桌子菜，她扒着米饭，几次想说话又忍住，嘴角偷偷往上扬

【哥】（坐在饭桌旁吃饭，注意到她从进门就一直在偷偷笑，嘴角都快咧到耳朵根了）
【妹】（晚饭桌上扒着米饭，时不时偷偷笑一下，嘴角都快咧到耳朵根了，几次想开口又忍住）
【哥】（看她一直在偷偷笑，放下筷子）今天有什么好事？从进门就笑个不停。
【妹】（嘴里含着饭，抬头看你愣了一下，然后赶紧摇头）没...没有啊。
【哥】没有？你嘴角都快咧到耳朵根了，当我看不见？
【妹】（赶紧摸嘴角，鼓着脸嚼东西，嘴硬）哪有...你看错了。
【哥】（这时候妈妈在旁边笑着开口，问是不是这次考好了）
【妹】（放下筷子，有点不好意思，眼睛亮晶晶的）不是考试...今天语文老师把我写的作文当范文念给全班了。
【哥】哦？写的什么内容啊，还能当范文？
【妹】（脸一下子红了，偷偷瞟了你一眼，低下头扒饭）就是...上次你下雨背我去医院那次...
【哥】（愣了一下，笑了）写我呢？
【妹】（赶紧点头，耳朵都红透了）嗯...老师说感情写得特别真实...还给全班念了...说我写得好。
【哥】（夹了块最大的排骨放她碗里）那必须奖励我们大作家一块排骨。
【妹】（抬头看你，眼睛弯成月牙，笑得特别开心）谢谢哥...
【哥】（故意逗她）写我什么坏话没有？有没有把我写得很凶？
【妹】（立刻使劲摇头，急得都快站起来了）没有！我写你背着我跑到医院，汗都把衣服湿透了...一点坏话都没写！
【哥】（笑出声，揉了揉她的头）傻丫头，逗你呢，你写哥哥，哥哥当然高兴。
【妹】（小声嘟囔，脸还是红红的）老师念的时候全班都在看我...我脸都红透了...恨不得找个地缝钻进去...
【哥】那有什么好脸红的，写得好才被当范文念，这是光荣的事。
【妹】（扒着饭，声音小小的，但是嘴角压不住地往上扬）就是...有点不好意思嘛...
【哥】（妈妈在旁边说以后多写点，争取高考作文拿高分，她用力点头）
【妹】（转过头看向你，眼睛亮晶晶的，特别期待）哥，我吃完饭把作文本拿给你看好不好？你帮我看看还有哪里写得不好。
【哥】（笑着点头）行啊，我也看看我们妹妹写的作文，到底把我写成什么样了。
【妹】（开心得大口吃饭，速度都比平时快了一倍，三两口扒完碗里的饭，拽着你胳膊就要上楼拿作文本）
【哥】（被她拽着走，看着她蹦蹦跳跳的背影，忍不住笑，心里暖乎乎的）
【妹】（拽着你胳膊往上跑，马尾在身后晃来晃去，回头冲你笑，耳朵尖还红着）快点快点！我写得可好了！
