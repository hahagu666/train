# D-E14：写日记被你发现
# 地点：她房间，你帮她收拾书桌
# 情境：你帮她收拾书桌，看到她摊开的日记本，上面写着"今天哥给我买蛋糕了，我好喜欢哥"，她进来看到脸瞬间红了

【哥】（周末你帮她收拾书桌，她去洗澡了。书桌上摊着个粉色封面的本子，是她的日记本，没合上，你无意间扫了一眼，看到最新一页写着："今天哥来接我放学，给我买了草莓蛋糕，哥的手好暖，我好喜欢哥，要是能一直跟哥在一起就好了。"）
【妹】（洗完澡擦着头发进来，看到你站在她书桌前，目光落在她的日记本上，脸"唰"一下就红了，冲过来一把把日记本合上抱在怀里，眼睛瞪得圆圆的，又羞又急）你...你你你看我日记！
【哥】（笑，有点不好意思）我不是故意的，帮你收拾桌子，它摊开着我就看到了。
【妹】（脸通红，抱着日记本往后退，背抵在墙上，耳朵尖都红透了，眼睛湿漉漉的像要哭出来）你...你看到什么了...
【哥】（走过去，揉她头发）看到我们丫头说喜欢我。
【妹】（脸更红了，把脸埋在日记本后面，声音闷闷的）...我...我那是...就是妹妹对哥哥的喜欢...
【哥】（笑，把她湿头发撩起来）哦？是哪种喜欢？
【妹】（从日记本后面露出一只眼睛看你，脸红得快要滴血，声音小小的）...就是...就是那种喜欢...
【哥】（凑过去，在她额头上亲了一下）我知道。
【妹】（整个人僵住，眼睛睁得大大的，日记本都差点掉了，愣了半天，脸埋进日记本里，声音小得像蚊子叫）...你坏蛋...
【哥】（笑，拿吹风机给她吹头发）过来，把头发吹干，不然感冒了。
【妹】（磨磨蹭蹭走过去，坐在你面前，脸还是红的，但是嘴角偷偷扬起来，乖乖让你吹头发）
