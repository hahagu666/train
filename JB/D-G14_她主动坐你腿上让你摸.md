# D-G14：她主动坐你腿上让你摸
# 地点：你房间椅子上
# 情境：你在写作业，她主动过来坐在你腿上，拉着你的手伸进她衣服里让你摸她

【哥】（晚上你坐在书桌前写作业，她推开门进来，穿着睡裙，蹭到你身边。）
【妹】（蹭到你身边，看你写作业，看了一会，直接一屁股坐在你腿上，背靠着你胸口，拿起你的笔在你本子上乱画。）哥，陪我玩嘛，写什么作业。
【哥】（别闹，写完这点就陪你。手自然地扶在她腰上。）别闹，写完这点就陪你。
【妹】（鼓着脸，扭了扭屁股，刚好蹭在你大腿根，能感觉到你很快就硬了，顶在她屁股上，她脸一红，但是没躲开，反而往后靠得更紧，拉着你的手往上移，放到她胸上。）嗯...
【哥】（手被她按在胸上，隔着薄薄的睡裙，能感觉到她软软的乳房和硬硬的乳头。）这...
【妹】（感觉到你的手放在胸上，她脸红红的，但是很大胆，按着你的手让你揉，声音小小的黏黏的。）哥...你摸我...
【哥】（手隔着睡裙轻轻揉着她的胸，她的胸软软的，小小的一只，握在手里刚好。）嗯...
【妹】（嗯...舒服地哼了一声，靠在你怀里，头靠在你肩膀上，眯着眼睛像只小猫，还拉着你的手让你伸进睡裙领口里面。）嗯...伸进去摸...隔着衣服不舒服...
【哥】（手顺着她领口伸进去，直接握住她赤裸的乳房，温热柔软的触感直接传过来，没有胸罩，她居然没穿胸罩。）没穿？
【妹】（啊...直接被你握住胸，她叫了一声，身体没力气，主动挺了挺胸让你握得更方便，呼吸暖暖的喷在你脖子上，声音黏黏的。）啊...我...我今天没穿胸罩...舒服吗...
【哥】（舒服，软软的。手指捏了捏她硬硬的乳头。）舒服，软软的。
【妹】（被捏乳头，她浑身麻了一下，另一只手往下，摸到你硬邦邦的肉棒，隔着裤子轻轻握了握，然后她把你的另一只手往下拉，拉到她腿上。）嗯...哥...下面也想让你摸...
【哥】（手顺着她的腿往上滑，摸到她内裤，已经湿透了。）这么湿。
【妹】（被你摸到湿透的内裤，她脸红透了，但是主动分开腿，让你的手更容易碰到，声音带着撒娇。）都怪你...每次和你在一起...就会湿...
【哥】（手伸进她内裤里，直接摸到她湿漉漉的小穴，手指轻轻揉着她的阴蒂。）嗯...
【妹】（啊！她立刻叫出来，身体在你怀里弓起来，坐在你腿上，你肉棒顶着她的屁股，你的手在她下面揉着，胸被你另一只手握着，她爽得浑身发抖，主动扭着腰配合你的动作，声音发颤。）啊！哥...用点力...对...就是那里...
【哥】（手指加快速度揉着她的阴蒂，另一只手捏着她的乳头。）嗯...
【妹】（很快就高潮了，身体猛地绷紧，然后一阵颤抖，小穴里水流出来，弄湿了你的手和她的内裤，她瘫在你怀里大口喘气，过了半天，转过身跨坐在你腿上，面对着你，吻住你的嘴唇，手解你的裤子拉链，声音黏黏的。）哥...我也帮你...
