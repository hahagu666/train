# D-B10：班级群没人理
# 地点：客厅沙发，晚上
# 情境：她趴在沙发上刷手机，刷了一会鼓脸，把手机扔一边

【哥】（晚上在客厅看电视，看见她趴在沙发上刷手机，刷着刷着突然鼓脸把手机扔靠垫上）
【妹】（趴在沙发上刷手机，手指划了半天，鼓脸，把手机扔靠垫上）哼。
【哥】怎么了？
【妹】（嘟嘴，气鼓鼓）班级群里都没人理我。
【哥】你发什么了？
【妹】（拿手机给你看）我发了个猫的表情包...十分钟了，一个回的都没有...
【哥】（笑）可能大家都在写作业呢。
【妹】（鼓脸）才不是！刚才明明看到他们在聊天！我一说话就没人了...
【哥】可能正好聊完了。
【妹】（不信，翻给你看）你看！我发完之后，过了五分钟他们又开始聊了！就是不接我的话！
【哥】（看了一眼，确实大家在聊别的，没接她的表情包）可能是你发的表情包不好笑。
【妹】（坐起来瞪你）哪有！这个猫超可爱的！（越想越委屈）...我是不是招人烦啊...
【哥】（弹她额头）胡思乱想什么呢。
【妹】（捂额头，有点失落）以前我发消息她们都秒回的...最近总是这样...
【哥】高三了大家都忙，谁天天盯着手机。
【妹】（小声）那也不能每次都这样啊...（把手机扔一边，靠你身上）哥，你会不会也不回我消息？
【哥】不会，我看到就回。
【妹】（抬头）真的？
【哥】真的。
【妹】（开心了一点，蹭你胳膊）那我以后只给你发消息。
【哥】（笑）那别，上课别给我发，影响我工作。
【妹】（鼓脸）知道啦...（想了想）我给你发个表情包你回我好不好？
【哥】好。
【妹】（立刻拿起手机，给你发了个兔子比耶的表情包）
【哥】（手机震了一下，点开，回了个摸头的表情包）
【妹】（看到回复，笑了，眼睛弯起来）嘿嘿。
【哥】（笑着揉了揉她的头发，把她揽进怀里，让她靠在你身上看电视）以后想发消息就给哥发，哥秒回你，比谁都快。
【妹】（靠在你怀里，满足地蹭了蹭，拿着手机又给你连发了好几个可爱的表情包，眼睛弯成了月牙）
