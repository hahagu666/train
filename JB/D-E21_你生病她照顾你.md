# D-E21：你生病她照顾你
# 地点：你房间，感冒发烧
# 情境：你感冒发烧躺在床上，她急得不行，端水喂药给你敷毛巾

【哥】（周末感冒发烧，躺在床上浑身没劲，头晕乎乎的，门没关严，她听见你咳嗽推开门进来）
【妹】（站在门口看见你躺在床上脸红通通的，吓了一跳，立刻跑过来摸你额头，手凉冰冰的，一碰到你烫得她手缩了一下）哥你发烧了！怎么这么烫！
【哥】（嗓子哑得说不出话，点点头）没事，小感冒，睡一觉就好了。
【妹】（急得眼眶都红了，伸手摸你额头又摸自己额头对比，转身就跑出去）你等着！我去给你拿药！
【妹】（端着一杯温水拿着退烧药跑进来，还拿了个体温计，手忙脚乱的，水都洒出来一点，把你扶起来靠在枕头上，把药递到你嘴边，又把水递过来，看你把药吃了，又把体温计塞你腋下，坐在床边看着你，眉头皱得紧紧的）来吃药！先量体温！都多少度了还说没事！早上就听见你咳嗽你怎么不说！
【哥】（喝完药靠在枕头上，嗓子还是疼）不想让你担心。
【妹】（鼓着脸，但是眼睛还是红红的，伸手给你掖被角，把被子裹得严严实实的，只露出个脑袋）你不告诉我我才担心呢！（她跑出去，过了一会端了个盆进来，里面是温水，拧了毛巾叠好放在你额头上，凉丝丝的很舒服）我给你物理降温！以前我发烧妈妈就是这么给我弄的！
【哥】（看着她忙前忙后，小脸上满是着急，额头上都出汗了，头发跑乱了也不管）你别忙了，坐会。
【妹】（摇摇头，坐在床边，每隔两分钟就伸手摸你额头试试温度，又摸毛巾热了没有，热了就重新拧凉，还时不时给你掖被角，像个小大人一样）你饿不饿？我去给你煮点粥？
【哥】不饿，你别忙活了。
【妹】（不听，跑出去，过了半小时端了碗白粥进来，还煎了个鸡蛋，粥有点糊底了，但是还是热的，她坐在床边，舀了一勺吹凉了递到你嘴边）多少吃点！吃完药得吃东西！
【哥】（张嘴吃了，粥有点糊，但是味道还行，她一口一口吹凉了喂你，喂得特别认真，嘴角沾了点粥粒自己都不知道）你自己吃了吗？
【妹】（摇摇头，继续舀粥吹凉喂你）我不饿！你先吃！（等你吃完半碗粥，她把碗放一边，又给你换了个凉毛巾放在额头上，手摸你的脸，好像没那么烫了，她松了口气）好像退烧了一点。
【哥】（看着她坐在床边，眼睛一直看着你，满是担心，小手一直抓着被角）我没事，别担心。
【妹】（摇摇头，伸手握住你的手，她的手凉冰冰的，握着你的手，声音小小的）下次不许生病了...你生病我好害怕...（她趴在床边，手握着你的手，额头靠在你手边上，过了一会看你睡着了，轻轻给你盖好被子，小声说）等你好了我给你做你爱吃的糖醋排骨...（她一直坐在床边握着你的手，时不时摸你额头，直到你退烧了，她才趴在床边睡着了，手还紧紧握着你的手，眉头还是微微皱着，脸上满是担心）
