# D-E45：把脸埋在你脖子里撒娇
# 地点：沙发上，周末晚上
# 情境：她犯了错把你杯子打碎了，不敢说，跑过来把脸埋在你脖子里撒娇认错

【哥】（周末晚上你在沙发上看书，听见厨房哐当一声，然后就没动静了，过了五分钟，她磨磨蹭蹭从厨房出来，走到你旁边站着，也不说话）
【妹】（站在你旁边揪着衣角，头低着，半天不敢说话，过了好久，才磨磨蹭蹭走到你身边，坐下，然后慢慢往你身边靠，最后直接扑过来，把脸埋在你脖子里，手臂抱着你的腰，紧紧贴着你，也不说话，就那么埋着）
【哥】（被她突然扑过来，脸埋在你脖子里，暖暖的呼吸喷在你脖子上，痒痒的，她还蹭了蹭，像只认错的小猫）怎么了？又闯什么祸了？
【妹】（埋在你脖子里，声音闷闷的，带着点撒娇的哭腔，说话的时候热气喷在你脖子上，痒痒的）我错了...
【哥】错哪了？
【妹】（埋在你脖子里蹭了蹭，抱得更紧了一点，声音小小的，发着颤像小猫哼哼一样）我刚才想给你倒杯水...不小心把你最喜欢的那个杯子打碎了...我不是故意的...（她越说声音越小，抱得更紧了，脸埋在你脖子里，暖暖的，呼吸有点快，怕你生气）
【哥】（就为这事啊，那个杯子用了好几年了，碎了就碎了）没划到手吧？
【妹】（听见你没生气，她愣了一下，抬起头看你，眼睛有点红，但是立刻又把脸埋回你脖子里，蹭啊蹭，像只撒娇的小猫，声音还是闷闷的，但是没那么害怕了）没有...我打扫干净了...你不生气啊...
【哥】一个杯子而已，你没受伤就好。
【妹】（这才彻底松了口气，但是还是不肯把脸从你脖子里抬起来，反而抱得更紧了，腿都盘到你腿上了，像八爪鱼一样挂在你身上，脸在你脖子里蹭来蹭去，软软的脸蹭得你脖子痒痒的，呼吸暖暖的，她还故意轻轻吹了口气，痒得你缩了一下脖子）
【哥】（被她蹭得痒，笑了，伸手捏了捏她的腰，她怕痒，咯咯笑，但是还是不肯把脸抬起来，就埋在你脖子里笑，笑声闷闷的，震得你脖子痒痒的）别闹，痒。
【妹】（听见你说痒，反而故意往你脖子里吹热气，还轻轻用嘴唇碰了一下你的脖子，像羽毛扫过一样，温温热热的，她自己先脸红了，但是就是不肯抬头，声音黏糊糊的带着笑意，撒娇一样）我错了嘛...你别生气...我给你买个新的杯子...比那个还好看的...
【哥】（拍了拍她的背，她软软的身体贴在你身上，暖暖的，脸埋在你脖子里，头发蹭得你下巴痒）不用了，下次小心点就行。
【妹】（嗯了一声，但是还是不肯抬头，就那么埋在你脖子里抱着你，呼吸暖暖的，安安静静抱了半天，才小声说，声音就在你耳边，发嗲一样带着点撒娇）哥...你身上好暖...我最喜欢这样抱着你了...（她又轻轻蹭了蹭你的脖子，在你颈窝亲了一下，温温热热的嘴唇碰在你皮肤上，然后立刻把脸埋得更深，耳朵红透了，但是抱着你的手一直没松，像只黏人的小猫，赖在你脖子里不肯下来）
