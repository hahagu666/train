# D-I30：厨房做饭你从后面掀她裙子做
# 地点：你家厨房
# 情境：她穿着围裙在厨房做饭，你从后面抱她，把内裤拉到腿弯就在灶台边做

【哥】（周末下午你饿了，进厨房找吃的，看见她穿着可爱的小熊围裙在炒饭，下面穿的睡裙，露出白白的小腿，你从后面轻轻抱住她。）做什么好吃的呢？
【妹】（正专心炒饭，突然被人从后面抱住，吓了一跳，回头看见是你，松了口气，用胳膊肘轻轻顶了你一下。）别闹，我炒饭呢，一会糊了。
【哥】（你没松手，反而吻她的脖子，手顺着她的腰往下摸，撩起她的睡裙，摸到她棉质的内裤，已经有点湿了。）炒饭重要还是我重要。
【妹】（被你摸得一抖，锅铲都差点掉了，脸红了，想夹紧腿但是被你用膝盖顶开，声音发颤带着求饶。）别...饭要糊了...晚上...晚上给你...
【哥】（你没听她的，直接把她内裤拉到腿弯，硬邦邦的肉棒抵在她湿滑的穴口，扶着一挺腰就全部插进去，她啊的一声叫出来，扶着灶台才没软下去。）等不到晚上了。
【妹】（啊！你突然进来，她叫出声，手紧紧抓着灶台边缘，锅铲掉在锅里，发出哐当一声，你在后面抱着她的腰开始抽插，她随着你的动作往前晃，前面的锅滋滋响着，饭差点糊了。）哥...饭...饭要糊了...啊...
【哥】（你腾出一只手把火关小，然后继续抓着她的腰快速抽插，从后面干她，她的小穴紧紧裹着你，围裙还系在腰上，睡裙撩起来堆在腰上，白屁股被你撞得晃来晃去。）糊了就糊了，先吃你。
【妹】（你...她被你操得说不出话，前面是灶台，后面是你狠狠顶弄，快感来得特别快，小穴里不停流水，顺着大腿往下流，她扶着灶台小声呻吟，奶子被围裙勒着，随着你的动作晃。）啊...哥...太突然了...在厨房...
【哥】（厨房怎么了，家里又没人，你拍了一下她的屁股，加快速度，伸手到前面揉她的阴蒂。）叫大声点，家里没人。
【妹】（啊...我要到了...哥...她身体抖起来，小穴剧烈收缩，但是她还扶着灶台，怕倒下去，高潮来得又快又猛，她软得靠在你怀里，要不是你抱着她就滑下去了。）啊...！
【哥】（她高潮夹得你也射了，你腰一挺全部插进去，射在她里面，抱着她喘了半天，才慢慢退出来，帮她把内裤拉好。）嗯...射了...
【妹】（被你抱在怀里，腿还是软的，脸红得像苹果，喘了半天才想起锅里的饭，赶紧关火，一看饭有点糊了，回头瞪你。）都怪你！饭糊了！吃什么啊！
【哥】（你笑着吻她的脸，把她抱起来放在灶台上，吻她的嘴唇。）吃你就够了。
【妹】（她脸红了，捶了一下你的胸口，但是笑着环住你的脖子。）不要脸...那今晚你做饭...
