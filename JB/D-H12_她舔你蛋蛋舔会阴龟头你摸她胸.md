# D-H12：她舔你蛋蛋舔会阴龟头你摸她胸
# 地点：你床上
# 情境：她给你口交的时候不只是舔龟头，还舔遍蛋蛋和会阴，你躺着摸她胸和乳头

【哥】（嗯...龟头被她暖乎乎的嘴含住，她还在舔刚才的会阴，你手上揉着她的胸，特别舒服。）嗯...
【妹】（含着龟头，舌头在嘴里不停扫着冠状沟和系带，一只手快速套弄阴茎体，另一只手继续轻轻揉着你的蛋蛋，时不时用指尖轻轻按一下会阴，嘴和手两只手一起配合，每一处敏感的地方都照顾到。）嗯...

【哥】（把她拉上来抱在怀里，亲了亲她。）你从哪学的这些？太舒服了。

【哥】（揉了揉她的胸，亲了亲她的乳头。）真乖。
【妹】（被你亲乳头，她舒服地哼了一声，往你怀里钻，小声说）那你也奖励我...帮我舔...
