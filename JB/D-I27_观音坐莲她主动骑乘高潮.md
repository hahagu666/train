# D-I27：她主动骑乘主动求欢
# 地点：你床上
# 情境：她主动想要，骑在你身上自己动，自己弄高潮了

【哥】（晚上你靠在床头看手机，她洗完澡爬到你床上，直接跨坐在你腿上，吻你的脖子，手解你的睡裤。）嗯？宝贝这是怎么了？
【妹】（跨坐在你腿上，手把你的睡裤拉下去，握住你的肉棒套弄了两下，扶着对准自己湿漉漉的小穴，直接坐下去，全部吞进去，脸红红的看着你。）哥...我想要...
【哥】（你愣了一下，她今天特别主动，你放下手机，手揉着她的腰。）今天这么主动？小淫娃，自己想要了？
【妹】（她嗯了一声，也不害羞了，开始自己上下动，手撑在你胸口，腰起起伏伏，眼睛一直看着你，奶子在你眼前晃，她自己动得特别快，比你平时带她动还快。）想了...今天上课都在想...想你插我...
【哥】（被她直白的话弄硬了，你抓着她的腰帮她动，看着她主动的样子，特别性感。）上课都在想？想我怎么操你？
【妹】（嗯...她脸红了，但是点点头，动得越来越快，小穴紧紧裹着你的肉棒，淫水哗哗流，把你小腹都打湿了，她自己揉着自己的乳房，捏着乳头，小声呻吟。）想你把我按在床上...想你后入我...想你射在里面...
【哥】（你被她说得更兴奋了，腰往上挺，配合她的动作，每一下都顶到她最深处，她啊的一声叫出来。）小淫娃，这么想要。
【妹】（啊...对...就是那里...哥...她动得更快了，身体往前倾，手抓着你的肩膀，脸凑在你耳边呻吟，呼吸暖暖的喷在你耳朵上。）好舒服...哥...你的肉棒好粗...插得我好满...
【哥】（你伸手揉着她的阴蒂，她抖了一下，动得更乱更快，明显快高潮了。）快到了吗？自己弄高潮给我看。
【妹】（啊...哥...我要到了...她叫出声，腰猛地坐到底，小穴剧烈收缩，紧紧咬着你的肉棒，高潮了，身体抖个不停，但是她还在动，自己骑在你身上慢慢动，享受高潮的余韵。）啊...好舒服...
【哥】（她高潮的时候夹得你太爽了，你抱着她的腰快速往上顶了十几下，腰一挺射在她里面。）嗯...射了...
【妹】（你射的时候她又抖了一下，趴在你胸口喘着气，满足地叹了口气，吻你的下巴。）自己动高潮...好舒服...
【哥】（你抱着她，揉着她软软的屁股。）以后想要就自己坐上来，不用等我动手。
【妹】（她脸红了，但是点点头，在你嘴唇上亲了一下。）嗯...以后天天骑你...
