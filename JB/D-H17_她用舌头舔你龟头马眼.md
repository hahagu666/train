# D-H17：她用舌头尖快速舔你龟头马眼
# 地点：你床上
# 情境：她学会了用舌尖快速扫马眼这个特别敏感的地方，手配合揉蛋蛋

【哥】（你靠在床头，她跪在你两腿之间，小手握着你的肉棒，这次她不急着含进去，就握着看。）
【妹】（跪在你腿间，小手软软地握着你的肉棒，抬头对你笑，眼睛亮晶晶的，声音黏黏的）哥...我今天发现一个地方...你肯定特别舒服...
【哥】（好奇地看着她。）什么地方？
【妹】（笑了笑，没说话，低下头，伸出舌头，只用舌尖，轻轻点了一下你龟头上的马眼，那里正流出一点透明的前列腺液。）嗯...
【哥】（嘶...马眼是最敏感的地方，被她舌尖轻轻一点，你舒服得倒吸凉气，腰都抖了一下。）嘶...
【妹】（看见你反应这么大，她笑得特别开心，知道找对地方了，舌尖开始快速在马眼上点着舔，小小的舌尖不停扫着马眼，一圈一圈打圈，偶尔还轻轻把舌尖往马眼里面顶一点点，一只手握着阴茎体快速套弄，另一只手轻轻揉着你的睾丸。）嗯...
【哥】（啊...太刺激了...马眼被她舌尖快速舔着，手还套弄揉蛋蛋，三重刺激，你舒服得叫出声，手抓着床单。）啊...
【妹】（听见你叫出声，她更卖力了，舌尖在马眼上快速舔动，像小猫舔奶一样，速度特别快，时不时用嘴唇含住整个龟头轻轻吸吮，手快速套弄，揉蛋蛋的手也轻轻用力，时不时捏一下。）嗯...哥...
【哥】（这种刺激太强烈了，和平时完全不一样，你快感涨得特别快，呼吸都急促了。）舒服...别停...
【妹】（舔了一会马眼，她又把舌头往下移，用舌尖快速扫着冠状沟那一圈嫩肉，来回扫，然后又回到马眼上继续快速舔，嘴里还发出咕咕的声音，震动传在龟头上，手一直没停套弄和揉蛋蛋。）嗯...
【哥】（太舒服了...你忍不住轻轻挺腰。）啊...
【妹】（感觉到你挺腰，她知道你特别舒服，她抬起头看你一眼，眼睛水汪汪的，然后低下头，这次把整个龟头含进嘴里，嘴唇紧紧裹着，舌头在嘴里不停扫着马眼和冠状沟，快速动着，手快速套弄。）嗯...
【哥】（她的舌头在嘴里不停顶马眼，比刚才还刺激，你肉棒在她嘴里跳个不停。）快了...
【妹】（含着龟头快速吞吐了十几下，又吐出来，继续用舌尖快速舔马眼，手快速套弄，揉蛋蛋的手也加快速度，这样反复，含一会又吐出来舔马眼，刺激得你快要疯了。）嗯...
【哥】（快感冲到顶点，你忍不住喊出来。）快...我要射了...别停...
【妹】（听见你说要射了，她立刻把整个龟头紧紧含在嘴里，嘴唇密封，舌头死死顶住马眼快速舔，手快速套弄，另一只手用力揉着蛋蛋。）嗯...射给我...
【哥】（啊...快感冲到顶点，你腰猛地一挺，一股股精液直接射在她嘴里，大部分都射在她舌头上和喉咙口。）啊...
【妹】（你射的时候她乖乖咽着，因为舌头顶着马眼，能清晰感觉到精液一股一股从马眼喷出来，她全部咽下去，等你射完，还轻轻用舌尖舔着马眼，把残留的精液都舔干净，才抬起头。）嗯...
【哥】（喘着气，摸了摸她的头。）你从哪学的这招？差点把我弄疯了。
【妹】（笑得特别得意，擦了擦嘴角的口水，爬到你怀里，声音黏黏的）我自己试出来的...上次舔到这里你抖了一下...我就知道这里特别敏感...舒服吗...
【哥】（抱着她亲了亲。）舒服，太舒服了，你个小妖精。
【妹】（往你怀里钻，笑得特别开心，在你下巴上亲了一下，声音黏黏的）那以后我天天这么给你舔...
