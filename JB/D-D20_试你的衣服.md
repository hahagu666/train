# D-D20：试你的衣服
# 地点：你房间，周末下午
# 情境：你在洗澡，她跑进你房间翻你衣柜，拿出你的大T恤穿上

【哥】（洗完澡出来，擦着头发，刚走出浴室）
【妹】（偷偷溜进你房间，打开你衣柜，翻出一件你常穿的白色大T恤，拿在身上比了比。T恤很大，下摆到大腿中间，袖子长出来一大截，套上T恤，整个人裹在里面，衣料上还有你淡淡的洗衣液味道，站在镜子前面转了个圈）
【哥】（看到她穿着自己的T恤站在镜子前面）你穿我衣服干什么？
【妹】（吓了一跳，回头看你，脸一下子红了，手抓着T恤下摆）我...我看你衣服放着，就试了一下...
【哥】（笑）穿成这样像偷穿大人衣服的小孩。
【妹】（鼓脸，转了个圈给你看，T恤下摆晃来晃去）哪有！挺大的啊...你看，到这里呢...（手在大腿中间比划）
【哥】不穿裤子都能当裙子了。
【妹】（脸更红了，赶紧拉了拉T恤下摆，下面穿着安全裤，但是还是有点不好意思）我穿了裤子的！
【哥】走两步看看。
【妹】（在你房间里走了两步，袖子太长把手都盖住了，她甩了甩袖子，笑起来）好大啊...你的衣服怎么都这么大...
【哥】我比你高二十公分，当然大。
【妹】（凑到你面前，仰脸看你，袖子卷起来露出指尖，笑嘻嘻的）有男朋友衬衫的感觉吗？
【哥】（弹她额头）小丫头片子知道什么男朋友衬衫。
【妹】（捂额头，但是笑得更开心了，转了个圈，衣摆扬起来）穿着好舒服啊...比我的睡衣舒服...
【哥】喜欢就穿着吧。
【妹】（眼睛亮了）真的给我了？
【哥】嗯，给你当睡衣穿。
【妹】（开心得扑过来抱你，脸埋在你胸口，T恤上的味道和你身上的味道一样）谢谢哥！
