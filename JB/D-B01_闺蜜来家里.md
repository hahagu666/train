# D-B01：闺蜜来家里
# 地点：家里客厅，周末下午
# 情境：她闺蜜来家里玩，俩人坐客厅沙发上吃零食聊天，你从房间出来倒水

【哥】（周末下午在房间看书，听见客厅里传来两个女孩子笑闹的声音和薯片袋子哗啦响，知道是她闺蜜来了，放下书从房间出来）
【妹】（和闺蜜坐在沙发上，俩人凑在一起看手机，笑成一团，薯片袋子哗啦响，看到你出来，立刻坐直了，收敛笑容，声音都变小了，有点拘谨）...哥。
【哥】同学来了？
【妹】（点头，偷偷看了一眼旁边的闺蜜，闺蜜在旁边小声说"你哥好帅"，她脸一下子红了）嗯...
【哥】嗯，你们玩，我给你们切点水果。
【妹】（等你进了厨房，松了口气，拍胸口，小声跟闺蜜说）吓死我了...
【哥】（在厨房里听到她们小声说话，忍不住笑了一下，没出声，认真切水果）
【妹】（闺蜜在旁边小声调侃你哥长得帅，还问有没有女朋友，她脸更红了，赶紧把薯片塞闺蜜嘴里不让她说）
【哥】（端着切好的水果出来）聊什么呢？
【妹】（脸有点红，接过来放茶几上，眼神躲躲闪闪）没...没聊什么...谢谢哥。
【哥】（笑）你们玩，我回房间了，有事叫我。
【妹】（等你进房间关上门，立刻扑过去捂闺蜜的嘴，小声凶她）你再乱说话我下次不让你来了！
【哥】（在房间里关上门，听到外面传来闺蜜的笑声和她凶巴巴的声音，忍不住笑着摇了摇头，戴上耳机继续听音乐，不打扰她们女孩子聊天）
【妹】（闺蜜笑着掰开她的手，继续调侃她脸红，她摸了摸自己的脸，确实烫得厉害，抓起抱枕砸过去，不让她笑）
【哥】（傍晚闺蜜走了之后，你从房间出来倒水，看见她抱着抱枕坐在沙发上，脸还有点红，你故意逗她）今天聊得挺开心啊？你闺蜜还说我帅呢？
【妹】（听见你提这个，脸一下子又红了，抓起抱枕砸你，鼓着脸）你都听到了！不许笑！
【哥】（笑着接住抱枕，揉了揉她的头发，去厨房倒水）好好好，不笑，我们妹妹脸都红透了，跟小苹果似的。
【妹】（鼓着脸追过去抢抱枕，不依不饶地捂住你的嘴不让你笑，脸还是红红的）
