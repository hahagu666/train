# D-E46：你帮她扎辫子扎歪了也开心
# 地点：家里，早上赶时间上学
# 情境：早上她起晚了，头发乱蓬蓬的来不及扎，让你帮她扎马尾，结果扎歪了她也特别开心

【哥】（早上她起晚了，慌慌张张穿衣服吃早饭，头发乱蓬蓬的披在肩上，一只手啃面包一只手找皮筋，找了半天找不到，急得快哭了）哥！我皮筋找不到了！我要迟到了！
【妹】（头发乱蓬蓬的像鸡窝一样，嘴里塞满面包，鼓着脸像小松鼠，急得团团转，校服拉链都拉歪了）我昨天明明放桌子上了！怎么找不到了！头发散着没法跑步！
【哥】（从口袋里摸出个黑色皮筋，是上次她落你车上的）我这有个，过来，我帮你扎。
【妹】（眼睛一下子亮了，立刻乖乖跑过来，背对着你站好，嘴里还叼着半片面包，乖乖把头发拢到后面递给你）你会扎吗...别扎太疼啊...
【哥】（笨手笨脚地给她扎头发，从来没给女生扎过辫子，揪得她头发疼，她嘶了一声，但是没躲，乖乖站着让你扎，手忙脚乱扎了半天，终于扎好了一个马尾，但是明显歪了，一边高一边低）好了。
【妹】（赶紧跑去照镜子，看见镜子里歪歪扭扭的马尾，一边高一边低，还有好几缕碎发散在外面，像个小疯子，她愣了一下，然后咯咯笑起来，笑得特别开心，转了两圈）
【哥】（有点不好意思，扎得确实太丑了）扎歪了，要不我重新扎？
【妹】（立刻摇头，用手护住马尾，不让你拆，笑得眼睛都弯成月牙了，摸了摸歪歪的马尾，特别宝贝）不歪！一点都不歪！特别好看！
【哥】这都歪到耳朵旁边了还不歪。
【妹】（鼓着脸，但是嘴角一直扬着，又照了照镜子，越看越喜欢，伸手摸了摸你给她扎的马尾，脸红红的，但是特别开心）这是你第一次给我扎头发！歪了也好看！我今天就这么去学校！不拆了！
【哥】（看着她开心的样子，虽然马尾扎得歪歪扭扭的，碎头发到处都是，但是她笑得特别开心，像拿到了全世界最好的礼物，心里暖融融的）快走吧，不然真迟到了。
【妹】（乖乖背上书包，但是跑了两步又跑回来，凑到你面前，指了指自己扎歪的马尾，眼睛亮晶晶的，脸红红的）哥...你明天还给我扎好不好...
【哥】扎这么丑你还要我扎？
【妹】（使劲点头，伸手摸了摸歪歪的马尾，笑得特别甜，嘴角扬得高高的，踮起脚在你脸上亲了一下，然后转身往门口跑，跑到门口回头看你，脸红扑扑的，马尾歪歪的但是特别可爱）丑我也喜欢！这是我哥给我扎的！全世界独一份！（说完她就背着书包咚咚咚跑下楼了，那天她扎着歪歪扭扭的马尾去学校，同学问她头发怎么扎歪了，她特别骄傲地说，这是我哥给我扎的，好看吧，一整天都舍不得拆，连体育课跑步都小心翼翼护着马尾，生怕散了）
