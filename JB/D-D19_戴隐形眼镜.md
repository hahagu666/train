# D-D19：戴隐形眼镜
# 地点：卫生间镜子前，周末早上
# 情境：她买了隐形眼镜，第一次戴，对着镜子戴了半天戴不进去，眼睛都红了

【哥】（路过卫生间，看见她撑着眼睛对着镜子戳了半天，眼睛都红了）戴进去了吗？
【妹】（放下手，眼睛红红的，眨了眨，眼泪都出来了）没有...我戴了半小时了...怎么都戴不进去...
【哥】我看看。
【妹】（凑到镜子前，眼睛红红的，下眼睑都被撑红了）你看，我一放进去就眨眼睛...
【哥】你别害怕，眼睛别使劲眨。来，看着镜子，别眨眼。
【妹】（乖乖撑着眼睛，看着镜子，手指拿着隐形眼镜凑过来，快碰到眼球的时候还是忍不住眨了一下）啊——不行，我控制不住...
【哥】慢慢来，深呼吸。
【妹】（深呼吸，撑着眼睛，手有点抖）我再来一次...
【哥】（在旁边看着她，鼓励她）
【妹】（试了一次，又眨了，隐形眼镜粘在手指上，她有点泄气，鼓着脸）怎么这么难啊...朋友说她第一次戴十分钟就戴上了...
【哥】她戴她的，你慢慢来。（拿过隐形眼镜）我帮你？
【妹】（犹豫了一下，点点头，仰起脸，撑着眼睛）你轻点...
【哥】（用手指轻轻撑开她的上下眼睑，把隐形眼镜凑过去）别眨眼，看上面。
【妹】（乖乖看着天花板，眼睛还是有点抖，能感觉到凉凉的镜片碰到眼球，"啪"一下吸上去了）
【哥】好了，眨眨眼。
【妹】（眨了眨眼睛，转了转眼珠，对着镜子看）哇！戴上了！一点感觉都没有！
【哥】嗯，另一只。
【妹】（乖乖仰脸让你帮她戴另一只，戴好之后对着镜子照了又照，笑起来）哥你好厉害！我自己戴半天都戴不上！
【哥】晚上摘的时候我再帮你。
【妹】（开心地点头，对着镜子左看右看，没有眼镜框挡着，眼睛显得大大的）
