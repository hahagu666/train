# D-I25：你坐在椅子上她面对你坐下来
# 地点：你房间椅子上
# 情境：你坐在椅子上，她面对你跨坐下来，自己动，眼睛一直看着你

【哥】（晚上你坐在椅子上看书，她洗完澡进来，什么都没穿，直接走到你面前，跨坐在你腿上，脸红红的看着你。）怎么了宝贝？不穿衣服就过来了。
【妹】（光着身子跨坐在你腿上，手搂着你的脖子，吻你的嘴唇，小穴贴着你已经硬了的肉棒，蹭了蹭，眼睛亮晶晶的看着你。）哥...别看书了...看我...
【哥】（你把书扔到桌上，回吻她，手揉着她软软的屁股，扶着肉棒对准她湿滑的穴口，她自己扶着，慢慢往下坐。）好，不看书，看你。
【妹】（啊...她慢慢坐到底，全部吞进去，舒服得叹了口气，手搂着你的脖子，开始自己上下动，眼睛一直看着你，脸红红的，奶子贴在你胸口。）哥...你看着我...
【哥】（你点点头，扶着她的腰帮她动，看着她脸红动情的样子，咬着嘴唇小声呻吟，眼睛水汪汪的一直看着你，特别漂亮。）我看着呢，宝贝真好看。
【妹】（她自己动着，每一下都坐到底，龟头蹭着她最敏感的地方，她舒服得小声哼着，但是眼睛一直不离开你的脸，吻你的嘴唇、下巴、脖子。）哥...我是不是特别好色...天天都想要...
【哥】（你笑着揉她的屁股，拍了一下。）是，我的小淫娃，但是我就喜欢你好色。
【妹】（她脸红了，但是动得更快了，小穴紧紧裹着你，淫水顺着你的腿流到椅子上，她坐在你身上起伏，奶子在你眼前晃，你含住一个乳头吸吮。）啊...哥...别吸...太舒服了...
【哥】（你吸吮着她的乳头，手揉着另一个，腰往上挺，配合她的动作，每一下都从下往上顶到她最深处。）唔...含着真舒服。
【妹】（啊...对...就是那里...她抱着你的头，埋在你脖子里，小声呻吟，小穴开始收缩，快高潮了。）哥...我要到了...
【哥】（你一只手伸到你们中间，揉着她的阴蒂，快速往上顶。）嗯...到了就叫出来。
【妹】（啊...！她身体猛地绷紧，小穴剧烈收缩，高潮了，紧紧咬着你的肉棒，眼睛还看着你，眼泪流出来，吻着你的嘴唇，抖个不停。）哥...我爱你...
【哥】（你抱着她的腰快速顶了十几下，腰一挺全部射进去，射在她最里面，她又抖了一下。）我也爱你。
【妹】（她趴在你胸口喘了半天，两个人就这么坐在椅子上，肉棒还插在她小穴里，她满足地蹭着你的下巴，小声说。）这样做...能一直看着你...好喜欢...
【哥】（你抱着她，吻她的头发。）那以后天天这么做。
【妹】（她笑着点头，在你嘴唇上亲了一下，小穴故意夹了夹你的肉棒。）好呀...
