# D-A19：图书馆占座
# 地点：市图书馆，周末上午
# 情境：她早起去图书馆帮你占座，你晚到了半小时，她鼓着脸在座位上等你

【哥】（堵车堵了半小时，终于赶到图书馆，走到她占的位置旁边）
【妹】（坐在靠窗的位置，面前摊着两摞书，看到你走过来，鼓脸）你怎么才来啊！
【哥】（拉开椅子坐下）路上堵车了。
【妹】我六点半就来排队了！我进来的时候人好多，差点没占到这个靠窗的位置...
【哥】（看桌上放着给你占座的书和一瓶水）给我占了？
【妹】（点头，把一杯豆浆推给你）楼下买的，还热着呢。
【哥】（笑，接过豆浆）谢谢。
【妹】（鼓脸，但是没真生气）你再不来我都要把你位置让给那个一直问我有没有人的男生了。
【哥】有人问你？
【妹】嗯！一个戴眼镜的男生，过来问了两次我旁边有没有人...我说我哥要来，他才走。
【哥】（挑眉）那你怎么没让给他？
【妹】（瞪你）我才不！我特意给你占的位置...（低头翻书，耳朵有点红）这里光线好，你坐这看你的书，我写作业。
【哥】（摸她头）知道了。
【妹】（拍开你手）别乱摸我头发，都弄乱了。（翻开练习册）我跟你说，不许出声打扰我，我今天要把这套模拟卷写完。
【哥】行。
【妹】（写了两笔，抬头）那个...你要是困了就趴在桌上睡会，我带了外套给你盖。
【哥】嗯。
【妹】（写了一会，偷偷从书包里摸出一颗糖递你）给你，柠檬味的。
【哥】你不是说不许说话吗。
【妹】（脸红，塞你手里）吃你的糖！别说话！
【哥】（笑，剥开糖纸吃了）
【妹】（低头写题，嘴角偷偷扬起来，脚在桌子底下轻轻碰了碰你的脚）
【哥】（也悄悄用脚回碰了一下她的脚，翻开书看着她微微发红的耳尖，嘴角也忍不住扬起来）
【妹】（感觉到你的回应，耳朵更红了，但嘴角的笑意藏都藏不住，阳光透过窗户照在两个人身上，安安静静的特别美好）
