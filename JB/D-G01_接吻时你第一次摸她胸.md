# D-G01：接吻时你第一次摸她胸
# 地点：你房间，晚上关了门
# 情境：初吻之后，你们经常趁爸妈睡着偷偷接吻，这次接吻的时候你手慢慢放到她胸上，她身体僵了但没推开

【哥】（晚上爸妈都睡了，她溜进你房间，关上门，爬到你床上坐在你旁边。）
【妹】（刚洗完澡，穿着睡衣，头发香香的，凑过来看着你，脸红扑扑的。）哥...我想亲你...
【哥】（伸手把她揽进怀里，低头吻住她的嘴唇，软软的，甜甜的。）嗯...
【妹】（闭上眼睛，乖乖被你亲，手抓着你胸前的衣服，身体软软靠在你怀里，回应你的吻，生涩但是认真。）嗯...
【哥】（吻着吻着，你的手慢慢从她腰往上移，慢慢放到她胸部侧面，隔着睡衣轻轻搭在那里，没敢用力。）唔...
【妹】（吻到一半，感觉到你的手放到了胸上，她身体猛地一僵，嘴唇离开你的，眼睛一下子睁开了，睁得圆圆的看着你，呼吸一下子停了。）哥...你...
【哥】（手停在那里，没动，看着她，她脸红得像熟透的苹果，眼睛水汪汪的，呼吸急促，但是没推开你的手，也没说话。）对不起...
【妹】（僵了半天，身体轻轻发抖，不仅没躲开，反而悄悄往你怀里靠了靠，胸轻轻蹭了一下你的手心，声音小小的发着颤，带着点颤抖的撒娇。）哥...
【哥】（听见她发颤的声音，你大着胆子，手心轻轻贴上去，隔着薄薄的睡衣，能感觉到她胸部软软的，暖暖的，虽然不大，但是形状很好。）软...
【妹】（被你整个手心贴住胸，她小声啊地叫了一下，身体没力气了一半，靠在你怀里，呼吸更急了，热热的喷在你脖子上，脸烫得吓人，但是没推开你，只是抓着你衣服的手更紧了，声音发着颤带着哭腔。）你...你手...别乱摸...
【哥】（手没拿开，轻轻在她胸上揉了一下，软软的，弹性很好。）不摸了？
【妹】（被你一揉，她浑身像过电一样麻了一下，赶紧咬住嘴唇，不让自己发出声音，身体没力气得像没骨头一样靠在你怀里，头埋在你肩膀上，耳朵红得要滴血，不仅没推开你，反而轻轻往你手心里蹭了蹭胸，声音闷闷的小小的。）嗯...轻...轻点...疼...
【哥】（听见她说疼，立刻放轻了动作，手心轻轻覆在她胸上，隔着睡衣慢慢揉，动作很温柔。）好。
【妹】（被你揉得浑身发麻，下面隐隐有点痒痒的感觉，她紧紧抱着你，身体轻轻发抖，呼吸又快又热，过了半天，抬起头看你，眼睛水汪汪蒙着一层雾，脸红得不行，凑过来主动吻住你的嘴唇，吻得柔柔的，手把你的手按得更贴紧在她胸上，声音黏黏的带着撒娇和羞涩。）哥...我喜欢你摸我...
【哥】（抱着她软软的身体，吻着她甜甜的嘴唇，手心感受着她胸部柔软的弹性，她乖乖靠在你怀里任你揉，脸红得可爱。）真的？
【妹】（亲了你一会，又埋回你肩膀上，身体轻轻发抖，被你揉得腿都发颤了，小声哼哼唧唧的，像只被顺毛的小猫，过了半天，说完脸更红了，抓着你衣服，偷偷把胸往你手心里又拱了拱，其实她心里一点都不讨厌，反而痒痒的很舒服。）嗯...但是...但是不许伸进去摸...今天只能隔着衣服...
