# D-F10：她躺你腿上睡觉你摸她脸
# 地点：沙发上，周末下午
# 情境：周末下午她在你腿上睡着了，你摸她的脸和嘴唇，她迷迷糊糊醒过来，还含住了你的手指

【哥】（周末下午阳光暖暖的照在客厅，你坐在沙发上看书，她看着电视就困了，头一歪躺到你腿上，枕着你的大腿睡着了，呼吸轻轻的，像小猫一样，长长的睫毛垂着，皮肤白白嫩嫩的，嘴唇粉粉的微微张着。）
【妹】（睡得迷迷糊糊的，枕在你暖暖的腿上特别舒服，阳光晒在身上暖暖的，她蹭了蹭你的大腿，找了个舒服的位置继续睡，嘴角微微扬着，呼吸均匀，手还轻轻抓着你的裤子。）
【哥】（看了一会书，低头看见她躺在你腿上睡得特别香，阳光照在她脸上，皮肤白白的像透明的一样，睫毛长长的，嘴唇粉润润的，特别可爱，忍不住伸出手，轻轻摸了摸她的脸，皮肤软软滑滑的，像剥了壳的鸡蛋。）真软。
【妹】（睡得正香，感觉到有人摸她的脸，迷迷糊糊醒了一点，但是没睁开眼睛，蹭了蹭你的手心，像小猫被摸舒服了一样，嘴唇微微张着，呼吸暖暖的吹在你手腕上。）嗯...
【哥】（看她没醒，胆子大了一点，拇指轻轻抚摸她的嘴唇，软软的，润润的，带着她唇膏的甜味，指尖轻轻按了按她的下唇，软软的触感特别好。）嘴唇也软。
【妹】（迷迷糊糊感觉到嘴唇上有东西，以为是做梦，微微张开嘴，你拇指刚好按在她下唇上，她居然下意识地含住了你的指尖，嘴唇软软的包裹着你的手指，暖暖的，舌头还轻轻舔了一下你的指尖，湿湿软软的。）唔...
【哥】（手指突然被她含进嘴里，暖暖的湿湿的，舌头软软的舔过你的指尖，像触电一样浑身麻了一下，整个人都僵住了，低头看她，她还是闭着眼睛没醒，像小猫喝奶一样含着你的手指，轻轻吮吸了一下，嘴唇一动一动的。）这...
【妹】（含了两下，尝到手指上淡淡的肥皂味道，迷迷糊糊睁开眼睛，正好对上你低头看她的目光，她一下子反应过来嘴里含着是什么，眼睛瞬间睁得圆圆的，整个人都僵住了，但是没把你的手指吐出来，就那么含着，看着你，脸瞬间红透了，从脸颊红到脖子根，眼睛睁得大大的，满是羞涩和慌乱。）啊...
【哥】（两个人都僵住了，你的手指还在她嘴里，软软的嘴唇包裹着，暖暖的湿湿的，她的舌头就在指尖旁边，能感觉到她的呼吸变得急促起来，热热的吹在你手上，她的脸离你特别近，能看清她脸上细小的绒毛，和水汪汪的大眼睛。）那个...我...
【妹】（反应过来，赶紧把你的手指吐出来，脸烫得能煎鸡蛋，赶紧坐起来，背对着你，手捂着嘴，身体都在轻轻发抖，心跳快得咚咚咚的，脑子里全是刚才含着你手指的感觉，软软的，硬硬的，还有点咸咸的味道，她羞耻得快哭出来了，但是不知道为什么，心里还有点痒痒的，声音小小的带着哭腔，颤抖着。）你...你故意的...你把手指伸我嘴里...
【哥】（看着她背对着你肩膀一抽一抽的，耳朵红得要滴血，手还捂着嘴，也有点尴尬，赶紧解释。）不是...我就是摸你脸，你自己含住的...
【妹】（听见你这么说，猛地转过身，眼睛水汪汪的瞪着你，脸红得像苹果，眼泪都快羞出来了，但是反驳不了，因为确实是她自己迷迷糊糊含住的，她鼓着脸瞪了你半天，说不出话来，过了半天，突然扑过来，把脸埋在你胸口，手轻轻捶你胸口一下，但是一点力气都没有，声音闷闷的带着哭腔撒娇，她埋在你胸口，脸烫得吓人，但是不肯抬头，嘴唇上还留着你手指的触感，心跳得快要炸开了，过了半天，她小声嘟囔。）你坏...你欺负我...你手指...咸咸的...
