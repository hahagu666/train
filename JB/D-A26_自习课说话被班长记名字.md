# D-A26：自习课说话被班长记名字
# 地点：学校走廊/家里，下午放学
# 情境：自习课她跟同桌说话被班长记了名字，要被罚抄课文，她委屈得红了眼眶，下课找你告状说班长针对她

【哥】（下课刚收拾好东西准备去找她，就看见她鼓着脸从教室里走出来，眼眶红红的，走到你面前也不说话，把一张记名字的小纸条往你手里一塞，嘴撅得老高）
【妹】（站在你面前，委屈巴巴的，手指使劲揪着校服衣角，声音带着哭腔）哥...班长针对我...我就跟同桌说了一句话...她就把我名字记下来了...要抄课文三遍...
【哥】（拿起小纸条一看，上面确实写着她的名字，违纪原因是"自习课说话"，你挑了挑眉，拉着她走到走廊窗边，让她慢慢说）慢慢说，怎么回事？自习课说什么了？
【妹】（鼓着脸，委屈得眼泪在眼眶里打转）我...我就是问同桌借个橡皮...就说了三个字"借橡皮"...她就把我名字记下来了...她就是针对我！上次她问我借尺子我没借她，她就记仇！
【哥】（听完有点哭笑不得，弹了她脑门一下）那你自习课说话就是不对啊，不管说什么，自习课就是不能说话，班长记你名字也是应该的，怎么是针对你？
【妹】（没想到你不帮她，反而说她不对，眼泪"唰"就掉下来了，鼓着脸瞪你，更委屈了）连你也帮她说话！我就说了三个字！别人说话她怎么不记！就记我！她就是故意的！我不抄！我凭什么抄！
【哥】（看她哭了，赶紧把她拉到怀里帮她擦眼泪，她挣了两下没挣开，就趴在你怀里抽抽搭搭的，肩膀一抽一抽的，委屈得不行。你轻轻拍她的背）好了好了，不哭了，班长记你名字是她的职责，就算是借橡皮，自习课说话就是违反纪律，对不对？
【妹】（在你怀里抽抽搭搭的，还是不服气，声音闷闷的）...可是别人也说话了...她为什么不记别人...就记我...
【哥】（帮她擦干净眼泪，捏了捏她红红的鼻子，笑着说）那说明我们妹妹长得好看，班长都忍不住多看你两眼，别人说话她没看见，就看见你说话了，说明你存在感高啊。
【妹】（被你逗得"噗嗤"一声笑出来，但是还是鼓着脸，捶了你胸口一下）你就会哄我...什么存在感高...她就是看我好欺负...
【哥】（笑着揉了揉她的头发，从书包里掏出她最爱吃的草莓糖递给她）好了，不委屈了，三遍课文而已，放学我陪你一起抄，我帮你抄一遍，你自己抄两遍，很快就抄完了，抄完我带你去吃冰淇淋，好不好？
【妹】（接过草莓糖剥开吃了，甜甜的草莓味在嘴里散开，心情好多了，但是还是有点别扭，小声说）...那...那你要帮我抄一遍...不许骗我...
【哥】（笑着点头，拉着她的手往校门口走）不骗你，但是你要答应我，以后自习课不许说话了，有什么事下课再说，不然下次被记名字，我可不帮你抄了，知道吗？
【妹】（乖乖点头，但是还是有点不服气，走了两步突然抬头看你，眼睛亮晶晶的，小声问）...哥...你说...班长是不是真的针对我啊...我平时也没得罪她啊...
【哥】（捏了捏她的脸，笑着说）傻丫头，哪有人针对你，班长就是秉公办事，你别想那么多，下次自习课安安静静写作业，她想记你名字也记不到，对不对？
【妹】（想了想，好像确实是这个道理，点了点头，但是还是有点小委屈，往你身边靠了靠，小声说）...那好吧...下次我自习课不说话了...但是你还是要陪我抄课文...还要请我吃冰淇淋...要双球的...
【哥】（笑着答应了，牵着她的手往家走，她吃着草莓糖，蹦蹦跳跳的，刚才的委屈全没了，果然小孩子的脾气来得快去得也快，一颗糖一个冰淇淋就能哄好）
【妹】（晚上你陪她抄课文，她写两个字就抬头看你一眼，笑得眼睛都弯了，其实抄课文也没那么难受嘛，有你陪着，抄十遍都愿意，手里攥着你给她的草莓糖纸，舍不得扔）
