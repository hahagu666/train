# D-I17：闺蜜打电话她强装正常你在后面动
# 地点：你床上
# 情境：你们正在做，她闺蜜突然打电话来，她接电话强装正常，你故意加快

【哥】软软，你手机响了。（你们正做到一半，你压在她身上快速抽插，她呻吟得正大声，突然她手机响了，是她闺蜜打来的，她吓得一下子捂住嘴，看着手机。）
【妹】（啊...等...等一下...我闺蜜电话...她想推开你去接电话，但是你不动了，肉棒还插在她小穴里，她急得小声说。）你别动...我接个电话...很快的...
【哥】（你坏笑了一下，没拔出来，就这么插在她里面，对她点点头，示意她接。）接啊，怎么不接？
【妹】（她瞪了你一眼，但是电话一直响，她只能接起来，按了接听，声音尽量正常。）喂...小丽啊...怎么了...
【哥】（她刚说完，你就突然开始动，慢慢抽插，她身体一下子绷紧了，差点叫出声，赶紧咬着嘴唇，手抓着床单。）嗯...继续聊啊...
【妹】（你故意动，她声音都抖了，赶紧对着电话解释，又狠狠瞪了你一眼，用口型说"你别动！"，但是你不仅没停，反而加快了速度，浅浅快速抽插，龟头蹭着她G点。）没...没怎么...刚...刚喝水呛了一下...
【哥】（你凑在她耳边，小声说让她继续聊，手伸到前面揉她的阴蒂。）跟你闺蜜说你在干嘛呢。
【妹】（啊...她差点叫出来，赶紧捂住话筒，小声喘了两下，然后强装镇定对着电话说话，声音发颤，小穴里不停流水，紧紧裹着你，快感越来越强，眼泪都快出来了。）啊...你说...你说周末去哪玩...嗯...我听着呢...
【哥】（你越动越快，每一下都顶到她最深处，她奶子被你揉着，身体抖个不停，她快忍不住了。）舒服吗？
【妹】（她话都说不完整了，声音越来越抖，腰不自觉往上抬，配合你的动作，她快高潮了，急急忙忙对着电话说要挂。）我...我周末可能...可能不去了...啊...不对...我有点...有点不舒服...小丽我...我先挂了...我肚子有点疼...回头跟你说...
【哥】（她刚挂电话，你就狠狠干起来，她立刻叫出声。）怎么挂了？不跟你闺蜜聊了？
【妹】（啊...哥...你混蛋...我受不了了...她哭着抱着你，身体抖得厉害，小穴剧烈收缩，没两下就高潮了，叫得特别大声。）啊...我去了...
【哥】（她高潮夹得你也射了，腰一挺全部射进去，两个人抱着喘了半天。）啊...射了...
【妹】（喘了半天，她捶着你的胸口，脸红得不行。）都怪你！让我在闺蜜面前出丑！她肯定听出来了！
【哥】（你笑着吻她的眼泪。）听出来什么？听出来你在被哥哥操啊？
【妹】（她脸更红了，把脸埋在枕头里，不好意思看你。）你不要脸...我以后怎么见小丽啊...
【哥】（你笑着把她抱进怀里，捏了捏她的屁股。）怕什么，她又不知道是我。
【妹】（她抬起头瞪了你一眼，但是小穴还在夹你的肉棒，小声嘟囔。）下次我打电话你再敢这样...我就...我就咬你...
