# D-E22：来例假肚子疼撒娇
# 地点：她房间，下午
# 情境：她来例假肚子疼得厉害，趴在床上不想动，喊你过去给她揉肚子

【哥】（你在客厅看电视，她在房间喊你，声音小小的，有气无力的）哥...你过来一下...
【妹】（你推开她房间门，她趴在床上，脸埋在枕头里，头发散在床上，蜷成一小团，手捂着肚子，脸色苍白，看见你进来，可怜巴巴看着你）哥...我肚子疼...
【哥】（走过去坐在床边，伸手摸她额头，没发烧，看她捂着肚子，立刻明白了）来例假了？
【妹】（点点头，眼睛红红的，声音带着哭腔，疼得眉头皱成一团）嗯...疼死了...比上次还疼...我喝了热水也没用...
【哥】（起身想去给她冲红糖水，她立刻伸手抓住你的衣角，不让你走，力气不大但是抓得紧紧的）
【妹】（摇摇头，眼眶红红的，疼得声音都发颤）别走...你别走...你一走更疼了...
【哥】不走，我去给你冲杯红糖水，再拿个暖水袋，很快回来。
【妹】（犹豫了一下，还是松了手，但是眼睛一直看着你出门，不到两分钟你回来，她立刻伸出手要你抱）你回来了...
【哥】（把冲好的红糖水递到她嘴边，她坐起来靠在你怀里，你喂她喝了半碗，暖水袋充好电了，裹上毛巾放在她肚子上）
【妹】（喝了红糖水，暖水袋焐着肚子，疼得稍微好一点了，但是还是靠在你怀里不肯动，手捂着暖水袋，脸色还是苍白，有气无力地靠在你胸口）还是疼...
【哥】（伸手隔着暖水袋轻轻给她揉肚子，顺时针慢慢揉，她立刻舒服了一点，叹了口气，往你怀里钻了钻）
【妹】（乖乖靠在你怀里让你揉肚子，呼吸慢慢平稳了一点，但是还是疼，眉头微微皱着，手抓着你的衣服，声音发虚，有气无力）你手好暖...比暖水袋还舒服...
【哥】中午吃凉的了？
【妹】（鼓着脸，但是因为疼没什么力气，小声嘟囔）中午太热了...买了个冰淇淋吃了两口...就两口...
【哥】（伸手敲了下她额头，她嗷了一声，委屈地看着你）还敢吃凉的？每次来都疼还不记着。
【妹】（往你怀里缩了缩，像只小猫一样，脸蹭了蹭你胸口，声音小小的）我错了嘛...下次不吃了...你别生气...（她抓着你的手放在她肚子上，让你继续揉，暖水袋慢慢凉了，但是你的手一直暖暖的，揉了半个小时，她好像没那么疼了，但是还是不肯起来，就靠在你怀里）
【哥】不疼了？
【妹】（摇摇头，还是靠在你怀里，手抱着你的腰，声音小小的，带着鼻音，有点撒娇）还有点疼...你再给我揉会...别停...（她抬头看你，眼睛因为刚才疼过有点水汪汪的，脸色还是白，但是嘴角微微扬着，手偷偷把暖水袋拿开，让你的手直接贴在她肚子上，隔着薄薄的睡衣，暖暖的）你手放这就不疼了...你今天别去上班了好不好...在家陪我...
【哥】（揉着她软软的肚子，她靠在你怀里，呼吸暖暖的吹在你脖子上，头发蹭得你下巴痒，过了一会她好像不疼了，但是还是不肯撒手，抱着你的腰，脸埋在你胸口，声音越来越小，好像快睡着了）
【妹】（迷迷糊糊快睡着的时候，含含糊糊嘟囔）哥...以后我每次来例假你都给我揉肚子好不好...（她蹭了蹭你胸口，手紧紧抱着你的腰，暖水袋早就凉在一边，她觉得你的手比什么都暖，疼了一下午，被你揉了半个多小时，终于不疼了，安心地在你怀里睡着了，嘴角还扬着）
