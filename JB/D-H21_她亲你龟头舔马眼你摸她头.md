# D-H21：她亲你龟头舔马眼你摸她头
# 地点：你床上
# 情境：她跪在你两腿之间，不着急含，先从龟头开始一点点亲，舌头舔马眼，你摸着她的头

【哥】（你靠在床头，她跪坐在你腿间，小手轻轻握着你的肉棒，抬头看着你。）
【妹】（眼睛亮晶晶看着你，低下头，先在龟头上轻轻亲了一口，像亲果冻一样，嘴唇软软的碰了一下，然后抬头对你笑。）哥，我先亲亲它好不好？
【哥】（你笑着摸了摸她的头发，点头。）好，都听你的。
【妹】（听见你答应，她开心地低下头，小嘴在龟头上一下一下亲着，从马眼亲到冠状沟，再亲到阴茎体，亲得密密麻麻的，像小鸡啄米一样。）嗯...
【哥】（她柔软的嘴唇亲在龟头上，痒痒的麻麻的，你舒服得轻轻嗯了一声，手顺着她的头发抚摸。）嗯...
【妹】（亲了一会龟头，她伸出粉粉的舌尖，只舔马眼那一点，舌尖轻轻点着马眼，慢慢打转，把流出来的透明前列腺液都舔干净。）哥，这里流出来咸咸的水。
【哥】（被她舌尖点着马眼，你舒服得腰轻轻抖了一下，手指插在她头发里。）那是前列腺液，没事。
【妹】（哦了一声，继续用舌尖快速扫着马眼，一只手轻轻套弄着阴茎体，另一只手往下，轻轻揉着你的两个蛋蛋，指尖轻轻打转。）嗯...
【哥】（她舌尖扫马眼，手揉蛋蛋，双重刺激特别舒服，你呼吸慢慢变重了。）啊...舒服...
【妹】（舔了一会马眼，她张开嘴，把整个龟头含进去，嘴唇紧紧裹着，舌头在嘴里不停扫着冠状沟，同时手继续快速套弄阴茎，揉蛋蛋的手也没停。）嗯...
【哥】（龟头被她温热的嘴包裹住，舌头扫着冠状沟，比单纯亲舔舒服多了，你舒服得闷哼。）嗯...对，就这样。
【妹】（听见你夸她，她嘴角偷偷扬起来，含着龟头慢慢上下动，舌头一直顶着系带那个最敏感的地方，每抬起来都用舌尖扫一下马眼，再含下去，节奏特别好。）嗯...
【哥】（你摸着她的头，看着她小脑袋一上一下认真服侍你，心里特别满足，快感越来越强。）啊...太舒服了...
【妹】（能感觉到你肉棒在她嘴里跳，她知道你快舒服了，加快吞吐速度，手也快速套弄，揉蛋蛋的手稍微用了点力，舌头一直死死顶着系带。）嗯...哥...
【哥】（快感冲到顶点，你抓着她的头发，腰轻轻挺了一下。）我要射了。
【妹】（她不仅没躲开，反而把龟头含得更深一点，喉咙轻轻夹着龟头，等着你射进来，眼睛还抬头看着你。）嗯...射给我...
【哥】（你腰一挺，一股股精液射在她嘴里，射在她舌头上。）啊...
【妹】（你射的时候她乖乖咽着，一口一口全部咽下去，等你射完，她还轻轻用舌尖把马眼舔干净，把残留的精液都舔掉，才抬起头。）嗯...
【哥】（你拉她上来抱在怀里，擦了擦她嘴角的口水，亲了亲她的额头。）累不累？
【妹】（摇摇头，趴在你怀里，小手轻轻摸着你软下来的肉棒，抬头对你笑，嘴角还亮晶晶的。）不累，能让哥哥舒服就好。
【哥】（你把她紧紧搂在怀里，亲了亲她的嘴唇。）真乖。
【妹】（往你怀里钻了钻，把脸埋在你胸口，听着你的心跳，声音黏黏的。）哥，下次我亲蛋蛋给你看好不好？我看片子里亲那里你会更舒服。
