# D-G08：帮你打飞机她用两只手
# 地点：你床上
# 情境：你用手指让她高潮了，她休息过来，红着脸主动要帮你打飞机，这次两只手一起上

【哥】（她刚高潮完，软在你怀里喘气，脸红红的，过了一会，她手往下摸，碰到你还硬着的肉棒。）
【妹】（摸着你硬硬的肉棒，抬头看你，眼睛水汪汪的还带着高潮后的水汽，脸红扑扑的，声音黏黏的。）哥...你还硬着...难受吧...
【哥】（看着她。）没事，你刚累了，歇会吧。
【妹】（摇摇头，小手握住你的肉棒，这次比上次熟练多了，她慢慢坐起来，跪在你两腿之间，看着你的肉棒，脸红红的。）我帮你...上次我弄的不好...这次我学过了...
【哥】（惊讶地看着她。）你学什么了？
【妹】（脸更红了，不好意思说。）我...我昨天偷偷看片子学了...
【哥】（挑了挑眉。）哦？还敢偷偷看片？
【妹】（鼓着脸，但是手没停，握住你的肉棒上下套弄了一下，比上次稳多了，她还学着片子里的样子，吐了点口水在手上，让润滑更好一点。）我...我还不是为了帮你...
【哥】（被她滑溜溜的小手握着，特别舒服，你忍不住闷哼了一声。）嗯...
【妹】（听见你舒服的声音，她笑了，笑得眼睛弯弯的，胆子大了一点，两只手一起握上来，一只手握着阴茎上下套弄，另一只手轻轻揉着你的睾丸。）我看片子里说...揉这里你会舒服...
【哥】（舒服地叹气。）嗯...对...就是这样...你真聪明。
【妹】（被你夸奖，她更开心了，手上动作更卖力，上下来回套弄，小手软软的握得刚刚好，速度不快不慢，偶尔用拇指蹭一下你龟头的马眼，那里湿漉漉的全是前列腺液。）哥...这样舒服吗...
【哥】（喘着气。）舒服...比我自己弄舒服多了...
【妹】（听见你说舒服，她脸红红的，凑过来，低头看着你的肉棒，犹豫了一下，然后伸出舌头，轻轻舔了一下龟头。）嗯...
【哥】（被她温热的舌头一舔，你忍不住倒吸一口凉气，身体都麻了一下。）嘶...
【妹】（抬头看你反应，看见你这么舒服，她眼睛亮了，但是没继续舔，还是用手，两只手配合着，一只手握阴茎套弄，另一只手揉睾丸，偶尔蹭一下龟头，她还学着片子里的样子，在龟头上打转。）怎么样？
【哥】（快感越来越强烈，你呼吸越来越急促，肉棒在她手里一跳一跳的。）嗯...快了...
【妹】（感觉到它在跳，她知道你快射了，手加快了速度，握得紧了一点，声音黏黏的。）哥...你要射了吗...射吧...我拿着呢...
【哥】（腰绷紧。）嗯...我要射了...
【妹】（手继续快速套弄，另一只手轻轻揉着你的睾丸，抬头看着你，眼睛亮晶晶的。）嗯...
【哥】（快感冲到顶点，你腰一挺，浓浓的精液射出来，一股股喷在她手上和小腹上。）啊...
【妹】（感觉到滚烫的精液喷在她手上，她吓了一跳，但是没躲开，就那么握着，直到你射完，她看着手上白白的精液，好奇的用手指沾了一点，黏黏的，抬头看你，脸红扑扑的。）哥...射出来这么多...
【哥】（喘着气，摸了摸她的头。）累不累？
【妹】（摇摇头，拿纸巾帮你擦干净，又擦了擦自己手上和肚子上的精液，然后钻回你怀里，抱着你，脸埋在你胸口，声音黏黏的带着满足，在你怀里蹭了蹭，手还轻轻摸着软下来的肉棒，好奇它怎么变小了，心里觉得特别有意思。）不累...能帮你舒服...我就开心...
