# D-D13：夏天吃冰棒
# 地点：客厅，夏天下午
# 情境：空调开着，她刚从外面补课回来，热得满头汗，从冰箱拿了冰棒吃

【哥】（夏天下午，外面太阳火辣辣的，蝉在树上叫个不停，你在客厅吹空调看电视，听到开门声）
【妹】（开门进来，满头是汗，校服外套脱了搭在胳膊上，脸跑得红扑扑的，刘海都湿了贴在额头上）
【哥】（抬头看她满头汗的样子，递了张纸巾过去）补课回来了？看你热的，快过来吹会空调。
【妹】（换了鞋直奔冰箱，拉开冷冻层，凉气冒出来，她舒服地叹了口气）热死了热死了...快让我凉快凉快...
【哥】（笑，看着她急急忙忙的样子）刚从外面回来别吃那么急，小心肚子疼。
【妹】（拿出一根绿豆冰棒，撕开包装，咬了一大口，冰得缩了下脖子，眼睛都眯起来了）唔——好冰！太爽了！
【哥】（摇摇头，给她倒了杯温水放桌上）慢点吃，又没人跟你抢。
【妹】（含着冰棒走过来，坐在你旁边，空调吹着凉风，舒服地叹了口气，靠在你肩膀上）今天外面三十八度...我走回来快热化了...感觉都要中暑了...
【哥】（笑，戳了戳她晒红的脸）让你带伞你不带，这下知道热了吧，晒黑了别又哭。
【妹】（鼓脸，舔着冰棒，冰棒化了一点，顺着手指往下流，她赶紧舔掉）带伞麻烦嘛...（冰棒碰到嘴唇，凉得她嘶了一声，缩了下脖子）
【哥】（看着她吃冰棒吃得一脸满足的样子，觉得好笑，拿纸巾给她擦手上的冰水）吃个冰棒看把你开心的。
【妹】（咬了一小口，冰棒在嘴里慢慢化，绿豆的甜味散开，她眯起眼睛像只满足的小猫）太爽了...你要不要吃一口？真的特别好吃！绿豆味超浓！
【哥】（摇摇头）我不吃，你吃吧，我怕凉。
【妹】（把冰棒递到你嘴边，手举着，眼神期待）就一口！特别好吃！你尝一口嘛！
【哥】（没办法，张嘴咬了一小口，确实挺甜的，绿豆味很浓）嗯，挺甜的。
【妹】（笑起来，自己继续吃，冰棒水顺着手指流到手腕，她去拿纸巾擦，冰棒举在你面前）帮我拿一下！我擦个手！
【哥】（帮她拿着冰棒，冰棒有点化了，滴了一滴在你手上）
【妹】（擦完手回来拿，看到你拿着冰棒，凑过去咬了一大口，含在嘴里，冰得她眉毛皱起来又松开，眼睛弯起来）
【哥】（笑着弹她额头）慢点吃，没人跟你抢，看你吃得一脸都是。
【妹】（舔了舔嘴唇上的冰水，笑眯眯的，靠在你肩膀上）夏天吃冰棒最幸福了...要是每天都能吃就好了...
【哥】（笑）想得美，吃多了肚子疼，到时候又要哭。
【妹】（吃完冰棒，去扔棍子，回来的时候嘴角沾了一点冰水，自己没察觉，蹦蹦跳跳的）
【哥】（伸手帮她擦掉嘴角的冰水，指尖碰到她温热的脸颊）嘴角都是，跟个小花猫似的。
【妹】（愣了一下，脸红了，赶紧自己擦了擦，耳朵尖都红了）哦...谢谢哥...
【哥】（笑着揉揉她的头发，把温水递她手里）喝点温水，别光吃冰的。
【妹】（接过温水喝了一口，靠在你肩膀上继续吹空调）
