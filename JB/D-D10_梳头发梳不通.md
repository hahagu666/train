# D-D10：梳头发梳不通
# 地点：她房间梳妆台，早上
# 情境：早上起来头发打结，她拿着梳子跟头发较劲，疼得呲牙咧嘴

【哥】（路过她房间门口，听见里面传来嘶嘶的声音）怎么了？
【妹】（坐在梳妆台前面，拿着梳子使劲梳头发，梳到一半梳不动了，皱着眉头扯，回头看你，鼓着脸，头发乱蓬蓬的，梳子卡在头发中间）头发打结了...梳不通...好疼...
【哥】（走过来）我看看。
【妹】（乖乖坐好，背对着你，手里还拿着梳子）昨天晚上睡觉头发没干就睡了，早上起来就打结了...
【哥】（拿过梳子，从发尾开始慢慢梳）你慢点梳，从发尾开始，别从发根使劲扯。
【妹】（坐在镜子前，你帮她梳头发，梳子碰到打结的地方她就缩一下脖子）嘶...轻点...
【哥】忍一下，马上就开了。
【妹】（乖乖坐着不动，从镜子里看你帮她梳头发，嘴角偷偷扬起来）
【哥】你看你，头发这么长也不好好梳。
【妹】（从镜子里冲你做了个鬼脸）我这不是梳不通嘛...每次都扯得我头皮疼。
【哥】（梳通了，用手帮她理了理头发）好了，通了。
【妹】（摸了摸顺滑的头发，笑起来，从镜子里看你）还是你梳得好...我自己梳半天都梳不开...
【哥】以后洗完头吹干了再睡。
【妹】（点头，拿起皮筋，回头看你）哥你帮我扎个马尾好不好？
【哥】我哪会扎头发。
【妹】（拉你袖子晃）就随便扎一下嘛...你扎的比我自己扎的紧...
【哥】（接过皮筋，笨拙地帮她扎马尾）扎歪了别怨我。
【妹】（乖乖坐着让你扎，从镜子里看你笨手笨脚的样子，忍不住笑出来）
【哥】（好不容易扎好，虽然有点歪，但是很结实，拍拍她的头）好了，扎完了。
【妹】（摸了摸马尾，笑起来，从镜子里冲你做鬼脸）
