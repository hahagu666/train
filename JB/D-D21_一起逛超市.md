# D-D21：一起逛超市
# 地点：家附近的超市，周六下午
# 情境：推着购物车，她坐在购物车里让你推，零食区眼睛亮晶晶的

【哥】（周六下午换好鞋，拿上购物袋）走了，去超市，家里牛奶鸡蛋都没了。
【妹】（蹦蹦跳跳跟过来，抢过购物袋挂自己胳膊上）我也要去！我要买薯片！
【哥】上周买的薯片不是还没吃完？
【妹】（拽着你胳膊晃）那个口味不好吃嘛...（拉着你往超市方向走）这次我要黄瓜味的！
【哥】（进了超市推购物车，她直接爬进去坐里面）你多大了还坐购物车？
【妹】（坐在车里抬头看你，腿晃来晃去）我不管，这样你推着我走省力气。（手指零食区）哥！那边！
【哥】（推着车往零食区走，顺手拿了两盒牛奶放车里）先买必需品，零食最后拿。
【妹】（鼓脸，但还是乖乖坐着看你拿鸡蛋蔬菜，趁你挑西红柿的时候偷偷伸手够货架上的薯片）
【哥】（转头看见她手伸得老长，把薯片拿下来放车里）说好最后拿的。
【妹】（立刻开心地抱住薯片，眼睛弯成月牙）谢谢哥！（又指着果冻）那个那个！我要桃子味的！
【哥】（拿了果冻放车里，又拿了两盒酸奶）这个你早上喝。
【妹】（坐在车里，伸手戳了戳酸奶盒，抬头看你）哥...你怎么知道我想喝这个？
【哥】你上次在超市盯着看了三分钟。
【妹】（脸一下子红了，低下头扒着购物车边，声音小小的）...你居然记得。
【哥】（推着车去结账，她坐在车里抱着一堆零食，嘴角压不住地往上扬）
【妹】（结完账你拎着两大袋，她从车里跳下来抢过一袋轻的拎着，走了两步又凑过来挽住你胳膊）
【哥】（侧头看她，她脸还红着，但是笑得特别开心，头发随着步子晃来晃去）
【妹】（挽着你胳膊走，另一只手拆开薯片递到你嘴边）哥你吃第一片！（眼睛亮晶晶看你，超市门口的风一吹，她头发飘起来，发梢蹭到你手腕）黄瓜味的，可好吃了！
