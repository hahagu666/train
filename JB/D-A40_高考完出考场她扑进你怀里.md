# D-A40：高考完出考场她扑进你怀里
# 最后一门英语考完，她第一个冲出考场，看见你站在门口抱着向日葵等她，直接蹦起来扑进你怀里，哭着说"我考完了"
# 地点：考场门口/停车场，高考最后一门结束

【哥】（最后一门英语考试结束，你抱着一大束向日葵站在考场门口等，周围都是接孩子的家长，你站在最前面，眼睛一直盯着考场出口。考试结束铃响了，考生们开始往外走）
【妹】（英语考完停笔的那一刻，她手都在抖，一年的努力终于结束了。交完卷子她第一个冲出考场，跑得飞快，马尾辫甩起来，在人群里一眼就看见你站在门口，抱着一束金灿灿的向日葵，冲她笑）
【哥】（笑着朝她挥手）
【妹】（眼泪一下子就掉下来了，什么都顾不上了，背着大书包直接冲过去，蹦起来扑进你怀里，紧紧抱着你的脖子，把脸埋在你肩膀上，哭得稀里哗啦的，声音哽咽）哥！！！我考完了！！！我终于考完了！！！
【哥】（赶紧伸手接住她，向日葵被挤在两个人中间，花瓣掉了好几片，你稳稳抱着她，她整个人都挂在你身上，哭得肩膀一抽一抽的，像个小孩子。你轻轻拍她的背，声音温柔得能滴出水来）考完了就好，考完了就解放了，我们妹妹辛苦了。
【妹】（挂在你身上哭了好久，周围考生和家长都在看你们，她也不管，就紧紧抱着你的脖子不撒手，眼泪把你T恤都打湿了一大片，一边哭一边笑，话都说不完整）我...我刚才写作文的时候...手都在抖...我还以为我写不完...我...我终于考完了...
【哥】（笑着帮她把背上的大书包摘下来自己提着，另一只手抱着她，帮她擦眼泪，她脸上又是眼泪又是汗，头发都乱了，但是眼睛亮得像装了星星，比手里的向日葵还耀眼）好好好，考完了就好，不哭了啊，再哭就成小花猫了。
【妹】（从你怀里下来，脚刚沾地就腿软了一下，你赶紧扶住她，她站在你面前，擦了擦眼泪，看着你手里的向日葵，眼睛亮晶晶的，又哭又笑）你还给我买花啊...
【哥】（把向日葵递到她手里，揉了揉她乱蓬蓬的头发，笑着说）当然买，庆祝我们妹妹顺利考完，辛苦了一年，终于解放了。
【妹】（抱着那束向日葵，把脸埋在花里，向日葵金灿灿的，特别香，她抬起头，脸上还挂着眼泪，但是笑得特别灿烂，像夏天里最亮的小太阳。周围有同学起哄，她也不害羞了，就站在你身边，紧紧拉着你的手）
【哥】（牵着她的手往停车场走，她蹦蹦跳跳的，像只刚飞出笼子的小鸟，一会儿说"终于不用背单词了"，一会儿说"我要睡三天三夜"，叽叽喳喳说个不停，你笑着听她说，心里的石头终于落地了）
【妹】（走到车旁边，她突然停下来，转过身看着你，抱着向日葵，眼睛亮晶晶的，脸上还带着泪痕，但是特别认真地看着你）哥...我...我感觉我考得挺好的...我应该能考上你那个城市的大学...
【哥】（心里一暖，伸手把她揽进怀里，亲了亲她的发顶，笑着说）我就知道我们妹妹可以的，不管考成什么样，你都是最棒的。
【妹】（靠在你怀里，抱着向日葵，笑得特别甜，过了一会儿抬起头，眼睛亮晶晶的，小声问）哥...那...我考完了...你之前答应我的事还算数吗...
【哥】（故意逗她，装作想不起来）什么事？我答应你什么了？
【妹】（鼓着脸，捶了你胸口一下，但是力气小得像挠痒痒，脸红扑扑的）你忘了！你说等我高考完...你就...你就当我男朋友的！
【哥】（忍不住笑出声，低头看着她红红的脸蛋，在她嘴唇上轻轻亲了一下，她一下子僵住了，眼睛睁得大大的，抱着向日葵的手都紧了，脸"唰"地一下红透了。你笑着看着她）当然算数，从今天起，你就不是我妹妹了，是我女朋友，好不好？
【妹】（愣了两秒，然后一下子笑了，眼泪又掉下来了，但是这次是开心的眼泪，她把向日葵放在车顶上，扑过来紧紧抱着你，踮起脚尖在你嘴唇上亲了一口，声音带着哭腔但是特别开心）好！！！
【哥】（抱着她，在夏天的风里，在考场门口，在金灿灿的向日葵旁边，低头吻住她。一年的辛苦、熬夜的夜晚、做不完的卷子、所有的紧张和不安，在这个吻里全都烟消云散了。她抱着你的脖子，回应着你的吻，笑得比向日葵还灿烂）
【妹】（吻了好久才松开，脸红得像熟透的苹果，但是眼睛亮得惊人，牵着你的手晃啊晃，蹦蹦跳跳地说"我要去吃火锅！要吃毛肚虾滑肥牛卷！要喝冰可乐！要逛一晚上街！要去看演唱会！要去海边！"）
【哥】（笑着一一答应，把她的书包放进车里，给她系好安全带）
【妹】（抱着向日葵坐在副驾驶，车窗开着，夏天的风吹进来，吹起她的头发，她哼着歌，笑容灿烂得像整个夏天的阳光都落在她脸上，心里想着，以后再也不用跟哥哥分开了）
