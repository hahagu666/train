# D-H23：你扶着她的头口交
# 地点：你床上
# 情境：她给你口交的时候，你轻轻扶着她的头，控制节奏，她配合你

【哥】（她跪在你两腿之间给你口交，含着龟头吞吐，你伸手轻轻扶着她的头，没有用力按，只是跟着她的节奏。）
【妹】（她感觉到你扶着她的头，抬头看了你一眼，眼睛水汪汪的，不仅没躲开，反而主动顺着你手的力道动，嘴里含着龟头发出咕咕的声音。）嗯...
【哥】（你轻轻扶着她的头，慢慢带着她动，让她含得深一点，她很配合，顺着你的力道往下吞，龟头抵在她喉咙口。）嗯...
【妹】（龟头抵着喉咙，她有点难受，但是没躲开，调整了一下呼吸，用喉咙轻轻夹着你的龟头，手继续快速套弄阴茎，另一只手揉着你的蛋蛋。）嗯...
【哥】（她喉咙夹着龟头特别紧特别暖，你舒服得闷哼出声，扶着她头的手稍微加快了一点节奏。）嗯...就这样...
【妹】（她顺着你手的节奏，小脑袋一上一下动着，嘴唇一直紧紧裹着你的肉棒，舌头不停扫着系带，配合得特别好，口水顺着嘴角流下来。）嗯...
【哥】（你扶着她的头，节奏越来越快，她也跟着你快速吞吐，喉咙紧紧夹着龟头，手配合着快速套弄，揉蛋蛋的手也没停。）啊...太舒服了...
【妹】（她能感觉到你肉棒在她嘴里跳得越来越厉害，知道你快射了，不仅没退开，反而主动把嘴含得更深，让龟头全部进喉咙里。）嗯...哥...
【哥】（快感越来越强，你扶着她的头，腰轻轻往上挺了一点。）我要射了。
【妹】（她听见你说要射，抬头看了你一眼，眼睛水汪汪的，然后把龟头含得紧紧的，喉咙不停收缩夹着，等着你射进来。）嗯...射给我...
【哥】（你腰一挺，一股股浓浓的精液直接射进她喉咙里。）啊...
【妹】（你射的时候她乖乖咽着，喉咙一缩一缩的，把所有精液都咽下去，等你射完，她还轻轻舔了半天龟头，才慢慢退出来。）嗯...
【哥】（你拉她上来，擦了擦她嘴角的口水，亲了亲她。）呛到没有？
【妹】（她摇摇头，趴在你怀里喘气，脸红红的，但是笑得特别开心。）没有，刚开始有点难受，习惯了就好。
【哥】（你摸着她的头发，把她搂紧。）傻丫头，难受就退出来，不用勉强。
【妹】（她往你怀里钻，小手轻轻摸着你的胸口，声音黏黏的。）不勉强，只要你舒服，我就开心。
【哥】（你亲了亲她的额头。）真乖。
【妹】（她抬起头，在你嘴唇上亲了一下，眼睛亮晶晶看着你。）哥，你扶着我头的时候...我特别有感觉...你想怎么动就怎么动，我配合你。
【哥】（你笑着捏了捏她的脸。）知道了，小坏蛋。
【妹】（她嘻嘻笑了笑，往你怀里钻得更深，把脸埋在你脖子上，亲了亲你的下巴。）那你下次可不许心疼我。
