# D-K07：考试没考好你说她她哭
# 期中考试她数学考了五十八分不及格，拿着卷子磨磨蹭蹭回家不敢给你看，你说她两句她就哭了，说自己已经很努力了

【哥】（坐在沙发上看手机，她磨磨蹭蹭开门进来，书包背在肩上，头低着，换鞋换了半天，看见你就赶紧往房间溜，你皱起眉头）站住，这次期中考试成绩出来了吧？考得怎么样？
【妹】（脚步顿住，背对着你，站在原地不说话，肩膀缩着，手紧紧抓着书包带子，声音小小的）...还...还行...
【哥】（走过去，伸手）卷子拿出来我看看。
【妹】（磨磨蹭蹭不肯拿，头埋得更低了，眼眶一下子就红了，声音带着哭腔）...我...我没考好...
【哥】（看她快哭了，心一下子软了，但是还是伸手把她书包拿过来，翻出数学卷子，打开一看，58分，红笔写的分数特别刺眼，好多题都是不该错的基础题。你皱起眉头："怎么考成这样？这些题我上周不是刚给你讲过吗？"
【妹】（站在原地，眼泪"啪嗒啪嗒"掉下来，攥着衣角，声音哽咽）我...我考试的时候紧张了...好多题明明会做...一紧张就忘了怎么写了...我也不想考这么低的...
【哥】（看着卷子上那些讲过好几遍还是错的题，有点生气，语气重了一点）紧张？我看你就是考试前一天还在看漫画！让你复习你说都会了，现在考五十八分回来，你对得起你自己天天熬夜学习吗？
【妹】（被你一说，哭得更凶了，肩膀一抽一抽的，抬起头抹眼泪，委屈得不行）我没有天天看漫画...我考前复习了好久...我每天都学到十二点...我就是笨...我就是学不会数学...我也想考好的...
【哥】（看见她哭得喘不过气的样子，话一下子就说不出口了，心里又气又心疼。她这次确实每天晚上都学到很晚，你都看在眼里，可能是方法不对，也可能是太紧张了。你叹了口气，把卷子放在桌子上）
【妹】（看你不说话，哭得更委屈了，站在原地，眼泪把校服袖子都打湿了，抽抽搭搭的）...我知道我笨...我让你失望了...你骂我吧...
【哥】（伸手把她拉过来，让她坐在你身边，拿纸巾帮她擦眼泪，她一开始还挣扎，不想让你擦，但是你力气大，把她按在怀里帮她擦眼泪）谁说你笨了？我们妹妹才不笨，就是学习方法不对，太紧张了，下次好好考就行了，哭什么。
【妹】（靠在你怀里，听见你这么说，反而哭得更厉害了，把脸埋在你胸口，把眼泪都擦在你衣服上，声音闷闷的）...我以为...我以为你会生气...会骂我...我都不敢回家...
【哥】（轻轻拍着她的背帮她顺气，揉了揉她的头发，语气软下来）我是有点生气，但是我不是气你考得差，我是气你明明讲过好几遍的题还是错，气你不把自己的身体当回事，学到十二点，白天上课犯困，能考好才怪。
【妹】（在你怀里点点头，抽抽搭搭的，手紧紧抓着你的衣服，小声说）...我下次...我下次一定好好考...我再也不看到半夜了...上课也不犯困了...你别生气好不好...
【哥】（帮她把脸上的眼泪擦干净，捏了捏她哭得红红的鼻子，笑着说）我不生气，但是下次不许考这么差了，也不许学到那么晚，每天晚上十点半必须睡觉，知道吗？
【妹】（使劲点头，眼睛红红的像只小兔子，但是不哭了，靠在你怀里，过了一会儿抬起头看你，小声问）...哥...那...那你能不能...能不能以后每天晚上帮我讲一个小时数学啊...我自己学总是学不会...
【哥】（笑着捏了捏她的脸，点头答应）好，以后每天晚上我帮你讲一个小时数学，把不会的题都讲明白，但是你得答应我，不许学到那么晚，不许给自己太大压力，考不好没关系，我们慢慢来，知道吗？
【妹】（听你这么说，一下子破涕为笑，凑过来在你下巴上亲了一口，眼泪还挂在脸上就笑了，声音黏黏的）知道了！哥哥最好了！
【哥】（笑着把卷子拿过来，把她拉到书桌边）好了，现在先把这些错题改了，我给你讲，哪里不会就问。
【妹】（乖乖坐在椅子上，拿起笔，靠在你身边，你一道题一道题给她讲，她听得特别认真，偶尔抬头看你一眼，眼睛红红的，但是特别亮)
