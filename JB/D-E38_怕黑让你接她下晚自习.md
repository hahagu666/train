# D-E38：怕黑让你接她下晚自习
# 地点：小区楼下，晚上九点半
# 情境：下晚自习小区那段路灯坏了，她怕黑，给你打电话让你去接她，站在小区门口等你

【哥】（晚上九点半，你正在看书，手机响了，是她打来的，声音小小的带着点哭腔）哥...你能不能来小区门口接我一下...
【妹】（电话里她声音小小的，周围黑黑的，还有风吹树叶的声音，她声音发颤）我下晚自习了...咱们小区门口那段路灯坏了...全黑了...我不敢走...
【哥】（立刻站起来拿外套）站在那别动，我马上下来。
【妹】（嗯了一声，电话没挂，能听见她紧张的呼吸声，还有她小声给自己打气的声音，她肯定是站在路灯底下不敢动）
【哥】（三分钟就跑到小区门口，远远看见她站在便利店门口的路灯底下，背着大大的书包，抱着胳膊缩成一小团，东张西望的，看见你过来，眼睛一下子亮了，立刻跑过来扑进你怀里）
【妹】（扑进你怀里，手紧紧抱着你的腰，脸埋在你胸口，身体还在微微发抖，声音带着点哭腔）你终于来了...我等了你好久...那段路全黑了...我一个人不敢走...
【哥】（拍着她的背给她顺气，她的手冰凉冰凉的，脸也冻得凉凉的，肯定站在冷风里等了好一会了）不是说了让你给我打电话吗，怎么不早点打。
【妹】（埋在你胸口不肯抬头，手紧紧抓着你的外套，声音闷闷的）我想自己试试走过来...可是走到门口看见全黑了...我腿都软了...（她抬起头看你，眼睛红红的，在路灯底下亮晶晶的）我是不是特别没用...这么大了还怕黑...
【哥】（牵着她的手往小区里走，那段路确实全黑了，一点光都没有，她立刻紧紧抓着你的手，整个人都贴在你胳膊上，另一只手还抓着你的衣角，走得特别慢，紧紧挨着你）
【妹】（走在黑夜里，她紧紧抓着你的手，手心全是汗，身体有点抖，但是因为你牵着她，没那么怕了，走两步就往你身边靠一靠，声音小小的）哥...你慢点走...我看不见...
【哥】（握紧她的手，把她往身边拉了拉，让她靠在你身上走）我牵着你呢，别怕，跟着我走就行。
【妹】（乖乖点点头，紧紧靠着你，抓着你的手不放，走在黑夜里，但是因为牵着你的手，听着你的脚步声，她一点都不怕了，甚至能闻到你身上洗衣液的味道，暖暖的，走了五分钟就到单元楼门口了，灯一亮她才松了口气）
【哥】（到了家门口，她还是抓着你的手不肯放，脸红红的，有点不好意思，但是还是看着你）
【妹】（到家开了灯，她才松开手，但是手还留着你手心的温度，暖暖的，她看着你，脸有点红，声音小小的）谢谢你哥...要是你不来我真的要在门口站一晚上了...（她顿了顿，小声说）以后...以后我下晚自习你都来接我好不好...那段路灯修好之前...我都不敢一个人走...
【哥】好，每天都来接你。
【妹】（眼睛一下子亮了，立刻开心起来，扑过来抱了你一下，然后脸红红地跑回房间，跑到门口又回头看你，眼睛亮晶晶的，嘴角扬着，声音黏黏的）哥你最好了！（她回到房间，从书包里掏出一颗草莓糖，跑回来塞你手里，脸红红的，这是她攒了一天舍不得吃的糖，给你当谢礼，然后砰地关上房门，靠在门后心跳得特别快，但是特别开心，知道以后每天下晚自习，你都会在门口等她）
