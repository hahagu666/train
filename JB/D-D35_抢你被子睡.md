# D-D35：抢你被子睡
# 地点：你房间，冬天深夜
# 情境：她房间暖气坏了，半夜抱着枕头钻你被窝抢被子，冻得冰凉

【哥】（冬天半夜睡得正香，感觉到床边陷下去一块，然后被子被掀开一个角，一股冷气钻进来，一个冰凉的小东西钻进来）
【妹】（冻得发抖，抱着自己的枕头钻你被窝，身上冰凉的，牙齿都在打颤，往你身边挤）哥...哥你醒醒...
【哥】（迷迷糊糊醒过来，摸到她冰凉的胳膊，一下子清醒了）怎么了？做噩梦了？
【妹】（整个人往你怀里钻，脚都是冰的，贴在你腿上，冷得嘶了一声）我房间暖气坏了...好冷...我冻了半小时了实在睡不着...
【哥】（把被子往她那边拉了拉，裹住她，她整个人冰得像块雪糕，蜷在你身边）你不会早点过来。
【妹】（牙齿还在打颤，但是抱住你腰，脸贴在你胸口，你的身体暖乎乎的，她舒服得叹了口气）我怕你生气...我敲了两下门你没醒...（她的脚还是冰的，偷偷往你腿中间伸）
【哥】（被冰得嘶了一声，缩了一下）你脚怎么这么冰。
【妹】（赶紧把脚缩回去，有点不好意思，声音小小的）对不起...我冰到你了...（但是没走，还是往你怀里钻，身体慢慢暖过来了）你被窝好暖和...
【哥】（叹了口气，把她往怀里搂了搂，用自己的腿夹住她冰凉的脚给她暖，她一下子僵了，然后整个人软下来）睡吧。
【妹】（安静了一会，手抱着你的腰，脸贴在你胸口听你的心跳，身体慢慢暖过来了，呼吸轻轻吹在你脖子上，痒痒的）哥...
【哥】嗯？
【妹】（声音小小的，带着困意，暖乎乎的气喷在你胸口）我以后房间暖气坏了都过来跟你睡好不好...一个人睡太冷了...
【哥】你啊，就不能叫人来修暖气。
【妹】（蹭了蹭你胸口，像小猫一样，腿也暖过来了，整个人都暖乎乎的，困得眼睛都睁不开了）明天修...今天先睡...（她打了个小小的哈欠，手臂抱紧你的腰，头发蹭得你脖子痒，声音越来越小）你身上好暖...像暖宝宝一样...
【哥】（拍了拍她的背，像哄小孩一样，她呼吸慢慢平稳下来，快睡着了，嘴角偷偷扬着，手紧紧抓着你的睡衣）
【妹】（半梦半醒间，迷迷糊糊在你胸口亲了一下，然后把脸埋进去，声音黏糊糊的）晚安哥...明天我不跟你抢被子...（话刚说完她就把被子往她那边卷了一半，整个人裹成蚕宝宝，窝在你怀里睡着了，呼吸轻轻的，头发散在你胸口，暖乎乎的，像只小猫）
