# D-D26：抢遥控器
# 地点：客厅沙发，晚上
# 情境：你想看球赛，她想看偶像剧，两个人抢遥控器

【哥】（吃完饭坐在沙发上，拿过遥控器打开电视，调到体育频道，球赛刚开始）
【妹】（端着洗好的草莓从厨房出来，看见你在看球赛，鼓着脸走过来）哥！我要看偶像剧！大结局今晚！
【哥】（把遥控器攥手里）球赛就这一场，踢完了你再看。
【妹】（坐在你旁边伸手抢遥控器，你手举高她够不着，整个人扑过来）不行！偶像剧大结局明天就被剧透了！
【哥】（另一只手搂着她不让她扑过来，眼睛还盯着电视）剧透怎么了，反正你最后肯定跟男主在一起。
【妹】（抢不到遥控器，干脆整个人跨坐在你腿上，两只手掰你举着遥控器的手）你怎么知道！万一男二呢！给我给我！
【哥】（被她晃得差点坐不稳，但是遥控器还是举得高高的）你先下去，压着我了。
【妹】（不下去，反而凑得更近，鼻子都快碰到你下巴了）你给不给我？（她伸手挠你腰，你最怕痒）
【哥】（被她挠得笑出声，手一松，遥控器被她抢走了）哎！别挠！
【妹】（抢到遥控器立刻爬回去坐好，快速调到偶像剧，把遥控器抱在怀里，得意地看你）哼！跟我抢！
【哥】（无奈地靠在沙发上，看她美滋滋地抱着靠枕看剧，看到男主女主相遇，她眼睛一眨不眨）
【妹】（看了十分钟，发现你一直没说话，悄悄侧头看你，你靠在沙发上假装生气，她咬了咬嘴唇，把草莓递到你嘴边）哥...你吃草莓。
【哥】（偏过头不吃，故意板着脸）不给看球，不吃。
【妹】（赶紧把草莓塞你嘴里，又凑过来摇你胳膊）球赛明天有回放嘛...我陪你看回放好不好？广告的时候换过去给你看比分？
【哥】（嚼着草莓，看她眼巴巴看着你，还是故意不说话）
【妹】（干脆把遥控器放你手里，但是整个人往你怀里钻，头靠在你肩膀上）那...那我们看五分钟球赛，然后看电视剧...好不好？（她仰头看你，眼睛水汪汪的，头发蹭得你脖子痒）广告的时候我不跟你抢...
【哥】（看着她可怜巴巴的样子，忍不住笑了，揉了揉她的头，把电视切成两分屏一边球赛一边剧）行，一起看。
【妹】（眼睛一下子亮了，开心地在你怀里蹭了蹭，靠在你肩膀上，一边看剧一边给你喂草莓，看到男主表白的时候她偷偷脸红，手紧紧抓着你的衣角，草莓递到你嘴边都忘了松手）你看你看！他表白了！（她激动得抬头看你，头发蹭到你下巴，眼睛亮晶晶的，嘴角全是草莓汁）
