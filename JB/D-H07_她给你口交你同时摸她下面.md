# D-H07：她给你口交你同时摸她下面

# 情境：她跨坐在你脸上方给你口交，你躺着同时摸她胸舔她下面，两个人同时爽

【妹】（啊！你手指插进来，她嘴里含着你的肉棒，舒服得闷哼一声，震动传在你龟头上，特别刺激，她动作顿了一下，立刻又继续含着你吞吐，舌头不停舔着，手配合套弄。）呜...

【妹】（呜！她整个人都抖了一下，差点坐你脸上，你舌头舔着她阴蒂，手指插着她小穴，她嘴里还含着你的肉棒，三重快感一起上来，她差点喘不上气，但是努力集中精神继续给你口交，含着龟头快速吞吐，舌头不停舔着系带，手快速套弄，只是动作因为快感有点抖。）呜...哥...

【哥】（她揉着你的睾丸，嘴里含着你吞吐，你舔着她阴蒂手指插着她，两个人都在卖力让对方舒服，快感同时在两个人身上累积。）嗯...

【哥】（被她喉咙一夹，你也忍不住了，腰一挺，精液直接射进她嘴里。）啊...

【妹】（鼓着脸，但是没坚持，在你胸口蹭了蹭，小声说）那好吧...但是下次...下次你一定要给我...
