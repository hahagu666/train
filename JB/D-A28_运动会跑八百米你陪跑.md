# D-A28：运动会跑八百米你陪跑
# 地点：学校操场/回家路上，秋季运动会
# 情境：运动会她被班长报了八百米，跑到第二圈就跑不动了落到最后一名，急得快哭了，你在内道陪着她跑给她加油

【哥】（站在看台上，看见她站在八百米起跑线上紧张得手都在抖）
【妹】（站在八百米起跑线上，紧张得手都在抖，往看台上看，一眼就看见你站在最前面冲她挥挥手，她也赶紧冲你挥挥手，但是腿都软了）哥...我好紧张...我跑不动怎么办...
【哥】（站在看台上喊，声音很大，她听得清清楚楚）别紧张！慢慢跑！跑不动就走！我在这儿陪你！
【妹】（枪响了，大家都冲出去，她跟着大部队跑，第一圈还能跟上，第二圈刚过弯道就不行了，腿像灌了铅一样沉，喘得肺都疼，速度越来越慢，慢慢落到了最后一名，前面的人都快超她一圈了）
【哥】（看她跑得满头大汗，脸白得像纸，脚步都踉跄了，赶紧从看台上跑下来，跑到跑道内道，跟在她身边陪着她跑，跟她并排，声音很大给她加油）丫头！别停！慢慢跑！调整呼吸！我在这儿陪着你！
【妹】（跑得晕头转向的，突然听见你的声音，抬头看见你在内道陪着她跑，一下子眼睛就红了，眼泪混着汗水往下掉，喘得话都说不完整）哥...我...我跑不动了...我不想跑了...
【哥】（一边陪她跑一边给她加油，伸手能碰到她的胳膊，声音坚定）能跑动！再坚持一下！还有最后一百米！你看终点就在前面！我陪着你！我们慢慢跑！不着急！
【妹】（眼泪掉得更凶了，腿已经软得快抬不起来了，但是看见你一直在她身边陪着跑，咬着牙，一步一步往前挪，跑得特别慢，但是没停下来，周围看台上的同学都在给她加油，她什么都听不见，就听见你在她身边喊"加油""快到了""好样的"）
【哥】（一直陪着她跑到终点，她冲过终点线的那一刻，腿一软直接往前倒，你赶紧伸手接住她，把她打横抱起来）
【妹】（扑在你怀里，大口大口喘气，哭得稀里哗啦的，把你运动服都哭湿了）呜...我...我是最后一名...我跑了倒数第一...太丢人了...
【哥】（抱着她走到操场边，把她放在椅子上，拿过矿泉水拧开给她喝，又拿毛巾帮她擦脸上的汗和眼泪，笑着揉她的头发）什么最后一名，你跑完全程了就是最棒的，在我心里你是第一名。
【妹】（喝了口水，还是喘得厉害，腿软得站不起来，靠在你肩膀上，眼泪还是往下掉，抽抽搭搭的）我...我本来想跑个前三名给你看的...结果跑了倒数第一...
【哥】（帮她揉了揉发酸的小腿，动作轻轻的，怕弄疼她，笑着说）傻丫头，谁让你一定要拿名次了？你敢站在跑道上跑完全程，就已经特别厉害了，你没看见刚才大家都在给你加油吗？
【妹】（靠在你肩膀上，喘了半天才缓过来，想起刚才你一直在内道陪着她跑，别人都有人陪，只有你一直陪在她身边，心里暖得不行，把脸埋在你脖子里，声音闷闷的）...哥...谢谢你陪我跑...要不是你...我可能中途就放弃了...
【哥】（笑着抱紧她，亲了亲她汗湿的发顶，轻声说）我当然要陪你跑，不管你跑第几，我都陪着你，以后不管什么事，我都陪着你，知道吗？
【妹】（在你怀里点点头，破涕为笑，虽然跑得腿疼，虽然是倒数第一，但是有你陪着跑，好像也没那么丢人了。过了一会儿，班长和同学都过来给她递水递纸巾，说"你好厉害啊，坚持跑完全程了"，她脸红了，但是特别开心）
【哥】（等她休息够了，你背着她往家走）
【妹】（趴在你背上，腿还酸酸的，但是特别开心，晃着脚，在你耳边小声说）哥...下次运动会...我还要报八百米...下次我一定不跑最后一名...
【哥】（背着她，笑着说）好，下次你还报，我还陪你跑，跑多少次我都陪你。
【妹】（趴在你背上，笑得特别甜，把脸贴在你后背，心里想，就算每次都跑最后一名也没关系，只要有你陪着跑，就什么都不怕。夕阳把你们的影子拉得很长，你背着她慢慢走，她在你背上哼着歌，刚才的累和委屈全没了）
