# D-C12：做家务分工
# 地点：厨房/客厅，周末
# 情境：吃完饭爸妈出去散步，留下碗要洗，你跟她石头剪刀布谁输了谁洗

【哥】（收拾碗筷放厨房，看她坐在沙发上玩手机）碗谁洗？总不能每次都是我洗吧。
【妹】（抬头，眼珠子转了转）石头剪刀布！谁输了谁洗！
【哥】（擦桌子，笑）行，来，不许耍赖啊。
【妹】（站起来，摩拳擦掌）来！谁耍赖谁是小狗！
【哥】（擦完手，站好）石头剪刀布。
【妹】（出剪刀，你出石头，愣了一下）啊！三局两胜！
【哥】（笑）刚才没说三局两胜，愿赌服输。
【妹】（耍赖拉住你胳膊晃）三局两胜嘛！就一局不公平！
【哥】（被她晃得没办法，笑）行，三局两胜，最后一把定胜负。
【妹】（认真脸）准备好了啊！石头剪刀——布！
【哥】（出剪刀，她出布，笑）愿赌服输，去洗吧。
【妹】（鼓脸，不情不愿走进厨房，开水龙头，洗了两下回头，可怜巴巴看着你）哥...
【哥】（靠在厨房门口看她）嗯？怎么了？
【妹】（可怜巴巴看着你）我洗不干净...你上次说我洗的碗还有油...
【哥】（笑）那你想怎么样？耍赖不洗？
【妹】（走过来拉你手晃）你帮我洗嘛...我在旁边陪你说话！给你递盘子！
【哥】（被她拉到水池边）那跟我洗有什么区别？你又不洗。
【妹】（笑，眼睛亮晶晶）区别就是我陪你啊！我给你唱歌听好不好？
【哥】（接过洗碗布）别唱了，上次你唱歌跑调吓得邻居都来敲门了。
【妹】（鼓脸，递洗碗布给你）哪有！我唱歌明明很好听！
【哥】（接过来洗碗，水龙头哗哗响）
【妹】（站在你旁边，乖乖帮你递冲干净的碗放架子上，嘴里哼着歌，脚在地上晃来晃去）
【哥】（洗着碗，感觉到她偷偷从后面抱你腰，手顿了一下，笑）干嘛，偷袭我？
【妹】（脸贴你后背，声音甜甜的）哥你最好了。
【哥】（低头继续洗碗，嘴角扬着）少来这套，下次碗还是你洗。
【妹】（抱得更紧，蹭你后背，声音黏黏的，耍赖）下次再说嘛...
