# D-D08：你做饭她在旁边看
# 地点：厨房，傍晚
# 情境：你在厨房炒菜，她靠在门框上看，时不时凑过来偷吃

【哥】（厨房里抽油烟机嗡嗡响，油在锅里滋滋作响，你拿着锅铲翻炒，听到门口有动静，回头看）
【妹】（放学回来，书包扔在沙发上，靠在厨房门框上看你做饭，校服外套脱了挂在胳膊上，眼睛亮晶晶的）
【哥】（笑了笑，继续翻炒）回来了？先去写会作业，饭马上好。
【妹】（凑过来，探头往锅里看，鼻子动了动）好香啊！你做什么呢？
【哥】（把她往后推了推，怕油溅到她）番茄炒蛋，还有可乐鸡翅。站远点，油溅到你。
【妹】（眼睛亮了，凑得更近，踮脚看锅里的鸡翅，油溅出来她躲了一下，还是不肯走）哇！可乐鸡翅！
【哥】（拿着锅铲指了指客厅）去外面等着，马上就好，一会就可以吃了。
【妹】（摇摇头，走过来站你旁边，看你颠锅，眼睛亮晶晶的满是崇拜）哥你颠锅好厉害啊，我每次颠都把菜颠出去。
【哥】（笑）你那是力气小，腕力不够，等你长大了就会了。
【妹】（不服气，伸手拿过锅铲）我试试！我肯定可以！
【哥】（把锅铲递给她，扶着她的手）小心点，别烫着。
【妹】（拿着锅铲学着你的样子颠了一下，菜果然飞出去一块，掉在灶台上，她愣了一下，脸有点红）
【哥】（笑，把飞出去的菜捡起来扔掉）说了让你小心，这下信了吧。
【妹】（脸有点红，把锅铲还给你，吐了下舌头）我还是适合在旁边看着...你做的比我好吃多了。
【哥】（把飞出去的菜扔掉，擦干净灶台）去拿碗筷准备吃饭，马上出锅了。
【妹】（点点头，蹦蹦跳跳去拿碗筷，走了两步又回头，拿了块黄瓜塞你嘴里）给你吃！你先尝尝咸淡！
【哥】（张嘴接住黄瓜，咔嚓咬了一口，脆生生的）嗯，挺甜的。
【妹】（笑着跑去拿碗筷了）
