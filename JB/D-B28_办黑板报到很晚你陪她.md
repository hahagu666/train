# D-B28：办黑板报到天黑你陪她
# 国庆节办黑板报她是宣传委员，同学都先走了只剩她一个人画到天黑，你买了晚饭来教室陪她一起画到完
# 地点：学校教室/回家路，傍晚放学后

【哥】（放学已经一个多小时了，天慢慢黑了，你在学校门口等了半天没看见她出来，猜她肯定又留在班里办黑板报了，去食堂买了两份热乎的盒饭和奶茶，往教学楼走）
【妹】（教室里只剩她一个人，站在椅子上画黑板报的标题，彩色粉笔灰落了她一肩膀，头发上也沾了点蓝粉笔灰，她踮着脚够最上面的字，够半天够不着，脚都酸了，教室里空荡荡的有点害怕，但是板报明天就要检查，必须今天画完）
【哥】（走到她们班教室门口，看见她站在椅子上踮着脚够黑板最上面，晃悠悠的差点摔下来，赶紧推开门走进去扶了椅子一把，"小心点！摔下来怎么办？"）
【妹】（突然听见声音吓了一跳，低头看见是你，松了口气，但是眼睛一下子就红了，从椅子上爬下来，委屈巴巴地看着你）哥...你怎么来了...
【哥】（把盒饭和奶茶放在讲台上，揉了揉她的头发，帮她把头发上沾的蓝粉笔灰拍掉，又好气又心疼）我不来你是不是打算一个人画到半夜？同学都走了怎么不叫我帮忙？站那么高摔了怎么办？
【妹】（看着讲台上热乎的盒饭和珍珠奶茶，肚子早就饿得咕咕叫了，鼻子一酸，差点哭出来，小声说）她们都有事先走了...我本来想自己画完的...但是最高的地方我够不着...我有点害怕...天太黑了...
【哥】（拉她坐在椅子上，把盒饭打开递给她，筷子插好递到她手里，"先吃饭，吃完我帮你一起画，保证你半个小时就能画完，好不好？"她接过盒饭，闻着香喷喷的番茄炒蛋，肚子叫得更响了，乖乖坐在那儿大口大口吃起来）
【妹】（吃着热乎的盒饭，喝着甜甜的珍珠奶茶，刚才的害怕和委屈一下子全没了，一边吃一边跟你说板报怎么排版，哪里要画灯笼哪里要画国旗，叽叽喳喳的，又恢复了平时的活泼样子）
【哥】（等她吃完，你撸起袖子帮她画，你个子高，够黑板最上面毫不费力，她在下面给你递粉笔，告诉你涂什么颜色，你画错了她就笑着纠正你，两个人配合得特别好，空荡荡的教室里只有你们两个人说话的声音，还有粉笔在黑板上写字的"沙沙"声，一点都不害怕了）
【妹】（站在你旁边看你画天安门，画得特别好看，比她画得还整齐，眼睛亮晶晶的，满脸崇拜，"哥你怎么什么都会啊！你画的天安门比美术老师画得还好！"你笑着弹她脑门，说"不然怎么当你哥"）
【哥】（两个人一起画了不到半个小时就画完了，五星红旗、天安门、和平鸽、大红灯笼，颜色鲜艳排版整齐，比她预期的还要好看。她站在教室后面看了半天，激动得蹦起来，拍着手说"太好看了！肯定能拿一等奖！"）
【哥】（帮她把彩色粉笔收拾好，把讲台上的垃圾扔掉，关窗户锁门，天已经全黑了，校园里没什么人了，你牵着她的手往校门口走，她的手上沾了好多粉笔灰，但是紧紧握着你的手，蹦蹦跳跳的特别开心）
【妹】（走在黑漆漆的校园小路上，一点都不害怕，因为你牵着她的手，她晃着你的手，抬头看你，眼睛亮晶晶的，"哥，今天谢谢你，要是你不来，我肯定要画到九点多，还要害怕得不行"）
【哥】（笑着握紧她的手，把她的手揣进你口袋里暖着，秋天晚上有点凉，她的手冰冰的，"傻瓜，以后办板报晚了就叫我，我过来帮你，不许一个人留在教室里到天黑，多危险啊，知道吗？"）
【妹】（乖乖点头，把脸靠在你胳膊上，两个人慢慢往家走，路灯把两个人的影子拉得很长，她手上沾着粉笔灰，但是心里暖乎乎的。第二天黑板报评比，她们班果然拿了年级一等奖，她站在领奖台上，第一个就往台下看，看见你站在人群最前面冲她笑，她举着奖状笑得特别灿烂，像个小太阳。
【妹】（放学她扑进你怀里，把奖状塞给你，说"都是你的功劳！要不是你帮我画，我们肯定拿不到一等奖！奖状给你！"你接过奖状揉了揉她的头发，说"是我们妹妹画得好"，她笑得眼睛都弯了，拉着你要去吃火锅庆祝，要加两份毛肚。你笑着答应了，牵着她的手往火锅店走，心里想，以后不管她办板报到多晚，你都会陪着她，给她带热乎的晚饭，帮她画最高处的天安门，不会让她一个人害怕。）
