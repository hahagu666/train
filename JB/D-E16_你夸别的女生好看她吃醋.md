# D-E16：你夸别的女生好看她吃醋
# 地点：客厅，晚上一起看电视
# 情境：电视里女明星出来，你随口说真好看，她听见了立刻不高兴了，鼓着脸不理你

【哥】（晚上吃完饭和她一起坐在沙发上看电视，偶像剧里女主角出场，穿裙子特别好看，你随口说了一句）这女的长得挺好看啊。
【妹】（本来靠在你肩膀上吃薯片，听见这句话，动作停了一下，薯片也不吃了，坐直身体，鼓着脸盯着电视看）
【哥】（没注意她表情，还在看）腿也长，身材真好。
【妹】（把薯片袋往茶几上一放，抱臂靠在沙发另一边，离你远远的，不说话，盯着电视但是眼神明显不在看）
【哥】（这才发现她不对劲，侧头看她）怎么了？
【妹】（别过头不看你，声音闷闷的）没怎么。好看你多看会。
【哥】（笑了，凑过去）生气了？
【妹】（往旁边挪了挪，不让你靠近，鼓着脸，嘴角往下撇）我生什么气，跟我又没关系。你觉得好看就好看呗。
【哥】我就随口一说，电视上的明星嘛。
【妹】（终于回头看你，眼睛有点气鼓鼓的，但是又有点委屈，手指绞着抱枕角）随口一说你还看那么认真！还说人家长腿身材好！你怎么不说我腿也长！
【哥】（忍住笑，看着她气鼓鼓的样子，脸都鼓成包子了）你腿也长，你最好看。
【妹】（哼了一声，但是没刚才那么气了，还是别过头，但是耳朵红了）现在才说，晚了。
【哥】（凑过去把她拉过来，她挣扎了两下就不动了，还是鼓着脸，但是靠在你肩膀上了）真生气了？
【妹】（靠在你肩膀上，手抓着你的衣角，小声嘟囔）我以后也穿短裙...比她还好看...
【哥】那你穿，穿什么都好看。
【妹】（抬头看你，眼睛亮晶晶的，但是还是有点小别扭，伸手掐你胳膊一下）以后不许夸别的女生好看！只能夸我！
【哥】好，只夸你。
【妹】（这才满意了，重新靠回你肩膀上，但是把薯片拿过来自己吃，喂你一片，故意塞你嘴里堵住你的嘴，小声说）电视里的有什么好看的...真人就在你旁边呢...（她把脸埋在你肩膀上，耳朵还是红的，手偷偷抱住你的腰，电视演什么她根本不看了，嘴角偷偷往上扬，但是故意装作还在生气的样子，掐你腰的手都没用力）
