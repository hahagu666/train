# D-B19：运动会接力掉棒她自责哭
# 她跑最后一棒接力，接棒的时候没接住棒掉了，本来班级第一变成倒数第一，她蹲在终点线哭，你过去把她抱起来
# 地点：学校操场/看台，运动会当天

【哥】（运动会女子4×100接力赛，她跑最后一棒，你站在终点线等她，她们班前三棒一直领先，跑第二，眼看就要追上第一了，她接棒的时候手滑了一下，接力棒"啪"地掉在地上，她愣了一秒钟才捡起来，但是已经被其他班超过去了，最后她们班拿了倒数第二）
【妹】（冲过终点线的那一刻，她看着别的班同学欢呼拥抱，手里紧紧攥着接力棒，站在跑道上，眼泪一下子就掉下来了，蹲在地上，把脸埋在膝盖里，哭得肩膀一抽一抽的，特别自责）
【哥】（看见她蹲在地上哭，赶紧跑过去，跑道上还有其他同学在跑，你把她拉起来，带到操场边没人的地方，她蹲在地上不肯起来，哭得稀里哗啦的，话都说不完整）
【妹】（蹲在地上，手使劲攥着接力棒，指节都发白了，哭得抽抽搭搭，声音哽咽）都怪我...都怪我...我没接住棒...我们本来能拿第二的...我把全班的努力都毁了...她们肯定都怪我...
【哥】（蹲在她面前，轻轻拍她的背，想把她拉起来，但是她不肯起来，一个劲哭，眼泪掉在跑道上，把运动服袖子都哭湿了，你心疼得不行，伸手把她打横抱起来）
【妹】（突然被你抱起来，愣了一下，赶紧搂住你的脖子，把脸埋在你肩膀上，哭得更凶了，眼泪把你运动服都打湿了一大片，一边哭一边说）都怪我...我太笨了...我连棒都接不住...她们肯定都讨厌我了...以后再也不让我跑接力了...
【哥】（把她抱到看台上坐下，拿出矿泉水给她喝，又拿毛巾帮她擦脸和汗，但是她越擦眼泪掉得越凶，你干脆就让她靠在你怀里哭，轻轻拍她的背，像哄小孩子一样）不哭了不哭了，不就是掉个棒吗，多大点事，没人怪你，知道吗？
【妹】（靠在你怀里哭了快十分钟，才慢慢停下来，抽抽搭搭的，眼睛肿得像桃子，鼻子红红的，手里还是紧紧攥着那个接力棒，声音闷闷的）怎么没人怪我...我们班练了好久接力赛...每天放学都练...就因为我掉棒...我们倒数第二...大家肯定都很失望...
【哥】（拿过她手里的接力棒放在一边，帮她把散下来的头发别到耳后，认真看着她红红的眼睛，认真地说）没有人怪你，我刚才听见你们班同学都说了，说你跑得特别快，要不是掉棒肯定能拿第一，没有人怪你，大家都知道你不是故意的，接力赛掉棒太正常了，哪个班运动会没掉过棒啊？
【妹】（抬起头看你，眼睛还是红红的，眼泪还挂在脸上，有点不信，抽抽搭搭地问）真的？她们真的没怪我？我刚才看见体育委员脸都黑了...
【哥】（笑着帮她擦眼泪，弹了她脑门一下）他那是跑累的，不是怪你。你看，你们班同学都过来了，肯定是来安慰你的。
【妹】（顺着你指的方向看过去，果然她们班跑接力的几个女生都往这边走过来，手里还拿着水和巧克力，第一个跑过来的就是她的同桌林晓，跑过来就抱她，说"没事没事，我们下次再赢回来"，其他同学也纷纷说"就是，掉个棒而已，你跑得最快了""下次我们再练，肯定拿第一"）
【妹】（看着同学们都来安慰她，没有人怪她，眼泪又掉下来了，但是这次是感动的，抱着林晓哭了一会儿，然后转过头看你，眼睛亮晶晶的，你冲她笑了笑，比了个加油的手势）
【哥】（等同学们都走了，她才回到你身边，眼睛还是肿的，但是已经不哭了，靠在你肩膀上，看着操场上其他比赛，小声说）哥...我刚才真的特别害怕...我怕大家怪我...我怕以后她们都不跟我玩了...
【哥】（揉了揉她的头发，把巧克力剥开喂到她嘴里，巧克力甜甜的，她含着巧克力，心情好多了。你笑着说）你看，大家都那么喜欢你，怎么会怪你呢？而且你跑得那么快，下次运动会我们再把第一赢回来不就行了，对不对？
【妹】（含着巧克力，点了点头，但是还是有点自责，小声说）...下次我一定好好练接棒...绝对不再掉棒了...下次一定给班级拿个第一回来...
【哥】（笑着点头，帮她把运动服拉链拉好，风有点大，别感冒了。你牵着她的手往看台下面走，她的手小小的暖暖的，被你握在手里，虽然刚才哭了半天，但是脚步已经轻快多了，还跟你说下次要练一百米，要拿短跑冠军。
【妹】（走到操场边，她突然停下来，转过身抱了你一下，把脸埋在你胸口，小声说）哥...谢谢你...刚才我蹲在地上哭的时候...我第一个看见的就是你...有你在...我就不难过了...
【哥】（心里一暖，抱紧她，轻轻拍她的背，在她耳边轻声说）傻瓜，不管发生什么事，我都第一个到你身边，就算全世界都怪你，我也不会怪你，知道吗？
【妹】（靠在你怀里，使劲点头，虽然眼睛还是肿的，但是脸上已经露出笑容了。阳光照在操场上，风一吹，她的马尾辫晃啊晃，像什么事都没发生过一样。晚上你带她去吃了她最爱的火锅，她吃着毛肚，早就把掉棒的事忘得一干二净了，叽叽喳喳跟你说下次运动会一定要拿三个金牌给你看）
