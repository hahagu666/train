# D-E34：牵她手过马路她手心出汗
# 地点：马路上，周末一起去超市
# 情境：过马路的时候车很多，你伸手牵住她的手，她瞬间僵住，手心全是汗

【哥】（周末和她一起去超市买东西，过十字路口的时候车特别多，她走在你旁边东张西望，差点被电动车碰到，你伸手一把抓住她的手）看车！
【妹】（被你突然抓住手，整个人一下子僵住了，像被点了穴一样，站在原地忘了动，脸瞬间从耳朵尖红到脖子根，心跳突然就快了，咚咚咚的，自己都能听见，手心一下子就出汗了）
【哥】（拉着她过马路，她的手软软的，小小的，握在手里刚好，就是手心全是汗，过了马路到对面人行道，你以为她会松开，结果她手僵着，没松开）过马路看路，别东张西望的，多危险。
【妹】（这才反应过来，但是手还是被你握着，没抽回去，脸红红的，头埋得低低的，不敢看你，声音小小的，像蚊子叫）哦...知道了...
【哥】（感觉到她手心全是汗，以为她是刚才被吓到了）吓着了？看你手都出汗了。
【妹】（赶紧点头，又赶紧摇头，脸更红了，头埋得更低，手想抽回去又有点舍不得，犹豫了半天还是没抽，手软软的任由你握着，手心的汗越来越多）没...没吓着...就是...就是有点热...
【哥】（笑了，故意逗她，握紧了一点她的手，她的手小小的，软软的，手指细细的）热啊，那我松开？
【妹】（立刻握紧你的手，不让你松开，但是握完就后悔了，脸烫得吓人，头埋得更低，声音小小的，带着点慌乱又有点撒娇）别...别松开...车多...等...等过完马路再说...
【哥】（都已经到人行道了，前面就是超市，根本没有车了，但是她还是紧紧握着你的手不肯放，手指还偷偷动了动，轻轻勾住你的手指，像小钩子一样勾着你）
【妹】（走了一路，脸一直红着，头埋着不敢看你，但是手一直紧紧握着你的手，手指时不时偷偷勾一下你的手指，手心一直出汗，把你的手都弄湿了，但是她一点都不想松开，嘴角偷偷往上扬，自己都没发觉）
【哥】（到了超市门口，该推购物车了，你松开手拿购物车，她的手空在那里，愣了半天，手指还保持着握东西的姿势，脸红红的，有点失落的样子）
【妹】（等你推上购物车，她又立刻凑过来，悄悄把手伸进你手里，握住你的手，头扭到一边看货架，假装在看零食，但是耳朵红得要滴血，声音小小的，假装满不在乎）超市人多...别走丢了...
【哥】（忍住笑，握紧她的手，她的手软软的，还是有点出汗，但是握得紧紧的，逛超市的时候一直牵着，她挑零食的时候都没松开，就用另一只手拿，脸一直红扑扑的，但是嘴角一直扬着，眼睛亮晶晶的，比买到了最爱吃的零食还开心）
【妹】（逛完超市出来，天快黑了，回去的路上她还是一直牵着你的手，这次不紧张了，手指还敢轻轻蹭你的手背，晃来晃去的，像散步的小朋友，脸还是红红的，但是敢偷偷抬头看你了，眼睛亮晶晶的，嘴角扬得高高的，小声说）下次过马路...你还要牵我...（她握紧你的手，手心的汗干了一点，但是还是软软暖暖的，觉得被你牵着手走路，比什么都开心）
