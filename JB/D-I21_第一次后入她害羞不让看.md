# D-I21：第一次后入她害羞不让你看
# 地点：你床上
# 情境：你想试试后入，她害羞趴在床上不敢回头，哄了半天才同意

【哥】（晚上做完一次，你还硬着，抱着她，她趴在你怀里，你拍了拍她软软的屁股。）软软，我们换个姿势好不好？
【妹】（正满足地窝在你怀里，听见你说换姿势，她抬起头，脸红了，有点好奇又有点害羞。）什么姿势呀...
【哥】（你让她跪起来，趴在床上，屁股翘起来对着你，她立刻明白了，脸一下子红透了，赶紧想趴下。）宝贝乖，就试这个姿势。
【妹】（被你抱着腰不让趴下，你吻着她的背哄她，她耳朵红得发烫，声音闷闷的。）不要...这个姿势好羞耻...我不要...
【哥】（你哄着她，吻她的背和后颈。）就试一次，好不好？这个姿势插得深，特别舒服。
【妹】（她趴在床上，把脸埋在枕头里，屁股翘得高高的，手紧紧抓着枕头，声音带着害羞的哭腔。）那...那你不许看我屁股...也不许笑我...
【哥】（你笑着答应，扶着硬邦邦的肉棒，龟头蹭了蹭她湿漉漉的穴口，她穴口一张一合的特别可爱，你慢慢顶进去。）嗯...进来了，好紧。
【妹】（啊...！全部进来的那一刻，她叫出声，这个姿势插得太深了，龟头直接抵在宫颈上，她身体往前一冲，差点趴下去，你抓着她的腰拉住她。）好深...哥...太深了...顶到我肚子里了...
【哥】（你抓着她的腰，开始慢慢抽插，从后面能清清楚楚看见你的肉棒在她小穴里进进出出，白屁股被你撞得晃来晃去，你拍了一下她的屁股。）啪...喜欢吗？
【妹】（啊！你拍她屁股，她抖了一下，小穴一下子收紧了，又羞又爽，脸埋在枕头里，屁股不自觉往后迎。）你别打...羞死人了...啊...
【哥】（你开始加快速度，从后面干她的感觉特别爽，紧紧包裹着你，每一下都整根没入，发出啪嗒啪嗒的肉体碰撞声。）舒服吗？软软，这个姿势舒服吗？
【妹】（舒服...嗯...太舒服了...她哭着点头，再也顾不上害羞，腰自己扭着，屁股往后迎你的动作，奶子在床上晃来晃去。）啊...哥...比刚才深好多...我要到了...
【哥】（你伸手到前面揉她的阴蒂，快速抽插，她抖得更厉害了。）嗯...快到了，叫出来。
【妹】（啊...！她身体猛地绷紧，小穴剧烈收缩，高潮了，紧紧咬着你的肉棒，身体软得快趴下去，你抓着她的腰不让她倒，继续快速抽插了十几下，腰一挺射在她最里面。）啊...哥...
【哥】（你射完趴在她背上，两个人喘了半天，你把她翻过来抱在怀里，她脸红得像苹果，埋在你胸口不敢抬头。）宝贝真棒。
【妹】（捶了一下你的胸口，声音发黏还带着喘息。）都怪你...这个姿势好羞耻...但是...但是好舒服...
【哥】（你笑着吻她的头发，捏了捏她软软的屁股。）那下次还换不换？
【妹】（她脸红了，往你怀里钻，手指在你胸口画着圈，屁股偷偷蹭了蹭你还硬着的肉棒，声音小得像蚊子叫。）...换...但是你不许拍我屁股了...羞死人了...
