# D-A33：攒钱给你买生日礼物
# 你生日快到了，她省了三个月零花钱，每天中午不吃零食，偷偷给你买了你念叨很久的那款无线耳机，生日当天红着脸递给你
# 地点：家里，生日当天晚上放学回家

【哥】（生日当天，你以为她忘了，毕竟她最近天天放学就躲在房间里写作业，也没提你生日的事，你也没说什么，想着晚上自己煮碗面就行。放学回家开门，灯突然亮了，她举着个小蛋糕站在门口，脸上还沾了点奶油）
【妹】（看见你回来，脸一下子红了，有点紧张，把手里藏在背后的东西攥得紧紧的，结结巴巴地说）哥...你...你回来了...生日快乐...
【哥】（愣了一下，然后笑了，换鞋走进来，桌子上摆着个小小的草莓蛋糕，上面歪歪扭扭写着"哥哥生日快乐"，还画了个小兔子，一看就是她自己做的。你揉了揉她的头发）你做的？
【妹】（脸更红了，点点头，手指紧张地抠着背后的包装盒，磨磨蹭蹭走到你面前，把一个包装得漂漂亮亮的小盒子递到你面前，眼睛不敢看你，声音小小的）给...给你的生日礼物...
【哥】（接过盒子，有点惊讶，你记得这款无线耳机，是你上个月跟同学去数码城的时候随口提了一句说音质不错，没想到她记下来了。你抬头看她，她耳朵尖都红了，手指紧张地绞着衣角）你买的？这耳机不便宜啊，你哪来的钱？
【妹】（低着头，声音小小的，有点不好意思）我...我攒了三个月零花钱...每天中午都不吃零食...也没买漫画...就...就攒够了...
【哥】（愣了一下，心里一下子暖得一塌糊涂，她平时最爱吃草莓大福和漫画书，为了给你买耳机，居然三个月没买零食没买漫画，你伸手把她拉进怀里，声音都有点哑了）傻丫头，谁让你攒钱买这个的，你平时想吃什么就买什么，给我买这么贵的东西干嘛。
【妹】（被你抱在怀里，脸通红通红的，把脸埋在你胸口，声音闷闷的）我...我听见你跟同学说这个耳机音质好...你旧耳机不是有一边没声音了吗...我就想给你买个新的...
【哥】（抱着她，心里说不出是什么滋味，又暖又心疼，揉了揉她的头发，亲了亲她的发顶）谢谢你，我特别喜欢，这是我收到过最好的生日礼物。
【妹】（听见你说喜欢，一下子抬起头，眼睛亮晶晶的，笑得特别开心，但是又有点不好意思，小声说）真的吗？你喜欢就好...我还怕你不喜欢呢...我挑了好久才挑到这个颜色的...黑色的...适合你...
【哥】（打开盒子拿出耳机，确实是你喜欢的黑色，音质特别好，你把耳机戴上，摸了摸她的头，笑着说）特别喜欢，我们妹妹送的，我天天戴。
【妹】（笑得眼睛都弯了，拉着你走到桌子边，给你切蛋糕，切了最大的一块递给你，自己切了一小块，小口小口吃着，嘴角沾了奶油也没察觉）
【哥】（看着她吃得像只小花猫，忍不住笑了，伸手帮她擦掉嘴角的奶油，指尖碰到她软软的脸颊，她的脸"唰"地一下就红了，像熟透的樱桃）
【妹】（吃了两口蛋糕，突然抬起头看你，眼睛亮晶晶的，小声问）哥...你...你知道吗...我给你买耳机的时候...店员问我是不是给男朋友买的...我...我当时脸都红了...
【哥】（愣了一下，然后笑了，捏了捏她红红的脸蛋，故意逗她）哦？那你怎么说的？
【妹】（脸更红了，低下头戳蛋糕，声音小得像蚊子）我...我说是给我哥买的...但是...但是我心里想...要是...要是真的是给男朋友买的...也挺好的...
【哥】（心里一动，伸手抬起她的下巴，在她沾了奶油的嘴角亲了一下，她一下子僵住了，眼睛睁得大大的，脸通红通红的，像熟透的苹果。你笑着看着她）那以后就当男朋友送，好不好？
【妹】（整个人都僵在原地，过了好半天才反应过来，脸更红了，"嘤"了一声把脸埋进你怀里，捶了你胸口一下，但是力气轻得像挠痒痒，半天说不出话来，过了好久才小声说）...你讨厌...
【哥】（笑着抱紧她，戴上她送你的耳机，里面放着她最喜欢的那首歌，怀里抱着她，桌子上摆着她亲手做的歪歪扭扭的蛋糕，心里暖得不行，这确实是你过的最开心的一个生日。
【妹】（靠在你怀里，听着你心跳，过了一会儿抬起头，眼睛亮晶晶的，小声说）哥...等我以后赚钱了...我给你买更好的耳机...给你买好多好多东西...
【哥】（笑着亲了亲她的额头，轻声说）好，我等着。但是不用买贵的，你在我身边，就是最好的生日礼物。
【妹】（脸红红的，但是笑得特别甜，往你怀里缩了缩，紧紧抱着你的腰，心想，三个月不吃零食真的太值了，只要你开心，她什么都愿意。）
