# D-K04：不让她吃太多冰她闹脾气
# 大夏天她一天吃了三个冰淇淋还要吃，你不让，她坐在沙发上鼓着脸闹脾气，说你不爱她了

【哥】（从外面回来，一进门就看见她坐在沙发上，手里拿着第四个冰淇淋，包装袋扔了一桌子，你皱起眉头走过去）还吃？今天都吃几个了？
【妹】（咬了一口冰淇淋，巧克力味的，吃得一脸满足，抬头看你，鼓着脸，含糊不清地说）第三个...不对...第四个...怎么了嘛！今天三十多度！热死了！
【哥】（伸手把她手里的冰淇淋拿过来，她"哎"了一声伸手要抢，你举得高高的她够不着）第四个还不够？你忘了上次来例假吃冰疼得直哭，是谁半夜起来给你煮姜茶揉肚子的？
【妹】（够了半天够不着，鼓着脸坐在沙发上，气呼呼地瞪你，手叉着腰）上次是上次！这次是这次！我今天热嘛！就再吃最后一个！吃完这个绝对不吃了！
【哥】（把冰淇淋放进冰箱冷冻层关上门，态度很坚决）不行，最多吃两个，再吃肚子疼了又要哭。想凉快吃西瓜去，我刚买的冰镇西瓜。
【妹】（看见你把冰淇淋收走了，立刻瘪了嘴，往沙发上一靠，抱着抱枕不理你，鼓着脸瞪天花板，声音气鼓鼓的）你不让我吃冰淇淋...你不爱我了...
【哥】（被她气笑了，走过去坐在她身边，她立刻往旁边挪了挪，背对着你，不让你碰。你碰了碰她的肩膀，她"哼"了一声，又往旁边挪了挪）就因为一个冰淇淋，我就不爱你了？
【妹】（背对着你，声音闷闷的，带着点委屈）就是！你以前都让我吃的！现在连个冰淇淋都不让我吃！你就是不爱我了！
【哥】（哭笑不得，伸手从后面把她捞进怀里，她挣了两下没挣开，鼓着脸不看你，但是也没真的用力挣。你从果盘里拿了一块切好的冰镇西瓜递到她嘴边）乖，先吃块西瓜，西瓜也甜，也凉快，吃多了冰淇淋真的会肚子疼，到时候受罪的还不是你自己。
【妹】（扭过头不张嘴，鼓着脸，但是闻到西瓜甜甜的香味，又有点想吃，偷偷用眼睛瞟那块西瓜，咽了下口水，还是硬撑着）我不吃！我就要吃冰淇淋！你不给我吃我就不理你了！
【哥】（故意逗她，把西瓜送到自己嘴边咬了一口，故意说"嗯，真甜，比冰淇淋还甜"）
【妹】（她听见了，立刻转过头瞪你，眼睛瞪得圆圆的，像只小河豚，看你吃得香，更气了，伸手捶你胸口一下，但是力气小得像挠痒痒）你坏！你故意的！
【哥】（笑着把另一块西瓜递到她嘴边，这次她没再拒绝，张嘴咬了一大口，冰镇西瓜甜甜的，汁水特别多，确实凉快。她吃了一口，鼓着脸还是有点气，但是没那么抗拒了，喂她吃了两块西瓜，拿纸巾帮她擦掉嘴角的西瓜汁，语气软下来哄她）不是我不让你吃，你想想，你上次例假疼得打滚，哭着说以后再也不吃冰了，忘了？我这是为了你好，等你例假过了，我带你去吃你最爱的那家芒果冰，让你吃个够，好不好？
【妹】（听你这么说，脸色慢慢缓和了，但是还是有点别扭，揪着你的衣角，小声问）...真的？等我例假过了带我去吃芒果冰？要大份的，加芒果粒加芋圆？
【哥】（笑着点头，揉了揉她的头发）真的，大份的，加双份芒果粒双份芋圆，让你吃个够。但是现在不许再吃冰淇淋了，行不行？
【妹】（鼓着脸想了想，好像芒果冰确实比冰淇淋好吃，而且还是大份的，她勉为其难地点点头，但是还是有点小别扭）...那...那说话算话...不许骗我...
【哥】（笑着伸出小拇指，她伸出小拇指跟你拉钩，大拇指按在一起盖章。拉完钩她还是有点不好意思，往你怀里缩了缩，小声说）...哥...我刚才是不是太任性了...
【妹】（抬头看你，等着你的回答）
【哥】（抱紧她，捏了捏她的脸，笑着说）有点，但是我们妹妹任性也可爱。
【妹】（脸一下子红了，埋在你怀里捶你一下，但是嘴角忍不住往上翘，拿起一块西瓜递到你嘴边）你也吃！西瓜特别甜！
【哥】（张嘴吃了西瓜，确实很甜，但是怀里的人比西瓜还甜，你看着她一口一口吃西瓜，吃得腮帮子鼓鼓的，像只小仓鼠，心想下次还是得看着她点，不能让她吃太多冰）
【妹】（靠在你怀里吃西瓜，一口一口吃得特别香，刚才的气早就消了，嘴角还沾着西瓜汁，偷偷抬眼看你，眼睛亮晶晶的）
