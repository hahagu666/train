# D-E04：害羞被你盯着看
# 地点：你房间，晚上写题
# 情境：她在你书桌前写题，你坐在旁边看她，她被你看得脸红，写不下去题

【哥】（晚上她坐在你书桌前写模拟卷，你坐在旁边沙发上看书，时不时抬头看她，没说话，继续看她）
【妹】（又写了两行，实在写不下去了，抬头瞪你，脸通红）你...你别老看我啊！
【哥】我看我妹妹怎么了。
【妹】（脸更红了，拿笔挡着脸）你看得我都写不下去题了...
【哥】怎么写不下去了？
【妹】（声音小小的，放下笔）...紧张...
【哥】紧张什么，我又不吃人。
【妹】（鼓脸，但是还是红着脸，偷偷看你一眼）你老盯着我看...我就紧张...心跳都快了...
【哥】（笑，凑过去一点）哦？心跳快了？我摸摸。（伸手要摸她胸口）
【妹】（立刻躲开，脸红得像苹果，拍你手）你干嘛！
【哥】不是说心跳快吗，我摸摸是不是真的。
【妹】（捂胸口，背过身去，耳朵尖都红透了）你耍流氓！
【哥】（笑，坐回去）好好好，不逗你了，写题吧。
【妹】（背对着你，半天没动，过了一会偷偷回头，发现你真的在看书没看她，又有点小失落，咬着笔想了想，转过来小声说）...其实...你也不是不能看...
【哥】（闻言立刻放下书，撑着下巴看着她，眼睛里带着笑意）那我就不客气了，我们丫头害羞的样子真好看。
【妹】（脸更红了，赶紧低下头写题，嘴角却忍不住扬起来）
