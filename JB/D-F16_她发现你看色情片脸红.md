# D-F16：她发现你看色情片脸红
# 地点：你房间，你以为她睡着了看片
# 情境：你以为她回房间了，偷偷在房间看色情片，结果她敲门进来送水果，正好看到屏幕

【哥】（晚上你以为她回自己房间睡觉了，关了门偷偷在电脑上看色情片，戴了耳机，声音开得很小，屏幕上男女在做爱，女生呻吟的声音从耳机里传出来，你正看得认真，突然敲门声响起。）
【妹】（她推门直接进来了，你没锁门，她端着一盘西瓜走进来，正好看到电脑屏幕上裸体男女纠缠的画面，女生光着身体坐在男生身上起伏，她一下子僵在原地，盘子差点掉在地上，眼睛睁得圆圆的看着屏幕，脸瞬间从脸颊红到脖子根，整个人都傻了。）哥~我切了西瓜，给你送一块...
【哥】（听见声音赶紧手忙脚乱关页面，但是已经晚了，她全都看见了，你也尴尬得不行，脸也有点热，赶紧把电脑合上，咳嗽了一声，不知道说什么。）那个...我...
【妹】（站在原地，端着西瓜盘，脸红得像熟透的番茄，眼睛睁得圆圆的，脑子里全是刚才屏幕上看到的画面，女生光着身体，还有那个男生那个东西，她心跳快得咚咚咚的，站在那里走也不是留也不是，过了半天，才结结巴巴说出话，声音小得像蚊子叫，带着点颤抖。）你...你在看...看那种东西...
【哥】（尴尬得要死，抓了抓头发，不知道怎么解释，毕竟确实被抓包了。）就是...成年人嘛...偶尔看看...你怎么不敲门就进来了...
【妹】（脸更红了，急得跺脚。）我敲了！
【哥】（你尴尬地咳嗽了一声。）我...我戴耳机了没听见...
【妹】（听见你让她走，她不仅没走，反而悄悄往前走了一步，站在你桌子旁边，手指绞着睡衣裙角，脸红得快滴血，犹豫了半天，才小声问，声音小小的带着好奇和羞涩。）那个...他们...那样不疼吗...
【哥】（愣了一下，没想到她会问这个，看着她脸红扑扑的，眼睛亮晶晶的，满是好奇又害羞的样子，心跳也快了。）这个...等你长大就知道了。
【妹】（鼓着脸，有点不服气，但是脸还是红的，往电脑那边看了一眼，但是电脑已经合上了，她又低下头，手指绞着衣角，过了半天，声音更小了，几乎听不见，带着点羞涩的期待。）那...那你下次看...能不能叫我一起看...我也想知道...
【哥】（你愣在原地，看着她脸红的样子，心跳得厉害。）你...
【妹】（她说完自己先羞得不行，转身就往门外跑，跑到门口又停下来，背对着你，脸红得能冒烟，小声补充了一句。）我就是好奇！没别的意思！
【哥】（你还没反应过来，她就砰地带上门跑了，你坐在椅子上，看着桌上她端来的西瓜，又看了看合上的电脑，心跳半天没平静下来，忍不住笑了。）这丫头...
【妹】（她跑回自己房间靠在门后，捂着火辣辣的脸，心跳快得要从胸口跳出来，刚才屏幕上的画面一直在脑子里转，女生的呻吟声好像还在耳边，她摸了摸自己发烫的脸，下面居然有点痒痒的感觉，羞耻得把脸埋在枕头里，但是又忍不住偷偷笑了。）嗯...
