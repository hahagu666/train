# D-I28：跪趴后入式扶着腰狠狠干
# 地点：你床上
# 情境：她跪趴在床上，屁股翘得高高的，你从后面扶着她腰狠狠干

【哥】（晚上洗完澡，你让她跪趴在床上，屁股翘起来对着你，她害羞但是听话地跪好了，脸埋在枕头里，屁股白白翘翘的，小穴湿漉漉的一张一合。）趴好，屁股翘高点。
【妹】（跪趴在床上，屁股翘得高高的，脸埋在枕头里，耳朵红得发烫，手紧紧抓着枕头，声音闷闷的。）你快点...这样跪着好酸...
【哥】（你扶着肉棒，龟头在她穴口蹭了蹭，她淫水特别多，一下子就滑进去了，你扶着她的腰，直接开始快速抽插，后入式本来就深，加上她跪着，每一下都整根没入，啪嗒啪嗒响。）这就来了。
【妹】（啊！你一上来就这么快，她叫出声，身体往前一冲，被你拉着腰拉回来，白屁股被你撞得晃来晃去，淫水顺着大腿往下流。）哥...慢点...太快了...
【哥】（你没慢，反而抓着她的腰更快地抽插，拍了一下她白白的屁股，留下一个红印。）慢什么，你屁股都翘这么高了，不就是想让我狠狠干你吗。
【妹】（啊...我没有...她嘴上否认，但是屁股却主动往后迎，配合你的动作，小穴紧紧裹着你，淫水越来越多，咕叽咕叽的声音特别响，她脸埋在枕头里，呻吟声闷闷的但是特别大。）嗯...哥...好舒服...打我屁股...再打...
【哥】（你听她这么说，连着拍了她好几下屁股，两边都红了，她小穴一下子收得更紧，叫得更大声，你加快速度狠狠干。）小淫娃，还说不想，被打屁股还更紧了。
【妹】（啊...我是小淫娃...哥的小淫娃...她被你操得胡言乱语，奶子晃来晃去蹭着床单，乳头都蹭红了，腰抖个不停，快高潮了。）哥...我要到了...
【哥】（你伸手到前面揉她的阴蒂，快速抽插，她身体立刻绷紧。）嗯...快到了，叫出来。
【妹】（啊...！她尖叫出声，小穴剧烈收缩，高潮了，身体软得快趴下去，你抓着她的腰不让她倒，继续快速抽插。）啊...哥...
【哥】（又快速抽插了十几下，你腰一挺射在她最深处，射完趴在她背上，两个人喘了半天，她腿软得直接趴在床上，屁股还翘着，你拔出来，精液混着淫水从她小穴里流出来。）嗯...射了...
【妹】（趴在床上，连动都动不了，喘着气，脸红扑扑的，屁股上全是红印，她回头瞪你一眼，但是一点威慑力都没有。）你太狠了...我膝盖都跪红了...
【哥】（你笑着帮她揉膝盖，吻她的背。）下次给你垫个枕头。
【妹】（她脸红了，往你怀里钻。）谁要下次...
【哥】（你捏了捏她还红着的屁股。）刚才是谁说让我再打的？
【妹】（她脸更红了，把脸埋在枕头里不理你，但是嘴角带着笑。）我没有...你听错了...
