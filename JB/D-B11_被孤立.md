# D-B11：被孤立
# 地点：她房间，晚上
# 情境：她因为成绩进步快，被几个女同学排挤，放学一个人走回来，低着头不说话

【哥】（晚上在家等她放学，听见开门声，但是没像往常一样听见她喊"我回来了"，从厨房出来看看）
【妹】（开门进来，换鞋，没像往常一样喊"我回来了"，低着头往房间走）
【哥】回来了？今天怎么这么晚？
【妹】（没回头，声音小小的）...路上走得慢。
【哥】（看她不对劲，跟着进她房间）怎么了？不开心？
【妹】（把书包放椅子上，坐床上，不说话，抠床单）
【哥】（坐她旁边）有人欺负你了？
【妹】（肩膀抖了一下，摇摇头，但眼泪掉下来了）
【哥】（把她拉过来）哭什么，跟哥说。
【妹】（靠你怀里，声音哽咽）...她们说我作弊...
【哥】谁？
【妹】（擦眼泪）上次模考我进步了十五名，张萌她们就在背后说我是抄的...还跟别的同学说不要跟我玩...
【哥】（皱眉）老师知道吗？
【妹】（摇头）我没说...今天收作业，她们把我作业本藏起来，我找了半天没找到，被老师说不交作业...
【哥】（拍她背）你怎么不告诉老师？
【妹】（摇摇头，声音发颤）我怕她们说我打小报告...那样更没人跟我玩了...
【哥】（叹气，摸她头）你没作弊，管她们说什么。
【妹】（哭出来）可是她们都不跟我说话...吃饭也不叫我...今天体育课自由活动，就我一个人站在操场边上...
【哥】（抱紧她）明天我送你去学校，跟你们班主任说。
【妹】（抬头，眼睛红红的）不要...那样她们更要说了...
【哥】不说怎么解决？她们这是校园欺凌，不能惯着。
【妹】（犹豫了一下，靠你怀里不说话）
【哥】明天先跟班主任反映，让老师调监控查作业本是谁藏的。
【妹】（小声）...嗯。
【哥】（擦她眼泪）不哭了，啊？你考得好是你自己努力的，她们那是嫉妒。
【妹】（点点头，擦干净眼泪）...哥。
【哥】嗯？
【妹】（声音黏黏的带着哭后的鼻音）还好回家能看到你...
【哥】（把她抱得更紧了，下巴轻轻抵在她头顶，声音温柔）哥一直都在，只要你回头，哥永远在你身后。
【妹】（靠在你怀里，紧紧抱住你的腰，眼泪又掉下来，但这次是安心的眼泪）
