# D-F04：亲你脖子她呼吸急促
# 地点：你房间，晚上她写完作业
# 情境：她在你房间写完作业赖着不走，趴在你背后抱着你，你开玩笑咬了她耳朵，然后亲她脖子，她瞬间软了

【哥】（晚上她在你房间写作业，写完了不回自己房间，从背后趴在你背上，手臂抱着你的脖子，下巴垫在你肩膀上看你玩手机，头发蹭得你脖子痒痒的，暖暖的呼吸吹在你耳朵上。）还不回去睡觉，明天不上课了？
【妹】（抱着你脖子不撒手，在你肩膀上蹭了蹭，像只撒娇的小猫，声音黏黏甜甜的。）不回去...我房间冷...你房间暖和...再待五分钟...就五分钟...
【哥】（笑着摇了摇头，继续玩手机，她在你背后蹭来蹭去，头发扫得你脖子特别痒，你想逗逗她，转头对着她耳朵轻轻吹了口气，然后轻轻咬了一下她的耳垂。）小懒猫。
【妹】（正哼着歌蹭你脖子，突然被你咬了耳垂，身体像过电一样猛地抖了一下，抱着你脖子的手一下子收紧了，呼吸瞬间就乱了，暖暖的呼吸急促地喷在你脖子上，声音都发颤了。）啊！哥...你干嘛...
【哥】（感觉她身体一下子绷紧了，呼吸变得又快又热，觉得好玩，又对着她脖子亲了一下，嘴唇软软的贴在她脖子皮肤上，亲了一下还轻轻舔了一下。）嗯...这里好软。
【妹】（被你亲在脖子上，还被舔了一下，整个人瞬间没力气了，手臂没力气地挂在你脖子上，身体瘫在你背上，呼吸变得特别急促，热热的一阵一阵喷在你脖子上，身体轻轻发抖，声音发着颤，带着点哭腔。）嗯...啊...哥...别...别亲那里...
【哥】（感觉到她整个人都瘫在你背上，呼吸烫得吓人，身体轻轻抖，觉得有意思，嘴唇贴在她脖子上又亲了几口，从耳后亲到脖子侧面，还轻轻吸了一下，吸出来一个淡淡的红印。）这里很敏感吗？
【妹】（被你吸得浑身发麻，一点力气都没有了，膝盖都发颤，要不是挂在你背上都要滑下去了，呼吸急促得像刚跑完步，嘴里控制不住地发出细细的呻吟声，声音小小的，带着点哭腔，又害羞又舒服，想推开你但是手一点力气都没有，脸烫得能煎鸡蛋，声音抖得不成样子。）嗯...啊...别...别吸...会留印子的...妈妈会看到的...
【哥】（听见她声音都发颤了，笑着转过去看她，她整个人挂在你身上，脸通红通红的，眼睛水汪汪的像蒙了一层水汽，嘴唇微微张着喘气，胸口随着呼吸剧烈起伏，脖子上那个淡淡的红印特别明显，她看见你看她，立刻把脸埋在你肩膀上，不敢抬头。）怕什么，又看不到。
【妹】（把脸埋在你肩膀上，身体还在轻轻发抖，呼吸还是没平复下来，暖暖的一阵一阵喷在你脖子上，手紧紧抓着你的衣服，过了半天才找回自己的声音，黏黏的，像撒娇又像抱怨，带着点哭腔。）你欺负我...
【哥】（伸手揉了揉她的头发，她头发软软的，脸烫得吓人，身体还在轻轻抖，拍了拍她的背。）谁让你赖在我房间不走。
【妹】（在你肩膀上蹭了蹭，把脸埋得更深，不仅没撒手，反而抱得更紧了一点，身体没力气地贴在你背上，过了半天，声音小小的，带着点害羞的期待，呼吸还没完全平稳，热热的喷在你脖子上，她说完自己先脸红透了，但是没抬头，就那么埋在你肩膀上，等着你的嘴唇再贴上来，心跳快得你都能感觉到。）那...那你再亲一下...就一下...
