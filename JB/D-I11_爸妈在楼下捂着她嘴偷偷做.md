# D-I11：爸妈在楼下客厅你在她房间捂着她嘴偷偷做
# 地点：她房间，周末下午
# 情境：爸妈在楼下客厅看电视，你在她房间，她不敢出声，你捂着她嘴偷偷做

【哥】软软，在写作业呢？（周末下午，爸妈在楼下客厅看电视，声音开得不算小，你溜进她房间，她正趴在书桌上写作业，穿着吊带睡裙，你从后面抱住她。）
【妹】（突然被人从后面抱住，她吓了一跳，回头看见是你，松了口气，但是立刻紧张起来，指了指楼下，小声说。）别闹！爸妈在楼下呢！
【哥】（你吻她的脖子，手伸进她睡裙里摸她的乳房，她乳头一下子硬了，你凑在她耳边小声说。）没事，他们在看电视，听不到。
【妹】（她身体抖了一下，想推开你，但是手没力气，下面已经湿了，她咬着嘴唇，小声求饶。）不行...会被听见的...晚上好不好...晚上我去你房间...
【哥】（你没听她的，直接把她按在书桌上，睡裙撩起来，露出白白的屁股，她内裤是粉色的，你拉下来，扶着肉棒对准她穴口，龟头蹭了蹭湿滑的穴口。）现在就要，等不到晚上。
【妹】（啊！你突然插进来，她吓得叫出声，你赶紧用手捂住她的嘴，她的声音闷在你手心里，身体绷紧，小穴紧紧裹着你，她眼泪都快出来了，回头看着你，眼睛水汪汪的带着求饶。）唔...
【哥】（你捂着她的嘴，在她耳边小声说，腰开始慢慢抽插。）不许叫，叫出声被爸妈听见就完了，知道吗？
【妹】（她赶紧点头，眼泪汪汪的，但是你每一下都插得很深，顶在书桌上，她舒服得忍不住想哼，全部闷在你手心里，小穴里不停流水，作业被她压在身下，笔掉在地上。）唔...唔...哥...
【哥】（你开始加快速度，肉棒在她湿滑的小穴里快速抽插，发出咕叽咕叽的水声，好在楼下电视声音够大，应该听不见，你另一只手揉着她的阴蒂。）唔...夹紧了...
【妹】（啊...太舒服了...她被你捂着嘴，只能发出呜呜的声音，身体抖个不停，奶子被压在书桌上蹭来蹭去，乳头硬得发疼，她腰不自觉往上抬，配合你的动作，但是又不敢动太大。）唔...嗯...
【哥】（你故意插得更深更快，她抖得更厉害，眼泪都流出来了，流在你手背上，你在她耳边说。）舒服吗？叫老公，叫老公我就让你高潮。
【妹】（她脸红得快滴血，但是被你操得受不了，在你手心里小声呜呜地叫。）唔...老...公...
【哥】（你听她叫老公，更兴奋了，快速抽插了十几下，揉着她阴蒂的手加快速度，她身体猛地绷紧。）嗯...这才乖...
【妹】（唔...！她高潮了，小穴剧烈收缩，紧紧咬着你的肉棒，身体软得趴在书桌上，连呜呜的声音都发不出来，眼泪流了一脸。）唔...哥...
【哥】（她高潮的时候夹得你太爽了，你腰一挺，全部插进去，射在她里面，精液一股股喷在她子宫里。）啊...射了...
【妹】（你射的时候她又抖了一下，趴在书桌上喘了半天，你才松开捂着她嘴的手，她大口喘着气，脸红得像熟透的苹果，回头捶了你一下，声音还带着哭腔发颤。）你混蛋...差点被爸妈听见...吓死我了...
【哥】（你笑着吻掉她的眼泪，帮她把内裤拉好，睡裙放下来，捡起地上的笔。）这不是没听见吗，刺激不刺激？
【妹】（她脸更红了，瞪了你一眼，但是下面还在流你的精液，她夹着腿，小声说。）刺激个鬼...下次不许了...
【哥】（你捏了捏她的脸，笑着说。）下次还来。
【妹】（她脸红得不行，赶紧整理作业本，但是作业本湿了一片，是她的淫水，她脸更红了，赶紧藏起来。）都怪你！作业本都湿了！
