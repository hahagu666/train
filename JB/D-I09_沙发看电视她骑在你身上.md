# D-I09：沙发看电视她骑在你身上
# 地点：客厅沙发，晚上爸妈出去散步了
# 情境：晚上爸妈出去散步，你们在沙发上看电视，看着看着就摸起来，她骑在你身上做，电视还开着

【哥】这个电视剧确实挺无聊的。（晚上爸妈出去散步了，家里就你们两个人，你们坐在沙发上看电视，她窝在你怀里，穿着宽松的家居服，头靠在你肩膀上，吃着薯片。）
【妹】（窝在你怀里，看着电视，手拿着薯片喂你一片，脚搭在茶几上，家居服裤子松松的，露出一点脚踝，她蹭了蹭你的脖子。）这个电视剧好无聊啊...
【哥】（你手搭在她腰上，顺着她的腰往下摸，摸到她大腿，光滑的皮肤，她今天没穿内裤？不对，穿了短裤，你手伸进她裤腿里。）无聊就做点不无聊的。
【妹】（被你摸到大腿，她抖了一下，脸红了，看了一眼门口，爸妈刚走，要一个小时才回来，她小声说。）别...爸妈一会就回来了...
【哥】（你手往上摸，摸到她内裤，已经湿了一片，你凑在她耳边说。）他们要一个小时才回来，来得及。
【妹】（她咬着嘴唇，看了看大门，又看了看你，眼睛水汪汪的，主动伸手解开你裤子拉链，把你的肉棒掏出来，已经硬了，她脸红扑扑的。）那...那你快点...别弄太大声...
【哥】（你把她短裤和内裤拉到腿弯，扶着肉棒对准她湿滑的穴口，她扶着你的肩膀，慢慢往下坐，龟头一点点挤进去，她啊了一声，赶紧捂住嘴。）嗯...进来了...
【妹】（嗯...全部坐进去，肉棒深深插在小穴里，她坐在你腿上，背对着电视，面对着你，开始慢慢动，电视还在放着广告，声音不大不小，刚好能盖住声音，她小声呻吟着。）哥...好深...沙发好软...
【哥】（你靠在沙发上，看着她在你身上起伏，白白的乳房在宽松的家居服里晃，你伸手把她衣服撩起来，含住她的乳头吸吮，手抱着她的腰帮她动。）唔...你的乳头硬了...
【妹】（啊...被你吸着乳头，她舒服得叫出声，又赶紧捂住嘴，腰动得越来越快，小穴里不停流水，顺着你的蛋蛋流在沙发上，她怕弄脏沙发，但是停不下来，小声哼着。）嗯...哥...别吸了...太舒服了...我要高潮了...
【哥】（你松开她的乳头，吻住她的嘴唇，不让她叫出声，手揉着她的阴蒂，腰往上挺，每一下都从下往上顶到她最深处。）嗯...别叫出声...
【妹】（唔...她吻着你，呻吟声都被你吞进肚子里，腰抖个不停，小穴剧烈收缩，高潮了，身体软得趴在你身上，喘着气。）唔...哥...
【哥】（她高潮了还在动，你抱着她的腰快速抽插了十几下，也忍不住了，腰一挺全部插进去，射在她里面。）啊...射了...
【妹】（你射在里面的时候她又抖了一下，趴在你身上喘了半天，电视上广告播完了，电视剧又开始了，她赶紧想起来，但是你抱着她不让走。）别...拔出来...我要去擦...一会沙发脏了...
【哥】（你抱着她不让她动，肉棒还插在她小穴里，吻了吻她的脸。）没事，垫了浴巾，脏不了。
【妹】（她这才发现你早就垫了浴巾在沙发上，脸红了，捶了一下你的胸口。）你早就预谋好了是不是！坏死了！
【哥】（你笑着捏了捏她的屁股，拍了一下。）是你自己坐上来的，小淫娃。
【妹】（她脸红得不行，往你怀里钻，这时候听见钥匙开门的声音，她吓得脸都白了，赶紧从你身上下来，拉好裤子，但是肉棒拔出来的时候精液顺着腿流下来，你赶紧拿纸巾给她擦。）完了完了爸妈回来了！
【哥】（你赶紧拉好拉链，把她搂在怀里假装看电视，爸妈进来的时候，她脸还红通通的，你淡定地跟爸妈打招呼，她紧张得手都在抖。）爸妈回来了。
【妹】（她赶紧把脸埋在你肩膀上，假装在你怀里睡觉，耳朵红得快滴血，手偷偷在你腰上掐了一把，声音小得像蚊子叫只有你能听见。）都怪你...等爸妈走了看我怎么收拾你...
