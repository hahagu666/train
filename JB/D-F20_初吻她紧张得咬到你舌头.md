# D-F20：初吻她紧张得咬到你舌头
# 地点：你房间，晚上爸妈都睡了
# 情境：晚上在你房间，气氛暧昧，你第一次吻她，她紧张得浑身发抖，不小心咬到你舌头

【哥】（晚上爸妈都睡了，她赖在你房间不走，坐在你床上跟你聊天，聊到很晚，灯关了只开了个小台灯，暖暖的光线下她脸红扑扑的，特别好看，你看着她的嘴唇粉润润的，忍不住凑过去。）
【妹】（正跟你说学校里的事，说得开心，突然看见你凑过来，离她越来越近，她一下子停住不说了，眼睛睁得圆圆的看着你，呼吸瞬间停了，身体一下子僵住，脸瞬间红透了，想往后躲但是背已经靠着墙了，没地方躲，只能看着你越凑越近，心跳快得咚咚咚的，像要从胸口跳出来。）哥...你...你干嘛...
【哥】（没说话，看着她红红的脸和亮晶晶的眼睛，还有粉润润微微张着的嘴唇，凑上去，嘴唇轻轻贴在她的嘴唇上，软软的，润润的，带着她刚吃的草莓糖的甜味。）
【妹】（嘴唇被你碰到的瞬间，她整个人像被雷击中了一样，浑身僵硬，脑子嗡的一声一片空白，眼睛睁得大大的，连呼吸都忘了，就那么僵着，嘴唇软软的被你亲着，身体抖得像筛糠一样，她太紧张了，下意识地咬了一下，啊...结果牙齿咬到了你伸进来的舌头。）啊...
【哥】（舌头突然被她咬了一下，疼得嘶了一声，赶紧退开，捂着舌头看着她。）嘶...
【妹】（这才反应过来自己咬到你了，看见你皱着眉捂舌头，她一下子慌了，脸通红通红的，眼睛都急出眼泪了，赶紧凑过来，手足无措看着你，声音都快哭了，带着哭腔的撒娇。）对...对不起！我不是故意的！我太紧张了...我从来没亲过...疼不疼啊...我看看...
【哥】（看着她急得快哭了，脸通红，眼睛水汪汪的，嘴唇被亲得红红的润润的，特别可爱，也不疼了，忍不住笑了，揉了揉她的头。）没事，不疼，谁让你这么紧张。
【妹】（看见你笑，知道你没生气，松了口气，但是脸还是红得像熟透的苹果，不好意思地低下头，手指绞着睡衣衣角，过了半天，抬起头看你，眼睛水汪汪的，嘴唇粉粉的还带着被亲过的红润，声音小小的带着羞涩和期待。）那...那我们再试一次好不好...这次我肯定不咬你了...
【哥】（看着她期待的眼神，脸红扑扑的，嘴唇微微嘟着，等你亲她，心跳也快了，凑过去，又轻轻吻住她的嘴唇，这次她没睁眼，乖乖闭着眼睛，虽然还是紧张得身体微微发抖，但是牙齿没再咬，嘴唇软软的任由你亲，过了一会，她还学着你的样子，笨拙地轻轻回应你，虽然动作很生涩，但是软软的，特别甜。）嗯...
【妹】（闭着眼睛被你亲着，脑子一片空白，浑身都没力气了，手不自觉地抓住你的衣服，紧紧抓着，身体轻轻发抖，嘴唇软软的和你贴在一起，草莓糖的甜味在两个人嘴里散开，她笨拙地学着你的样子动了动嘴唇，虽然生涩，但是特别认真，亲了半天，你退开的时候，她还追着轻轻碰了一下你的嘴唇，然后才反应过来，脸埋在你胸口，不敢抬头，喘着气，身体没力气得像没有骨头一样，声音闷闷的带着撒娇和羞涩。）哥...我喘不上气了...
【哥】（抱着她软软的身体，她趴在你胸口，脸烫得吓人，呼吸暖暖的喷在你脖子上，心跳快得你都能感觉到，拍了拍她的背。）傻丫头，换气都不会。
【妹】（趴在你怀里，过了半天，才抬起头，脸红扑扑的，嘴唇被亲得红红的润润的，眼睛水汪汪像蒙了一层雾，看着你，然后凑过来，飞快地又在你嘴唇上亲了一下，然后立刻把脸埋回你胸口，声音小小的带着笑意和撒娇，抱着你的腰，紧紧贴在你怀里，嘴角一直扬着，嘴唇上还留着你的温度和草莓糖的甜味，初吻的感觉，比她想象的还要甜一万倍，她赖在你怀里，再也不想起来了。）我学会了...这次没咬到你...
