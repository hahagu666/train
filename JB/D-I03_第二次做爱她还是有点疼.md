# D-I03：第二次做爱她还是有点疼
# 地点：你床上，第二天晚上
# 情境：第一次之后第二天晚上，她主动要你，进去还是有点疼，但是比第一次好多了

【哥】（第二天晚上，爸妈都睡了，她溜进你房间，爬到你床上，钻进你被窝里，身体暖暖的贴过来。）怎么过来了？
【妹】（钻进你被窝，从后面抱着你的腰，脸贴在你背上，声音黏黏的，有点不好意思。）哥...你睡了吗...
【哥】（你转过身，抱住她，她身体软软的，穿着睡衣，能感觉到她心跳很快。）还没，怎么了？下面还疼吗？
【妹】（她脸红了，摇摇头，小手往下摸，摸到你已经硬了的肉棒，轻轻握了握，声音更小了。）不怎么疼了...哥...我想要...
【哥】（你愣了一下，摸了摸她的脸。）不疼了？不行，再休息一天，别弄伤了。
【妹】（她摇摇头，凑过来吻你的嘴唇，手轻轻套弄你的肉棒，腿搭在你的腰上，小穴隔着内裤蹭你的腿，已经有点湿了。）真的不疼了...我想要你...哥...给我嘛...
【哥】（被她蹭得硬得更厉害了，你吻着她，手伸进她睡衣里摸她的乳房，她乳头一下子硬了。）真的不疼？疼就说。
【妹】（她嗯了一声，主动脱掉自己的内裤，分开腿，拉着你的手放在她湿漉漉的小穴上，引导你扶着肉棒对准她穴口，眼睛水汪汪看着你。）嗯...你轻一点进来就好...
【哥】（你扶着肉棒，龟头抵在她湿滑的穴口，这次比第一次滑多了，你慢慢顶进去，她还是啊了一声，身体绷紧了。）那我进去了。
【妹】（嘶...还是有点疼，但是比第一次好多了，是那种胀胀的疼，她咬着嘴唇，手抓着你的胳膊，呼吸急促，但是没让你停，反而把你往她怀里拉。）嗯...进来...哥...
【哥】（你慢慢全部插进去，她小穴还是紧紧的裹着你，比第一次更热更紧，你不敢动，吻着她的脸。）疼吗？
【妹】（她摇摇头，过了几秒，那种胀疼慢慢退去，变成一种满满的感觉，她轻轻动了动腰，嗯了一声，小声说。）不疼了...你动一动...
【哥】（你开始慢慢抽动，不敢太快，浅浅的抽插，每一下都能感觉到她小穴紧紧吸着你。）嗯...那我动了。
【妹】（你慢慢动着，她小声呻吟着，手抱着你的脖子，腿环住你的腰，这次比第一次舒服多了，那种胀胀的感觉里带着一点麻，她小声哼着。）嗯...哥...舒服...
【哥】（你看她不疼了，稍微加快了一点速度，吻着她的脖子，手揉着她的乳头。）真的舒服？
【妹】（她嗯了一声，脸红红的，眼睛水汪汪的，主动抬腰配合你的动作，小穴里流出更多水来，滑溜溜的。）真的...比昨天舒服...嗯...
【哥】（你越动越快，她小穴紧紧裹着你，快感越来越强，你抱着她，在她耳边说。）我要射了...
【妹】（她赶紧搂紧你，腿把你夹得更紧，小穴收缩着，声音黏黏的带着撒娇。）射在里面...哥...给我...
【哥】（你腰一挺，全部插进去，射在她深处，一股股精液喷在她子宫口。）啊...射了...
【妹】（你射的时候她感觉到一股暖流冲进来，她也舒服得身体发抖，小穴不停收缩，抱着你喘了半天，等你软了才松开腿。）啊...哥...好烫...
【哥】（你趴在她身上喘了会气，慢慢退出来，这次没有流血，你松了口气，抱她去清理。）嗯...这次没流血。
【妹】（她腿还是有点软，靠在你怀里让你帮她擦，脸红扑扑的，小声说。）哥...这次真的好舒服...
【哥】（你亲了亲她的额头，把她抱回床上搂紧。）以后会越来越舒服的。
【妹】（她往你怀里钻，抱着你的腰，满足地闭上眼睛。）那以后天天要...
