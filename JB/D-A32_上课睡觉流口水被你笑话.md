# D-A32：上课睡觉流口水被你笑话
# 她前一天晚上复习到太晚，语文课打瞌睡睡着了，口水流了一课本，你下课过去拍她，她醒了脸通红追着你打
# 地点：学校教室/走廊，语文课下课

【哥】（语文课下课，你去她教室找她借橡皮，一进门就看见她趴在桌子上睡得正香，头枕着胳膊，嘴巴微微张着，语文课本上湿了一大片，还亮晶晶的，明显是流口水了。同桌在旁边憋笑憋得肩膀都抖）
【妹】（睡得正香，还吧唧了两下嘴，梦见你给她买草莓蛋糕，刚要咬一口，突然被人拍了一下肩膀，迷迷糊糊抬起头，眼睛都睁不开，含糊不清地说）...干嘛...下课了吗...
【哥】（憋着笑，站在她桌子旁边，指了指她课本上那一大片口水印，故意大声说）哟，我们妹妹上课睡觉就算了，怎么还流口水啊？这课本都被你淹了，梦见吃什么好吃的了，口水流这么长？
【妹】（迷迷糊糊的，还没反应过来，顺着你指的方向低头一看，语文课本上湿了好大一片，亮晶晶的，还在往下滴，她瞬间就清醒了，脸"唰"地一下从耳朵尖红到脖子根，赶紧用袖子去擦，越擦越明显，周围同学都看过来，哄堂大笑）
【哥】（笑着看着她手忙脚乱擦口水）
【妹】（又羞又窘，脸通红通红的，抬头瞪你，眼睛里都快冒出火来了，抓起课本就往你身上砸）你混蛋！你不许笑！不许看！
【哥】（笑着躲开，举着手投降，但是还是忍不住笑）好好好我不笑，但是你流口水也太可爱了吧，是不是梦见我给你买草莓蛋糕了？
【妹】（脸更红了，羞得恨不得找个地缝钻进去，站起来追着你打，你笑着往教室外面跑，她追了你半条走廊，最后在楼梯拐角追上你，捶了你好几下，力气小得像挠痒痒，脸还是红得像熟透的苹果）
【哥】（被她追着打也不生气，反而觉得她脸红的样子特别可爱）
【妹】（鼓着脸瞪你，眼眶都羞红了，声音小小的，又气又羞）都怪你！你故意的！你故意大声说让全班都听见！我以后怎么见人啊！他们肯定要笑我一学期！
【哥】（看她真的快羞哭了，赶紧止住笑，把她拉到走廊没人的地方，帮她理了理睡乱的头发，从口袋里掏出纸巾递给她擦课本）好了好了，我错了，不该大声说，我跟你道歉好不好？谁让你前一天晚上复习到那么晚，不困才怪呢。
【妹】（接过纸巾擦课本，擦了半天还是有印子，鼓着脸不理你，但是嘴角还是忍不住微微翘起来，其实她自己也觉得好笑，就是太丢人了，小声嘟囔）...还不都怪你...昨天晚上非要让我把那套数学卷子做完...做到十二点...困死我了...
【哥】（笑着揉了揉她的头发，把她额前睡翘起来的一撮头发按下去）那也是为了你好啊，马上考试了，多做一套题多拿点分。但是下次上课不许睡觉了，再睡觉流口水被老师看见，老师也要笑话你，知道吗？
【妹】（鼓着脸点点头，但是还是有点气不过，伸手掐了你腰一下，小声说）...那你不许把这件事告诉别人...也不许再笑我...不然我就...我就再也不理你了...
【哥】（憋着笑点点头，故意板着脸说）好好好，我不告诉别人，也不笑你，但是你得告诉我，你刚才睡觉梦见什么了，口水流那么长？是不是梦见我给你买好吃的了？
【妹】（脸一下子又红了，她刚才真的梦见你给她买草莓蛋糕了，刚咬了一口就被你拍醒了，她捶了你胸口一下，把头埋在你胳膊上，声音闷闷的）...我才不要告诉你...反正不是梦见你...
【哥】（被她嘴硬的样子逗笑了，从书包里掏出你早上买的草莓大福递给她）好了，不逗你了，给你买的草莓大福，吃点东西补补，省得你下节课接着睡觉流口水。
【妹】（眼睛一下子亮了，接过草莓大福，咬了一口，甜甜的豆沙和草莓在嘴里散开，刚才的羞恼一下子就没了，但是还是鼓着脸瞪你一眼）...这次就原谅你...下次再笑话我...我就把你那份也吃了...
【哥】（笑着点头，看着她鼓着脸吃草莓大福，腮帮子鼓鼓的像只小仓鼠，嘴角还沾了点豆沙，特别可爱，忍不住伸手帮她擦掉，她脸又红了，但是没躲开）
【妹】（上课铃响了，她抱着课本往教室跑，跑了两步又回头，冲你做了个鬼脸，小声喊）"不许告诉别人！"
【哥】（笑着点点头，看着她跑回教室）
【妹】（回到座位上，摸着自己还发烫的脸，偷偷笑了，虽然被笑话了，但是草莓大福真好吃）
