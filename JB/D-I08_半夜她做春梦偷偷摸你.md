# D-I08：半夜她做春梦偷偷摸你
# 地点：你床上，半夜
# 情境：半夜你睡得迷迷糊糊，她在做春梦，手偷偷摸你肉棒，把你弄醒了

【哥】（半夜你睡得正香，迷迷糊糊感觉有一只软软的小手在摸你下面，握住你的肉棒轻轻套弄，你一下子醒了，黑暗里看见她窝在你身边，闭着眼睛，脸红红的，呼吸急促，手还在动。）唔...你在干嘛？
【妹】（睡得迷迷糊糊的，做了个春梦，梦里你在要她，她身体发烫，手不自觉地往下摸，握住你硬硬的肉棒，轻轻套弄，嘴里还发出小小的呻吟声，完全没醒。）唔...哥...
【哥】（你看着她闭着眼睛偷摸你，还说梦话叫哥哥，又可爱又色情，你没叫醒她，就那么躺着让她摸，手轻轻摸着她的头发。）嗯...继续摸...
【妹】（摸了半天，她迷迷糊糊睁开眼睛，发现自己手正握着你的肉棒，你醒着看着她，她啊了一声，脸瞬间红透了，手像触电一样想收回来，被你抓住了。）啊...哥...你醒了...
【哥】（你抓住她的手不让她收回去，反而让她继续握着，凑在她耳边小声说。）摸都摸了，怎么不继续了？
【妹】（黑暗里她脸红得能冒烟，手被你抓着继续放在你的肉棒上，她又羞又想要，身体烫得吓人，小穴早就湿了一片，她小声说，声音发颤带着哭腔。）我...我做了个梦...梦见你...
【哥】（你把她拉过来，吻住她的嘴唇，手伸进她内裤里，摸到她湿漉漉的小穴，阴蒂硬邦邦的。）梦见我怎么了？梦见我要你是不是？
【妹】（啊...被你摸到阴蒂，她浑身一颤，主动分开腿，让你的手指摸进去，吻着你的嘴唇小声嗯了一声，手继续套弄你的肉棒。）嗯...梦见你插进来...好舒服...我就...
【哥】（你手指在她小穴里抽插，她淫水好多，手指抽插发出咕叽的声音，你吻着她的脖子。）那我现在就满足你好不好？
【妹】（她赶紧点头，主动脱掉自己的内裤，分开腿，扶着你的肉棒对准自己穴口，自己往下坐，黑暗里一下子全部坐进去，她啊的一声叫出来，赶紧捂住嘴怕被听见。）啊...
【哥】（她直接坐到底，小穴紧紧裹着你，半夜里她里面特别热特别紧，你抱着她的腰，让她自己动。）自己动，小淫娃，想要就自己来。
【妹】（她脸红得不行，但是骑在你腰上，开始自己上下动，半夜里不敢出声，咬着嘴唇，只有小小的压抑的呻吟声，小穴里不停流水，床轻轻晃着，她小声哼着。）嗯...哥...好深...半夜做...好刺激...
【哥】（你看着她在你身上动，月光照进来一点，能看见她白白的乳房晃来晃去，你伸手揉着她的乳头，腰往上挺配合她。）舒服吗？
【妹】（舒服...嗯...她动得越来越快，小穴紧紧夹着你，快高潮的时候她俯下身，咬着你的肩膀不让自己叫出声，身体抖个不停，小穴剧烈收缩。）哥...我要去了...
【哥】（你抱着她的腰快速往上挺，顶得她啊的一声闷叫，高潮了，小穴死死咬着你的肉棒，你也忍不住了，腰一挺射在她里面。）啊...射了...
【妹】（你射的时候她还在高潮，身体抖了好半天才软下来，趴在你胸口喘着气，脸红红的，小声说。）丢死人了...居然做春梦摸你...
【哥】（你抱着她，吻了吻她汗湿的额头，笑着说。）不丢人，以后想要就直接叫醒我，别偷偷摸摸自己摸。
【妹】（她把脸埋在你胸口，捶了一下你的胸口，小声说。）谁偷偷摸摸了...人家是在做梦...
【哥】（你笑了，拍了拍她软软的屁股。）嗯，做梦，下次做梦记得叫醒我一起做。
【妹】（她脸红得更厉害了，往你怀里钻，抱着你的腰，腿还搭在你的腿上，肉棒还插在她小穴里没拔出来，没过一会就睡着了，嘴角还带着满足的笑。）嗯...知道了...
