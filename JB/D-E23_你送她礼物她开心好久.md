# D-E23：你送她礼物她开心好久
# 地点：家里，她生日那天
# 情境：她生日你送了她上次逛街盯着看了好久的那个发夹，她开心得抱着你跳

【哥】（她生日，吃完饭你从包里拿出个小盒子递给她，她盯着那个盒子看了半天，眼睛一下子亮了）生日快乐。
【妹】（坐在沙发上，看着你递过来的小盒子，愣了两秒，才伸手接过去，手指都有点抖）给我的？
【哥】不然给谁。
【妹】（小心翼翼打开盒子，里面是上次她跟你一起逛街，在饰品店盯着看了好久但是没舍得买的那个小兔子发夹，水钻做的眼睛，特别精致，她当时看了好久说太贵了没买，她一下子捂住嘴，眼睛瞬间红了）你...你怎么买这个了...
【哥】上次看你盯着看了半天，就买了。喜欢吗？
【妹】（使劲点头，眼泪都掉下来了，但是嘴角一直扬着，笑得合不拢嘴，拿出发夹翻来覆去看，看了半天，抬头看你，眼睛亮晶晶的全是眼泪，但是笑得特别开心）喜欢！特别喜欢！我以为你没注意...
【哥】你都快趴在玻璃上了，我怎么没注意。
【妹】（脸一下子红了，但是还是特别开心，把发夹拿起来递到你面前）哥你帮我戴上！
【哥】（接过发夹，她乖乖坐好，头发散着，你帮她把发夹夹在她刘海边，小兔子刚好露在外面，特别好看）好了。
【妹】（立刻跑去照镜子，在镜子前面转了两圈，摸了摸发夹，笑得眼睛都弯成月牙了，跑回来扑进你怀里，抱着你脖子跳了两下）好看吗好看吗！
【哥】好看，我们妹妹最好看。
【妹】（抱着你脖子不撒手，脸埋在你颈窝，笑得特别开心，身体都在轻轻晃，声音里全是笑意）我太喜欢了...这是我收到最好的礼物...（她抬起头，在你脸上亲了一大口，啵的一声，然后又不好意思地脸红了，但是还是抱着你不撒手）
【哥】不就是个发夹，看你开心的。
【妹】（鼓着脸，但是嘴角还是扬着，摸着头上的发夹，小心翼翼的，生怕碰掉了）这不是普通的发夹！是你送我的！（她把脸埋在你胸口，抱着你的腰，声音小小的，带着点撒娇）你怎么知道我喜欢这个...我当时都没说我想要...
【哥】你盯着看了五分钟，我又不瞎。
【妹】（抬起头看你，眼睛亮晶晶的，脸红红的，突然又凑过来，在你另一边脸上也亲了一下，然后抱着你，把脸埋在你肩膀上，声音发甜）哥你真好...我以后天天都戴这个...睡觉都不摘...（她说到做到，那天晚上睡觉真的没摘，第二天早上起来头发乱蓬蓬的，发夹歪了但是还在头上，跑过来给你看，笑得特别开心，像拿到了全世界最好的宝贝，那之后整整一个星期，她天天都戴着那个发夹，谁问她她都特别骄傲说这是我哥送我的，眼睛亮得像装了星星）
