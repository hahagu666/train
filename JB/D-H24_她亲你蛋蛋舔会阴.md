# D-H24：她亲你蛋蛋舔会阴
# 地点：你床上
# 情境：她这次不着急含龟头，从蛋蛋开始，亲遍蛋蛋和会阴，最后才含龟头

【哥】（你靠在床头，她跪在你两腿之间，这次她不急着含龟头，低下头看着你的蛋蛋。）
【妹】（她抬起头对你笑了笑，小手轻轻把你的肉棒往上抬起来，低下头，先在左边蛋蛋上轻轻亲了一口，嘴唇软软的。）哥，我今天先亲它们好不好？
【哥】（你笑着点头，摸了摸她的头。）好，怎么亲都可以。
【妹】（她听见你答应，开心地低下头，小嘴在两个蛋蛋上亲来亲去，像亲果冻一样，轻轻的，软软的，然后伸出舌头，慢慢舔着整个阴囊，把两个蛋蛋都舔得湿漉漉的。）嗯...
【哥】（蛋蛋被她软软的舌头舔着，酥酥麻麻的快感传上来，你舒服得轻轻嗯了一声。）嗯...
【妹】（她舔了一会蛋蛋，嘴唇轻轻含住一个，用舌尖轻轻打着圈揉，另一只手轻轻揉着另一个蛋蛋，两只手和嘴一起配合。）哥，这样舒服吗？
【哥】（她含着蛋蛋轻轻吸吮，手揉着另一个，特别舒服，你点头。）舒服，特别舒服。
【妹】（她听见你说舒服，含了一会这个，又换另一个含进嘴里轻轻吸吮，舌头不停舔着，手轻轻揉着，玩了好半天蛋蛋，她才继续往下。）嗯...
【哥】（她舌头继续往下，舔到你蛋蛋和肛门之间的会阴，那里特别敏感，被她舌尖一舔，你忍不住倒吸一口凉气。）嘶...那里...
【妹】（她知道找对地方了，舌尖在会阴那里轻轻打转，时不时轻轻吸吮一下，一只手往上握住你的肉棒慢慢套弄，另一只手继续揉着蛋蛋。）哥，这里是不是特别舒服？我看片子里男生这里很敏感。
【哥】（会阴被她舔着，手还套弄肉棒揉蛋蛋，三重刺激，你舒服得腰都轻轻抖了。）对...就是那里...别停...
【妹】（她开心地笑了，舌尖在会阴那里快速舔了几十下，然后才慢慢往上，舌头顺着阴茎体从下往上一直舔到龟头，绕着冠状沟转了好几圈。）嗯...
【哥】（她从会阴一路舔上来，你快感已经积累得很高了，呼吸都重了。）啊...舒服...
【妹】（她舔到龟头，张开嘴直接把整个龟头含进去，嘴唇紧紧裹着，舌头不停扫着系带，手继续快速套弄阴茎，另一只手还时不时揉一下会阴，嘴和两只手一起配合，所有敏感点都照顾到。）嗯...
【哥】（她嘴含着龟头，舌头舔系带，手套弄，另一只手揉会阴，太舒服了，你快感一下子冲到顶点。）我要射了...
【妹】（她不仅没退，反而把龟头含得更深，喉咙夹着龟头，手快速套弄，等着你射进来。）嗯...射给我...
【哥】（你腰一挺，一股股精液射进她嘴里。）啊...
【妹】（她乖乖全部咽下去，等你射完，还轻轻舔干净龟头、蛋蛋和会阴上的水，才抬起头，嘴角亮晶晶的。）哥，这次舒服吗？我照顾到所有地方了。
【哥】（你拉她上来抱在怀里，亲了亲她。）太舒服了，你怎么这么会。
【妹】（她往你怀里钻，笑得特别甜。）我专门学了好久呢，就想让你从头到脚都舒服。
【哥】（你紧紧抱着她，心里满满的。）真好。
【妹】（她抬起头亲你的下巴，声音黏黏的。）那你也要让我舒服呀...
