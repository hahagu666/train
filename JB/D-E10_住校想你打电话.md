# D-E10：住校想你打电话
# 地点：她房间，高一住校第一个晚上
# 情境：高一第一次住校，晚上在宿舍躺着想你，偷偷躲在被子里给你打电话，声音带着哭腔

【哥】（半夜被手机震动吵醒，拿起来接，声音有点哑，显然是刚醒）怎么了？
【妹】（高一开学，她第一次住校。晚上宿舍熄灯了，室友都睡着了，她躲在被子里，拿着手机，偷偷给你打电话，捂着嘴怕出声，声音小小的，带着鼻音）...哥。
【哥】怎么还没睡？不习惯？
【妹】（嗯了一声，声音有点发颤，眼泪一下子就下来了，没敢哭出声，抽了下鼻子）我...我想回家...
【哥】（声音放柔）怎么了，受委屈了？
【妹】（摇头，在被子里擦眼泪，声音小小的）没有...就是...宿舍的床好硬...我睡不着...也没有人给我盖被子...我想你...
【哥】（笑，声音很轻）才第一天就想我了？
【妹】（声音带着哭腔，委屈）嗯...我想回家...我不想住校了...我想每天跟你在一起...让你给我讲题...吃你做的饭...
【哥】周五就回来了，就四天，很快的。
【妹】（吸鼻子，眼泪掉在枕头上）四天好长啊...我现在就想回去...
【哥】乖，明天我去看你，给你带你爱吃的草莓蛋糕好不好？
【妹】（眼睛亮了一下，但是还是抽鼻子）...真的？
【哥】真的，下午放学我在你们学校门口等你。
【妹】（嗯了一声，擦了擦眼泪，声音发黏）...那你说话算话。
【哥】算话。快睡吧，明天还要上课。
【妹】（小声）...你先别挂...我听着你呼吸睡...
【哥】好，我不挂。
【妹】（把手机放在耳边，听着你那边平稳的呼吸声，慢慢闭上眼睛，嘴角还带着点委屈，但是安心多了）
