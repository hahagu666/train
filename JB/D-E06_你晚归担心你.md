# D-E06：你晚归担心你
# 地点：客厅沙发，凌晨一点
# 情境：你公司聚餐说十点回来，结果凌晨一点还没到，电话也打不通，她坐在沙发上等你，听到钥匙声立刻跑过去

【哥】（公司聚餐结束，终于到家，拿出钥匙开门）
【妹】（凌晨一点，客厅灯开着，她穿着睡衣坐在沙发上，电视开着但是没看，手机攥在手里，屏幕亮了又灭。已经打了五个电话，都是无人接听。她越等越慌，咬着嘴唇，眼泪都快出来了，脑补各种不好的画面，听到钥匙声立刻从沙发上弹起来，鞋都没穿，光着脚跑过去，门一开就扑过来）哥！
【哥】（喝了点酒，有点晕，被她扑得晃了一下）怎么还没睡？
【妹】（抱着你腰，脸埋你胸口，声音带着哭腔，手紧紧抓着你衣服）你怎么才回来啊...我给你打了好多电话你都不接...我都快吓死了...
【哥】（拍她背，酒劲上来有点懵）哦...同事拉着又喝了两杯，手机放包里没听见...
【妹】（抬头看你，眼睛红红的，眼泪挂在脸上，有点生气又有点委屈）你知不知道我多担心啊！我都想出去找你了！
【哥】（摸她头，她脸冰凉的）抱歉抱歉，是哥不对，下次一定提前说，不让你等了。
【妹】（鼓脸，但是手还是没松开，蹭你身上闻了闻）你喝酒了...
【哥】就喝了一点，没事。
【妹】（扶着你往沙发走，给你倒蜂蜜水，嘴里嘟囔）下次再这么晚回来不告诉我，我就...我就不理你了！
【哥】（笑，接过蜂蜜水喝）知道了，小管家婆。
【妹】（蹲在你旁边，看着你喝完，伸手摸你脸，还是有点后怕）...以后不许这样了。
【哥】嗯，不这样了。
【妹】（点点头，靠在你腿上，终于放下心来）
