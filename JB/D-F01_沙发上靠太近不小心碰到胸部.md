# D-F01：沙发上靠太近不小心碰到胸部
# 地点：客厅沙发，晚上看电视
# 情境：一起看电视恐怖片，她害怕往你怀里钻，你的手不小心碰到她胸部，两个人都僵住了

【哥】（晚上一起在客厅看恐怖电影，爸妈出去散步了，电视里突然跳出个鬼，她吓了一跳往你怀里钻，你伸手扶她，手刚好按在她胸口软软的地方。）
【妹】（正吓得往你怀里钻，突然被你按到胸部，整个人一下子僵住了，电视里还在放恐怖片她都不害怕了，脸瞬间从耳朵尖红到脖子根，身体僵在那里不动，连呼吸都停了半秒。）
【哥】（手也僵住了，掌心里软软的一团，还有弹性，能感觉到她胸罩薄薄的布料，赶紧把手收回来，也有点尴尬，咳嗽了一声。）对...对不起，我不是故意的。
【妹】（僵在你怀里，脸烫得吓人，能听见自己心跳咚咚咚的快得要跳出来，过了两秒才反应过来，赶紧往旁边挪了挪，但是离你不远，手捂着胸口，头埋得低低的，不敢看你，声音小得像蚊子叫。）没...没关系...我没注意...
【哥】（电视还在放，但是两个人都没心思看了，空气里有点尴尬，你能闻到她头发上的洗发水香味，刚才掌心里软软的触感一直没散，她坐在你旁边，肩膀还在微微发抖。）嗯...
【妹】（坐了半天，偷偷抬眼看你，正好和你对视，立刻又低下头，手指绞着睡衣衣角，脸红得像熟透的苹果，过了半天小声说。）你...你手怎么乱放...
【哥】（尴尬地挠了挠头，声音也有点不自然。）我不是故意的，你突然扑过来我没扶住。
【妹】（鼓着脸，但是没生气，耳朵还是红得发烫，往你身边悄悄挪了一点点，假装在看电视，过了一会电视里又出来一个恐怖镜头，她没好意思直接扑你怀里，但是抓住了你的胳膊，抓得紧紧的，脸埋在你肩膀上，身体离你更近了。）这个电影好吓人...我们别看了好不好...
【哥】（感觉到她靠过来，软软的身体贴在你胳膊上，她的胸部刚好蹭在你胳膊上，暖暖的软软的，她自己好像也感觉到了，身体僵了一下，但是没躲开，反而抓得更紧了。）好...都听你的。
【妹】（脸埋在你肩膀上，能闻到你身上的味道，心跳快得不行，胸部蹭在你胳膊上那种软软的触感让她浑身发软，明明电影没那么恐怖了，但是她还是赖在你肩膀上不肯起来，声音小小的闷闷的。）呜...你身上好暖和...
【哥】（伸手想拿遥控器换台，胳膊一动又碰到她胸部，这次两个人都僵了，但是没躲开，反而更紧地贴在你身上，脸埋在你脖子里，呼吸暖暖的喷在你皮肤上，烫得吓人。）啊...
【妹】（在你颈窝蹭了蹭，脸烫得能煎鸡蛋，手紧紧抓着你的衣服，身体没动，就那么贴在你身上，胸部软软地压在你胳膊上，心跳快得你都能感觉到，电视还在放着恐怖镜头，但是谁都没在看了，过了半天，声音小小的发着颤，带着点撒娇，几乎听不见。）你...你故意的...
