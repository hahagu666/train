# D-I39：她穿着你的白衬衫骑在你身上
# 地点：你床上
# 情境：她只穿了你的一件宽大的白衬衫，骑在你身上自己动

【哥】（晚上你靠在床头，她洗完澡进来，没穿睡衣，只穿了你一件宽大的白衬衫，长长的下摆到大腿中间，扣子没扣几颗，露出白白的乳房和腿，走到你面前跨坐上来。）嗯？穿我的衬衫？
【妹】（穿着你的宽大的白衬衫，跨坐在你腿上，吻你的嘴唇，衬衫滑下来露出肩膀和一边乳房，她扶着你的肉棒对准自己湿漉漉的小穴，慢慢坐下去，全部吞进去，舒服得叹了口气。）哥...穿你的衬衫...是不是特别好看...
【哥】（你看着她穿着你的白衬衫，松松垮垮的，露出白白的皮肤，衬衫下面什么都没穿，坐在你肉棒上，特别色情，你手抓着她的腰，帮她动。）好看，太好看了，我的小淫娃。
【妹】（她脸红了，但是开始自己上下动，衬衫随着她的动作晃来晃去，下摆扫过你的小腹，奶子从衬衫敞开的地方露出来，晃来晃去，她手抓着衬衫领子，看着你，眼睛亮晶晶的。）哥...我喜欢穿你的衣服...上面有你的味道...
【哥】（你伸手揉着她露出来的乳房，捏着硬硬的乳头，腰往上挺配合她的动作，每一下都顶到她最深处，她穿着你的衬衫被你操的样子，特别诱人。）喜欢就天天穿给我看。
【妹】（嗯...她动得越来越快，衬衫扣子又崩开两颗，整个乳房都露出来了，她也不管，就穿着你的白衬衫骑在你身上起伏，小穴紧紧裹着你，淫水把你小腹都打湿了。）哥...好舒服...穿着你的衣服被你操...特别有感觉...
【哥】（你拍了一下她的屁股，她抖了一下，小穴收得更紧，你伸手到衬衫下面揉她的阴蒂。）小淫娃，穿着我的衣服都想着被我操。
【妹】（啊...对...我是哥的小淫娃...她被你说得脸红，但是动得更快了，小穴开始收缩，快高潮了，她俯下身吻你，衬衫罩住两个人的头，里面全是你的味道，她更兴奋了。）哥...我要到了...
【哥】（你抱紧她，快速往上顶，揉阴蒂的手加快，她身体绷紧，啊的一声叫出来，高潮了，小穴剧烈收缩，紧紧咬着你的肉棒，抖个不停。）嗯...到了...
【妹】（啊...哥...她高潮了还在你身上轻轻动着，喘着气，脸红红的。）好舒服...
【哥】（你也忍不住了，腰一挺全部射在她里面，两个人抱着，她还穿着你的白衬衫，趴在你胸口喘着气。）嗯...射了...
【妹】（喘了半天，她抬起头，衬衫还皱巴巴的穿在身上，脸红扑扑的看着你，吻你的下巴。）以后我只穿你的衬衫...不穿别的...
【哥】（你笑着拍了拍她的屁股，把她连衬衫一起抱进怀里。）好，以后在家什么都别穿，就穿我的衬衫。
【妹】（她脸红了，但是点点头，在你嘴唇上亲了一下，趴在你胸口，衬衫皱巴巴的罩在两个人身上，闻着衬衫上你和她混合的味道，小穴还在一缩一缩的夹着你射进去的精液，声音黏黏的带着撒娇。）嗯...都听你的...那你的衬衫以后都归我穿了...不准给别的女人穿...听到没有...
