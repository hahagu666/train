# D-B14：攀比裙子
# 地点：家里客厅，放学
# 情境：她放学回来，有点闷闷不乐，把书包放下坐在沙发上，时不时看你一眼欲言又止

【哥】（看她坐在那扭扭捏捏的）怎么了？有话就说。
【妹】（抠手指，犹豫了半天）哥...
【哥】嗯？
【妹】（声音小小的）...张萌今天穿了条新裙子来学校...
【哥】嗯，然后呢？
【妹】（抠得更用力了）是那个牌子的...就是上次我们在商场看到的，好贵的那个...她们都围着她看，说好看...
【哥】你也想要？
【妹】（脸有点红，点头又摇头）...也不是特别想要...就是...我那条裙子还是去年买的...
【哥】（笑）想要就说，别拐弯抹角的。
【妹】（抬头看你，眼睛亮了一下，又暗下去）可是好贵啊...要三百多呢...
【哥】周末带你去买。
【妹】（愣了一下，坐直了）真的？
【哥】真的，但是买了不许上课总想着穿臭美，好好学习。
【妹】（立刻开心起来，扑过来抱你胳膊）我就知道哥最好了！（想了想又有点不好意思）...其实我就是...有点羡慕...
【哥】（捏她脸）羡慕什么，我们妹妹穿什么都好看。
【妹】（脸红，打你一下）你又哄我...
【哥】我什么时候哄你了，上次你穿那条白裙子，楼下阿姨都问我在哪买的。
【妹】（眼睛弯成月牙，笑得特别开心）真的吗？我也觉得那条好看！
【哥】周末去买新的，顺便给你买双小白鞋配裙子。
【妹】（开心得不行，蹦起来在你脸上亲了一口）哥你太好了！
【哥】（愣了一下，她也愣了，脸红到耳根，转身跑回房间）
【妹】（房间里传来声音，声音小小的）...我去写作业了！
