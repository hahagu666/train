# D-E37：你叫她小名她特别开心
# 地点：家里，晚饭时间
# 情境：你第一次叫她的小名"软软"，她愣了半天，然后开心得不行，一整天都黏着你

【哥】（晚饭的时候妈妈让你喊她吃饭，你在她房间门口喊了一声"软软，吃饭了"，这是她的小名，小时候叫过，长大了就很少叫了）
【妹】（本来在房间写作业，听见你喊她小名，笔一下子停在作业本上，愣了两秒，立刻站起来跑出去，跑到你面前，眼睛亮晶晶的看着你，脸有点红，有点不敢相信）哥...你刚才叫我什么？
【哥】（奇怪地看着她）叫你吃饭啊，怎么了？
【妹】（站在你面前，手抓着衣角，有点期待又有点不好意思，声音小小的）不是...你刚才叫我软软...你好久没叫我小名了...
【哥】哦，随口叫的，不行啊。
【妹】（立刻使劲摇头，头摇得像拨浪鼓一样，脸一下子红了，但是眼睛亮晶晶的，嘴角控制不住往上扬，特别开心，一下子扑过来抱住你的胳膊，晃来晃去）行！怎么不行！特别好听！
【哥】（被她晃得差点站不稳，笑着揉了揉她的头）不就是叫个小名，看你开心的。
【妹】（鼓着脸，但是嘴角一直扬着，抱着你胳膊不肯撒手，跟你一起往餐厅走，走路都蹦蹦跳跳的，像只开心的小兔子）你好久都没叫过我小名了！上一次叫还是我小学的时候！你平时都叫我"喂"或者"哎"！
【哥】那以后叫你软软？
【妹】（眼睛一下子亮得像星星，使劲点头，脸红红的，但是笑得特别开心，抱着你胳膊晃得更厉害了）嗯！就叫软软！以后都叫我软软！不许再叫我"喂"了！
【哥】吃饭的时候，你试着叫了一声"软软，帮我拿张纸巾"，她立刻开心地站起来去给你拿纸巾，递到你手里的时候脸红红的，嘴角一直扬着，吃饭都比平时多吃了半碗。
【妹】（吃完饭她一直黏在你身边，你去客厅她跟着去客厅，你去倒水她跟着去倒水，你看书她就坐在你旁边托着下巴看你，过了半天，小声说）哥...你再叫我一声好不好...
【哥】（看着她期待的眼神，眼睛亮晶晶的像只等投喂的小猫，忍不住笑了）软软。
【妹】（听见你叫她，脸一下子红透了，但是笑得特别开心，眼睛弯成了月牙，扑过来抱住你的腰，把脸埋在你胸口蹭啊蹭，像只开心的小猫，声音闷闷的带着笑意）哎！（她抱着你蹭了半天，抬起头看你，眼睛亮晶晶的，脸红红的，声音黏黏的）真好听...你以后天天都要叫我小名好不好...
【哥】好。
【妹】（更开心了，抱着你不肯撒手，坐在你旁边，时不时就抬头看你，等着你叫她小名，你每次叫她她都特别开心地应一声，脸红红的但是笑得特别甜，那天晚上她连写作业都哼着歌，写完作业跑过来跟你说晚安，站在门口不走，直到你笑着说"晚安软软"，她才特别满足地笑着跑回房间，睡觉前还趴在门口喊了一声"哥晚安"，其实是等着听你再叫她一声小名）
