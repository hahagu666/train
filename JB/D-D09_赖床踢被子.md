# D-D09：赖床踢被子
# 地点：她房间，早上六点半
# 情境：你去叫她起床，发现被子全掉在地上，她蜷成一团睡着

【哥】（闹钟在床头响了三遍，已经被按掉了。你推开门进去，看到被子一大半都掉在地上，她蜷成小小的一团抱着枕头睡得正香，头发乱蓬蓬地散在枕头上，嘴微微张着，呼吸均匀，完全没察觉你进来）
【妹】（迷迷糊糊哼了一声，没醒，往枕头里缩了缩，像只小猫一样蹭了蹭枕头）
【哥】（走过去捡被子，拍了拍她的脸）起床了，小懒猪，被子都掉地上了。（把被子给她盖上，又拍了拍她的脸）醒醒，六点半了，再不起要迟到了。
【妹】（皱了下眉头，眼睛没睁开，伸手抓住你的袖子，嘟囔着）...再睡五分钟...就五分钟...
【哥】（捏捏她的脸）昨天也是五分钟，最后迟到了被老师说，忘了？
【妹】（没说话，抓着你袖子不放，眼睛还是闭着的，像只小猫一样蹭了蹭你的手）
【哥】（无奈，捏她鼻子）起不起？不起我掀被子了啊。
【妹】（无法呼吸，皱着眉睁开眼睛，眼神还是迷迷糊糊的，手拍你）唔...起...起了...别捏了...
【哥】（松手，把校服递她面前）那坐起来，把衣服穿了。
【妹】（坐起来，头发乱得像鸟窝，眼睛半睁半闭，坐了两秒又开始往下倒，眼看又要睡过去）
【哥】（接住她，把她捞起来，让她靠在你身上）哎，别又睡过去了，快清醒清醒。
【妹】（靠在你身上，闭着眼睛，声音黏糊糊的还带着睡意）...哥我困...我真的好困...
【哥】（拍她的脸）穿好衣服再睡，先把衣服穿上，牛奶热好了在桌上。
【妹】（点点头，但是没动，靠在你身上蹭来蹭去，像没骨头一样挂在你身上）
【哥】（把校服递她手里，把她扶坐好）拿着，自己穿，我去给你热牛奶。
【妹】（接过校服抱在怀里，眯着眼睛点头）嗯...知道了...
【哥】（走到门口回头看，果然看到她坐在床上抱着校服，眼睛又开始闭上，头一点一点的，快要睡着了，走回来弹她额头，声音提高一点）醒醒！
【妹】（被弹醒，吓了一跳，立刻睁开眼，坐直了）啊！我醒了！我醒了！我这就穿衣服！
【哥】（笑着揉她乱蓬蓬的头发）这才乖，快点啊，我在外面等你。
【妹】（点点头，拿起衣服开始穿，眼睛还是睁不开的样子，但是动作快了不少）知道啦...
