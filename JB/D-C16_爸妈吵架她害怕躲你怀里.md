# D-C16：爸妈吵架她害怕躲进你怀里
# 爸妈因为琐事吵架越吵越凶，她吓得脸色发白，光着脚跑到你房间钻进你怀里捂耳朵，你抱着她哄

【哥】（晚上在房间写作业，听见客厅爸妈吵架声越来越大，还传来摔杯子的声音，刚想起身去看她，房门就被轻轻推开了）
【妹】（穿着小熊睡衣，光着脚站在门口，脸色发白，眼泪在眼眶里打转，又一声东西摔碎的声音传来，她吓得"啊"了一声，直接扑进你怀里，浑身发抖）哥...我害怕...
【哥】（赶紧接住她，把她抱到腿上紧紧搂住，用手捂住她的耳朵，轻声哄）不怕不怕，哥哥在呢，爸妈就是拌两句嘴，不会有事的。
【妹】（把脸埋在你胸口，手紧紧抓着你的衣服，眼泪瞬间把你T恤打湿，声音抖得不成样子）他们会不会离婚啊...我同学爸妈吵完架就离婚了...我不要...
【哥】（帮她擦掉眼泪，拇指蹭着她哭红的脸蛋，声音坚定）傻瓜，不会的，上次吵完第二天不就和好了吗？还给我们买草莓蛋糕，对不对？这次也一样。
【妹】（抬起哭肿的眼睛看你，还是有点不信，抽抽搭搭）真的吗...你不骗我？
【哥】（点点头，拿耳机给她戴上，放她最喜欢的轻柔歌，把她的头按回你胸口听心跳）真的，听哥哥的心跳，什么都别想，睡一会儿就好了。
【妹】（靠在你怀里，听着沉稳的心跳和耳机里的歌，身体慢慢不抖了，但还是紧紧抓着你的衣角不肯松手，小声说）我今晚跟你睡...我不敢一个人回房间...
【哥】（把她抱到床上盖好被子，躺在她身边轻轻拍背）好，跟我睡，哥哥抱着你，什么都不用怕。
【妹】（往你怀里缩了缩，像小猫找了个舒服的位置，闻着你身上熟悉的味道，紧绷的神经终于松下来，没一会儿就呼吸平稳睡着了，眉头还微微皱着）
【哥】（轻轻帮她揉开眉头，在她额头上亲了一下，轻声说"哥哥在"，抱着她慢慢也睡着了）
【妹】（第二天早上醒过来，发现自己整个人缠在你身上，脸一下子红了，刚想偷偷溜回去，就听见外面妈妈喊"吃饭了，今天做了煎蛋"，爸妈果然和好了）
【哥】（被她动静弄醒，笑着揉她乱蓬蓬的头发，捏捏她红透的脸蛋）你看，我说什么来着，和好了吧？快起来吃早饭。
【妹】（松开手爬起来，眼睛还是有点肿，但笑得眼睛弯成月牙，凑过来在你脸上飞快亲了一口，然后红着脸光着脚跑出去了）
