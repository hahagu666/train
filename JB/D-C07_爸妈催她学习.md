# D-C07：爸妈催她学习
# 地点：客厅，周末下午
# 情境：她刚从书房出来想歇会看会电视，妈妈从厨房出来催她回去学习，她鼓着脸找你告状

【哥】（周末下午从房间出来接水，靠在门框上，看她拿着遥控器刚打开电视，妈妈从厨房出来问她怎么又出来了作业写完没有）怎么了这是，鼓着脸。
【妹】（拿着遥控器，鼓脸）我写了一上午了...就看十分钟电视...
【哥】（看着她敢怒不敢言的样子，妈妈在说看什么电视还有三十多天就高考了赶紧回去写题，忍住笑）
【妹】（不情不愿关掉电视，站起来，磨磨蹭蹭往书房走，一步三回头）
【哥】（给她使了个眼色，示意她一会来自己房间）
【妹】（妈妈在后面说别磨磨蹭蹭的这次模考又退步了知不知道，她没说话，低头进书房了）
【哥】（回自己房间，留了个门缝，等她过来）
【妹】（过了十分钟，偷偷溜进你房间，关上门，背靠着门拍胸口）
【哥】（在工作，回头看她溜进来关上门，笑了）怎么了？跟个小老鼠似的。
【妹】（走到你旁边，鼓着脸，一脸委屈，拉你椅子）妈又催我...我就想歇十分钟都不行...
【哥】（笑，转过来摸她头）妈也是为你好，着急你高考。
【妹】（拉你椅子，蹲你旁边，抱你胳膊晃）我都学了一上午了...脑子都学懵了...歇会怎么了嘛...
【哥】（被她晃得没办法，拉了把小椅子过来）那在我这歇会，别让妈看到。
【妹】（眼睛亮了，立刻搬了个小椅子坐你旁边，头靠你胳膊上蹭）哥你最好了...
【哥】（把桌上的糖递给她）说好啊，就歇十分钟，到点就得回去。
【妹】（点头，像小猫一样蹭你胳膊，看你工作屏幕）你在做什么啊？
【哥】（敲了敲键盘）工作报表，大人的事，小孩别问，乖乖歇着。
【妹】（看不懂，但是乖乖靠着你，不说话，安安静静坐了五分钟，手指玩你衣服扣子）
【哥】（看了眼时间，敲敲她脑袋）到点了啊，十分钟到了。
【妹】（抬头看你，眼睛湿漉漉的，撒娇晃你胳膊）再歇五分钟嘛...就五分钟...
【哥】（故意板脸）不行，妈一会该过来查房了，看到你在我这又要说你。
【妹】（鼓脸，不情不愿站起来，磨磨蹭蹭往门口走）知道了...（走到门口又回头）哥，晚上我要吃你做的番茄鸡蛋面。
【哥】（笑，点点头）行，给你做，加两个蛋，乖乖回去学习。
【妹】（笑了，开门溜出去，正好碰到妈过来，立刻装作刚从卫生间出来的样子，往书房走，背挺得笔直）
【哥】（看着她装模作样的背影，忍不住笑出声，摇摇头继续工作）
【妹】（走到书房门口，回头冲你做了个鬼脸，小声比了个口型"加两个蛋"）
