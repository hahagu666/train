# D-E30：你摸她头她脸红心跳
# 地点：客厅沙发，她在你旁边玩手机
# 情境：她跟你说学校里的趣事，你笑着伸手揉了揉她的头，她瞬间脸红，心跳快得不行

【哥】（吃完晚饭和她一起坐在沙发上，她靠在你旁边玩手机，跟你说今天学校里的趣事，说她们班主任上课拉链开了全班都憋笑，说得绘声绘色的）
【妹】（说得特别开心，手舞足蹈的，眼睛亮晶晶的，嘴角一直扬着，说到好笑的地方自己先笑倒在你肩膀上）你都不知道！他站在讲台上讲了半节课！最后还是班长给他递了个纸条他才发现！全班都快憋出内伤了！
【哥】（听她说得有意思，忍不住笑了，伸手揉了揉她的头发，她头发软软的，摸起来特别舒服）你们也太坏了。
【妹】（正笑着，突然被你摸头，动作一下子僵住了，脸瞬间从耳朵尖红到脖子根，手机都差点掉在沙发上，眼睛睁得圆圆的看着你，心跳突然就快了，咚咚咚的，自己都能听见）
【哥】（看她突然不说话了，脸通红，像熟透的苹果，奇怪地看着她）怎么了？
【妹】（这才反应过来，赶紧低下头，假装继续玩手机，但是手指都在抖，屏幕划了半天都没划对地方，脸烫得吓人，声音小小的，带着点慌乱）没...没怎么...
【哥】（觉得好笑，又伸手揉了揉她的头，这次揉得更久了，手指穿过她软软的头发，她整个人都僵了，身体往沙发里缩了缩，但是没躲开）脸怎么这么红，发烧了？
【妹】（赶紧摇头，头埋得低低的，头发都垂下来挡住脸，但是耳朵还是红得要滴血，心跳快得像要跳出来一样，连呼吸都有点不稳，声音小小的像蚊子叫）没...没有...就是有点热...
【哥】热啊，那我把空调开低点。
【妹】（赶紧伸手拉住你，手碰到你的手又像触电一样缩回去，脸更红了，头埋得更低，声音都发颤了）别...不用！不热了！我开玩笑的！
【哥】（看着她这副样子，觉得特别可爱，故意又伸手揉了揉她的头发，还轻轻捏了捏她的耳朵，她耳朵烫得吓人，被你一捏，她整个身体都抖了一下，小声啊了一声）
【妹】（被你捏了耳朵，整个人都快冒烟了，往沙发角落缩，但是沙发就那么大，没地方躲，干脆把脸埋在靠垫里，不肯抬头，声音闷闷的，带着点撒娇又有点不好意思）你别摸我头了...
【哥】为什么，小时候不天天让我摸吗。
【妹】（埋在靠垫里不肯出来，声音闷闷的，耳朵红得发烫，心跳快得不行，过了半天才小声说）小时候是小时候...现在不一样了...（她偷偷从靠垫缝里看你，正好和你对视，立刻又把脸埋回去，但是你能看见她露在外面的耳朵红得快要滴血，身体都在轻轻发抖，不是害怕，是害羞，手紧紧抓着靠垫，指节都有点发白）
【哥】哪里不一样了？
【妹】（半天没说话，过了好久才慢慢抬起头，脸还是通红的，眼睛水汪汪的看着你，嘴唇粉润润的，心跳快得胸口都在微微起伏，声音小小的，发嗲，像撒娇一样）就是...就是不一样了...（她嘴上这么说，但是却悄悄往你身边挪了挪，离你更近了一点，头微微低着，但是没躲开你的手，意思是你想摸就再摸一会，头发软软的蹭在你手心里，烫烫的）
