# D-G20：互相爱抚说好下次做爱
# 地点：你床上，事后
# 情境：爱抚完两个人抱着聊天，约定好等她下次生日那天，把第一次给你

【哥】（你用手让她高潮了两次，她瘫在你怀里，浑身都是汗，大口喘气，你把她搂在怀里，擦了擦她额头的汗。）
【妹】（靠在你怀里，浑身一点力气都没有，手指在你胸口画圈圈，脸红红的，还沉浸在高潮的余韵里，时不时轻轻抖一下。）嗯...
【哥】（亲了亲她的额头。）累坏了吧？
【妹】（点点头，在你胸口蹭了蹭，像只小猫，声音黏黏的哑哑的。）嗯...腿都发颤了...哥你太厉害了...
【哥】（笑了笑，抱着她。）傻丫头。
【妹】（沉默了一会，抬起头看你，眼睛亮晶晶的，手指摸着你的下巴，小声说。）哥...我下个月就十八了...
【哥】（看着她。）我知道，怎么了？
【妹】（脸一下子红透了，埋回你胸口，半天不说话，过了好半天，才闷闷地说声音小小的。）十八了...就是成年人了...那天...那天我把第一次给你好不好...
【哥】（愣了一下，看着她，她脸红得像熟透的苹果，但是眼神很认真，不像是在说笑。）你确定？
【妹】（抬起头看你不说话，以为你不愿意，有点急了，捧着你的脸，声音黏黏的带着撒娇。）我愿意的...真的...我早就想给你了...我不怕疼...
【哥】（摸着她的头发。）不是怕你疼吗？而且第一次会很疼。
【妹】（摇摇头，凑过来吻你的嘴唇，吻得黏黏的认真，手轻轻摸着你的脸，认真地说。）我不怕...只要是和你...再疼我都愿意...而且...而且我们都这样了...我想...想真正和你在一起...
【哥】（看着她认真的眼神，点了点头。）好，那等你生日那天。
【妹】（听见你答应，她眼睛一下子亮了，笑得特别开心，像得了糖的小孩，凑过来不停亲你的脸和嘴唇，在你怀里扭来扭去，特别开心。）真的？你说真的？不许反悔！
【哥】（伸手捏了捏她软软的屁股。）不反悔。
【妹】（被你捏屁股，她嘤了一声，脸红扑扑的，主动吻住你的嘴唇，手往下摸到你硬邦邦的肉棒，轻轻套弄着，声音黏黏的。）那...那在那之前...我先用嘴帮你好不好...还有...你也用嘴帮我...我想试试...
【哥】（喘着气。）你不怕吗？
【妹】（摇摇头，往下缩了缩，跪在你两腿之间，抬头看你，头发散在你大腿上，脸红扑扑的，眼睛亮晶晶的，特别认真，她说着，低头凑近你硬邦邦的肉棒，鼻尖都快碰到了，温热的呼吸喷在龟头上。）不怕...只要是和你...我什么都不怕...而且...我想让你舒服...
【哥】（摸着她的头，她的头发软软的。）嗯...
【妹】（抬头看你一眼，然后闭上眼睛，伸出粉粉的小舌头，轻轻舔了一下你的龟头，软软的，热热的，这是她第一次用嘴碰你。）嗯...
