# D-G18：后入姿势手指插她
# 地点：你床上
# 情境：她趴在床上，你从后面手指插她，她第一次这个姿势，特别害羞

【哥】（她趴在床上，屁股翘得高高的，脸埋在枕头里，脸红得要滴血，因为你让她趴着，说要换个姿势。）
【妹】（趴在床上，脸埋在枕头里，屁股翘着，睡衣掀到背上，内裤拉到大腿根，白白的屁股露在你面前，她羞得不敢抬头，声音闷闷的从枕头里传出来。）哥...你快点...这个姿势好丢人...
【哥】（跪坐在她后面，看着她白白嫩嫩的屁股，还有臀缝里湿漉漉的小穴，水都流到大腿上了，你伸手拍了一下她软软的屁股。）丢什么人。
【妹】（啊！被你拍了一下屁股，她身体抖了一下，屁股下意识往你手那里凑了凑，声音带着哭腔的撒娇。）啊！你...你别打我屁股...快点...
【哥】（沾了她的水，手指对准她湿滑的穴口，慢慢插进去一根手指，从后面插进去，角度和平时不一样，顶得更深。）嗯...
【妹】（啊...从后面插进来感觉完全不一样，顶得特别深，她叫出来，腰不自觉往下塌，屁股翘得更高，让你插得更深一点，声音发颤。）啊...好深...哥...比刚才深...
【哥】（手指在她里面抽插了几下，又加了第二根手指，从后面两根手指一起插，抠着她前面敏感的G点。）满吗？
【妹】（两根手指进来，撑得满满的，还从后面顶到她从来没被碰到过的地方，她爽得尖叫出来，腰不停扭着，屁股主动往后坐，让你手指插得更深。）啊！那里！哥...那里好舒服...
【哥】（另一只手伸到前面，揉着她阴蒂，两根手指在后面快速抽插，前面揉阴蒂，前后夹击。）这样呢？
【妹】（被你前后一起摸，快感翻倍，她再也忍不住，趴在床上呜呜地哭，嗯嗯啊啊的呻吟，屁股不停往后蹭，水哗哗流出来，把床单都浸湿了，话都说不完整了。）哥...好哥哥...我不行了...太舒服了...要死了...
【哥】（手指加速抽插，能看到她的小穴在两根手指进出的时候翻来翻去，水跟着溅出来，白白嫩嫩的屁股因为快感泛着粉色。）嗯...
【妹】（啊！！来了！来了！她尖叫一声，身体猛地绷紧，屁股死死往后顶着你的手，小穴疯狂收缩，一股水喷出来，直接喷在床单上，高潮了，她趴在床上大口喘气，连动的力气都没有了，身体还在不停抽搐。）啊...
【哥】（慢慢抽出手指，手上全是她的水，拍了拍她软软的屁股。）爽了？
【妹】（被你拍屁股，她轻轻抖了一下，过了半天，才转过头，脸红得像苹果，眼睛水汪汪的全是眼泪和水汽，看着你，声音哑哑的黏黏的。）哥...这个姿势...好羞耻...但是...但是好舒服...
【哥】（趴到她身边，把她搂过来。）舒服就好。
【妹】（往你怀里钻，抱着你的腰，脸埋在你胸口，过了一会，手往下摸到你的肉棒，发现它硬得厉害，她抬头看你，眼神亮晶晶的，小声说。）哥...你也硬了...我帮你...
【哥】（摸着她的头。）不用了，你刚累了。
【妹】（摇摇头，主动趴下去，小脑袋埋在你腿间，头发散在你大腿上，抬头看你，脸红扑扑的，声音黏黏的。）我不累...我想用嘴...你教我好不好...
