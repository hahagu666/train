# D-D12：网购到货
# 地点：玄关/客厅，周末下午
# 情境：好几个快递堆在玄关，是她买的文具和小玩意，她兴奋地一个个拆

【哥】（门口堆着四五个快递盒，都写着她的名字，你坐在沙发上看书，听到她跑出来的声音）
【妹】（写完作业跑出来，蹲在地上拆快递，剪刀划开胶带的声音哗啦响，眼睛亮晶晶的，像只找到宝藏的小松鼠）
【哥】（放下书，笑着看她）买了什么好东西，这么开心。
【妹】（拿起最上面的一个盒子，划开胶带，眼睛亮得像星星）我的文具到了！
【哥】（挑挑眉）你上次不是刚买了一盒笔吗？这才多久。
【妹】（拿出一盒按动中性笔，各种颜色的，摆在地上给你看）你看！这个笔写起来特别顺滑！我上次借同学的用了一次特别好写，就买了一盒！
【哥】（拿起一支笔按了按，确实挺好用）行吧，记笔记用是吧。
【妹】（鼓脸，又拆开下一个盒子）上次的是黑色的，这次我买了彩色的，记笔记用！（拿出一个小熊造型的笔袋，软乎乎的，抱在怀里）你看这个笔袋！可爱吧！
【哥】（笑着数了数沙发上她的笔袋）你笔袋都有三个了，还买？
【妹】（把笔袋抱在怀里，笑，脸有点红）这个好看嘛...跟之前的都不一样...（又拆开一个，是一盒便签纸，各种小动物图案）还有这个！贴在错题本上特别方便！
【哥】（笑，伸手点了点她的额头）你是买文具还是用文具？买这么多能用得完吗。
【妹】（吐舌头，冲你做了个鬼脸，继续拆最后一个，是一条发带，她立刻扎在头上，跑到镜子前面照，转了个圈）哥你看！这个发带洗脸的时候用！再也不会弄湿头发了！
【哥】（看着她扎着发带的样子，确实挺可爱）嗯，好看，像个小兔子。
【妹】（开心地跑回来，把文具都摆在茶几上，一个个给你展示，笔按开又按上，咔哒咔哒响，玩得不亦乐乎）
【哥】（看着她开心的样子，笑着问）买这么多，零花钱够花吗？不够跟我说。
【妹】（点头，笑嘻嘻，把笔摆得整整齐齐）够！这个月零花钱还有剩！（拿起一支蓝色的笔递你，笔帽上还有个小熊挂件）这个给你！你上班记东西用！
【哥】（接过笔，笔杆小小的握在手里，笑着揉揉她的头发）谢谢妹妹。
【妹】（笑得特别开心，把所有文具都收进新笔袋里，抱在怀里，像抱着什么宝贝，凑过来亲了你脸一口）
【哥】（被她亲得一愣，笑着捏捏她的脸）傻丫头。
【妹】（抱着新笔袋蹦蹦跳跳地跑回房间了）
