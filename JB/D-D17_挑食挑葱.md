# D-D17：挑食挑葱
# 地点：晚饭桌上
# 情境：晚饭做了葱油面，她把葱花一根一根挑出来堆在你碗里

【哥】（桌子上摆着两碗葱油面，香气飘出来，看着她拿起筷子先挑葱）
【妹】（拿起筷子，先把面上的葱花一根一根挑出来）
【哥】（看她挑葱）又挑葱。
【妹】（鼓脸，把最后一根葱花挑出来，堆在你碗边）我不吃葱嘛...葱好难吃。
【哥】葱有营养，多吃点。
【妹】（摇头，夹了一筷子面吃，看到碗里还有个葱花渣，赶紧挑出来放你碗里）
【哥】你都挑我碗里干什么。
【妹】（理所当然地）你吃啊，你又不挑。
【哥】（笑着看她，把碗边的葱都夹到自己碗里）行，都给我吃。
【妹】（笑眯眯地吃面条，吃了两口，咬到一块姜，立刻吐出来，皱着眉头）唔...还有姜！
【哥】（把姜夹走）吃个饭事真多。
【妹】（鼓脸，但是继续吃，把面条吃得干干净净，汤都喝了，碗里干干净净的，除了挑出来的姜）
【哥】（看着她碗边堆的葱和姜）
【妹】（脸红，赶紧把葱和姜收进自己碗里，不好意思地笑）下次我挑纸上...
【哥】（笑）没事，我吃。
【妹】（抬头看你，眼睛亮晶晶的，笑起来）哥最好了！
