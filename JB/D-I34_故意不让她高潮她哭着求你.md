# D-I34：故意 edging 不让她高潮她哭着求你
# 地点：你床上
# 情境：你故意在她快高潮的时候停下来，反复几次，她急得哭了求你

【哥】（晚上你压在她身上慢慢做，她快高潮的时候，你突然停下来，不动了，肉棒还插在她小穴里。）舒服吗？宝贝。
【妹】（啊...哥...你怎么不动了...快...快动...她正爽到一半，突然停下来，快感卡在那里不上不下，难受得她扭着腰想自己动，被你按住腰不让动，她急得眼泪都出来了。）求你了哥...动一动...我要到了...
【哥】（你笑着吻她的眼泪，就是不动，手揉着她的乳头。）想要吗？求我，求我就让你高潮。
【妹】（我求你...哥...求你让我高潮...她哭着求你，腰扭来扭去，小穴一缩一缩的夹你的肉棒，想自己获得快感，但是被你按得死死的，动不了。）好难受...哥...我错了...你让我去...
【哥】（看她急成这样，你才又开始慢慢动，她立刻舒服得哼出声，但是刚动了没一会，眼看她又要高潮，你又停下来了。）等等，不急。
【妹】（啊！你又停！不要！哥！她真的哭出来了，眼泪流了一脸，难受得蹭你，咬你的肩膀。）你坏死了...故意欺负我...求你了...让我高潮...我什么都听你的...
【哥】（你吻着她的眼泪，在她耳边问她。）下次还敢不敢故意穿那么短的裙子在别的男生面前晃？
【妹】（不敢了...再也不敢了...我以后只穿给你一个人看...求你了哥...动一动...她哭得稀里哗啦，小穴里淫水哗哗流，床单都湿了一大片，她真的快受不了了。）我以后裙子都穿长的...再也不让别的男生看我...你让我高潮...
【哥】（你这才满意，开始快速抽插，手揉着她的阴蒂，狠狠干她，她一下子叫出声，快感像潮水一样涌上来。）这才乖。
【妹】（啊...啊...太舒服了...哥...她被你反复吊了好几次，这次一上来就直接高潮了，而且是特别强烈的高潮，她尖叫出声，身体弓起来，小穴剧烈收缩，紧紧咬着你的肉棒，抖得像筛子一样，连气都喘不上来，眼泪流得更凶了。）啊...我去了...哥...
【哥】（她高潮的时候你也射了，腰一挺全部插进去，射在她最深处，两个人抱着喘了半天。）嗯...射了...
【妹】（她高潮完，整个人都软了，连哭的力气都没有，趴在你怀里抽噎，捶你的胸口。）你欺负我...差点憋死我了...
【哥】（你笑着吻她，帮她擦眼泪。）下次不听话还这样惩罚你。
【妹】（她赶紧摇头，往你怀里钻。）我听话...我一定听话...你别再这样了...
