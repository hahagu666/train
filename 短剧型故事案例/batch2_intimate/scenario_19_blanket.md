# 场景19：冬天抢被子
# 地点：哥哥房间，冬天深夜
# 情境：妹妹跑到哥哥房间蹭暖气，半夜抢被子

【妹】（抱着枕头轻轻推开门）哥...你睡了吗？
【哥】（迷迷糊糊）...怎么了？
【妹】（小声）我房间好冷...暖气好像坏了...
【哥】...那你去把被子加厚点。
【妹】我加了还是冷...（走到床边）我能不能跟你睡...
【哥】不行，你都多大了。
【妹】就今天！我保证不挤你！（不等你回答就钻上床，在你旁边缩成一团）哇，你被窝好暖和...
【哥】...你。
【妹】（裹着被子蜷在旁边，背对着你）我就睡一小会，等暖气热了我就回去...
【哥】（叹气，往旁边挪了挪给她腾地方）
（半夜）
【哥】（被冷醒，发现被子全被她卷走了）喂...
【妹】（裹得像个蚕蛹，睡得正香，嘴角还挂着口水）
【哥】（拉了拉被子，拉不动）你给我留点。
【妹】（嘟囔了一声，反而把被子抱得更紧了，整个人滚到你这边，脑袋枕在你胳膊上）
【哥】（无奈，只好伸手把她连人带被子往这边拉了拉，两个人挤在一起）
【妹】（无意识地往你怀里钻了钻，像小猫一样蹭了蹭）
【哥】（僵了一下，然后放松下来，伸手帮她把被子掖好）
（第二天早上）
【妹】（先醒过来，发现自己整个人趴在你怀里，手搭在你腰上，脸瞬间通红）
【哥】（还没醒，呼吸均匀）
【妹】（小心翼翼想挪开，一动你就皱了下眉头，她吓得不敢动了）
【哥】（迷迷糊糊睁开眼睛，看到她近在咫尺的脸红的脸）...醒了？
【妹】（脸爆红，声音像蚊子）我、我不是故意的...我回去了...（想爬起来）
【哥】（伸手按住她的脑袋）再睡会，外面冷。
【妹】（僵硬地趴在你怀里，不敢动，但也没再挣扎）...哦。
