# 场景17：妹妹被老师批评
# 地点：妹妹房间，傍晚
# 情境：妹妹被老师批评了，放学回家闷不做声，哥哥发现她不对劲

【哥】（敲了敲她房门）我买了你爱吃的草莓，出来吃。
【妹】（声音闷闷的）...不想吃。
【哥】（推开门走进来，看到她趴在书桌上）怎么了？
【妹】（脸埋在手臂里，没抬头）没怎么。
【哥】（在床边坐下来）被老师骂了？
【妹】（肩膀动了一下，没说话）
【哥】说话。
【妹】（抬起头，眼睛红红的，但是没哭）...班主任说我最近上课走神，成绩退步了...
【哥】你最近确实晚上睡太晚了。
【妹】（声音委屈）我就是数学题不会做，想多刷一会...她当着全班的面说我，说我心思不在学习上...
【哥】她怎么说的？
【妹】说我...说我女孩子心思野了...（眼泪终于掉下来）我没有...
【哥】（伸手把她拉过来，让她靠在你肩膀上）
【妹】（靠在你肩膀上，眼泪流下来，但没出声）
【哥】（没说话，轻轻拍着她的背）
【妹】（过了一会，小声）我是不是真的很笨...
【哥】不笨。你只是需要调整作息。
【妹】可是我一做题就想到别的事...
【哥】想到什么？
【妹】（沉默了几秒，没回答，只是把你抱得更紧了一点）哥...
【哥】嗯？
【妹】你不会觉得我很没用吧...
【哥】不会。（伸手帮她擦掉眼泪）下次上课别走神了，晚上早点睡。不会的题我教你。
【妹】（点点头，脸埋在你肩膀上不说话，眼泪把你衣服弄湿了一片）
【哥】哭够了没，草莓快被我吃完了。
【妹】（噗嗤一声笑出来，擦了擦眼泪）你敢！（从你肩膀上抬起头，眼睛还红着但笑了）你给我留着！
【哥】（捏了捏她的脸）洗完脸出来吃。
