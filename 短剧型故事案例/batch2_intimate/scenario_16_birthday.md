# 场景16：妹妹生日
# 地点：家里客厅，晚上
# 情境：妹妹生日，哥哥准备了蛋糕和礼物

【妹】（放学回来，推门进来，客厅黑着）哥？怎么不开灯...
【哥】（端着点了蜡烛的蛋糕从厨房走出来，唱）祝你生日快乐...
【妹】（愣住了，然后眼睛瞬间红了）你...你记得...
【哥】我什么时候忘了？（把蛋糕放在桌上）许愿吧。
【妹】（走过来，眼睛亮晶晶的，双手合十闭上眼睛，过了几秒睁开眼吹灭蜡烛）
【哥】（开灯）许了什么愿？
【妹】（擦了擦眼角，笑了）不告诉你，说出来就不灵了。
【哥】（从桌子底下拿出一个包装好的盒子）给你的。
【妹】（接过来，小心翼翼拆开）...是新的耳机？！
【哥】你那个旧耳机不是一边不响了吗。
【妹】（拿着耳机看了半天，抬头看你，眼眶又红了）这个好贵的...
【哥】攒钱给你买的。
【妹】（突然扑过来抱住你，把脸埋在你肩膀上）哥...
【哥】（伸手拍拍她的头）怎么还哭了，过生日开心点。
【妹】（声音带着哭腔但笑着）我没哭...
【哥】行了行了，赶紧切蛋糕，草莓味的，你最爱吃的。
【妹】（松开你，擦了擦眼睛，拿起刀切蛋糕，切了一块递给你）第一块给你。
【哥】今天你生日你先吃。
【妹】不要！你给我买了耳机还给我买蛋糕，你先吃！（把蛋糕塞到你手里）
【哥】（接过来咬了一口）好甜。
【妹】（自己也切了一块，吃了一口，嘴角沾了奶油）嗯！好吃！
【哥】（伸手擦掉她嘴角的奶油）吃的满脸都是。
【妹】（脸红了一下，但没躲开）
【哥】（手指上沾了奶油，想找纸巾擦掉）
【妹】（突然伸手握住你的手指，把奶油舔掉了，然后脸通红）
【哥】（愣了一下）你...
【妹】（脸红到耳根，低下头吃蛋糕，不敢看你）...别浪费嘛...
