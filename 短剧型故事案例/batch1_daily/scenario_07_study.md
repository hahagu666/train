# 场景7：深夜刷题
# 地点：妹妹房间→哥哥房间，晚上十一点
# 情境：妹妹在刷数学题，遇到不会的去敲哥哥房门

【妹】（轻轻敲哥哥房门）
【哥】（声音从里面传来）进。
【妹】（推开门探进半个脑袋）哥...你还没睡啊？
【哥】（在看电脑）在看电脑。怎么了？
【妹】（手里拿着练习册走进来，小声）这道题我不会...
【哥】几点了还做题？
【妹】明天要交...（走到你旁边把练习册递过去）你看这个第二问...
【哥】（拉过椅子让她坐旁边）你先给我说说你是怎么想的。
【妹】（凑过来看，头发蹭到你胳膊）我算了半天，这个导数算出来是零，但我觉得不对...
【哥】（看了一眼题目）你求导算错了。这里，你把链式法则用错了。
【妹】（指着题目）哪里哪里？
【哥】这里。应该先对外层求导再乘以内层导数，你搞反了。
【妹】（盯着题目看了几秒）哦...好像是哦。
【哥】你重新算一遍。（把笔递给她）
【妹】（趴在书桌上算，算了一会）...是这样吗？
【哥】（看了一眼）对了。那第二问呢？
【妹】第二问要证这个不等式...（咬着笔帽想了一会）我好像还是不会。
【哥】你试试把第一问的结论用上。
【妹】（眼睛一亮）啊！构造函数？
【哥】自己想。
【妹】（低头又算了一会，突然笑了）啊！我会了！（兴奋地拍了下桌子）
【哥】小声点，隔壁都听见了。
【妹】（捂住嘴，压低声音）我做出来了！
【哥】（接过练习册看了一眼）嗯，对了。
【妹】（开心地晃腿）原来这么简单啊，我刚才想了半小时都没想出来...
【哥】你那是熬夜脑子不转了。赶紧去睡觉。
【妹】（看了一眼时钟，已经十二点了）哦...（收起练习册站起来）谢谢哥。
【哥】明天别熬这么晚。
【妹】（走到门口回头）哥你也早点睡。
【哥】嗯。
【妹】（犹豫了一下，站在门口不走）那个...我能不能在你这再待一会...我房间外面有个虫子一直叫，我害怕...
【哥】（看了她一眼）...你都高三了还怕虫子？
【妹】（站在门口不走）就待一会...
【哥】（叹了口气，把旁边的椅子拉开）坐吧。
【妹】（蹑手蹑脚走过来坐下，安安静静看你对着电脑，不说话了）
