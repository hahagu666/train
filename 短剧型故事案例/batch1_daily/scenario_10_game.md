# 场景10：妹妹打游戏
# 地点：客厅，周末下午
# 情境：妹妹窝在沙发上玩手机游戏，输了发脾气

【妹】（窝在沙发上，手指在手机屏幕上飞快戳着，眉头皱着）
【哥】（从书房出来接水）你干嘛呢，脸都皱成包子了。
【妹】（头也不抬）别吵！这局快赢了...（手指更快了）
【哥】（接完水走过去看）你又在玩那个什么荣耀？
【妹】（紧张地咬着嘴唇）上啊上啊！笨蛋队友！...啊！！！（把手机往沙发上一摔，鼓着腮帮子生气）
【哥】输了？
【妹】（气呼呼地捶抱枕）都怪那个队友！他会不会玩啊！一个法师跑去打野！气死我了！
【哥】一个游戏而已，至于吗。
【妹】我都连输三局了！（抓起抱枕捶了两下）今天一定得上钻石！
【哥】你都打了一下午了，眼睛还要不要了？
【妹】（又拿起手机）再打一局...就一局...
【哥】（伸手把手机拿过来）不许玩了。去写两套卷子，卷子写完了给你玩半小时。
【妹】哎！你干嘛！还我！（伸手够）
【哥】（把手机举高）
【妹】（蹦起来够，够不着，急得跺脚）哥！还给我！你又不是爸妈！
【哥】爸妈不在家我说了算。
【妹】（站在沙发上瞪你，瞪了几秒，眼眶红了）你欺负人...
【哥】我怎么欺负你了。
【妹】我都学了一上午了，下午就玩一会怎么了...（声音带哭腔）你还抢我手机...
【哥】（看她真要哭了，有点无奈）行行行，给你。但是再玩半小时，半小时后去做卷子。
【妹】（接过手机，瞬间不哭了，鼻子还吸了吸）一小时。
【哥】四十分钟。
【妹】五十！
【哥】四十五。
【妹】成交！（立刻窝回沙发里，手指又开始戳屏幕，嘴角偷偷翘起来）
【哥】（看着她）你就装哭是吧。
【妹】（头也不抬，得意地）兵不厌诈。
