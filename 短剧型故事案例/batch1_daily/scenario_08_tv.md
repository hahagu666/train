# 场景8：一起看电视
# 地点：客厅，周末晚上
# 情境：父母出去了，兄妹俩在客厅看电视，妹妹抢遥控器

【妹】（窝在沙发另一头吃薯片）哥你换个台，这个新闻不好看。
【哥】我看着呢，别吵。
【妹】（伸手去抢遥控器）看了一晚上了，让我看会综艺。
【哥】（把遥控器举高）等我看完这段。
【妹】（跪坐在沙发上够）你都看了四十分钟了！
【哥】再等五分钟。
【妹】（整个人扑过来抢，薯片袋掉在沙发上）遥控器给我！
【哥】（一只手接住她防止她摔下去）你小心点！
【妹】（趁机把遥控器抢过去，赶紧换到综艺台，得意地笑）嘿嘿，我的了。
【哥】（看着沙发上的薯片渣）你把薯片弄洒了。
【妹】（低头看了一眼，满不在乎地用手扫到地上）一会再扫。（往你旁边挪了挪，靠在你胳膊上）
【哥】（没动）你靠这么近干什么。
【妹】电视好看啊，凑近点看。（眼睛盯着屏幕笑）你看这个人好傻。
【哥】（看了一眼电视）这有什么好笑的。
【妹】（笑个不停，薯片渣从嘴里掉出来）哈哈你看他的表情...
【哥】你吃慢点，没人跟你抢。
【妹】（递了一片薯片到你嘴边）你吃不吃？番茄味的。
【哥】（张嘴吃了）
【妹】（继续看综艺，时不时笑出声，脚搭在沙发边缘晃来晃去）
【哥】（看了一会）这节目确实有点傻。
【妹】（拍了你胳膊一下）不许说！
【哥】（听到大门钥匙转动的声音）
【妹】（瞬间坐直了，赶紧换台到新闻，把薯片袋藏到靠枕后面）
【妈】（走进来看到他俩）怎么还在看新闻？
【妹】（一本正经）在看时事，学习呢。
【哥】（憋笑憋得肩膀抖）
【妹】（偷偷在背后掐了你一下）
