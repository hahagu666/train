# 场景5：哥哥和女生打电话（吃醋）
# 地点：客厅，晚上
# 情境：哥哥在阳台接了个女生电话，妹妹在客厅看电视但一直在偷听

【哥】（在阳台上打电话，笑声透过没关严的门传进来）嗯嗯，好，下周见。
【妹】（坐在沙发上，电视声音开得很小，耳朵竖着听阳台方向）
【哥】（挂了电话走进来）
【妹】（假装看电视，目不斜视）谁啊？
【哥】一个同事。
【妹】（语气平淡）哦。男的女的？
【哥】女的。怎么了？
【妹】（盯着电视屏幕，但明显没在看）聊得挺开心的。
【哥】工作上的事，说项目方案。
【妹】说方案要笑那么开心吗？（小声嘀咕）
【哥】你说什么？
【妹】（拿起遥控器换台，按得很快）没什么！
【哥】（在沙发另一边坐下来看着她）你是不是不高兴了？
【妹】我为什么要不高兴？（换了一圈台又换回来）你爱跟谁打电话跟谁打。
【哥】真没什么，就是讨论下周开会的事。
【妹】（把遥控器往茶几上一放）哦。
【哥】你生气了？
【妹】没有。
【哥】那你怎么不看电视了？
【妹】不好看。（抱着靠枕缩在沙发角落）
【哥】（伸手想摸她的头）
【妹】（往旁边一躲）别碰我。
【哥】真吃醋了？
【妹】我才没有！（脸鼓起来）我吃什么醋啊，我又不是你什么人...
【哥】你是我妹。
【妹】（眼眶有点红）对，我就是你妹。那你还跟别的女生打电话去吧。（把脸埋进靠枕里）
【哥】（沉默几秒）她下周要离职了，说请大家吃饭。
【妹】（闷闷的声音）关我什么事...
【哥】你要不要一起去？
【妹】（抬起头）我为什么要去？
【哥】你不是不放心吗。
【妹】谁不放心了！（脸通红）我才不要去！你自己去！
【哥】那我不去了。
【妹】...为什么？
【哥】家里有个小醋坛子要翻了，我得在家看着。
【妹】（抓起靠枕砸过去）你才是醋坛子！
