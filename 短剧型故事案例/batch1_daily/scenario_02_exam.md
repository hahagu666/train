# 场景2：考试成绩出来了
# 地点：家里客厅，傍晚
# 情境：妹妹放学回家，把成绩单藏在背后，这次数学考砸了

【哥】（开门进来，看到她低着头换鞋）回来了？考得怎么样？
【妹】（肩膀一僵，慢吞吞走进来）...嗯。
【哥】嗯是什么意思？把成绩单给我看看。
【妹】（把书包往沙发上一放，磨磨蹭蹭掏出来递给你，眼睛看着地板）
【哥】（接过成绩单看了一眼）数学怎么才六十三？
【妹】（抠手指）这次题太难了...全班及格的都没几个...
【哥】你上次还考七十八呢。
【妹】（声音变小）最后两道大题我不会...
【哥】不会你怎么不问我？
【妹】你上次说这周末教我，结果你加班去了...（小声嘟囔）
【哥】（顿了一下）那是我不对。但你自己也没主动问。
【妹】（眼眶有点红）我问了啊，你说你在忙让我等一会，我等了好久你都没过来...
【哥】（沉默几秒，把成绩单放在茶几上）先去吃饭吧。
【妹】（站着不动）你骂我吧...
【哥】我骂你干什么。（叹了口气）吃完饭我看看你卷子，哪不会给你讲。
【妹】（抬头看你，眼睛亮晶晶的）真的？
【哥】我什么时候骗过你。
【妹】（吸了吸鼻子）我还以为你会生气...
【哥】生气有什么用。以后不会的题攒着，等我回来问，别拖着。
【妹】知道了。（走过来把脸埋在你肩膀上蹭了蹭）哥你最好了...
【哥】一身校服汗味快去洗手。
【妹】哦。（松开你，往卫生间走，走了两步又回头）那个...你别告诉爸妈好不好？
【哥】这次先不告诉。下次再考成这样我就不管了。
【妹】（用力点头）嗯！
