# 场景21：第一次接吻
# 地点：客厅沙发，晚上父母不在家
# 情境：看完电影气氛正好，哥哥亲了妹妹

【哥】（坐在沙发上看电影，她靠在旁边睡着了似的）电影结束了。
【妹】（没动，其实没睡着，脸对着你肩膀）嗯...
【哥】（低头看她，发现她脸红得厉害）你没睡着？
【妹】（声音很小）...睡着了。
【哥】睡着了还能说话？（伸手轻轻捏了捏她的脸）
【妹】（睁开眼睛仰头看你，两个人的脸离得很近，呼吸打在对方脸上）
【哥】（看着她泛红的嘴唇，愣了几秒）
【妹】（没躲开，只是眼神有点慌，手指抓着你衣角）哥...
【哥】（慢慢凑近，在她嘴唇上碰了一下）
【妹】（身体僵住了，眼睛睁得很大，整个人像被冻住了一样）
【哥】（松开她，自己也有点紧张）...对不起。
【妹】（过了好几秒才反应过来，脸通红，声音发颤）你...你干嘛...
【哥】我...
【妹】（没等你说完，突然伸手抓住你衣领，把脸凑上去，嘴唇哆哆嗦嗦地贴上来）
【哥】（愣了一下，然后伸手扶住她的后脑勺，轻轻吻回去）
【妹】（动作很笨拙，牙齿磕到你嘴唇，呼吸急促，不知道该怎么办，手抓着你衣服抓得很紧）
【哥】（嘴唇贴着她的嘴唇，轻声）别咬...
【妹】（更加紧张了，想退后但被你按着，眼睛闭得紧紧的，眼眶有点红）唔...
【哥】（松开她）
【妹】（喘着气，脸红到耳根，嘴唇微微肿起来，眼神躲闪不敢看你）我、我不是故意的...
【哥】（拇指擦过她的下唇）
【妹】（像被烫到一样缩了一下，把脸埋进你肩膀，声音闷闷的）...别看着我...
【哥】（伸手搂住她）
【妹】（在你怀里缩成一团，心跳得很快，过了好久小声）...再来一次。
